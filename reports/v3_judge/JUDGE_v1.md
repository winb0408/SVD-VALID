## §1 被证伪的旧判据：n2n（奇/偶不一致度）

### 1.1 旧判据是什么

```
N_rel = mse(p, q) / mse(xo, xe)        全程在 log1p 域，掩膜 = valid_svd
```

`xo/xe` 是把 T=400 帧按**奇帧/偶帧**拆成两卷、各自走完全相同的 SVD 血流带滤波与归一化后得到
的；`p/q` 是把待评估计器作用在这两卷上得到的输出。含义：估计器把"同一位置两次独立采样之间
的随机差异"消掉了多少。旧口径的通过条件是 `N_rel <= (不处理的值)` 且 `core_keep >= 0.95`。

### 1.2 它在什么意义上仍然有效

`N_rel` 是**唯一能量化随机噪声残留**的量，没有替代品。它挡"什么都不做"（=1.0000）和"注噪"
（标定里 α=1.5 时 12.65）都精确可靠（§2.3 C4）。所以本文不是否定它，是把它**降级为三路之一**。

### 1.3 为什么必须废掉它当唯一判据：结构性盲区

`N_rel` 的分子只含 `p−q`。任何对奇偶两卷**相同**的确定性变换 `T` 满足 `T(xo)−T(xe)` 与
`x−x'` 的关系被 `T` 的局部斜率缩放，而一个**常数场**或**整片抬亮**在 `p−q` 里**精确抵消**。
于是：

- 把整幅图糊成灰色 → `p−q` 变小 → `N_rel` **变好**；
- 往全黑背景里加一个常数 → `p−q` 不变 → `N_rel` **纹丝不动**。

这不是阈值没调好，是数学上不含 bias 项。**证伪的测量证据有两条，互相独立：**

**(a) 幻影剂量扫描（§2.3 C1、C2、C3）**：高斯模糊 σ 从 0 加到 3，`N_rel` 从 1.0000 单调降到
0.0770（n2n 认为"越来越好"），同时**真值核心区误差从 0 dB 涨到 +12.50 dB**（真实损伤急剧恶化），
`S_rel` 掉到 0.3719。即 n2n 的排序与真值排序在缺陷类别上是反向的。抬亮扫描里 `N_rel` 恒为
**精确 1.0000**（5 个剂量，一位小数内无变化），而真值暗区误差涨到 +5.46 dB——n2n 对偏置完全
无反应。

**(b) 真实数据读图（L52）**：hsa64 上 ③（SVD+Wiener）在 `N_rel` 上 0.3830 明显优于 ②（=1.0000），
但 MIP 上 core−dark 对比度 −0.36 dB、body−dark −0.75 dB、body 梯度能量 −22%——分数是抹平买来的。
④ 四个种子在两组数据上 dark 能量被抬到输入的 2.7–7.3 倍，`N_rel` 却稳在 0.93–0.96。

**结论**：n2n 从"唯一验收判据"降级为三路判据中的 N 路。**旧口径的判负结论（L51）不因此作废**，
但它的**理由**必须换（见 L52「结论怎么修正」）。

## §2 标定历史（三轮，含两次失败）

标定物：`v3_simulator` 幻影，`shape=(32,64,64)`、`T=400`、`scene_seed=3`、`noise_seed=303`，
真值取 **3 次独立血流实现**的平均（压低真值自身散斑地板）。奇/偶各 T=200，血流带 `[30,175)`。
`valid` 87808 体素；掩膜体素 core 1623 / body 132 / dark 108457 / isolated 138。
剂量扫描的做法与理由见 `scripts/v3_judge_calibration.py` docstring：每道门对应一类**只由它负责**
的缺陷，看它是否单调响应、另两道门是否正确地不响应、真值误差是否朝预期方向走。

### 2.1 运行 0 —— J1.0 的"估计器排序"标定：**失败，作废**

做法：用 7 个估计器对同一个幻影做去噪，比较各自的总 MSE 与 n2n，看判据能否选出真值误差最小的那个。

失败原因（两条，都是构造错误不是调参问题）：

1. **分辨率不够**：幻影里共享静态杂波占误差的绝大部分，各估计器相对真值的**总误差差异只有
   ~0.1 dB**，完全落在真值自身散斑的地板里，排序不可信。
2. **口径错位**：总 MSE 被大片背景主导，**看不出结构破坏**——这正是本项目当初要另设
   core/body/dark 分区指标的原因。用总 MSE 排出来的"最好"是那个把图糊平的。

→ 因此标定方法整体换掉：从"给估计器排序"改为"**受控剂量-响应**"。这是标定方法的变更，不是
判据的变更。

### 2.2 J1.1 的设计与**失败**（3/5）

J1.1 首次提出三路 N/B/S，`B` 按**输入暗区能量**归一，且设**零容忍**（`B_rel <= 1.0`，即
"一点背景都不许添"）。

标定结果 **3/5**，失败原因三条：

| 问题 | 原始数字 | 判定 |
|---|---|---|
| 零容忍连项目自己的参考估计器都过不了 | 温和收缩 w=5 `B_rel=1.0120`；项目原设置 w=7 `1.0146`；阈值虚高×4 `1.0187`；过度平滑 w=13 `1.0325` | 要求本身不可实现 |
| 按输入归一使门槛跨数据集不可比 | 输入背景越脏，"同样的绝对添加"显得越轻 | 设计缺陷 |
| 协议 v1 的统计量在两处扫描上给出无意义读数 | 恒定列上 Spearman `ρ=nan`；0.07 dB 的单调交叉响应上 `ρ=−1.00` | 读数假象 |

`B_rel` 恒略大于 1.0 的机制：`out = mu + b·(x−mu)`，`mu` 是**log 值的局部均值**，在平坦背景上
`E[out] > E[x]`（Jensen），所以"完全不添背景"物理上做不到。→ 零容忍不成立。

### 2.3 协议 v1 → v2 的唯一改动

**只改"用什么统计量衡量敏感性"**：v1 用 Spearman 秩相关，v2 用**扫描首末的响应幅度**
（`span = rows[-1][field] − rows[0][field]`）。理由即上表第三行：秩相关在两处给出 nan 与
−1.00 的假象，而敏感性本就该按幅度衡量。**门槛、剂量、幻影、判据定义都没动。**

## §3 门槛锁定与推导（全部在跑之前写死）

| 门 | 锁定值 | 推导 | 是否从标定里取数 |
|---|---|---|---|
| N | `N_rel <= 0.5` | 含义定死："奇/偶不一致度必须至少砍半"。不处理 = 1.0000 | 否 |
| S | `S_rel >= 0.95` | **直接沿用**项目已预注册的 `THR_CORE = 0.95`，不新造数字 | 否 |
| B | `B_db <= −7.3 dB` | 幻影上**真值误差最小**的估计器（w=7，真值 all −0.007 dB）实测 `B_db = −10.28`；加**事先声明的 3 dB 松弛**（估计器尺度常数 `s` 与掩膜边界的量级）得 −7.28，取一位小数 −7.3 | **是，唯一一处** |

- **为什么给 3 dB 松弛**：门槛卡在参考估计器自己的读数上，等于要求任何候选都不许比 w=7 差
  一丁点，会把正常的方法间差异判成失败。3 dB 是"已知良好估计器两侧留余量"的事先声明。
- **−7.28 → −7.3 的影响**：事后核对过，幻影阶梯与本项目全部真实数据行里**没有任何一行的 `B_db`
  落在 (−7.30, −7.28]**，取整不改变任何一项判定。
- **三路同时满足**才算通过。**不设加权总分**——系数一旦可调就给了事后挪门槛的空间
  （L51 已因"事后挪门槛"退回过一次结论）。
- **不得做的**：事后改门槛、换秩带、挑种子重报。任一出现，本次标定作废，须重跑整套 C1–C5。

## §4 J1.2 的定义（实现见 `scripts/v3_judge.py`，本文不重复代码）

```
N_rel  = mse(p,q,valid) / mse(xo,xe,valid)
B_frac = b_dark(p,q,dark∩valid) / mean_core((p²+q²)/2)
         b_dark(a,b) = mean_dark((a²+b²)/2) − ½mean_dark((a−b)²)      # 消去 var，只剩 bias²
S_rel  = mean_core(p) / mean_core(xo)                                # 与 keep_ratio 逐字同一实现
pass   = (N_rel<=0.5) ∧ (S_rel>=0.95) ∧ (10log10 B_frac <= −7.3)
```

掩膜常数：`CORE_THR=0.65, BODY_LO=0.20, DARK_THR=0.05, BLOB_THR=0.5, BLOB_MAX_VOX=27`，
建在 `to_unit(0.5*(xo+xe))` 的 MIP 上（只用奇偶均值，不泄漏待评输出）。

## §6 已知局限（必须与任何引用本判据的结论并列写出）

1. **三道门是必要条件，不是充分条件**。全过只说明"没犯这三类错"，**不证明去噪变好**。
2. **B 只在"暗区真值为 0"的先验下成立**。真实数据无真值，该先验依据是 Power Doppler 的物理
   语义 + 掩膜低参考档（`DARK_THR=0.05`，未另调）。若暗区真有低速血流，B 会误判。
3. **亮区内部的过冲测不到**（把血管增强到超真值）。亮区无先验，三路都看不见。
4. **不设加权总分**，见 §3 理由。
5. **N 的门槛 0.5 是含义而非标定值**。若将来出现"确实只砍掉 40% 噪声但结构完好"的方法，
   它会被判负——这是有意的保守选择，改它需要重新走 §0.5 全流程。

## §7 通俗总结

**这一步到底证明了什么。** 我们以前用的那个评分，本质上是拿同一次拍摄的两半互相比，看处理
完之后两半还剩多少差别。这个办法只能看见"随机抖动"，看不见"整片被抹平"或者"整片被提亮"——
因为抹平和提亮对两半是一模一样的，一比就被消掉了。所以我们加了两把尺子：一把专门看"该黑的
地方有没有变亮"，一把专门看"血管该在的地方有没有被削薄"。为了确认这两把新尺子真管用，我们
造了一个**知道标准答案的假数据**，故意往里加三种毛病——模糊、提亮、加噪声——每种加五档，看
对应的尺子会不会跟着动、另外两把会不会瞎动。结果是：加模糊时新的"结构"尺子一路掉、旧的评分
反而一路涨（同时与标准答案的差距从小变大，涨了十二倍半）；加提亮时"背景"尺子从头到尾涨了
三点四倍，而旧评分**一动都不动**；加噪声时旧评分涨了十二倍多，"背景"尺子几乎没反应。三把尺子
各管各的，互不干扰，加上"什么都不做"和"已知般配的两个参数"在阶梯上判定正确，五项预设检查全过。

**对项目主张意味着什么。** 第一，我们现在有资格说"某条链没通过"了——以前那句话是靠旧评分
说的，而旧评分会把"糊成一片"判成优等，理由站不住。第二，换成新尺子重判之后，结论**没变**：
网络在真实数据上仍然没过。但理由变硬了，也更难听：网络几乎什么都没做（旧评分只降了百分之
三到七），同时在第一份数据上往本该死黑的背景里添了东西，并且八个组合里有五个把血管削薄到
不达标线以下。第三，一个之前被掩盖的事实浮出来了：那个不用训练的小滤波在第二份数据上自己
也削薄了血管，所以"网络输给了小滤波"这个说法要收回——小滤波在那份数据上的高分是抹平买来的。

**哪些话现在不能说。** 不能说"新判据证明方法有效"——它只能抓三类错，抓不到"血管被增强过头"，
三道全过也不等于去噪变好。不能说"背景里添东西一定错"——这个判断依赖"背景本该全黑"的前提，
真实数据没有标准答案，只有物理常识撑着。不能说"门槛还可以再松一点"——门槛是在看结果之前
写死的，唯一一个从假数据里取的数还带着事前声明过的三格余量。更不能因为新判据把旧结论的理由
换掉了，就顺带把结论本身也改掉——结论还是没过。
