# R12：微血管图像质量判据 —— 设计、已知答案标定、以及三个被标定否掉的端点

**日期**：2026-10-27　**判据版本**：`R12-v1`　**代码**：`scripts/v3_eval_microvessel.py`
**原始 JSON**：`reports/v3_R12/microvessel.json`（标定结果 + 每卷全部端点）

本文只做一件事：**把"弱血管有没有被压掉"变成一个不会被平凡解骗到的数字**。它不评价任何方法——
目前还没有方法被这套判据判过。

---

## 1. 为什么旧的判据不能用来判实验 C（旧判据的证伪记录）

现有 `scripts/eval_structure.py` 的分区**用输入自己定义**（`input >= 0.65` 叫 core、
`input <= 0.05` 叫 dark、"保住了多少"是 `mean(out)/mean(in)`）。三条硬伤：

1. **把观测当参考**。输入自己带晕和散斑，"core" 区里既有真血管也有噪声峰；"保住了 core"
   也可能是"保住了噪声"。
2. **结构上看不见弱血管**。弱血管在输入上不亮，淹在 `0.2 <= input < 0.65` 的 body 桶里，
   和血管旁的晕混在一起，无法回答"弱血管被压掉多少"。
3. **在 v1 仿真上完全退化**：v1 真值掩膜外恒 0，`(0,1)` 区间体素数为 **0**，弱血管区是空集。
   这不是门槛问题（v2 已修，占比 0.0203 / 0.0157）。

所以新判据的区域**全部由真值 `rho` 划分**，一个观测量都不碰。

## 2. 区域与端点

| 区域 | 定义 | 含义 |
|---|---|---|
| `deep` | `rho >= 0.9` | 粗血管核心 |
| `core` | `rho >= 0.5` | 血管主体 |
| `weak` | `0.1 <= rho < 0.5` | **弱血管 / 血管边缘**，本判据的主角 |
| `bg` | `rho <= 0` | 真背景 |

| 端点 | 定义 | 角色 |
|---|---|---|
| `r_weak` | `weak` 区 pred vs 真值的 Pearson | **主判据** |
| `r_core` / `r_deep` / `r_all` | 同式换区域 | 辅 |
| `recall@fpr5`、`auc_weak`、`auc_core`、`iou_core`、`ncomp_ratio`、`cnr_weak_db` | 见代码 | **仅描述，不作判据**（理由见 §4） |
| `width`（血管宽度/直径） | — | **撤除，不计算**（理由见 §5） |

常数输出（方差为 0）的相关系数**记 0.0 而不是 `nan`**：常数输出不含任何结构信息，
排序上必须落在最差端，记 `nan` 会让它从比较里消失。

## 3. 已知答案标定（`--calibrate`，两个评估卷全跑）

四个已知答案：`truth`（完美答案）、`input`（什么都不做）、`zero`（最强平凡解）、
`oracle_lowpass`（只按标定 PSF 糊一下）。

| 卷 | 臂 | `r_all` | `r_deep` | `r_core` | `r_weak` | `auc_weak` | `recall@fpr5` | `iou_core` |
|---|---|---|---|---|---|---|---|---|
| s30 | **truth** | 1.0000 | 1.0000 | 1.0000 | **1.0000** | 0.9646 | 0.7448 | 0.0499 |
| s30 | input | 0.9854 | 0.9179 | 0.8096 | **0.7916** | 0.9731 | 0.8258 | 0.0645 |
| s30 | zero | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0.5000 | 0.0000 | 0.0045 |
| s30 | oracle_lowpass | 0.9013 | 0.7579 | 0.5016 | **0.4747** | 0.9538 | 0.7264 | 0.0885 |
| s31 | **truth** | 1.0000 | 1.0000 | 1.0000 | **1.0000** | 0.9578 | 0.6384 | 0.0190 |
| s31 | input | 0.9867 | 0.9360 | 0.8640 | **0.7878** | 0.9647 | 0.7280 | 0.0258 |
| s31 | zero | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0.5000 | 0.0000 | 0.0049 |
| s31 | oracle_lowpass | 0.8942 | 0.6543 | 0.4182 | **0.3490** | 0.9675 | 0.7822 | 0.1306 |

**通过的检查**（两卷都通过，`all_pass=True`）：

- `r_weak(truth) = 1.0`，且 **真值 1.0 > 输入 0.79 > 纯低通 0.35–0.47 > 常数 0.0**，四档严格单调；
- `r_core(truth) = r_deep(truth) = 1.0`；
- 常数输出落在 0.0（不是 `nan`）。

**`r_weak` 为什么是一个良定义的判据**：`input = truth + 与真值无关的噪声`，所以
`r = σ_truth / sqrt(σ_truth² + σ_noise²)`——**去噪会把它推高，把弱血管糊掉会把它压低**，
两端都被钉住（上界 1.0 = 不动结构只去噪，下界 = 常数 0.0）。这是一个真正的"弱血管保真度"标尺，
不是"和输入越像越好"。

## 4. 三个被标定**否掉**的端点（这是本文最重要的结果）

| 端点 | 无噪真值 | 含噪输入 | 结论 |
|---|---|---|---|
| `recall@fpr5` | 0.7448 / 0.6384 | **0.8258 / 0.7280** | 真值**输给**输入 |
| `auc_weak` | 0.9646 / 0.9578 | **0.9731 / 0.9647**（低通 0.9538 / **0.9675**） | 真值**输给**输入，s31 上还输给低通 |
| `iou_core`（取前 `|core|` 个最亮体素） | 0.0499 / 0.0190 | 0.0645 / 0.0258 | 真值与 `core` 几乎不重合 |
| `ncomp_ratio` | 21/20 分量 | 同量级 | 没有分辨力 |
| `cnr_weak_db` | 8.42 | 9.52 / 9.31 | 真值更低 |

**根因（一条，可量化）**：v2 的真值**没有"血管 vs 背景"的体素级可分性**。PSF σ=(3.0, 2.37, 3.97)
体素 vs 血管半径 ~1.1 体素、对比度按 6 dB 定标，结果是背景被晕填满：
`truth` 在 `rho<=0` 的背景上中位数 **0.307**、最大值 **2.12**，而 `core` 中位数只有 **1.59**
（都在 `log1p` 域）。背景下限和血管中位数是**同一量级且重叠**，于是任何逐体素阈值判据
（recall / AUC / IoU / 连通性 / CNR）都无法把两者分开——这不是门槛选错，是**信息不在**。

这三个端点在 JSON 里显式带 `diagnostics_monotone: false`，**永不作判据**。标定脚本本身把这件
事写成了必须满足的反向检查（`falsified_recall_not_monotone` 等），这样将来若有人"修"得让真值
重新赢过输入，脚本会**立刻报错**，提醒重新审视数据生成而不是直接采信。

## 4.1 补上审查意见点名的 PSNR / SSIM（并说明它们为什么同样只作描述）

审查原文要求"PSNR、SSIM、弱血管 Recall@固定 FPR、中心线与分支、宽度误差、虚假血管"。本轮补齐
PSNR / SSIM（`data_range` = 真值在 valid 区的极差，逐体冻结并在 JSON 里记录）：

| 卷 / 答案 | PSNR (dB) | SSIM |
|---|---|---|
| s30 输入 / 纯低通 / 全零 | **11.48** / 11.10 / 10.87 | **0.4212** / 0.2651 / 0.2821 |
| s31 输入 / 纯低通 / 全零 | **12.16** / 11.68 / 11.57 | 0.3202 / 0.2102 / **0.3877** |

- **PSNR** 在两个体上恰好按"输入 > 纯低通 > 全零"排序，但它是 RMSE 的单调函数，而 RMSE 类端点
  已被 R06 证伪（v1 仿真里全零输出能拿最好的 RMSE），所以只作描述性记录，标在 JSON 的
  `psnr_ssim_role` 字段里；
- **SSIM 在 s31 上退化**：全零输出的 SSIM（0.3877）**高于**真输入（0.3202）——SSIM 奖励平滑。
  这一条已写成反向检查 `falsified_ssim_zero_beats_input`。标定框架相应改造：单调性检查要求
  **每个体都过**；"反标定"检查只要求**至少一个体**出现退化，并把结果聚合成
  `falsified_anywhere`（当前 4 条全为 True，`all_pass=True`）。

## 5. 撤除的端点：血管宽度/直径

成像后的半高宽由 PSF 决定（σ 3–4 体素），不是由血管决定（半径 ~1.1 体素）。任何方法测出来的宽度
都≈PSF 宽度，"宽度"对方法**不敏感**，做了只会制造假结论。按 Plan §0.5 记录为**撤除**，
JSON 里 `width` 字段写 `"not_computed"` 并附原因，而非留空。

## 6. 对实验 C 的影响

- **实验 C 的主终点可以定为 `r_weak`**（辅：`r_core`/`r_deep`），门槛"优于输入本身的 `r_weak`"，
  与实验 A 的 `r_roi` 同一分母口径、同一推理 API。
- **审查原文要求的 `recall@FPR` 在本数据上不可实现**，已用"真值自己都过不了"证明。若将来确实需要
  检测类端点，需要的是一次**数据集版本升级**（提高对比度定标，或缩小 PSF / 加粗血管），
  并且必须**先写新版本的预注册与标定**，不能就地调门槛。此项列入剩余风险，不在本阶段做。

## 7. 通俗总结

**这一步证明的是"尺子坏了"这件事本身能被发现。** 外部审查建议用"弱血管检出率"当主判据。
我按标准做法先给这把尺子做体检：拿一个"标准答案"（真值本身）去量，它应该拿满分。
结果**标准答案只得了 0.74，而"什么都不做"得了 0.83**——尺子量错了，不是答案错了。
顺手查了另外四把尺子（AUC、重合度、连通性、对比度噪声比），**同样量反了**。

**为什么量反了。** 这个仿真里的"血管"只有 1 个体素粗，而模糊核有 3–4 体素宽，两相叠加，
血管的亮被摊得到处都是：背景里的亮度中位数已经和血管里的中位数是同一量级。既然血管和背景
在数值上本来就分不开，那"按亮度划一条线数血管"当然谁都能刷分——噪声抖一抖就能让数字更好看。

**那还剩什么可用的。** 还有一把尺子通过了体检，而且方向正确：看"预测里弱血管的明暗起伏，
跟真值的起伏像不像"（相关系数）。标准答案 1.0、什么都不做 0.79、只做模糊 0.35、全抹平 0.0——
四档严格单调。它的含义也干净：去噪会把它推高，把细血管糊掉会把它压低。

**哪些话现在不能说。** 不能说"我们的方法在弱血管检出率上提高了"（这个指标在本数据上不成立）；
不能说"审查建议的判据不合适"（只是**这个仿真器**支撑不起逐体素的检测指标，真实数据上未必）；
也不能说"仿真器已经足够真实"——真值背景被晕填满到和血管同量级，这一点与真实 Power Doppler 的
观感是否一致，**尚未核验**。
