## 1. 旧口径错在哪（审查 R3-P01）

v1 估计"扣掉共同信号后两次观测还剩多少相关"用的是

```
r_A = log PD(g0) − log PD(g2+g3)
r_B = log PD(g1) − log PD(g2+g3)
Corr(r_A, r_B)
```

两个残差**共用同一个参考** `log PD(g2+g3)`，而这个参考本身是**有噪**估计。设单块（100 帧）噪声方差为 `v`，
`g2+g3` 是 200 帧，方差 `v/2`，则

```
Var(r_A) = Var(r_B) = v + v/2
Cov(r_A, r_B) = Var(参考噪声) = v/2
⇒ Corr = (v/2)/(v + v/2) = 1/3        ← 即使两路噪声完全独立
```

**v1 实测 0.357（SA64）/ 0.374（HSA64）≈ 1/3**，所以旧读数**不能**被解释为"有 36% 的真实噪声相关"。
这不是数据的问题，是统计量本身在独立噪声下就有 1/3 的基线。

单测把这个反例钉住（`tests/test_v3_round3_noise_covariance.py`，8 项）：

- 200 帧参考 vs 100 帧观测 ⇒ 1/3；
- 等长参考 ⇒ 1/2；
- 解析值 `v_S/(v_A+v_S)` 与仿真一致；
- 互不共享参考 ⇒ 0；
- 互不共享参考下**仍能**检出真实的共同成分（解析值 ≈0.111）；
- 伪像与信号强弱无关；
- 端到端（走真实的 `block_pd` + SVD 固定基）复现同一数值；
- 统计量对符号/尺度不变。

## 2. 新口径：互不共享参考

```
r_A = log PD(g0) − log PD(g2)
r_B = log PD(g1) − log PD(g3)
```

四个 100 帧块两两不共享帧，参考也互不共享 ⇒ **独立噪声下期望相关 = 0**。
块角色的六种置换给出统计量自身的波动（这些不是零假设的置换检验，而是"谁当观测、谁当参考"的稳定性检查）。

| 数据集 | 共用参考（旧口径） | 独立噪声基线 | 非共享参考（新口径） | 块角色置换区间 | 血管区（新口径） |
|---|---|---|---|---|---|
| SA64 | 0.3569 | 0.3333 | **0.0173** | 0.0173 – 0.0263 | 0.2440 |
| HSA64 | 0.3743 | 0.3333 | **0.0355** | 0.0355 – 0.0552 | 0.2130 |

判读（`G-R0-d`，**不设过门**，它是更正项）：

- 背景区从 0.357/0.374 掉到 **0.017/0.036** ⇒ 旧读数的绝大部分是**参考伪像**。
- 剩余 0.017–0.036 高于 0 但很小，且**不能**归因为"噪声相关"：共用 SVD 固定基、时间漂移、log 非线性都会贡献一点。
- 血管区仍有 0.21–0.24 的相关，但那**是血流信号**，不是噪声 —— 血管区本来就不该拿来做 N2N 可行性判断。
- 因此：**配对能不能当 N2N** 这个问题，在背景区现在的答案是"残差相关 ≈ 2%–4%，量级上可接受"，而不是 v1 暗示的"36% 相关，配对不可用"。

`gate_r0_{dataset}.json` 里 `G_R0_d.verdict = artifact_dominated`（分界带：<0.15 判伪像主导、>0.30 判数据主导，**写在新数值之前**）。

## 3. 这条更正改变了什么、没改变什么

**改变了**：v1 里"残差相关 0.36 ⇒ 真实噪声相关约 36%"这个读法作废。任何后续文档引用 0.357/0.374 时必须同时写出"旧口径，含 1/3 的共用参考伪像"。

**没改变**：

- `G-R0-a`（时间/空间两个代理在**同一噪声场**上一致，比值 0.862/0.858）：pass，与本次更正无关。
- `G-R0-c`（奇偶拆分 vs 连续拆分的读数差异，背景差 0.041/0.048、血管差 0.218/0.191）：pass —— 说明"配对方式本身是主导因素之一"，**不存在唯一可用的伪配对**。这条现在更重要，因为新口径同样是一种特定的配对方式。
- 配对残差相关**小**不等于"配对就是 N2N"：两路观测仍共享同一份静态散斑与血管；N2N 的合法性还依赖网络看到的噪声是否与目标噪声独立。这一点在 A/B 阶段用训练本身检验。

## 4. 限制

1. SA64 与 HSA64 是两次**不同发射协议**的成像，不是独立生物重复；所有"跨数据集一致"只能当外部一致性证据。
2. 四个 100 帧块来自同一次采集，共用同一套 SVD 固定基（官方口径 [59,350) 与 [29,175)）。基是全局的，块间残差因此仍有共同成分，这部分无法用分块消除。
3. 只测了背景体素（PD ≤ q20）与血管体素（PD ≥ q99）两端，中间过渡区没单独报。
4. 块角色置换只做了 6 种（`(0,1,2,3)` 及其有意义的变体），不是全排列；区间应读作"同量级波动"而不是置信区间。

## 5. 通俗总结

上一轮我们算了一个数：把一段采集拆成两半，各自扣掉"共同信号"之后，剩下那部分有多像。算出来约 36%，当时读作"这两半的噪声有 36% 是相关的，所以拿它们互相做训练目标会学歪"。

外部审阅指出：那个 36% 不是从数据里来的，而是**算法自己制造的**。因为两半扣掉的是同一个东西，而这个东西本身也有噪声 —— 好比两个人各自减去同一个粗略的"平均值"，减完之后剩下的误差自然会长得像。数学上，当两半的噪声完全独立时，这种算法**恰好**给出约 33%。我们实测 35.7% 和 37.4%，说明几乎全部是这种假象。

改用"各扣各的、互不共用"的算法之后，同一个数据只有 **1.7%–3.6%**。这说明真实数据里两半之间确实还有一点共同的残余，但量级很小，跟之前说的"36% 相关"完全是两回事。

现在可以说的：旧的那个悲观读法不成立了，用配对做训练目标在统计上没有被判死刑。
现在还不能说的：配对就一定能当训练目标 —— 那要看训练本身（A/B 阶段），不是统计能替代的。
