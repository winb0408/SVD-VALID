# R08：把三个常被混为一谈的说法拆开——仿真泛化 / 真实可训练性 / 零样本迁移

日期：2026-10-27。审查意见（R08）原文要求：「区分仿真泛化 / 真实可训练性 / 零样本迁移」。

本文件先给三个**互不蕴含**的操作定义与各自的检验方式，再把仓库里已有的证据按这三格分开摆，
最后明确写出哪一格现在是空的（写"未运行"，不猜）。

---

## 1. 三个说法，三套检验

| 说法 | 精确含义 | 需要的检验 | 判据（谁能回答它） |
|---|---|---|---|
| **C1 仿真泛化** | 在**仿真**上训练的网络，迁移到**未见过的仿真**解剖/噪声实现上仍然有效 | 训练体与评估体**场景互斥**；评估体另有独立第二观测 | `n2n_ratio`（不需真值）+ `r_roi`（需真值） |
| **C2 真实可训练性** | 在**真实**采集上训练的网络，能在**同一批真实数据**上学到东西 | 真实数据的**成对观测**（独立重复采集或奇偶拆半）+ 留出区；只有 `n2n_ratio` 可用（**无真值**） | `n2n_ratio` + 背景/血管区的分布位移；**不能用** `r_roi` |
| **C3 零样本迁移** | 仿真训练的网络**不微调**直接用在真实数据上有效 | 真实数据上的 `n2n_ratio` 与结构代理，与最强传统对照（Wiener）比 | 同 C2 的判据，但训练集是仿真 |

三者互不蕴含：C3 失败**不能**推出 C1 失败（域偏移可以单独致命）；C1 成功**不能**推出 C2 成功
（真实噪声的成对结构可能根本不可学）；C2 成功也**不能**推出 C3 成功（仿真与真实的噪声统计不同）。
这也是本项目此前最容易犯的偷换——把"仿真上不行"和"真实上不行"当同一句话。

## 2. 已有证据按三格分开摆

### 2.1 C1 仿真泛化：**已测到"失败"，且失败方式是"记忆"**

| 证据 | 数字 | 位置 |
|---|---|---|
| 单场景训练 600 epoch，在**训练用的那个目标**上比值 | **0.063**（远低于物理下限 0.615 = 记住了那一次噪声实现） | `phase4_report.md` §5.6.2 |
| 同一份预测换到**未见过**的同场景实现（n102/n103/n201） | 0.991 / 0.831 / 0.869 — **回到"没学到"的水平** | 同上 |
| faithful VALID 重训（实验 A 阶段 1，单体 v1 数据） | 见 `reports/v3_expA/expA_report.md`；阶段 2（16 体、未见过解剖）在跑 | — |

**结论（C1）**：以"同一场景 + 换噪声实现"为检验，网络学到的是**该实现自己的噪声**，不是可迁移的
去噪算子；"训练损失下降"在这里**不是进步的证据**。跨**解剖**的仿真泛化由实验 A 阶段 2 回答，
在结果落地前写**未定**。

### 2.2 C2 真实可训练性：**未运行**（这一格是空的，必须承认）

仓库里**没有**任何"用真实数据训练"的 run。已有的真实数据工作全部属于 C3（零样本）或纯 SVD 后处理。
若要补上，最小可行设计（**未执行**）：

- 配对来源：真实 SA64/HSA64 的**奇/偶帧拆半**（`build_crossfit_pairs.py` 已有交错划分与无帧泄漏断言）；
  这是"同一场景、两套独立散斑实现"的真实版本，前提是奇偶半卷的静态杂波相关足够低——
  **而这一条已被实测否掉**：`corr_odd_even` 在 SA64 上是 **0.9217**、HSA64 是 **0.9926**
  （`reports/v3_phase5_real/{SA64,HSA64}_network.json`）。奇偶半卷的噪声几乎完全相关，
  按 Noise2Noise 的教义它们**不是**两个独立观测。
- 因此 C2 若要可判，需要的是**真正的重复采集**（同一 ROI 两次采集），当前数据里没有；
  这一点是数据缺口，不是方法缺口。

**结论（C2）**：**未运行，且在现有数据上不可判**——因为唯一可用的"成对"构造（奇偶拆半）实测相关性
0.92/0.99，不满足自监督配对的前提。任何声称"真实数据上可训练/不可训练"的说法目前都没有依据。

### 2.3 C3 零样本迁移：**已测，失败**（这一格有最清楚的数字）

`reports/v3_phase5_real/{SA64,HSA64}_network.json`（协议：checkpoint 只在仿真 seed2–4 训练，
**从未见过真实数据**）：

| 数据 | 不处理 | ①Wiener w=7 | ④SVD+网络（4 seeds） |
|---|---|---|---|
| SA64 `n2n_ratio` | 1.000 | **0.273** | 0.961 / 0.944 / 0.954 / 0.955 |
| HSA64 `n2n_ratio` | 1.000 | **0.383** | 0.957 / 0.931 / 0.965 / 0.949 |
| SA64 `corr_odd_even` | 0.9217 | **0.9756** | 0.9386 / 0.9227 / 0.9290 / 0.9136 |
| HSA64 `corr_odd_even` | 0.9926 | **0.9968** | 0.9880 / 0.9902 / 0.9926 / 0.9915 |

**结论（C3）**：零样本迁移**失败**——网络只把 `n2n_ratio` 从 1.00 压到 0.94–0.96（几乎没压），
而 Wiener 能压到 0.27–0.38；结构侧 `corr_odd_even` 也没有超过输入。
**但这条只否定 C3，不能用来否定 C1/C2**，也不能说明"网络本身学不会去噪"——它对仿真数据是学了东西的
（哪怕学的是记忆），问题出在**域**与**任务定义**上。

## 3. 三条边界（写成表格，防止再被混引）

| 想说的话 | 现在能不能说 | 为什么 |
|---|---|---|
| "网络在仿真上学会了去噪" | **不能**（C1 的部分证据表明是记忆） | 0.063 vs 未见过实现 0.83–0.99 |
| "网络在真实数据上学不会" | **不能**（C2 未运行、且数据不满足前提） | 奇偶拆半相关 0.92/0.99，不是独立观测 |
| "仿真训练的网络不能直接用于真实数据" | **能**（C3 已测，且与最强传统对照差距明显） | 0.94–0.96 vs Wiener 0.27–0.38 |
| "所以 VALID 的自监督教义是错的" | **不能** | C3 失败可以由域偏移解释；R11 还给了另一半原因（相邻像素噪声相关 0.90–0.95） |
| "真实数据上还有一种没试过的做法" | **能**（需真正的重复采集） | 见 §2.2 的数据缺口 |

## 4. 通俗总结

**这一步到底证明了什么。** 审查方要我把三句话拆开，因为它们经常被当成一句话来讲：
"网络在仿真上没学会"、"网络在真实学不到"、"仿真训练的模型直接拿去用在真实上不行"。
拆开之后结论很不一样：**第三句有确凿数字，是真不行**——直接拿去用，噪声只压掉 4%–6%，
而一个最普通的传统滤波能压掉 63%–73%。**第一句只测了一半**：我们确实抓到过一个很难看的现象，
网络在训练过的那一次数据上分数好得不可能（比理论下限还好），换一次没见过的噪声立刻打回原形，
说明它记住的是那一次的噪声花纹。**第二句根本没法回答**——因为要用真实数据训练就得有两份独立的观测，
而我们手上唯一的做法是把奇偶帧拆两半分用，实测这两半的相关性是 0.92–0.99，几乎就是同一份数据，
拿到手的只会是"自己预测自己"。

**对项目主张意味着什么。** 意味着不能再用"真实数据上学不到"来给任何结论垫背——那句话没有证据，
而且当前数据也不支持去测它。真要做，缺的是**同一位置采两次**的数据，这是采集问题不是算法问题。
反过来，"仿真训练的模型不能直接用"这条已经有数字了，而且它**不否定**方法路线，
只是把问题定位到"仿真与真实的噪声统计不同"，这与我们在 R06/R11 里量到的相关性差异（仿真 0.93、
真实 0.90–0.95 的两视图相关）是同一件事。

**哪些话现在不能说。** 不能说"真实数据上不可训练"（未跑、且数据不满足前提）；
不能说"网络学不到任何东西"（在仿真上它学到了明确的东西，只是那东西不可迁移）；
不能把 C3 的失败当作对 VALID 教义的否证；也不能把 Wiener 的 0.27 当作"我们已经有好方法"——
Wiener 的 0.27 是**在噪比意义上**压得狠，它压掉噪声的同时也压掉了血管（`r_roi` 已降到 0.79 左右，
见 R12 的标定表），所以它不是"更好"，只是"更狠"。

**剩余风险**：① C1 的跨解剖证据要等实验 A 阶段 2；② 若将来真的做了重复采集，`n2n_ratio` 的分母
（两次观测的真实独立性）仍需先标定，否则比值不可解读；③ 本文件没有引入任何新实验，
它只是把已有数字按三个说法重新归位——**归位本身不产生新证据**。
