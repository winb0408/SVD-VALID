## 0. 一句话结论

审查说"仿真器的血流项不是血管密度卷积 PSF"，**核实成立，而且比审查说的更严重**：
本仿真的"无噪成像真值"在血管掩膜**之外恒等于 0**、血管掩膜本身**最薄到没有内部体素**，
PSF 只作用在散斑场、**从不把血管变宽**。直接后果有两条：①**"输出全零"这个退化解在全局
RMSE 上就能拿到 0.108（输入是 0.706）**，所以拿"RMSE vs 真值"当去噪判据是无效的；
②**本仿真无法检验亚分辨（微血管）恢复能力**，而微血管正是本项目的主张所在。

## 1. 显式前向模型（逐项可核对）

脚本 `scripts/v3_simulator.py` 生成的复数 IQ 体积为

```
X(z,y,x,t) = static(z,y,x) · u_static(t)                 # 固定散斑 × 慢时间起伏
           + dynamic_t(z,y,x)          ~ CN(0, psf_sigma) # 逐帧独立散斑
           + Σ_{r=1..6} c_r(z,y,x)·g_r(t)                 # 残余杂波（空间大尺度 × 低频时间）
           + flow_t(z,y,x) = G_t(z,y,x) · vessels(z,y,x)   # 血流：PSF 相关散斑 **乘以二值掩膜**
           + thermal_t(z,y,x)          ~ CN(0, thermal_sigma)

PD_obs  = Σ_t |B{X}_t|² / median(PD_obs[valid])
PD_true = Σ_t |B{flow}_t|² / median(PD_obs[valid])        # 只对血流项用同一条带通
B = 官方带通 SVD（1-based 60:350 → 0-based [59,350) = 291 个模式）
```

| 项 | 代码位置 |
|---|---|
| static | `scripts/v3_simulator.py:150` |
| dynamic / thermal | `scripts/v3_simulator.py:153-155` |
| clutter（rank 6） | `scripts/v3_simulator.py:157-163` |
| flow | `scripts/v3_simulator.py:171-175` ← **`gauss_field(psf) * vessels`** |
| 带通 | `scripts/official_pipeline.py:55` `svd_blood_band(x, 60, 350, faithful=True)` |
| PD | `scripts/v3_simulator.py:200` `band_and_pd` |

**与真实成像链的差别（这是审查的要害，逐条列出）**

1. **血流是"PSF 相关散斑 × 硬二值掩膜"**，不是"血管密度（部分容积加权）卷积 PSF"。
   卷积发生在散斑场上，**掩膜的支撑集原封不动**，所以血管不会被 PSF 展宽。
2. 血流没有**体素内速度分布**，因此没有谱展宽（真实 PD 的血管内频谱有宽度）。
3. 血管内没有**旁瓣/杂波耦合**，真实数据里血管附近总有一圈杂波晕。

## 2. 三类真值分离（数值核验）

| 记号 | 定义 | 实测 |
|---|---|---|
| **T1 几何真值** | `vessels`（14 根管，cfg `vessel_radius=1.1`） | 1891 / 143360 体素 = **1.32%** |
| **T2 无噪成像真值** | `gt_flow_pd` = 只对血流项做同一条带通的 PD | 血管内 log1p 均值 **0.8918**；**血管外最大值 = 0.0000** |
| **T3 有噪观测** | `pd_linear` = 对全部项做同一条带通的 PD | 血管内 log1p 均值 **2.1968**，背景 **0.6928** |

**关键读数**：`gt_max_outside_vessels = 0.0000`，`bg_std_truth = 0.0000`。
也就是说 **T2 与 T1 的支撑集完全相同**，T2 在掩膜外是**精确的常数 0**。

### 2.1 这条事实的第一个后果：所有 RMSE 型指标都是退化判据

| 输出 | 全局 RMSE（valid，log1p） | 血管内 RMSE |
|---|---|---|
| 输入（什么都不做） | 0.7057 | 0.979 |
| **全零输出** | **0.1082** | **0.571** |
| 最好的网络臂（见实验 A） | 0.691 | 0.751 |

全零输出比输入**好 6.5 倍**，而且在**血管内**也比任何一条真实训练出来的臂更好。
原因是真值**处处比观测暗得多**：背景精确为 0（输入是 `log1p(1) ≈ 0.693`），血管内真值 0.89
而观测 2.20。于是"把输出整体往 0 缩"同时改善背景与血管两处的 RMSE。

**这条结论本身也被证伪过一次，记录在此**：我先写下"改用血管内 RMSE（`rmse_ves`）作主判据，
因为真值在血管内非零"，随后用 `zero` 基线一算——它的血管内 RMSE 是 0.571，**比所有臂都好**，
于是该判据同样退化。可见"真值非零"不足以保证 RMSE 判据可用；**只要真值的动态范围
系统性低于观测，收缩就总是能降低 RMSE**。

按方案 §0.5（新判据要有：旧判据的证伪记录 + 已知答案校准 + 先写门槛），本报告据此证伪
**全部 RMSE 型判据**（全局与血管内），实验 A 改用两个**非退化**判读项：

* **`r_ves`**（血管内 Pearson）——对整体缩放不变；常数输出的相关系数无定义（nan），
  因此不会奖励"抹平"；
* **`n2n_ratio`**——对准同一场景的**第二次独立观测**（共享固定散斑、独立噪声实现，
  `sim_seed1_n201_s1.npz`），分子是本链的误差、分母是输入的同一误差。输入恒为 1.0，
  全零输出是 **266**，所以它同样不会奖励"抹平"。

`bg_std_ratio` 仅作辅助（它把 0 当最好，必须与 `r_ves` 合读）。这是**判据的收紧**：
旧判据会让全零输出"通过"。

### 2.2 观测是不是真值的单调重标定？

| 量 | 值 |
|---|---|
| pooled Pearson(log 观测, log 真值) | 0.9508 |
| 血管内 Pearson | 0.5684 |
| pooled Spearman | 0.1976 |

pooled r 高是**背景那 98.7% 的常数体素贡献的**（两边都近似常数），血管内只有 0.5684、
Spearman 只有 0.198。所以**去噪任务本身是真实的**，不是 "y = f(x)" 的重标定练习。
但这也说明 pooled r 同样被背景支配，与 §2.1 的结论一致。

### 2.3 血管剖面的第二个后果：本仿真测不了亚分辨

以"到血管掩膜的距离"为横轴统计 PD 均值：

| 距离（体素） | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| T2 无噪真值 | 7.04e7 | **0** | **0** | 0 | 0 | 0 |
| T3 观测 | 3.78e8 | 4.49e7 | 4.50e7 | 4.50e7 | 4.50e7 | 4.48e7 |

- 观测在 r=1 处已回到背景水平（4.49e7 vs 背景 4.48e7）——**血管在成像里也只有 1 个体素宽**。
- `mean_in_radius_of_1voxel_mask = 0.0`：**掩膜里没有任何"内部"体素**，每个血管体素都有背景邻居。
  即血管是 1 体素厚的壳，而 PSF 的 σ 是 (3.0, 2.37, 3.97) 体素——**PSF 比血管宽 2–4 倍，
  却没有把血管变宽**，这是 §1 第 1 条差别的直接体现。

**这意味着**：在这个仿真上，任何"恢复了细小血管"的说法都无法被检验——真值血管没有"细"这个
维度可失去。微血管恢复能力必须在**带 PSF 展宽的正向模型**上测，或者换真实数据 + 结构指标（R12）。

| 轴 | 仿真 lag1 | 实测 lag1 | 差 | rmse |
|---|---|---|---|---|

## 4. 对既有结论的影响（不重跑，只标注适用范围）

| 既有说法 | 现在能不能说 |
|---|---|
| "faithful VALID / 稀疏采样在仿真上的差距" | **能说，但要写明真值的性质**（见 §2） |
| "某臂 RMSE 更低 ⇒ 去噪更好" | **不能说**（§2.1，全零输出更好；血管内也一样） |
| "仿真器已验证了 PSF" | **不能说**（§3，y 轴过相关 0.20） |
| "某方法更能恢复微血管/小血管" | **不能说**（§2.3，真值血管无内部体素，成像不展宽） |
| "仿真真值 = 血管密度卷积 PSF" | **不能说**（§1，掩膜是硬乘的） |

**注**：Phase 4 §1 已经识别过"旧真值要求把背景抹成 0、而盲点网络的最优解是复现本底"这一目标冲突，
并因此改用 N2N 判据。本报告新增的不是这个冲突本身，而是：①把它的**代价量化**了（全零输出在
全局与血管内两处都优于输入与真实训练臂）；②查明其根源在**仿真器的真值定义**（背景精确为 0、
血管无 PSF 展宽），因此它无法通过换指标在同一个仿真上绕过，只能改仿真器或换真实数据。

## 5. 通俗总结

**这一步到底证明了什么。** 我把仿真器"到底在模拟什么"拆开来逐项核对，发现三件事，一件比一件要紧。
第一，我们叫它"无噪真值"的那个东西，在血管以外的**每一个体素上都精确等于零**——它不是"一张干净的
超声图"，而是一张"血管亮、别处全黑"的二值化靶子。第二，正因为这样，**一个什么都不算、直接输出
全零的程序，在"离真值有多远"这个分数上就比原始数据好六倍半**——而且我起初想换成"只看血管内部
有多接近"，一算发现**全零在血管内部也更接近**，因为真值到处都比观测暗。所以这类"离真值多远"的
分数我全部废掉，改成两把不会奖励"抹平"的尺子：一是"血管那部分的形状对不对"（只看相关性，
整体调亮调暗都不算数），二是"对准同一场景另拍一次，谁更接近"（什么都不做记 1 分，输出全零记
266 分，越小越好）。
第三，仿真里的 PSF（决定"一个点会被糊多大"的那个模糊核）**只糊散斑、不糊血管**，血管永远是
一个体素宽的壳，连"内部"都没有。也就是说，这个仿真**没有能力回答"小血管能不能恢复"**，而小血管
恰恰是我们最想说的话。

**对项目主张意味着什么。** 对项目主张是**不利但不致命**的。不利在于：我们最想宣称的那一条
（微血管恢复）在这个仿真上根本无法被检验，之前若有人从仿真结果推出这条，那是越界的。不致命在于：
"稀疏采样 vs 密集采样哪个更能保住血管"这个比较仍然成立，因为两边面对的是同一个靶子；只是这个
比较的**适用范围**要写清楚——它说的是"在一个人为的二值血管靶子上"，不是"在真实微血管上"。

**哪些话现在不能说。**
- 不能说"仿真的真值就是干净的超声图"——它在血管外恒为零。
- 不能说"某个方法离真值更近所以更好"——输出全零会赢。
- 不能说"仿真的散斑统计已经和实测对上了"——只有 z 轴对上，y 轴明显过相关。
- 不能说"仿真证明了能恢复小血管"——仿真里的血管没有"小"这个维度。
- 不能说审查这一条只是措辞问题了——它指出了仿真器**结构上**的缺陷，我核实后确认成立，而且更深。

**还剩什么没做。** 把血管真值改成"血管密度（部分容积）→ 卷积 PSF"的正向模型，需要重写仿真器，
而这会**改变所有仿真真值**，因此此前全部仿真数字都将不可直接比较，必须整套重跑。这一条我没有做，
写在这里作为已知缺口，不做猜测性评估。

## 6. v2 前向模型的实现、标定与端点再校准（2026-10-27 追加）

> 脚本：`scripts/v3_simulator.py`（`--forward v2`）、`scripts/v3_make_sim_dataset.py`、
> `scripts/v3_r06_v2_audit.py`、`scripts/v3_testretest_calibration.py`
> 产物：`data/processed/v3_sim_v2/`（16 训练体 + 2 评估体）、`reports/v3_r06/v2_endpoint_audit.json`、
> `reports/v3_r06/testretest_calibration.json`
> **§1–§5 的数字全部未改**，它们描述 v1；本节是 v1 缺口的处理记录。

### 6.1 改了什么（只改血流项）

```
v1:  flow_t(z,y,x) = gauss_field(psf_sigma) · vessels(z,y,x)        # 硬掩膜乘散斑
v2:  flow_t         = conv( sqrt(ρ) · white_noise_t , psf_sigma )   # 密度→PSF→IQ
     ρ ∈ [0,1] 为连续血管密度：随机游走管 + 线性软边缘（宽 density_soft=1.5 体素）
     E[血流的 PD] ∝ ρ ⊗ |psf|²   ⇒  真值在管周有晕、管内有脊，**不再处处为 0**
```

`vessels`（几何真值）在 v2 下仍保留，定义为 `ρ ≥ 0.5`，供结构指标使用。
其余各项（static / dynamic / clutter / thermal / 带通 / PD）**一字未动**，所以 v1 与 v2 的
背景部分逐位相同（`v1 两次调用逐位一致: True`；v1/v2 差异只出现在血流支撑上）。

**幅度标定**（这是 v2 唯一的"旋钮"）：`flow_contrast_db` 定义为

```
10·log10( median(真值PD[ρ≥0.5]) / median(观测PD[ρ=0]) )     # 带通之后
```

标定用**两阶迭代**：先以不含血流的带通功率估背景，定出 k₁；再把血流加回去重算背景
（把血流的晕算进来），定出 k₂。之所以必须迭代：第一版直接用**未带通**的功率估背景与核心，
结果逐体子的带通后对比度在 **−1.7 dB ~ +9.6 dB** 之间乱跳——因为背景里主导的静态散斑与杂波
正是被带通删掉的那部分，而未带通估计看不见这件事。改后实测偏差：

| seed | 目标 | 达成 |
|---|---|---|
| 100 | 6.0 dB | +5.96 dB |
| 109 | 6.0 dB | +5.98 dB |
| 110 | 6.0 dB | +5.96 dB |

16 个训练体在另一种背景口径（`background_mask` 20% 分位）下的实测是 6.40–6.44 dB，
两种口径差 0.43 dB 是"背景取 ρ=0 还是取分位数 20%"造成的，不是标定误差。

### 6.2 v2 是否真的修掉了 R06 的两个结构缺陷（已知答案，无需训练）

`scripts/v3_r06_v2_audit.py` 的输出（`reports/v3_r06/v2_endpoint_audit.json`）：

| 量 | v1（`sim_seed0`） | v2（eval s30 / s31） | 判读 |
|---|---|---|---|
| 真值在 valid 区为 0 的比例 | **0.9903** | **0.0000 / 0.0000** | 真值不再处处为 0 ✔ |
| ρ∈(0,1) 的体素占比 | 0.0000 | 0.0203 / 0.0157 | 有部分容积/晕 ✔ |
| 带通后 血管/背景 对比度 | 0.47 dB | **5.94 / 5.96 dB** | 命中 6 dB 目标 ✔ |
| 主 ROI（ρ≥0.5）体素数 | 1385 | 652 / 697 | 量级可用（10²） |
| 全局 RMSE：输入 / 全零 | 0.706 / **0.083**（全零胜 8.5×） | 0.573 / 0.615（**输入胜**） | RMSE 不再退化 ✔ |

**这是本节最重要的一条**：v1 上"输出全零"能在全局与血管内两处都赢（§2.1），v2 上它在两处都输。
所以"RMSE vs 真值"这个最直观的判据在 v2 上是**可用的**（不再奖励抹平）。但实验 A 的重跑仍然

且不依赖真值；RMSE 作为辅助项一并报告。

### 6.3 第二次观测的独立性（n2n 的分母）

| 量 | v1 | v2（s30 / s31） |
|---|---|---|
| `mse(obs1,obs2)`（valid，log1p 域） | 2.1e-3 | 2.97e-3 / 2.94e-3 |
| 占 `var(log1p PD)` | ~8% | 2.0% / 1.7% |

v2 的分母绝对值更大（噪声更"独立"），但占方差的比例更小，因为真值现在自身贡献了方差。
已知答案自检：同一个 seed 的两次观测 `rho` 逐位一致（`max|Δ|=0.0`，血管掩膜亦然），
所以"结构共享、噪声独立"成立。

**一处需要写的更正**：数据集脚本第一次写盘时打印 `rho_same=False`。查明原因是
`vessel_density` 里 `np.maximum(rho_f32, clip(float64))` 把结果升成 float64，
而落盘前存的是 float32，`np.array_equal` 因此判否——**两者实际只差 3e-8（float32 舍入）**。
已在 `vessel_density` 末尾显式 `.astype(np.float32)`，并把自检改为"在 float32 下比较 + 报 max|Δ|"。
复核：现有 npz 里的 rho 与重跑结果**逐位一致**（`max|Δ|=0.0`，`vessels` 亦一致），数据无需重生成。

### 6.4 测试-重测标定：真实数据与仿真"可去噪声比例"

定义（`scripts/v3_testretest_calibration.py`）：把**同一条**带通后的 IQ 按帧的奇偶各半重建 PD，
`noise_frac = mean((l₁−l₂)²) / (2·var(0.5(l₁+l₂)))`，log1p 域。它读作"整幅图 log-PD 方差里，
有多大比例是与判据同一种的、可在两次独立观测之间消掉的方差"。

| 数据 | `noise_frac` |
|---|---|
| 真实 SA64 | **0.0523** |
| 真实 HSA64 | **0.0052** |
| 仿真 v1 seed0 / seed1 | 0.0351 / 0.0287 |
| 仿真 v2 seed0 / seed1 | 0.0112 / 0.0077 |

**判读（必须连起来读）**：两条真实序列本身就差 10 倍（5.2% vs 0.5%），所以"仿真对上真实"这句话
不可能对两条同时成立。v1（3.5%/2.9%）接近 SA64；v2（1.1%/0.8%）接近 HSA64 那一端。
**可去噪声只有 0.5%–5%** 这个量级本身就是一条重要结论：任何"改动很大"的方法都在动共享结构，
而不是在去噪（实验 A §3.2 的"输出≈输入的轻度低通"与此一致）。

### 6.5 空间纹理仍对不上（未修，如实披露）

用同一套 `acf_vs_target`（背景 log-PD 的 lag-1，mode=fast）：

| 体 | z | y | x | overall rmse |
|---|---|---|---|---|
| v1 `sim_seed0` | −0.009 | **+0.200** | −0.079 | 0.1457 |
| v2 eval s30 | +0.037 | **+0.220** | −0.050 | 0.1197 |
| v2 eval s31 | +0.059 | **+0.221** | −0.062 | 0.1220 |

v2 **没有改善** y 轴的过相关（0.200 → 0.221），只是 z/x 略有变化。原因是这部分纹理由
static/dynamic 散斑决定，而 v2 只动了血流项。**所以 §3 的结论原样保留**：不能说"仿真的散斑统计
已标定到实测"。要修需要重标 `psf_sigma` 的各向异性，那会再次改动所有仿真真值，属下一轮。

### 6.6 对既有结论的影响

| 既有说法 | 现在能不能说 |
|---|---|
| "v1 真值在血管外恒为 0，所以 RMSE 退化" | **能说**（§2.1 不变） |
| "v2 上 RMSE 判据可用" | **能说**（§6.2：全零输出两处都输） |
| "仿真器现在能测亚分辨/小血管了" | **部分能说**：真值有连续密度与晕，可测"亚分辨**加权**"；但仍无体素内速度分布、无旁瓣耦合，且 y 轴纹理偏差仍在 |
| "仿真统计已与实测对齐" | **不能说**（§6.5） |
| "v2 让任务变简单了，所以方法会好看些" | **不能说**：噪声占比反而更低（1%），而真实 SA64 是 5% |

### 6.7 通俗总结

**这一步到底证明了什么。** 上一轮我发现仿真器有个结构毛病：它所谓的"干净答案"在血管以外
**每个点都精确等于零**，等于让程序去猜一张"除了血管全是黑的图"；而且血管永远只有一个像素宽，
哪怕成像系统的模糊核比它宽三倍也不变宽。这一轮我把这个毛病改了：现在先画一张"血管有多浓"的
灰度图（不是黑白），再让模糊核去糊它，于是"干净答案"在血管周围有一圈渐变的晕、在血管中心有一条
脊——这才像真实的超声图。我用了三个种子核对：目标对比度 6 分贝，实际都做到 5.94–5.98 分贝，
说明这个旋钮是准的。更关键的验证是：**在旧版上，一个什么都不算、直接输出全零的程序，比原始数据
更接近"正确答案"八倍半**，而我之前只能靠另两把尺子绕开它；**在新版上，全零输出了，原始数据反而
更接近正确答案**——也就是说最直观的那把尺子又能用了。

**对项目主张意味着什么。** 是**解除了一个限制**。之前我们最想说的那句"能不能恢复细小血管"在这个
仿真上根本无法被检验，因为"细"这个维度在答案里不存在；现在答案里有了连续浓淡，这个维度存在了。
但要说清楚：这**不等于**仿真已经像真实数据了——纹理（相邻像素之间的相似程度）在一个方向上的偏差
（0.22）一点没修，而且新版仿真里可去噪声只占 1%，真实数据里一条序列是 5%、另一条是 0.5%，
所以"仿真等于真实"这句话依然不成立。

**哪些话现在不能说。**
- 不能说"仿真已经和真实数据对齐"——纹理偏差还在，且两条真实序列本身差十倍。
- 不能说"新版仿真证明我们能恢复微血管"——只可以说"新版仿真第一次让这个问题变得可以问"。
- 不能说"新版把任务变简单了所以数字会好看"——噪声占比反而更低（1% vs 旧版 3%），更难。
- 不能说"血管宽度这个指标能区分方法"——我原本打算用它，校准后发现它在真值里恒等于 1
  （模糊核太宽，把管子的边缘抹平了），已撤销，记录在 `reports/v3_expA_v2/prereg.md` §3.2.1。

**还剩什么没做。** 纹理标定（psf 各向异性）、体素内速度分布、旁瓣杂波耦合这三条仍是缺口，
它们都会再次改动仿真真值，因此只能在下一轮统一处理。
