## 0. 这一轮到底在回答什么

实验 A 的结论是「faithful VALID 在 V3 仿真上不优于输入」。在做实验 B/C/D 之前，这一轮要把
实验 A 结论的**三个前提条件**逐个补齐或证伪：

| 编号 | 前提 | 若不成立的后果 |
|---|---|---|
| **P1 预算** | 训练预算足以让 faithful VALID 收敛到它的最优解 | 实验 A 的结论只能限定为"在此预算下" |
| **P2 任务定义** | 真值不是退化的（不会奖励"输出全零"） | 实验 A 的结论是**判据的结论**，不是方法的结论 |
| **P3 泛化与量** | 训练集不止一个体，"没学会"不等于"这一例学不会" | 同上 |

对应两个阶段，**同一份门槛，先写后跑**：

* **阶段 1（已在跑，见 §1）**：只补 P1。数据/判据/臂与实验 A 完全相同（仍是 v1 单体的退化真值），
  唯一改动是预算与上游超参。它的作用是**把"预算"这一个变量单独关掉**——如果加了 50 倍预算结论不变，
  那预算就不是解释；如果结论变了，说明实验 A 的结论必须降级。
* **阶段 2（排队，见 §3）**：补 P2 + P3。用 v2 前向模型的多体数据，判据按 §3.2 预注册。

**阶段 1 的结论无论正负都不单独构成"faithful VALID 行不行"的最终判断**，因为它的判据本身
（v1 真值）是已证伪的；它只负责回答"预算够不够"。

## 1. 阶段 1：预算对照（v1 单体，200,000 step）

### 1.1 与上游的预算差距（如实记账）

上游 VALID v1.0（clone 于 `/tmp/VALID_up`，commit `34f5637`）的实际配置来自
`jsons/train_params.json` + `train_pipeline.py:185`：

| 项 | 上游 | 实验 A（已跑） | 本阶段 | 本阶段 / 上游 |
|---|---|---|---|---|
| patch | **224³** = 11,239,424 体素 | 32×64×64 = 131,072 | 同左 | 1.2e-2 |
| 总步数 | 100 epoch × 10,000 = **1,000,000** | 4,000 | **200,000** | **0.20** |
| 总训练体素样本 | **1.12e13** | 5.24e8 | 2.62e10 | **2.3e-3** |
| LR 调度 | `lr·(1−e/E)^0.9`，**无 warmup** | warmup + 余弦 | **poly（已改）** | 一致 |
| 梯度裁剪 | `clip_gradients=100.0` | 20.0（写死） | **100.0（已改）** | 一致 |

**因此本阶段最多只能声称覆盖了上游步数的 20%、体素样本的 0.23%。** 任何结论都必须带这个限定语，

（为什么不直接跑 1e6 step：实测 0.064 s/step，1e6 step ≈ 17.8 h/臂，本机 4 卡并行也超出本次窗口。

## 3. 阶段 2：v2 多体 + 上游预算

### 3.1 数据

`scripts/v3_make_sim_dataset.py` 生成，产物 `data/processed/v3_sim_v2/`：
16 个训练体（seed 100–115，血管几何各不相同）、2 个评估体（seed 30–31，**与训练体不重叠**），
每个评估体另有一次独立观测（解剖与固定散斑相同、动态/血流/热噪声独立）。
所有体用 **v2 前向模型**：`flow = conv(sqrt(ρ)·white_noise, psf_sigma)`，ρ 为连续血管密度，
真值 = 只对血流项做同一条官方带通的 PD。

### 3.2 端点（预注册）

| 角色 | 端点 | 定义 | 为什么不是别的 |
|---|---|---|---|
| 主 | `n2n_ratio` | `mse(pred,obs2)/mse(obs1,obs2)`，valid 区，log1p 域 | 不需要真值，不奖励抹平（输入=1，全零=266） |
| 主 | `r_roi` | ROI（ρ>0，血流足迹）内 `pred` 与 v2 真值的 Pearson | 对整体缩放不变；v2 真值在整个足迹上非退化 |
| 主 | `pen_ratio` | ~~半影区/核心区 PD 均值比 vs 真值同量之比~~ **→ 已撤销，见 §3.2.1** | 校准后确认该量在真值与观测中恒 ≈1，没有判别力 |
| 辅 | `r_core` | 核心区（ρ≥0.5）与真值的 Pearson | 与 `r_roi` 同族，作稳定性核对 |
| 辅 | `bg_std_ratio` | 背景区 std / 输入背景 std | 只作辅助（0 最好，必须与主端点合读） |
| 对照 | `input` / `zero` / `wiener_w7` / `oracle_lowpass` | — | `zero` 必须**在新的 v2 真值下重新检查是否仍然退化**，见 §3.3 |

#### 3.2.1 端点撤销记录（写于 2026-10-27 00:5x，**早于阶段 2 的任何训练**）

原计划把"半影/核心 PD 比"作为 v2 独有的主端点（用来问"血管有没有被 PSF 展宽"）。
在生成数据集时做的已知答案校准（seed 100/109/110，`flow_contrast_db=6.0`）显示：

| seed | 真值 半影/核心 | 观测 半影/核心 | 带通后对比度 |
|---|---|---|---|
| 100 | 1.070 | 1.044 | +5.96 dB |
| 109 | 1.090 | 1.103 | +5.98 dB |
| 110 | 1.179 | 1.186 | +5.96 dB |

真值里"半影"并不比"核心"暗（比值 1.07–1.18），观测里也一样。原因是**物理的**：PSF 的
σ 是 (3.0,2.37,3.97) 体素，而管半径只有 1.1，卷积核覆盖的体素量级是 10³，
ρ 的软边缘（宽 1.5 体素）在这么宽的核下被完全抹平，于是 E[真值 PD] ∝ ρ⊗|psf|² 在管子附近
几乎是平的。**所以这个量在构造上就恒 ≈1，它不能区分任何方法**——按方案 §0.5，没有判别力的
端点必须撤销，且撤销发生在看到任何训练结果之前。

替换为 `r_roi`（ρ>0 的整个血流足迹内与真值的 Pearson）：足迹有 1.4e3–5.0e3 个体素，
且真值在整个足迹上非零、非退化（`gt==0` 比例 0.0000）。"血管被展宽"这件事改由 `r_roi`
与 `r_core` 的相对高低间接反映（若某方法只会输出宽而钝的斑块，两者会同时低）。

### 3.3 门槛（写在 v2 训练结果之前）

* **T2-通过（任务定义问题已消除，faithful VALID 可继续）**：`A_rand` 与 `A_fixed4` **都**满足
  `n2n_ratio < 1.0` 且 `r_roi >` 输入本身的 `r_roi`。
* **T2-未通过**：两条臂 `n2n_ratio` 都 **> 1.0** 或 `r_roi` 都 **< 输入**。
  → 判读：在同一预算与同一判据下，faithful VALID 在该仿真上不成立，实验 B/C/D 继续冻结，
  并把结论的适用范围写成"Kong 等 2024 的自监督去噪教义 + 本项目仿真协议"。
* **禁止的解释路径**：不得用"再换一个秩带 / 再放宽 ROI / 再换一个指标"来救结论（方案明文禁止）。
* **失败可归因规则**：只有在 §3.2 的 `zero` 对照确认全零**不再**优于输入时，T2 的失败才能
  归因于方法；否则结论必须写成"判据仍退化，不能判方法"。

## 4. 已知的、本轮无法关闭的缺口

1. **上游预算的 99.77% 未覆盖**（§1.1）。要真正关闭需要 17.8 h/臂 的连续训练。
2. **仿真纹理未完全标定**：v1 的 y 轴背景 ACF 过相关 +0.202（R06 §3），v2 的数字见审计 json。
3. **仿真仍是各向同性血流、无体素内速度分布、无旁瓣杂波耦合**（R06 §1 第 2–3 条）。
4. **真实数据上的可训练性（R08）未动**：真实数据没有真值，只能靠 n2n 与结构指标间接判断。
