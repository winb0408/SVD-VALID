## 0. 一句话结论

**T1 未通过。** 在 50 倍预算（4k → 200k step）下，两条臂的血管保真 `r_ves` 都**低于输入**，与第二次
独立观测的误差 `n2n_ratio` 都是输入的 **12–19 倍**。预注册写明：这种情况判为"**预算不是解释**"，
实验 A 的负面结论**不能**改写成"算力不够"。

两条臂的失败**机理不同**（§2）：`A_fixed4` 是"噪声也涨了"（背景噪声 1.14–1.19 倍）；
`A_rand` 是"噪声降了 42%、但血管被抹掉"（背景噪声 0.578 倍，血管相关性 −0.14）。

## 2. 端点（非退化判读项只有 `r_ves` 与 `n2n_ratio`）

| 行 | `r_ves`（越高越好，输入 0.9456） | `n2n_ratio`（越低越好，输入 1.0） | `bg_std_ratio` |
|---|---|---|---|
| 输入 | **0.9456** | **1.000** | 1.000 |
| ① Wiener（w=7） | 0.9454 | **0.781** | 0.641 |
| `zero`（全零，退化对照） | 0.5720 | 266.85 | 0.000 |
| `A_fixed4` s3407 / s3408 | 0.560 / 0.535 | 11.77 / 12.09 | 1.138 / 1.187 |
| `A_rand` s3407 / s3408 | **−0.140** / **−0.028** | 19.24 / 17.06 | 0.578 / 0.567 |

`rmse` / `rmse_ves` 不参与判定——它们被"输出全零"这个退化解最小化（`zero` 的 `rmse=0.108` 是全场最低），
这条在预注册里已经写死。

**`n2n_ratio` 到底是什么（这一条必须写清，否则会误读上表）**：它是
`‖输出 − 第二次观测‖² / ‖输入 − 第二次观测‖²`，即**与另一次独立观测的总误差**，其中包含
**偏差**（把血管抹掉的成分）与**噪声**两部分。所以：

- `A_fixed4`：`n2n_ratio` 11.8–12.1 倍**同时**伴随 `bg_std_ratio` 1.14–1.19，即背景噪声确实也涨了；
- `A_rand`：`n2n_ratio` 19 倍，但 `bg_std_ratio` **0.578** —— 它的背景噪声**降了** 42%，
  那 19 倍几乎全部来自**偏差**：血管被抹掉了，于是和带血管的第二观测差得很大。

换句话说，`A_rand` 不是"没降噪"，而是"降了噪、顺便把要看的信号一起抹了"。这两种失败模式
（噪声不降 vs 信号被抹）在项目里必须分开说，不能都叫"效果差"。

## 4. 机制判读：预算增加时，损失在降、血管在消失

这一条不是门槛，是预注册里的附加检查（§1.3）。原始数字来自各预算的 `expA_metrics.json` 与训练日志：

| 预算 | `A_rand` `r_ves` | `A_fixed4` `r_ves` | 训练损失（末 epoch） |
|---|---|---|---|
| 4k step | 0.7597 | 0.6865 | 0.024177（epoch 40） |
| 24k step | 0.2177 | 0.4110 | 0.017816（epoch 120） |
| 200k step | **−0.0839** | **0.5479** | 0.014960（epoch 200） |

**损失单调下降，`A_rand` 的血管保真单调下降并穿过 0。** 也就是说：这个网络在它自己的目标上越训越好，
在"能不能看见血管"上越训越差，到 200k 时输出与真实血管**负相关**。这不是"训得不够"，是"训得越多、
目标越被满足、而目标本身与保真不一致"。

这与本项目"loss-minimal"的出发点直接对上：N2N 的配对目标可以被一个**抑制结构**的解最小化，
所以损失曲线不能作为"降噪成功"的证据——这一点在实验 A 的阶段 1 上第一次有了端到端的数字。

## 5. 能说 / 不能说

| 能说 | 依据 |
|---|---|
| 在 v1 仿真数据上，200k step 的 faithful VALID 两条臂都**不如输入自己**，也**远不如 Wiener** | 上表，`n2n_ratio` 12–19 vs Wiener 0.781 |
| `A_rand` 的失败是**抹血管**（偏差），不是"没降噪"；`A_fixed4` 是**噪声和血管都退** | `bg_std_ratio` 0.578 vs 1.14–1.19 |
| 这个负面结论**不是预算不足**造成的 | 50 倍预算下结论不变，且随预算变差 |
| 训练损失下降与血管保真下降**同时发生**且方向相反 | §4 表 |
| `zero`、`input`、`wiener` 三个对照都**非退化**，判据没有被退化解骗过 | `zero` n2n=266.85、input=1.0、wiener=0.781 |

| 不能说 | 原因 |
|---|---|
| "faithful VALID 普遍失败" | 这只是 **v1 数据**。v1 数据的仿真器在 R06 里被查出有前向模型缺陷（PSF 施加顺序/速度场），阶段 2 用修正后的 v2 数据重跑，结论以阶段 2 为准 |
| "我们的采样/相位创新点无效" | 实验 A **不测**创新点，它测的是"上游做法在共同真值下能不能过"。创新点的公平检验是实验 C |
| "再训久一点会好" | 趋势是反的（§4），且 200k 已是 4k 的 50 倍 |
| "Wiener 已经解决问题了" | Wiener 只把 `n2n_ratio` 打到 0.781，`r_ves` 仍等于输入（0.9454 vs 0.9456）——它压了噪声但没提升血管保真，够不上"方法"，只够当强基线 |

## 6. 通俗总结

**这一步到底证明了什么。** 我们把上游那套"忠实照搬"的做法，在同一个真值、同一个评分尺子上，
狠狠训了 50 倍（从 1 小时训到 4 小时），结论是：**不是没训够**。两个版本最后给出的图都比
**原图本身**更看不清血管——相关性从 0.95（原图）掉到 0.55，甚至掉到 0 以下
（意思是它画的亮的地方，真实血管反而偏暗）。最简单的传统滤波器（Wiener）反而把噪声压到了 0.78 倍。

**两个版本坏的方式还不一样，这一点别混着说。** 固定采样那个版本，噪声也涨了（1.1–1.2 倍），
是"哪儿都更差"；随机采样那个版本，背景噪声其实**降了 42%**，但血管被一起抹平了——
所以它和另一次的观测差得最远（19 倍）。一个是不降噪，一个是降噪时把信号也当噪声扔了。

**更值得记住的一件事。** 训练损失一路在往下掉（0.024 → 0.018 → 0.015），而血管保真一路在往下掉
（0.76 → 0.22 → −0.08）。**网络在它自己的考试上越考越好，在真实阅卷上越考越差。** 它学会的是
"把图抹平"——因为只要输出够平滑，两次独立观测的差就小，损失就低。这是一个结构性的漏洞，
不是调参能解决的。

**对项目主张意味着什么。** 短期：实验 A 在 v1 数据上是**负结果**，而且这个负结果扛住了 50 倍算力，
不能拿"预算不足"糊过去。中期：它**支持**我们项目的出发点——不能拿训练损失当验收标准，
必须用独立真值 + 退化对照（全零、输入本身、Wiener）。这一轮这三个对照都表现正常，
说明**尺子本身是好的**，负结果是负结果，不是尺子坏了。**但**这还不能说明我们的相位采样创新点
有没有效——实验 A 压根没测那个，测那个的是实验 C，而 C 现在还被 T2 门锁着。

**哪些话现在不能说。** 不能说"VALID 这条路死了"（这是 v1 数据，v1 的仿真器在 R06 里被查出有毛病，
阶段 2 正在用修好的数据重跑）；不能说"我们的创新点失败了"（没测）；不能说"再训久一点就好"
（趋势相反）；也不能说"Wiener 已经够用"（它只压噪声、不提升血管，够不上方法）。
