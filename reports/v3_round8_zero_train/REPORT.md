## 0. 结论先行

1. **C4 的亮暗网格是我们推理协议造成的，不是 Tetris 采样方法的性质。** 换回上游那种
   "整块前向 + 重叠平均"的推理方式、**用同一批 checkpoints、零训练**，网格就消失了
   （8 相位残差标准差 SA64 0.1557 → 0.0055–0.0135，Y 向接缝指标 6.10 → 1.13–1.25，
   已低于输入自身的 1.55）。Round7 §3.1 里"固有代价""分包是方法的前提"两句维持撤回。

2. **但网格消失并不等于方法有增益。** 引入固定 Gaussian / Wiener 对照后，同样的完整推理
   **在噪声-保真两个代理指标上都输给固定滤波器**，而且在 SA64 上输得很悬殊（背景粗糙度
   2.5–6.1 倍于输入，固定 Gaussian 是 0.36–0.44 倍）。

3. **止损判定：`INFERENCE_ARTIFACT_FIXED_METHOD_NO_GAIN`。** 这是审查预先登记的判定字符串，
   触发条件（棋盘消失、但完整推理仍输给固定 Gaussian/Wiener）已满足。
   按预案：**不再堆网络复杂度**；同时"背景变粗 + 血管变平"这一反向操作触发第二条预案，
   **暂停所有 I1 采样优化**。

4. **I1 仍未完成。** 即使推理问题解决，物理先验选择器至今没有控制**训练侧**的采样器。
   本轮不改变这一事实。

## 1. 本轮结论的边界（必须写清楚）

**审查方在协议开头自述的那次自检是合成数据自检，不是真实数据的训练结果。**

同样要写明的边界：

- **没有 clean GT**（审查协议原话）。因此 `core_mean_ratio`、`bg_std_ratio`、粗糙度、
  配准相关都只是**代理指标**，不是画质判决。本轮据此下的是"是否止损"的判定，
  不是"谁画质更好"的判定。
- **checkpoints 是在抽稀输入上训的**。上游 VALID 训练端做 2 倍抽稀（`generate_subimages`

  **分布外**的。审查要求"零训练"，所以本轮只能用这个分布外的部署去测。
  这一点让"没有增益"成为一个**关于当前部署**的结论，而不是"这个方法理论上限"的结论；
  但按预注册，它足以触发止损，且预案明确写了不要靠加网络来解决。

- **没有全局位移**：最优点落在 `[0,0,0]` 的，SA64 是 4/10、HSA64 是 7/10；其余为 ±1–2 体素，

  当相关本身很低（0.033）时相关面是平的，位移估计在此已不可靠；故位移只在
  `corr_at_best` 明显高于 `corr_at_zero` 时才可解读，其余按"无位移"读。

## 5. 逐条回答审查提出的五个方法差异

### 差异 1：上游 tetris 的覆盖计数

**审查说法正确，与本仓库理解一致。** 上游每块独立抽一个 Tetris 模式（`idx_pair` 的 8 行之一），
四个角色（`mask1..mask4`）各取该模式的一个角点，经 `generate_subimages` 得到 4 个
`(D/2,H/2,W/2)` 子视图；每个子视图是全体素数的 1/8，四个合计 **1/2**。
本仓库 `datasets/sampling.py` 的 `TETRIS_PATTERNS` 与上游 `idx_pair` **逐项相同**（8×4 逐值核对过）。

### 差异 2：`valid_random_tetris()` 是逐块置换，上游是全局一次置换

**审查说法成立，我们原来的"忠实移植"声明是错的，已撤回并修正。**

证据（上游 `/tmp/valid_upstream/datasets/sampling.py`）：
`RandomSampler_0123.__init__` 里 `random.shuffle(self.numbers)` **只执行一次**，
随后四次 `draw()` 各弹出一个数，分别写入 `mask1..mask4` 的全部位置（`:264-268`）。
即**整个 patch 共用一次全局角色置换**。而我们一直是 `perm = torch.rand(nb,4).argsort(dim=1)`，
**每块独立置换**——随机性更强，但因此**不是**上游行为。

已做的修正（`datasets/sampling.py`，默认行为不变以保历史可复现）：

- `valid_random_tetris(..., role_perm="per_block"|"global")`，`"global"` 才是上游口径；
- `valid_random_tetris_strided(...)` 同步加上该参数；
- 两处 docstring 删除"exactly as the upstream … does"，替换为指向上游行号的偏差说明；
- 文件头对 `valid_random_tetris` 的"faithful port"描述同步更正；
- 新增回归测试 `tests/test_smoke.py::test_role_permutation_scope_matches_upstream_only_in_global_mode`，
  同时钉住"`global` 模式下所有块共用同一置换"与"默认 `per_block` 行为未被改动"两件事。

**顺带发现的第二处同类措辞问题（一并更正）**：`valid_random_tetris_cross` 的 docstring 原写
"VALID 的互补配对"，实际上游 `mask1/mask2`（输入）与 `mask3/mask4`（目标）取自**同一个** tet
的四个角，即在同 tet 内互补；我们的 cross 让目标来自**互补 tet**，是本仓库为了让体对角角色对
可达而做的设计（tet 内部恒不含体对角对）。现在该 docstring 明确写"这不是上游的配对方式"。
行为未改，只是不再冒充上游。

### 差异 3：cross 固定体对角 + 四个模型 P0–P3 分开训 + 8 相位回填 ≠ 上游的共享网络 + 整块推理；网格不能归因给 Tetris 方法

**全部同意，并且本轮已用实验证据坐实。** 具体拆开：

- 上游是**一个**网络、推理时喂**整块连续 patch**、`model(input)` 只前向一次、重叠区域累加平均；
- 我们是 P0–P3 **四个独立模型**（各自见过不同的固定角色对），推理时把整卷切成 8 个相位类、
  每类交给一个模型、按 `(2m)³` 格点**拼**回去。这一动作是**分割（partition）**：
  每个体素只被写一次，**不存在可平均的重叠**——所以 Round7 那种"靠平均消接缝"的路根本不存在。
- 本轮把推理换成上游口径（整块前向 + 重叠平均）后网格消失（§3），
  因此 **Round7 C4 的网格不能归因给 Tetris 采样方法本身**。这条归因错误已在
  `reports/v3_round7/final_4col.md` §3.1 的更正框里记录，本轮再次确认。

### 差异 4：零训练、同一批 P0–P3、同一 logeps 卷，比较 (A) 8 相位回填 / (B) 各模型完整 3D patch 推理并重叠平均 / (C) 四者均值，加 SVD 输入

**已完全按此执行**，结果见 §3、§4。七个输出（SVD 输入 + A + B×4 + C）全部存盘，
每条序列 3 个文件（标准化 logeps / 线性 PD / dB）。计算 12.65 s，新训练 jobs = 0。

### 差异 5：固定线性 PD 标定参考 + 共同 dB 显示窗口，不逐列重标定；ROI 由 SVD 输入选取，绝不从输出回读

**已执行。** `refmax` 取同一 SVD 输入锥内最大线性 PD，对所有方法（含固定对照）相同；
定性图统一 −25…0 dB；另加一张"窗口取输入 p1/p99、按行共用"的版本（仍不逐列、不读输出）。
亮区 ROI = 输入锥内 ≥p90（各 12024 体素），背景 ROI = 输入锥内 ≤p30（各 36070 体素），
**两者定义只依赖输入**，在方法之间完全一致。

## 6. 止损判定

审查预注册的判定字符串：**`INFERENCE_ARTIFACT_FIXED_METHOD_NO_GAIN`**。

触发条件逐项核对：

| 预案条件 | 本轮结果 | 是否触发 |
|---|---|---|

| 全卷输出稳定 | 无未覆盖体素（脚本内 `uncovered voxels` 断言未触发）、无 NaN、输出有限 | ✅ 已达成 |
| 未丢失有效体素 | 覆盖率 100%，每体素写入次数 ≥1 | ✅ 已达成 |
| 并排比较血管/背景 | 见 §4 两表 + 逐序列图 | ✅ 已达成 |
| **棋盘消失但完整推理仍输给固定 Gaussian/Wiener** | 是：`rough_bg` 2.5–6.1 vs Gauss 0.44（SA64）；HSA64 同强度对齐后 still 1.4–5.6 倍；`bg_std_ratio` 1.35–12.71 vs 1.03–1.20 | ⛔ **触发** |
| 严重位移 / 弱血管破坏 → 暂停所有 I1 采样优化 | 无全局位移；但"背景变粗 + 血管变平"的反向操作存在，SA64 亮区被整体提亮 | ⛔ **同属触发**（按预案从严） |

**明确表态：本轮止损。** 具体含义：

- **不再堆网络复杂度。** 当前 4 模型 + 8 相位回填这条线到此为止，不再加模块、
  不再加损失项、不再调模型结构。
- **暂停所有 I1 采样优化**（物理先验选择器 / 引导采样相关的一切后续实验）。
- **可以继续的只有一件事**：把"为什么分布外部署会让背景变粗"这条诊断做完——
  它是解释性的，不产生新方法，也不消耗训练预算。若审查认为连这条也不必做，
  则 Round8 即为这条线的终点。

**止损 ≠ 方法被证伪。** 本轮测的是"抽稀训出来的四个模型、直接拿去整块推理"这一部署；
这个部署是分布外的（§1）。因此正确表述是：
*当前部署没有跑赢固定滤波器，且牌面已经用完（不能靠加网络解决），故停止*；
而不是"Tetris/引导采样这条思路在任何部署下都不行"。

## 8. 通俗总结

**这一步到底证明了什么。**

上一轮我们看见本方法的结果里出现了亮暗交替的方格。这一轮做的事很简单：
**不训练任何新模型**，把已经训好的四个模型换一种"用"的方式——不再是切成一格一格分别算、
再拼回来，而是像上游原版那样，一次喂一整块、重叠的地方取平均。

结果是：**方格立刻消失了**。这证明方格不是方法的毛病，而是我们自己"切块再拼"这个用法造成的。
就像把一张图切成邮票大小的碎片分别处理再贴回去，接缝当然会出现；换成整张处理就没有接缝了。
所以上一轮我们说的"这是方法的固有代价"是错的，已经收回。

**但这一步同时证明了另一件更不好听的事。**

审稿人要求我们别只说"方格没了"，而是要跟**最简单的老办法**比。于是我们加了两个固定滤波器：
一个是高斯模糊，一个是经典的维纳滤波。这两种东西没有任何学习、没有任何神经网络，参数一次定死。

比下来的结果是：**我们的输出在"背景有没有变吵"这件事上，比固定高斯差得远。**
最直观的一个数：背景区域的粗糙程度，我们的输出是原始输入的 2.5 到 6 倍（也就是更吵了），
而固定高斯是 0.44（也就是变干净了）。更奇怪的是方向：我们的方法**把血管那边磨平、
把背景那边弄粗**，正好跟去噪该做的事相反。固定滤波器则是两边一起变干净。

我们还专门做了一次"公平比较"：怕人家说"你拿一个糊得太狠的高斯来比当然你赢"，
于是给每个网络输出配了一个"把血管磨得一样平"的高斯，再比背景。
即便这样对齐，我们的背景还是比高斯粗 1.4 到 5.6 倍。

还有一条更严重：在 SA64 这部数据上，我们的输出把最亮的那部分**整体提亮了 2% 到 62%**。
去噪不该让血管变亮，这更像是"整体加对比度"，不是去噪。

**为什么会这样，我们也有解释（但这不改变结论）。**
这四个模型当初是拿"抽稀过的、只有原来八分之一分辨率"的数据训的。现在让它们直接处理
完整分辨率的数据，等于让一个只见过模糊照片的人去修高清照片——它们没学过这种输入。
审稿人这轮规定"不许重新训练"，所以我们只能这样测。所以准确的说法是：
**"目前这个用法没有跑赢老办法，而且这条路已经走到头（不能靠再堆网络解决），所以停"**，
而**不是**"这个思路本身错了"。

**对项目主张意味着什么。**

- 我们原本想主张"引导采样能带来增益"。这一轮**不能**这么说了：在当前部署下，
  它连一个参数定死的高斯都比不过。
- "方格"这个曾经的疑点已经结清，但它结清的方式是**我们认错**，不是方法加分。
- 按审稿人预先写好的规则，触发的是止损条款。所以：**不再往网络里加东西**，
  **暂停所有采样优化的后续实验**。项目在这条线上暂时不往前走了。

**哪些说法现在绝对不能说。**

不能说"方格没了所以方法更好"；不能说"平均更亮/相位更一致所以更好"；
不能说"已经证明优于 SN2N"（这轮根本没跑 SN2N，两组不在同一次比较里）；
不能说"合成数据的自检通过就等于真实数据实验通过"（那只是脚本自己检查自己）；
也不能说"采样创新点已经完成"——它到现在都还没有真正控制训练侧的采样，这一点从头到尾没变。
