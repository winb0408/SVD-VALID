## 0. 一句话结论

**在与上游一致的配对方式（random Tetris / fixed-4）下重训 VALID，它在 V3 仿真上不但没有降噪，反而
把背景噪声放大约 1.8–2.2 倍、把血管相关性从输入的 0.946 降到 0.687–0.760。关键的是：在它自己训练过的
那个体上同样是 0.62–0.69，所以这不是"没泛化"，而是"根本没学会"。** 计划里预注册的 Gate——
「若 faithful VALID random 与 fixed-4 都**不优于输入**，则停止开发物理采样选择器」——**被触发**。
在此之前，任何 sampler 之间的比较都不成立。

## 2. 主实验结果（4000 step，3 种子；括号内为种子间 min–max）

| 臂 | `r_ves`↑ | `bg_std_ratio`↓ | `n2n_ratio`↓ | `sep_ratio`↑ | (`rmse_ves`，不作判据) |
|---|---|---|---|---|---|
| **输入本身** | **0.9456** | **1.000** | **1.000** | **1.686** | 0.9802 |
| ① Wiener (w=7) | 0.9454 | **0.641** | **0.781** | 1.682 | 0.9782 |
| A_rand（faithful random Tetris） | 0.760 (0.739–0.773) | 2.216 (1.477–2.783) | 10.702 (8.82–12.76) | 0.93 | 0.7549 |
| A_fixed4（8 模式中最优的固定 4 号） | 0.687 (0.669–0.696) | 1.799 (1.572–2.146) | 9.120 (8.57–9.87) | 1.15 | 0.8245 |
| `zero`（已知答案控制：输出全 0） | nan | 0.000 | 266.855 | 0.000 | 0.5720 |

脚本直接打印的判定：

```
A_fixed4   Δr_ves=-0.259(r_ves=0.687)  n2n=9.120  bg_std_ratio=1.799  → 血管保真不如输入 / 噪声高于输入 9.1×
A_rand     Δr_ves=-0.186(r_ves=0.760)  n2n=10.702 bg_std_ratio=2.216  → 血管保真不如输入 / 噪声高于输入 10.7×
```

**三个非退化读数一致指向"劣于输入"**：血管相关性掉了、背景噪声涨了、留出观测的预测误差涨了一个
数量级。三者互相独立（尺度相关 / 方差 / 跨实现一致性），不存在"某一指标恰好不利"的可能。
六个种子无一个越线：`r_ves` 最大值 0.773 仍远低于输入的 0.946。

### 2.1 为什么只有这三个指标算数（R06 的连带后果）

R06 审计已证明：本仿真的无噪真值在血管掩膜外**恒等于 0**，且血管只有 1 体素厚、无内部结构。
于是**所有 RMSE 类端点都被"向 0 收缩"支配**——`zero` 控制的全局 RMSE 0.1082 远优于输入的 0.7057，
**甚至血管内 RMSE 0.5720 也优于两个网络臂（0.755 / 0.825）**。所以：

- `rmse` / `rmse_ves` 在本仿真里**不能作为"更好"的证据**（表中列出只为与历史数字对齐）；
- 唯一非退化的读数是 **`r_ves`（尺度无关的 Pearson）** 与 **`n2n_ratio`（输入恒为 1.0、`zero` 为 266）**，
  再加一个描述性的 `bg_std_ratio`。

这条限制写进了 `scripts/v3_expA_faithful.py` 的 `metrics()` 文档字符串，也写进了
`reports/v3_repair_R06_forward_model.md` §2.1。

### 2.2 n2n 分母的已知弱点（必须随结果一起报）

本仿真的两个观测共享静态散斑，二者之差只剩动态散斑 + 热噪声，分母很小
（`n2n_den = 2.102e-03`，血管内 `8.7e-03`），比值对**整体电平偏移**极其敏感。
它能给出的是**排序**（输入 1.0 < Wiener 0.78 ≪ 两臂 9.1/10.7 ≪ zero 266），不应单独读作"噪声功率比"。
噪声电平判断请以 `bg_std_ratio` 为准（0.641 / 1.799 / 2.216）。

## 3. 训练体自检：是"没学会"还是"没泛化"？

把**训练时喂进去的那个体**（`sim_seed0`）当评价体，用同一套 `metrics()`、同一把 `s`、同一个
`infer.py`。这一刀能区分两种解释：

- (a) 训练失败——连自己见过的体都没学会降散斑；
- (b) 训练成功但不过关——训练体上有效，只是没泛化到留出体。

其中"喂进去的体 == 现场重算的体"逐位校验：**`train_log1p.npy` 与从 `sim_seed0.npz` 重算的输入
`max|Δ| = 0.0`**（预处理缓存没有漂移）。

| 在**训练体**上 | `r_ves`↑ | `bg_std_ratio`↓ | `sep_ratio`↑ |
|---|---|---|---|
| 输入本身 | **0.9307** | 1.000 | 2.041 |
| ① Wiener (w=7) | 0.9305 | **0.632** | 2.036 |
| A_rand s3407 / s3408 / s3409 | 0.6842 / 0.6623 / 0.6897 | 1.475 / 2.808 / 2.406 | 1.26 / 0.93 / 1.30 |
| A_fixed4 s3407 / s3408 / s3409 | 0.6269 / 0.6308 / 0.6154 | 1.671 / 2.156 / 1.579 | 1.46 / 1.31 / 1.45 |

**结论：属 (a) 训练失败。** 训练体上 `r_ves` 0.615–0.690，与留出体（0.687–0.760）**几乎同水平**，
没有"训练体好、留出体差"的落差；`bg_std_ratio` 在训练体上甚至更差（最高 2.81）。
所以主实验的失败**不能用泛化、过拟合或仿真体间不匹配来解释**——网络在它见过的那个体上就没学到
"压散斑、保血管"这个映射。

这条同时否掉了一个常见的"安慰性解释"：如果只是训练不足 × 泛化不好，长预算应当先修好训练体。
§4 的长预算对照把这一点也一并处理掉。

### 3.1 端点定义的一处必须声明的口径问题

`metrics()` 里的 `r_ves` 是拿网络输出与 **`gt_flow_pd`（只有血流项）** 比的。
但 `v3_simulator.py` 模块文档本来就写明：N2N 用**独立实现**当检验目标时，"保留静态本底就是对的，
不必把背景底抹成 0"。也就是说，**在本项目自己的教义下，输出保留静态散斑不算错**，
而 `r_ves` 会把"保留静态本底"计成错误。这一条对结论**没有影响**，因为判失败用的是另外两个端点：

- `n2n_ratio`（9.12 / 10.70 ≫ 1）——拿**第二次独立观测**当目标，正是教义认可的口径，与 `gt_flow_pd` 无关；
  它说"输出离共同信号比输入还远 3 倍（√9 ≈ 3）"。
- `bg_std_ratio`（1.80 / 2.22 > 1）——背景总起伏相对输入被放大了，无论那起伏算"信号"还是"噪声"都算坏。

**因此"faithful VALID 在这份数据上没有降噪"这一判定不依赖血流真值**；
但把 `r_ves` 单独摘出来说"血管保真度掉了"时，必须同时说明它部分来自"背景本底被保留"。
这一区分写进 `reports/v3_expA/output_linearity.json` 与 `task_dynamic_range.json` 的分析里。

### 3.2 它到底学成了什么：近似"输入的轻度低通"

对 `A_rand_s3407` 的整卷输出做了三件事（`reports/v3_expA/output_linearity.json`、
`output_lowpass_test.json`）：

1. **线性回归**：`pred ≈ 0.39·input + 0.44`（6 个 checkpoint 的斜率都在 0.30–0.44）。
   输出的均值 0.714 与输入均值 0.713 几乎相同，输出标准差 0.087–0.103 只有输入 0.178 的一半多。
   → 网络把输入**压向它自己的均值**，没有建立"该处的背景应当为 0"的映射。
2. **它更像低通**：`r(pred, input) = 0.794`，但 `r(pred, gaussian_filter(input, 1)) = 0.852`；
   对真值同样——`r_ves(pred, truth) = 0.768` 升到 `r_ves(pred, gaussian_filter(truth, 1)) = 0.851`。
   → 输出的最佳解释是"输入轻微模糊后的版本"。
3. **同时它还残留噪声**：与 2 体素平滑后的输入相比，背景标准差仍是 1.28 倍。
   → 既没压干净噪声，又把结构糊掉了。

**这解释了两件事**：为什么 `r_ves` 掉到 0.69（1 体素粗的血管被"轻度低通"整条抹平），
以及为什么 `bg_std_ratio` 反而涨（它没有做真正的噪声抑制，只是整体收缩 + 平滑）。

### 3.3 任务本身为什么这么难：真值的动态范围塌缩

同一个体上的统计（`reports/v3_expA/task_dynamic_range.json`）：

| 量 | 数值 |
|---|---|
| `valid` 内真值**恰好等于 0** 的体素比例 | **98.68%** |
| 真值方差集中在血管 ROI 内的比例 | 98.85% |
| 输入均值（`valid`） / 真值均值（`valid`） | 0.7126 / **0.0118** |
| 输入均值（背景）/ 真值均值（背景） | 0.6928 / **0** |
| 输入均值（血管 ROI）/ 真值均值（血管 ROI） | 1.247 / 0.329 |

即：**把 98.7% 的体素映射到"恰好 0"，同时把 1.3% 体素里的全部方差保留下来**。在整卷 MSE 下，
梯度几乎全部由"把背景压到 0"这一项提供，而背景里恰恰全是静态散斑——这项 N2N 目标是**不可能**
用 N2N 自身满足的（静态散斑在两个观测里是共有的，按定义就该被保留）。于是网络的次优解就是
"收缩 + 平滑"，这正是 §3.2 观测到的行为。

**再加上一条量级问题**：训练集只有**一个**仿真体（(37,64,64)，patch 32×64×64 ⇒ 每次只看到
半个 z 范围）。这类 CNR 方法通常需要在几十个体上训练。§4 用 6 倍预算检验"是不是只是步数不够"。

## 4. 长预算排除性对照（24000 step = 6× 主实验）

1 个种子（3407）、2 条臂，120 epoch × 200 step。产物：`runs/v3_expA_long/`、
`reports/v3_expA_long/expA_metrics.json`。**长预算同时拉长了余弦学习率周期**（`epochs` 从 40 变成 120），
所以这一节改变的不只是步数，还有一个学习率调度周期——这一点必须随结果一起说，不能声称"只改了步数"。

| 臂 | 预算 | `r_ves`↑ | `bg_std_ratio`↓ | `n2n_ratio`↓ | 训练 loss |
|---|---|---|---|---|---|
| 输入本身 | — | 0.9456 | 1.000 | 1.000 | — |
| A_rand | 4,000 step | 0.760 | 2.216 | 10.70 | 0.0242（epoch 40） |
| A_rand | **24,000 step** | **0.218** | 1.417 | **16.96** | **0.0178（epoch 120）** |
| A_fixed4 | 4,000 step | 0.687 | 1.799 | 9.12 | — |
| A_fixed4 | **24,000 step** | **0.411** | 2.065 | **12.51** | — |

**结论：不是"没训够"，恰恰相反。** 长预算把**训练目标本身**优化得更好（loss 0.0242 → 0.0178，降 26%），
而**每一项与任务相关的指标都更差**：`r_ves` 0.760 → 0.218，`n2n_ratio` 10.70 → 16.96。
继续训练只是让网络更彻底地走向 §3.2/§3.3 描述的那个解（收缩到均值 + 轻度平滑），
而那个解按定义就不可能保住 1 体素粗的血管。

这条把"预算不足"从解释清单里**划掉了**，并且反向说明：**问题在目标函数与任务构造上，
不在优化预算、不在抽样器、也不在泛化。**

（说明：json 的 `budget.seeds` 字段记录的是请求的种子列表；长预算实际只跑了 3407，
`arms` 字段里也只有 `*_s3407`。此处如实标注，不补造另外两个种子。）

## 5. 与既定 Gate 的逐项对照

计划里预注册的 Gate 原文：

> **判定**：若 faithful VALID random 与 fixed-4 都**不优于输入**，则停止开发物理采样选择器，
> 先解决任务与基础自监督基线；只有它们有效，才允许进入 B/C。

| Gate 条件 | 实测 | 结论 |
|---|---|---|
| faithful VALID random 优于输入？ | `r_ves` 0.760 < 0.946；`bg_std_ratio` 2.216 > 1.0；`n2n` 10.70 > 1.0 | **否** |
| faithful VALID fixed-4 优于输入？ | `r_ves` 0.687 < 0.946；`bg_std_ratio` 1.799 > 1.0；`n2n` 9.12 > 1.0 | **否** |
| 六个种子中有越线的吗？ | 无（`r_ves` 最高 0.773） | **否** |
| 是否被"没泛化"解释？ | 训练体上同样差（§3：0.615–0.690） | **否** |
| 是否被"没训够"解释？ | 6 倍预算后更差（`r_ves` 0.760→0.218、0.687→0.411），而训练 loss 下降 26%（§4） | **否** |

**Gate 判定：触发。** 依计划，**暂停物理采样选择器（I1）的开发，先行解决"任务定义 + 基础自监督
基线"**。实验 B/C 的前置条件（"只有它们有效，才允许进入 B/C"）**未满足**，故 B/C 暂不启动。

## 6. 通俗总结

**这一步到底证明了什么。** 外部审查说"你们从来没把原版 VALID 在这套数据上真正重训过，所以你们的
失败不能算数"。这一步就是去补这个洞：按原版的抽样方式重新训练（每个小块随机选对角、或固定选同一
组对角），两次各三个随机种子，用同一份没参与训练的数据、同一把亮度尺子、同一套指标来评。结果是：
**原版方法在这份数据上同样不工作，而且比"什么都不做"更差**——血管和真值的相关性从 0.95 掉到
0.69–0.76，背景噪声从 1 倍涨到 1.8–2.2 倍。作为对照，一个最简单的传统滤波（Wiener）在同一份数据上
把噪声压到 0.64 倍、相关性保持 0.945。

**最关键的一步在 §3。** 失败有两种可能：要么"没学会"，要么"学会了但换个场景就不行"。我把网络
**自己训练时用过的那个三维体**又拿去评了一遍——结果也是 0.62–0.69，和没见过的新体几乎一模一样，
噪声甚至更大。所以**不是泛化问题，是根本没学会**：在这份数据上，这个网络连"把散斑压掉、把血管
留住"这个最基本的映射都没建立起来。

**顺带把三种"安慰性解释"逐一堵死。** 说"它只是没学泛化"——不对，在它自己训练过的那个体上一样差
（0.62–0.69）。说"它只是训练步数不够"——不对，步数加到 6 倍，训练误差降了四分之一，可血管保真度
反而从 0.76 掉到 0.22。说"是我们指标不公平"——这一条部分成立：血管相关性确实会惩罚"保留背景本底"，
而按 Noise2Noise 的规矩保留背景本底是对的；但另外两个指标（用第二次独立观测当目标、以及背景起伏
有没有被压下去）不依赖血流真值，它们同样判失败，所以结论不靠那一条。

**对项目主张意味着什么。** 这是本轮最重要的一次"刹车"。我们原本的路线是"设计一个更聪明的抽样器"，
但连原版那套被公认为有效的自监督方案在这份数据上都学不出东西，那么**抽样器好不好根本还没轮到被
检验**——问题在更靠前的地方：任务定义、或基础网络与损失，还没跑通。所以现在**不能**说"我们的采样器
不如 VALID"，也**不能**说"我们证明了 VALID 不行"；能说的是：**在这份仿真、这套预算下，我们连一个
可用的基线都还没有。**

**哪些说法现在不能说。** 不能说"已证明物理采样选择器无效"（根本没有在有效基线上比过）；不能说
"VALID 方法本身有问题"（更可能是我们构造的仿真任务不对）；不能用表里的 RMSE 说"网络比输入差"
（RMSE 在本仿真里被"输出全 0"作弊支配，见 §2.1）；也不能把 Wiener 的胜出当成"结论已经清楚"——
Wiener 只用含噪观测自己，它不"从两个观测里学规律"，它只能说明"这份数据的噪声确实可被传统方法压掉"，
反过来说明网络没学到该学的东西。

**为什么学不会——这一步已经查到了原因，而且原因不在"训练不够"。** 我把预算加到 6 倍、训到第 120 轮，
它的"训练误差"确实降了四分之一——也就是说这个网络**在很努力地优化我们给它的目标**；但同一时刻，
它对血管的保真度从 0.76 跌到了 0.22。**目标是达成了，达成的却是错的目标。** 我把它的输出拆开看：
它其实只是把输入稍微糊了一下、并把整体亮度往均值上收，既没压掉噪声，又把只有一根血管那么粗的结构
抹平了。原因是任务本身长这样——我们要它把 98.7% 的地方输出成"正好 0"，而这 98.7% 的地方在输入里
全是散斑；同时它在两个观测里都能看到的那部分（静态散斑）按 Noise2Noise 的定义本就应该被保留。
两条要求互相打架，网络只能选"整体收缩 + 平滑"这种两头不讨好的折中。

**下一步的真实问题**不再是"哪个抽样器更好"，而是"要把这个任务重新定义对"。具体三处：
① 仿真器的前向模型必须真的走"血管 → PSF 卷积 → 复数 IQ → SVD 带通 → PD"，让真值不再是"血管外
恒等于 0、血管只有 1 体素厚"（这是 R06 的结论）；② 训练集只有一个 (37,64,64) 的体，相当于一张图，
必须扩成多个体才谈得上训练一个网络；③ 目标函数要明确"要保留什么、要去掉什么"——按现在的教义，
静态散斑属于该保留的信号，那么评分就不能拿"只有血流的真值"去扣它的分，否则永远判不过。
