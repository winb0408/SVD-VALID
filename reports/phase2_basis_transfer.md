## 0. 这一项要回答什么，以及它带来的意外

Phase 1 已经量到：宽带（proportional，T_C=134 时秩 97）在两个互斥帧组之间**几乎正交**。
计划书当时的读法是"宽带 P_C 主要由帧特有方向撑起来"，并把秩从"配方"降级为"扫描参数"。
但"子空间正交"和"图还能不能用"是两件事，中间隔着一层没说清的东西。本报告补上这层，结论比 Phase 1 记录的更细，其中一处与最初的直觉相反：

**先说意外的那一条。** 直觉上"两个子空间几乎正交"应该意味着"迁移过去的图是垃圾"。
实测确实如此 —— 但**只对计划书正在用的那个频带成立**。把频带下沿往后挪，
子空间余弦仍然很低（0.02–0.05），迁移过去的图却越来越像血管。
也就是说，**决定迁移成败的不是"两个子空间像不像"，而是频带落在频谱的哪一段**。
这一条改变了 §4 秩规则该怎么设计的判断，是本次诊断最重要的输出。

## 1. 方法

### 1.1 为什么大部分结论不需要跑 IQ

与前一项相同：400×400 的 Gram `G = X^H X` 已经缓存。任意"用 src 组的频带投影 tgt 组数据"的
**总能量**都可以只用 Gram 切片算出来：

```
||P_src^{[lo,hi)} X_tgt||²_F = sum_{k in [lo,hi)} | (v_k^H G[src,tgt]) / sqrt(lam_k) |²
```

不需要构造 V×R 的基，也不需要读 IQ。只有**图像级**指标（dB 相关、Dice、逐体素功率）必须读一次 IQ，
因此 A–F 六组对照只在两条序列的一折上做，而跨折/跨序列的迁移表是纯 Gram 的、覆盖全部 19 折。

### 1.2 结构指标与强度指标必须分开

本报告所有"结构"数字都是**每张图对自己的 p99.9 归一化后的 dB 相关**，它是尺度无关的 ——
"像不像血管"本来就是形状问题，图整体偏暗 100 倍不该影响结论。
所有"强度"数字（功率、迁移比）都是**绝对值**，单独报告。
两者从不混进同一个数。这一点与 §5 强度门槛的要求一致：结构可以归一化后比，
强度必须在共享映射下比。

### 1.3 五组对照，各杀一个便宜解释

"迁移过去的图不对"有五种便宜解释，必须逐个排除：

| 对照 | 要排除的解释 | 做法 |
|---|---|---|
| A | 标签/实现错了 | 基来源 × 目标数据 3×3 全遍历，六个交叉方向是否对称失败 |
| B | 频带的内容起了作用 | 在**同秩、同模式区间**内抽随机子空间，看确定性频带是否优于随机 |
| C | 迁移的是共同生理解剖 | 让校准组与目标组共享 k 帧，k 从 0 扫到全部，看迁移比随重叠的变化 |
| E | 与全序列参考对齐就够 | 参考图含 A 的 1/3 帧，故另取**与 A 帧互斥**的 B 组自投影图作无偏上限 |
| F | 换条更稳的频带就行 | 只用 C 自身拆半，量"保留子空间对自己是否可复现" |

## 2. 对照 A：不是标签错，是六个方向对称失败

SA64 一折（`sa64_int3_c0a1b2`，T_C=T_A=T_B=134/133/133），proportional 频带 `[20,117)`，秩 97：

| 基 → 目标 | 图像 dB 相关(与官方参考) | 平均功率(有效体素) |
|---|---|---|
| A → A（自） | **+0.836** | 4.388e+03 |
| B → B（自） | **+0.845** | 4.357e+03 |
| C → C（自） | **+0.821** | 4.422e+03 |
| C → A | +0.399 | 2.939e+02 |
| C → B | +0.400 | 2.815e+02 |
| A → B | +0.416 | 2.430e+02 |
| B → A | +0.417 | 2.454e+02 |
| A → C | +0.275 | 7.375e+02 |
| B → C | +0.254 | 8.832e+02 |

（`spectral` 频带作为对照：九个格子全部 +0.124…+0.157 功率 ~7e4，自投影与交叉投影无差别。）

**结论：三自投影一致地 0.82–0.85、功率一致地 ~4.4e3；六个交叉方向一致地 0.25–0.42、功率一致地低 5–18 倍。
完全对称。这不是 P1/P2 标签错位，也不是某个 fold 的偶然。**

顺带得到一条 Phase 1 没记录的正面事实：
**任何一组用自己 133 帧的 SVD，都能复现用全部 400 帧算出的官方 Power Doppler**
（相关 0.82–0.85，逐帧功率 4.4e3 对官方 3.9e3，差 13%）。
即官方 PD 本身对帧数是稳健的 —— 前提是**基和图像来自同一批帧**。

## 3. 对照 B：宽带的价值不超过一个随机子空间

在同秩、同模式区间内抽随机子空间（秩 = 频带秩，环境 = 校准组 `[20,T)` 的整个杂乱后空间）：

| 频带 | 秩 | 确定性/随机 能量比 | 确定性 dB相关 | 同秩随机 dB相关 |
|---|---|---|---|---|
| `[20,117)` proportional | 97 | **1.160** | **+0.399** | **+0.438** |
| `[40,134)` | 94 | 0.165 | +0.833 | +0.512 |
| `[70,134)` | 64 | 0.106 | +0.883 | +0.513 |

HSA64 同折：`[20,117)` 能量比 1.163、结构 0.829 对随机 0.853；`[70,134)` 结构 0.979 对随机 0.889。

**结论（两条序列一致）：proportional 宽带的能量只比随机子空间多 16%，结构甚至还略低于随机子空间
（0.399 vs 0.438）。也就是说，"把 C 的谱排好序取中间 72%"这个确定性动作，对跨组图像几乎不提供信息。**

同时注意**能量指标和结构指标给出方向相反的评价**：深频带的能量比只有 0.11（远低于随机），
结构却明显优于随机（0.883 vs 0.513）。所以
**"迁移能量比"不能当作"校准基是否带血"的代理指标** —— Phase 1 若只看能量比会得出相反结论。

## 8. 这一项确立了 / 没有确立什么

**确立（可复现、有对照）：**

- 自投影（任一帧组用自己的基）能复现官方 400 帧参考，相关 0.82–0.85、功率差 13%；三组之间互相关 0.90–0.93。
- 交叉投影（C 的基作用到 A/B）在 SA64 的全部分组上功率低 5–18 倍，结构对无偏上限的达成率掉到 71%。
- 这一失败在六个交叉方向上完全对称 → 不是实现或标签缺陷。
- 宽带频带的能量只比同秩随机子空间高 16%，结构略低于随机子空间 → 频带的**确定性排序**不提供跨组信息。
- 迁移质量是两帧组帧重叠的单调函数（0.067 → 1.01）→ **迁移的是共同的数据实现**。
- 频带下沿的位置比"子空间余弦"更决定成败：lo 从 20 推到 45–70，无偏达成率 71% → 95%，功率降 15 倍。
- 校准组自身的拆半重现性低于跨组重叠，且随 lo 单调下降 → 该帧数下没有"更稳的频带"可选。

**没有确立（不许外推）：**

- 没有证明宽带 P_C 对 A/B 的投影**一定**不含血。它含 0.067 的迁移能量、结构相关 0.40（对称 0.174 重叠时）。
  只能说：**在 SA64 的这些帧约下，它比自投影差得太多，且不优于随机子空间。**
- 没有证明 HSA64 也失败。HSA64 宽带迁移比 0.678、结构相关 0.83。**两序列行为不同，未解释。**
- 没有给出"应该用哪个频带"。§5 的 45–70 是按参考图挑的，不能当结论（见 §9）。
- 没有评价观测对是否可用于训练。本报告只看投影算子这一级。

## 9. 对计划书的影响（以及"这算不算救火"）

计划书 §4「未通过处理」第 3 条写的是：若 `spectral`（唯一可复现的秩带）在 Phase 2 也被判死，
则视为真实未通过、按结论 D 停止，**不再尝试其它秩带**，理由是"换一个秩带正是 §0.5 明令禁止的救火动作"。

本项测量的结果落在一个计划书没预料到的位置上：

- `spectral` 没有被判死，它的迁移比接近 1；
- 但它是**杂乱带**（与血流参考相关 0.15、Dice 0.008、能量占比高一个量级），
  **"可复现"和"有血流"在实测里是反的**；
- 宽带（现在正在用的）迁移极差；
- 而介于两者之间的频带（lo≈45–70）实测上确实能迁移血管结构。

**因此"再试一个秩带"这个动作在本项目里被两次独立测量指向了同一个方向**：
§3（随机子空间对照，不含参考图）说宽带的内容不比随机好；
§5（下沿扫描）说深频带明显好于随机。这两条**都不是**"看图好看就换参数"，
而是同一个机制（频带落在频谱哪一段决定它是帧特有还是共享）的两个侧面。

但这**不构成现在就去改秩规则的理由**，因为：

1. §5 的落点 45–70 是用参考图选出来的。**用参考图选频带就是救火，计划书禁止，我也认这条。**
2. 一个可接受的规则必须**只用校准组自己的数据**就能写出，且在看 A/B/参考之前冻结。
   §6 已经否掉了"按子空间稳定性选"；目前**没有**已知的无泄漏准则能在 SA64 上定位到 45–70。
3. HSA64 的宽带本来就迁移得动，一个按 SA64 调的规则未必对 HSA64 合适。

**建议动作（需用户裁决，不由本报告代决）：**
把 §4 的"秩"从敏感度参数升级为**一个显式的、预注册的机制假设**：
"保留带的成败由它相对杂乱拐点的位置决定，而不是由它的相对占比决定"，
然后**先写出无泄漏的定位准则并冻结**，再在 Phase 2 的同一套门槛下测。
在准则写出来之前，Phase 2 的门槛应按**当前 proportional 频带**跑完并如实出结论
—— 也就是按计划书原意走，不中途换参数。

## 10. 通俗总结

**这一步到底证明了什么**

我们做的事，是把"SVD 滤波"拆成两个开关分别拨动：**这个滤波器是从哪一批帧算出来的**，
以及**它被用在哪一批帧上**。然后把两批帧的所有组合都拍成图，比较这些图。

结果分三层。

第一层，最直白：**同一批帧自己给自己做滤波，图是对的。** 三组 133 帧各自算出的图，彼此像到 0.90，
也都像官方用 400 帧算出的图。这一点挺重要 —— 它说明我们这套 Power Doppler 做法本身没坏，
血管是能被复现出来的。

第二层，是坏消息：**拿一批帧算出来的滤波器，去滤另一批帧，图就废了。**
功率掉到 1/15，跟官方图只有 0.40 的相似度；六个方向试下来全一样，所以不是我们代码写错了。
更糟的是，我们没有找到任何"补救"的道理可讲：我们做了一个随机对照 ——
在那个滤波器挑出来的那一段里，随手乱挑同样多、同样位置的方向，效果居然**一样好，甚至略好**。
换句话说，**我们精心排好的那段滤波器，对另一批帧而言，跟乱挑没什么区别。**

第三层，是我们原来不知道的：**问题不在"两个滤波器像不像"，在"挑的是频谱的哪一段"。**
整条频谱可以粗分成三截：最前面一截是组织运动（强、但每批帧都不同）；
中间一截是还没落下去的残留运动（强、也各不相同）；最后面一截才是血流在的地方。
我们原来的做法，正好把中间那一截也圈进来了 —— 那截能量特别大，
于是图像就由它主导，而那截东西换到别的帧上就对不上号。
把圈的起点往后挪，图像立刻恢复：跟一个完全独立的帧组自己算的图能对上 95%。

**对项目主张意味着什么**

我们现在**不能**再说："从校准帧估出的公共滤波器，能给观测帧产出一张可用的血流图。"
至少对 SA64 这个序列、对我们现在这个频带，这句话是假的。
计划书 §5 里那条"用 C 估投影、作用到 A 和 B"的主方法，**在它当前的参数下不成立。**

也**不能**简单地说"那就把频带调一调"。虽然实测确实有个位置能用，但那个位置是**看着答案找出来的**，
这在方法上等于作弊 —— 计划书自己就禁止这种救火。要留出一条正路，
必须能用**只有校准帧的数据**写出一个准则、先写死、再测，而我们目前还写不出来。

还有一条必须照实说的：**在另一条序列 HSA64 上，宽带本来是能迁移的**（对得上 0.83）。
所以这不是"我们的方法原理上不行"，而是"在 SA64 上不行，原因还没查清"。
把 SA64 的失败当成普遍结论，同样是不诚实的。

**现在不能说、以后也不该说的**

- 不能说"宽带的保留子空间里没有血"（它有一点，只是被淹没）。
- 不能说"深频带就是正确解"（那是看着参考图挑的）。
- 不能说"换个秩规则就能救回来"（校准组自己拆半都不稳定，没有现成的稳定性准则可用）。
- 不能说"HSA64 也一样"（它不一样）。
