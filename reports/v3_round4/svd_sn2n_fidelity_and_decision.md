## 2. 逐项核对

| 组成 | 论文说法（原文要点） | 判定 |
|---|---|---|
| 输入表示 | 单张 **log 压缩后的 SVD 滤波功率多普勒/造影加权图** `y`；输出为去噪后的 log 信号 | **原文确定** |
| 对数操作 | `20·log10(·)`，随后按**指定动态范围裁剪（典型 50–100 dB）**，再 min/max 归一到 `[0,1]`；线性域与对数域走**同一条**下游管线，三种比较只差这一步预处理 | **原文确定** |
| 为什么必须取对数 | SVD 残余是乘性斑纹（`I = S·N`，N 为单位均值 Rayleigh），方差随信号变化 ⇒ 不满足 N2N 的零均值/加性假设；取对数后 `log N` 服从 Fisher–Tippett 律，方差 `π²/24 ≈ 0.411`（自然对数单位）**与信号无关**，且逐点操作不改变空间相关结构 | **原文确定** |
| 两个伴图怎么来 | **Diagonal Resampling**：在每个 2×2 像素块内取 `x1=(p1+p4)/2`、`x2=(p2+p3)/2` → 两张半分辨率伴图；理由是 2×2 块三种二分割里**只有对角分割两伴图共享同一质心**，因此**不引入半像素位移** | **原文确定** |
| Fourier 插值 | 半分辨率伴图用 **Fourier 零填充插值**放回原网格（先镜像填充防边界），理由是**空间域插值会用含噪邻居做线性组合、破坏噪声局部独立性** | **原文确定** |
| 损失 | 自约束 N2N：两项交叉预测（`L(f(x1), x2) + L(f(x2), x1)`）+ 第三项自一致正则 `L(f(x1), f(x2))`，`λ = 1`；损失用 **ℓ1**（收敛到条件中位数，故只要求零中位残差、不要求高斯） | **原文确定**（第三项的具体系数写法见式 (3)，式子在 XML 中以图片/公式给出，逐符号复现属**推断**） |
| 网络 | 2-D U-Net，4 下采样 + 4 上采样，3×3 卷积、BN、LeakyReLU、对称跳连、1×1 **sigmoid** 输出头 | **原文确定** |
| 训练细节 | 单卡 RTX 3080 Ti；patch 128×128；只从训练块取 patch，测试块完全不参与（不用于选模、不用于早停、只推理一次）；Patch2Patch 三种块交换增强 + 90° 旋转/翻转 | **原文确定** |
| 推理 | `f(x1)`、`f(x2)` 两预测取平均；两者逐像素绝对差作为"自一致图"，**明确声明是未标定的相对指标，不是不确定度** | **原文确定** |
| 隐含假设①②③ | ① log 残差零中位、方差与信号无关；② 空间近独立；③ 两伴图信号相同。论文**实测**：① 方差 0.409（预测 0.411），等效视数 1.00，但分布是 Fisher–Tippett 而非高斯（偏度 −1.14、峰度 5.41）；② 2-D ACF 落到 1/e 需 0.70 像素（轴向）/0.91 像素（横向），最近邻相关 0.09/0.31 ⇒ **两伴图噪声相关仍有 0.39**；③ `x1,x2` 相关 0.960，差值标准差 0.128 dB（传播噪声预测 0.143 dB） | **原文确定** |
| 自己的结论边界 | 明确写"SNR 与 FWHM 都是**图像导出**指标，窄 FWHM 只是与更高分辨**相容**、不是证明；未与 ULM/组织学等独立结构参照比较，因此**不主张结构保真**" | **原文确定** |
| 报告的数字 | 相对常规 SVD：图像 SNR +4.2–10.6 dB，表观 FWHM 缩小 34%–59%；**线性域对照只 +1.1–2.4 dB 且不缩窄血管**；增益随基线 SNR 越低越大 | **原文确定** |

## 3. 术语必须分清（同词不同义）

论文里的 "sub-view / 子视图" 是**图像像素域**的 2×2 对角拆分，**不是** SVD 模态/采样几何上的先验干预。
它不涉及"读入 PSF 或残余相关先验、改变采样角色"，
所以 **SVD-SN2N 不能作为本项目 I1（PSF/散斑相关感知正交采样）的支撑证据**，
也不能拿来当"I1 已有人验证"的说法。

## 4. 数值机制检验（本项目数据，零训练）

在同一批**已知真值**的仿真卷（low 档 e902–e905）上，对四种伴图构造各量三件事。
`signal_mismatch_rel = std(S1−S2)/std(S1)`（两伴图信号是否同一），
`noise_corr` 为两伴图噪声的逐像素相关，`noise_var_ves` 为伴图噪声在血管区的方差
（不拆分的原始值为 **8.0e-4**）。下表为 4 卷中位数：

| 构造 | 信号失配 | 信号形变 | 噪声相关（血管） | 伴图噪声方差 | 触点位移（体素） |
|---|---|---|---|---|---|
| 本项目 VALID tet（{0,1,2,4} vs {3,5,6,7}） | **0.122** | 0.063 | 0.056 | 1.75e-4 | (0.5,0.5,0.5) |
| 同上 + Fourier 插值 | 0.110 | 0.059 | 0.054 | 1.64e-4 | 同上 |
| **共享质心** tet（{0,3,5,6} vs {1,2,4,7}） | **0.00056** | 0.001 | 0.114 | 1.98e-4 | (0,0,0) |
| 同上 + Fourier 插值 | 0.00052 | 0.001 | 0.064 | 1.65e-4 | (0,0,0) |
| 论文 2D 对角（逐 z 切片） | 0.0065 | — | 0.027 | 4.04e-4 | (0,0,0) |
| 同上 + Fourier 插值 | 0.0058 | — | −0.019 | 3.61e-4 | (0,0,0) |

**三条可核验的结论**

1. **VALID 的 8 个 tetris 模式没有一个共享质心**（脚本逐模式核验，`any_shared = false`）。
   因此本项目的默认 tet 配对**天然带 (0.5,0.5,0.5) 体素的体对角位移**，
   实测造成 **12%** 的信号失配；论文强调的那条性质，我们的采样器**恰好不满足**。
2. 把配对换成共享质心的 `{0,3,5,6}/{1,2,4,7}`（"偶宇称对奇宇称"），
   信号失配从 0.122 降到 **0.00056（约 1/220）**，且噪声方差基本不变（1.75e-4 → 1.98e-4）。
   这是一条**改动极小、收益方向明确**的采样器改动，但本轮**没有训练验证**，只能登记为待验证假设。
3. Fourier 插值在本仿真上**没有**引入明显的伴图噪声相关（0.114 → 0.064，2D 上 0.027 → −0.019），
   即论文"带限插值不破坏噪声独立性"的说法在我们的数据上没有反例；
   但它的代价是每张伴图只能做 2 点平均（2D）/4 点平均（3D），**单伴图噪声方差降得比 tet 少一半**。
   两者是不同取舍：**信号几何 vs 单伴图噪声**。

**这条测量不支持的推论（明确写下）**：噪声相关更低 ≠ 训练更好；本轮**没有**训练任何
"SVD-SN2N 式"网络，因此不能声称"照论文做会更好"。

## 6. 通俗总结

这一步是去读一篇 2026 年的同类工作，并回答一个问题：**"别人已经证明了对数化有用"，这个说法在我们这里能不能直接用？**

能直接用的部分：那篇论文做了一件很朴素但关键的事——把图先取对数再训练，并明确说这就是它有效的原因。
它自己的对照实验说得很清楚：同一个网络、同样的训练，**线性输入几乎学不到东西（图像质量只提升一点点、血管不变细），
对数输入才明显变好**。这一点和我们 Round3 看到的现象一致（我们的网络输出几乎等于输入、只是幅度被压了一点）。
所以"用对数域"是有独立证据的操作，而不是玄学；我们 Round4-B1 的三臂实验正是在测同一件事。

不能直接用的部分有三条。第一，它没有代码"子视图"是真正的创新——它的"子视图"只是把一张图按像素对角拆成两半，
**和我们要做的"按采样几何/物理先验来挑选样点"完全不是一回事**，所以不能说"I1 已经有人验证过了"。
第二，它自己就承认：它用的两个图像指标（信噪比、血管宽度）**不能证明结构是真的**，
它没有和任何独立的血管参照对齐过。第三，它的超参数表是图片，读不到具体数值，所以"照抄"是不可能的。

我们自己额外量到一条有用的东西：论文强调"对角拆分的两半必须共享同一个中心，才不会错开半个像素"。
我们的采样器（VALID 那一套）**八个模式没有一个满足这条**，实测会让两半看到的结构差 **12%** 左右；
换成一个满足这条的分法，差异掉到 **0.05%**，而噪声水平基本不变。这是一个"改动很小、方向清楚"的候选改进，
但这一轮**没有训练验证**，所以它现在还只是一个待验证的想法，不能写成"发现了提升方法"。
