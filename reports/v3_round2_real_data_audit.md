## 2. R0-1：资产核查（够不够、能不能算）

形状、dtype、有限性、帧率、秩带切片全部通过（见 §1）。两条序列都是 400 帧、37×64×64，
可以按同一套流程跑；`tests/test_v3_round2_r0.py` 固定了 7 条不变量
（形状/轴序保持、带通恒等式、PD 非负且 `sum = mean × T`、块长归一化 `0.5*(pa+pb) == 全长`、
固定基下秩带投影是时间维度上的线性算子、ACF 与相关长度在合理范围）。

一条**订正类**的固定事实（测试里也写着）：官方秩带投影**不是**逐体素线性算子。
基 `V` 由整卷数据算出（数据依赖），所以改动一个体素会改变基、进而改动所有体素的输出。
R0-3 要求的"投影算子与分块无关"是在**固定基**意义下成立的，测试就按这个口径写。

## 3. R0-2：真实数据里有没有可恢复的噪声

### 3.1 两条互相独立的噪声代理（G-R0-a）

| | SA64 | HSA64 |
|---|---|---|
| 代理①时间：4×100 帧块间差 `mse/2` | 1.189e-2 | 1.283e-2 |
| 代理②空间：同一噪声场上的 4×4×4 块内方差（去均值偏差修正 ×4/3） | 1.025e-2 | 1.100e-2 |
| 比值（判据区间 [0.5, 2]） | **0.86** | **0.86** |
| 判定 | **pass** | **pass** |

两个 0.86 不是巧合：两条代理估计的是同一个量（100 帧块级 log PD 的噪声方差），
差 14% 来自空间代理在块边界与平滑静态分量上的少量泄漏。

**这条判据的正确做法要写清**：两条代理必须落在**同一个场**上才能比。第一版实现里，
空间代理直接作用在 400 帧的 log PD 上，那里噪声只有块级的 1/4，还混着静态散斑的空间涟漪，
于是得到一个"空间噪声比时间噪声大 2.5 倍"的**假比值**。把它改成在块间涨落场
`F_b = log PD_b − mean_b(log PD)` 上算，才是同一个量。JSON 里两个比值都保留
（`ratio_controlled_noise_field` 与 `ratio_naive_full_log_pd`），假比值也留档，说明为什么要改。

### 3.2 噪声有多大（相对量）

| 指标 | SA64 | HSA64 |
|---|---|---|
| 背景相对波动（块间标准差 / 均值） | 9.61% | 9.94% |
| 血管相对波动 | 13.2% | 19.2% |
| 背景块间方差 / 平均功率 | 0.92% | 0.99% |
| 背景 log PD 总方差 `Var(log PD)` | 2.16e-2 | 3.29e-2 |
| 其中噪声占（400 帧图，block-level/4） | ≈13.8% | ≈9.7% |

对照 v2 仿真：`reports/v3_r06/v2_endpoint_audit.json` 的 q3_n2n 口径给出噪声/总方差
2.02%（s30）/ 1.70%（s31）。**真实数据的噪声相对占比比 v2 仿真高约 5–7 倍**，
对应等效 `σ_ε ≈ 0.07`，正好落在 S0 噪声阶梯的"mid"档（0.077）。
这是"真实数据优先"最硬的理由：仿真把噪声做小了，任何"去噪无收益"的结论在仿真上都更容易成立。

### 3.3 噪声的空间结构（这次量准了）

用块间差得到的 log PD 噪声 ACF（lag 1）与相关长度：

| | SA64 | HSA64 |
|---|---|---|
| lag1 ρ(z, y, x) | −0.006 / 0.425 / 0.169 | 0.050 / 0.505 / 0.235 |
| 相关长度（体素） | 0.63 / 1.16 / 0.76 | 0.67 / 1.34 / 0.83 |

含义：**真实噪声在空间上接近白**（相关长度 ≈1 个体素），只在 y 轴上有可见的 1 像素相关。
这一点在下一节起决定作用。

### 3.4 R0-3：配对可分性（G-R0-c）

同样 200 帧一半的两种拆法，噪声占比（越大 = 两次观测越"不像"）：

| | SA64 | HSA64 |
|---|---|---|
| 背景：奇偶拆分 / 连续前后半 | 0.233 / 0.274 | 0.153 / 0.201 |
| 血管：奇偶拆分 / 连续前后半 | 0.073 / **0.291** | 0.013 / **0.204** |
| 判定（差 > 2 个百分点） | **pass** | **pass** |

血管区差 3–6 倍：连续前后半把慢运动/漂移也算进了"噪声"，奇偶拆分则不会。
**所以"用哪一半当配对"本身是主导因素之一**，不存在唯一正确的伪配对——
这条以前没有量过，现在有了。

再进一层（`r0_3_pairing`）：把 g0、g1 当两次观测、用 g2+g3 的 PD 当共享信号估计，
扣掉共享信号后两次观测的残差相关是：

| | SA64 | HSA64 |
|---|---|---|
| 背景 | 0.357 | 0.374 |
| 血管 | 0.509 | 0.444 |
| g0 与 g1 本身的直读相关（背景） | 0.625 | 0.718 |
| 共享信号占背景方差 | 61.6% | 71.0% |

残差相关 0.36–0.37 说明：**即使扣掉共同信号，两半之间仍有约三分之一强的成分是共享的**
（未建模的慢运动、非线性、以及共用的固定基）。伪配对**不能**当成独立同分布的两张观测，
这一点在写 B/C/D 的结论时必须显式带上。

## 4. log 域条件方差（G-R0-b）

背景区按信号分位分 8 箱，`Var(log PD_0 − log PD_1)` 与 `PD_0` 的关系：

| | SA64 | HSA64 |
|---|---|---|
| 线性域 `Var(noise)` vs 信号 的斜率（双对数） | **2.15** | **2.14** |
| log 域 `Var(log noise)` vs 信号 的斜率 | **−0.93** | **+0.24** |
| 判定（|slope| ≥ 0.10） | **pass** | **pass** |

斜率 ≈ 2（线性域）是"噪声功率与信号成正比"——即**乘性噪声**的签名；
变换到 log 域后斜率接近 0（−0.93 与 +0.24 落在 0 的两侧，符号在两个数据集上相反），
说明 **log 变换把"噪声强度依赖信号"这件事基本消掉了**。
这不是"log 域噪声完全与信号无关"的证明（HSA64 的 +0.24 仍显著），
但它是 2026 超声 SVD-SN2N 那条核心物理前提（乘性散斑 → 一次对数压缩 → 加性信号无关）
在**本数据**上的直接支持。

## 5. 更正：SN2N 子视图前提的旧读数被共享散斑污染了

旧文档 `reports/v3_R11/sn2n_difference_matrix.md` §3.1 写的是"两张对角子视图的噪声相关
0.90–0.95，前提彻底不成立"。审查 §0.8 指出那是把**共享静态散斑**当成了噪声。这次直接量：

在**只剩噪声的场**上做 SN2N 的 2×2 对角视图（`A=(ul+dr)/2, B=(ur+dl)/2`），
背景区、四像素都在背景内的块，阈值 0.10（与旧脚本相同，跑之前就写在文件里）：

| 数据 | 平面 (y,x) | 平面 (z,y) | 平面 (z,x) |
|---|---|---|---|
| 真实 SA64 · 噪声场（块间差） | **0.393** | 0.379 | 0.171 |
| 真实 HSA64 · 噪声场 | **0.306** | 0.260 | 0.080 |
| v2 仿真 s30 · 噪声场（两次独立观测之差） | **0.973** | 0.966 | 0.966 |
| v2 仿真 s31 · 噪声场 | **0.973** | 0.964 | 0.967 |
| 对照：真实 SA64 · 全图 log PD（含静态散斑） | 0.432 | 0.383 | 0.238 |
| 对照：旧口径原始 PD（含静态散斑，未取 log） | 0.945 | 0.936 | 0.907（旧文档表内值） |

三件事必须分开说：

1. **旧数字确实被污染了**：原始 PD 上 0.945，换成噪声场后降到 0.17–0.39。
   审查 §0.8 的批评成立，旧文档 §3.1 的"塌得很彻底"这句要收回。
2. **但前提仍然不成立**：0.17–0.39 都高于预注册的 0.10。SN2N 的自约束项要求两视图噪声无关，
   噪声还有 17–39% 的相关，那条约束仍会部分退化成"复制同一条相关噪声"。
   结论方向不变，程度要改。
3. **仿真比现实更糟（新发现）**：v2 仿真噪声的对角相关是 **0.97**，比真实数据高 2.5–5 倍。
   原因是模拟器把热噪声也过了 PSF 平滑（`thermal_sigma=(1.0,1.2,1.1)`，lag1 ρ≈0.78–0.84），
   而真实噪声接近白（lag1 ρ_y 0.43–0.51）。**推论**：任何"因为噪声相关所以 N2N 型方法不行"
   的判断，如果只在 v2 仿真上做过，都偏悲观；在真实数据上，噪声独立性这一前提**比仿真好得多**。
   这条不影响本轮 R0 的判定，但必须写进限制，并且它是下一步该优先用真实数据而不是仿真的直接理由。

`thermal_sigma` 目前没有标定来源（只在 `scripts/v3_simulator.py` 里写死），
这一轮**没有**改它——改噪声模型属于方案变更，要先单独立项并给出标定证据，不能顺手调。

## 6. 能说 / 不能说

**现在能说**
- 真实 Dryad 数据的资产、帧率、秩带切片与 SHA256 都核对过，可以放心跑对比。
- 真实数据里有可测的残余噪声，两种互不依赖的估计给出同一个量（比值 0.86/0.86）。
- 噪声在真实数据上**接近空间白**（相关长度 0.63–1.34 体素），只在 y 轴有 1 像素相关。
- 噪声在真实数据上相对方差占比约 10–14%，比 v2 仿真的 1.7–2.0% 高 5–7 倍。
- 线性域噪声方差 ∝ 信号²，log 域斜率接近 0 ⇒ 乘性噪声 + 一次对数压缩这条物理链在本数据上成立。
- 奇偶拆分与连续前后半拆分在血管区读数差 3–6 倍 ⇒ 配对方式本身是主导因素。
- 对角子视图的**噪声**相关在真实数据上是 0.17–0.39（> 0.10 阈值），在 v2 仿真上是 0.97。

**现在不能说**
- 不能说"SN2N 的独立子视图前提在真实数据上成立"——0.17–0.39 仍高于 0.10。
- 不能说"SN2N 在超声上行/不行"——前提读数只是必要条件，方法实际掉多少必须真跑（本轮没跑）。
- 不能说"我们的伪配对等价于两次独立观测"——扣掉共享信号后残差相关还有 0.36–0.37。
- 不能说"仿真结论可以直接外推到真实数据"——两者噪声结构差 2.5–5 倍，方向和量级都可能变。
- 不能把旧的 0.90–0.95 继续当作"噪声相关"引用，它是"背景涨落相关"。

## 8. 通俗总结

**这一步到底证明了什么。** 审查把"先把真实数据摸清楚"排在第一位，理由是：如果真实超声图里根本
没有能去掉的噪声，那后面所有"去噪方法好不好"的实验在一个假问题上打转。我按审查给的判据
（写在跑之前，不是看到结果再定）去量了两份真实数据，结论是**噪声确实在，而且量得出来**：
同一份数据用两种互不依赖的办法算出来的噪声大小几乎一样（比值 0.86，判据要求 0.5–2 之间），
说明这不是某一种算法的错觉。噪声有多大？大概占背景起伏的十分之一多一点。
噪声长什么样？很细，基本一个像素就换一个样，不像我们仿真里那样糊成一片。

**顺带纠正了自己以前的一个说法。** 之前我写过"两张错开的半图里噪声相关高达 0.90–0.95，
所以某类自监督方法的地基塌了"。这次分开量以后发现，那个 0.9 里绝大部分是**两份半图共享的
静止背景图案**，不是噪声本身。把背景共享部分扣掉，噪声的相关只有 0.17–0.39。
所以那句话要说轻：地基是松的，不是塌的。方向上"这类方法的前提不成立"仍然成立
（0.17–0.39 仍然超过 0.1 的红线），但程度差了 2–3 倍。

**还挖出一件更值得注意的事。** 我们自己的仿真数据里，噪声被"抹平"得比真实数据厉害得多
（相关 0.97 对 0.17–0.39）。也就是说，过去只在仿真上得出的"噪声太相关所以这招不行"，
放到真实数据上会宽松不少。这不改变本轮结论，但说明**下一步必须用真实数据说话，
不能继续拿仿真替代**。

**哪些说法现在还不能说。** 不能说"某类方法的独立子视图前提在真实数据上成立"（0.17–0.39
仍然超标）；不能说"那个方法在超声上到底行不行"（这轮没跑它）；不能说"我们的伪配对就是两次
独立观测"（扣掉共同部分后还有三成多的共享成分）；更不能拿仿真结论直接外推到真实数据。
