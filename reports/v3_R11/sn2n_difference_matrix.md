## 1. 逐项差异矩阵（左列 = SN2N v0.3.5 的实际代码行为，右列 = 本项目 V3 / VALID）

| 维度 | SN2N v0.3.5（代码位置） | 本项目 V3 / VALID | 后果（为什么不能互相代替） |
|---|---|---|---|
| **输入数值域** | 逐帧 **percentile 归一化**到 0–255 再 `/255`：`percentile_normalization.py` 用 `pmin=20, pmax=99.9`（注释说明这是为"超低信噪比 + 高本底"设的），随后 `datagen.slidingWindow3d` 里 `255*normalize(...)`（`normalize` = 逐 patch min-max） | `log1p(PD/s)`，`s = median(PD[valid])`，**不做逐 patch min-max**，不做百分位裁剪 | 两者都"压缩动态范围"但机制完全不同：SN2N 的 min-max 是**逐 patch** 的，等价于把每个 patch 的本底和增益都消掉；我们的 log1p 保住了跨 patch 的绝对电平。**所以"我们做了 log"绝不等于"满足 SN2N 的前提"** |
| **子视图构造** | xy 平面 2×2 交错取样后**对角线平均**：`block3d` 里 `left = ul/2 + dr/2`、`right = ur/2 + dl/2` → 每个输出像素是 4 个体素的平均（2×2 块的两个对角像素），**时间轴完全不参与** | 3D 立方体 8 相位（`datasets/sampling.one_phase`），每个相位取**一个**体素、**不做平均**；时间轴保留 | 这是最本质的差异：SN2N 的两张"观测"是**同一个 2D 平面上两组对角像素的均值**，噪声相关性由"2×2 块内对角像素的独立性"决定；我们的 8 相位是**逐体素**划分，既不平均也不跨相位混合 |
| **维度** | 2D（xy）；3D 版只是把多帧叠成 `(t,H,W)` 的通道/深度，**仍只在 xy 上做子视图**（`generator3D` 只切 xy） | 真 3D（z,y,x 三个轴都切） | SN2N 的 3D 严格说是"**2.5D**"：z 方向的噪声相关性**没有**被任何机制处理。若直接用在本项目数据上（z 只有 37 层且 PSF 在 z 上 σ=3.0），z 方向的相关噪声会被原样保留 |
| **插值/上采样** | **傅里叶零填充**：`fourier_inter` 先用对称填充把图扩到 `2n−1`，再用 `interpft`（MATLAB `interpft` 的移植，FFT 频域补零）插值回 2× 尺寸，负值截 0。默认 `ifx2=True, inter_mode='Fourier'` | **没有插值**：8 相位本身就是原分辨率体素，推理时整卷滑窗，不需要上采样 | SN2N 的"标签"是 2×2 平均后的低通图像再经傅里叶插值**伪造**出的原尺寸；这等于**主动把高频去掉再补回去**。我们的相位视图是真实采样，不用伪造 |
| **配对关系** | 固定的两组（left / right），P2P 增广里可做"t 方向互换"（`P2Pmode=1`）、"单帧内互换"（2）、"多帧不同区域互换"（3） | 预注册的有序角色对（`v3_phase2_role_order.md` §4）：体对角 = 泄漏最小；`cross` 配对（输入 tet A、目标互补 tet B） | SN2N 的配对**由几何唯一决定**（对角 vs 反对角），没有"选哪个当输入"的自由度；本项目整个创新点就在这个自由度上，**两者不是同一个设计空间** |
| **损失** | 双向前向 + **自约束**：`loss = (L1(f(x),y) + L1(f(y),x) + w·L1(f(y),f(x)))/(2+w)`，`w=1`；`criterion = L1Loss`；Adam `lr=2e-4, betas=(0.5,0.999)`，`ReduceLROnPlateau` | `0.5·MSE(h(xa),ya) + 0.5·MSE(h(xb),yb) + 1e-4·wavelet_hessian + 1.0·MSE(ha,hb)`，Adam `lr=1e-4, betas=(0.9,0.999)`，poly 衰减，`clip_grad=100` | 损失不同（L1 vs MSE + 小波 Hessian 正则）、优化器超参不同、学习率调度不同。**"换成 log 再训"复现不了任何一条** |
| **网络** | `Unet_2d` / `Unet_3d`，通道 64→128→256→512→512，**输出经 sigmoid**（因此必须吃 0–1 的输入） | `NetworkCNR`（f16, g4，含 DWT 子带），无 sigmoid | 输出端有 sigmoid 就意味着 SN2N 的输出被硬性限制在 0–1 且**不可能超过输入的最大值**；这在保本底的任务上是一个强先验 |
| **推理** | 逐帧（2D）/ 逐 volume（3D）分块，`overlap_shape` 线性羽化融合（`Predictor3D`），并对**训练过程中的多个快照模型**分别推理后再平均（`infer_mode=0`） | `infer.py` 整卷滑窗 + 重叠平均（overlap 0.1），**单一最终 checkpoint** | SN2N 默认做了"多快照模型平均"（一种 test-time ensembling），我们没有。任何公平比较必须把这个差异写明 |
| **数据单位** | 以 tif 帧为单位，逐帧处理后写盘；训练集是 patch 拼贴 | 以 3D 体为单位（`(37,64,64)`），patch 从体里裁 | 判据的"独立样本"单位不同，统计独立性不能混谈 |
| **适用对象** | 荧光显微（超分辨）"空间冗余 + 泊松-高斯混合噪声"，噪声在**空间上近似独立** | 超声 Power Doppler（散斑 + 杂波 + 静态回波），噪声在**空间上强相关**（PSF σ=(3.0,2.37,3.97)），且时间轴上有 SVD 可分的杂波 | **适用前提不同**：SN2N 的对角重采样假设"对角像素的噪声独立"，而超声散斑的噪声在一个 PSF 体积内是相关的（约 10³ 个体素）。这条差异决定了 SN2N 的子视图构造不能直接搬过来 |

## 2. 逐项核对"哪些结论现在可以下、哪些不能"

**可以下（有代码证据）**：
- SN2N v0.3.5 的关键步骤 = percentile 归一化 → xy 对角 2×2 平均子视图 → 傅里叶零填充插值回 2× →
  双向 L1 + 自约束 → U-Net(sigmoid) → 分块羽化融合 + 多快照平均。上面每一条都能指到具体函数。
- 「做一次 log1p 就等于 SN2N」是**错的**：两者在子视图、插值、损失、推理四处都不相同（§1 第 2/4/6/7 行）。

**不能下**：
- 不能说"我们复现了 SVD-SN2N"——**没有可核对的原文/代码**（§0）。
- 不能说"SN2N 在超声上不适用"——本轮没有任何 SN2N 实验数据。
- 不能说"SN2N 的子视图假设一定被超声破坏"——这是个**可测**的问题（下节给出测法），但目前没测。

### 3.1 上表最后一条"先做"的检验：**已做，前提被证伪**

`scripts/v3_r11_sn2n_subview_test.py`（阈值 0.10 写死在跑之前）在背景区直接测
`corr(A,B)`，A、B 就是 SN2N 的两条对角均值视图：

| 数据 | 平面 (y,x) | 平面 (z,y) | 平面 (z,x) |
|---|---|---|---|
| 真实 **SA64** | **0.945** | 0.936 | 0.907 |
| 仿真 v2 s30 | **0.927** | 0.910 | 0.911 |
| 仿真 v2 s31 | **0.923** | 0.906 | 0.915 |
| 解析（实测 ACF 快速分量，去平台） | SA64 0.896 / HSA64 0.929 / v2 0.919–0.932 | — | — |

实测与解析两条路给出一致的结论：**两张"视图"的噪声相关 0.90–0.95**，不是 0。
判定：SN2N 的独立子视图前提在本数据上**不成立**，而且偏差极大（阈值 0.10，实测高一个量级）。

这说明三件事：
1. 直接把 SN2N 搬到超声上，它的自监督约束会接近"从相关噪声预测同一条相关噪声"，
   这与本项目在 m=1 上测到的相位间泄漏 0.125–0.734 是同一个物理原因（PSF σ≈3 体素）；
2. 本项目"用实测相关性去挑位移最远的角色对"这条路，方向上正是对这一前提的修补
   （m=2 体对角线把泄漏压到 0.017）；
3. **在此之前不能说"SN2N 在超声上行/不行"**——现在能说的是"它的前提在本数据上不成立"，
   至于"前提不成立时方法实际掉多少"，仍然必须真跑才知道。

**口径诚实说明**：实测那列用的是背景区原始 PD 的相关，含**静态散斑**（它是本任务里"该保留"
的成分），所以严格说是"背景涨落的相关"而非纯热噪声的相关；解析那列用的是**去平台**后的
快速分量（0.896–0.932），两种口径结论相同，故这一条不影响判断。

## 4. 通俗总结

**这一步到底证明了什么。** 两件事。第一，审查方要求"把 SN2N 整个方法拿来对照，而不是只把数据取个
对数"——我核对后发现确实差得很远（机制层面四处不同，见上表），**而且我们没有做过它**。第二更硬：
SN2N 的地基假设是"一个 2×2 小方块里两条对角线上的像素，噪声彼此独立"，我在真实数据和仿真数据上
都量了，**两条"视图"的噪声相关是 0.90–0.95**，不是接近 0。地基是塌的，而且塌得很彻底。
我核对的结果是：**这两件事差得非常远，而且我们这边从来没有做过前者**。SN2N 的做法是——先把图像按
百分位压到 0–255，在水平面上把 2×2 的小方块按对角线平均成两张图（一张取左上+右下，一张取右上+左下），
再把它们用频域补零的方式插值放大回原尺寸，然后拿一个输出被压缩到 0–1 的 U-Net 双向训练、
训练中还要求两张图各自的预测互相靠近，最后推理时把若干个训练快照的结果平均起来。
我们这边是——取对数、按 8 个相位逐体素抽稀、没有插值、均方误差加小波正则、单模型整卷推理。
**四处关键机制完全不同，所以"我们试过 SN2N"这句话目前不成立。**

**对项目主张意味着什么。** 短期的意思：审查方在这一点上是对的，这是本轮一个真实的缺口，
我不打算用"我们做过 log"来掩饰。中长期的意思更重要：这个检验**反过来支持了我们自己的技术路线**——
我们做"用实测相关性挑位移最远的角色对"，本质上就是在修补 SN2N 那个塌掉的地基：m=2 的体对角角色对
把相位间泄漏从 0.125–0.734（m=1）压到 **0.017**。所以下一步该做的不是花算力去忠实地跑一个前提
已知不成立的方法，而是先量清"前提不成立时损失多大"，再决定要不要跑。

**哪些话现在不能说。** 不能说"我们复现了 SVD-SN2N"（找不到可核对的论文/代码，我不会拿一个同名
但无法核实的来源去顶替）；不能说"SN2N 不适合超声"（没跑）；不能说"SN2N 的关键就是取对数"
（被本节逐条否掉，最本质的是对角平均与频域插值，不是数值域）；也不能说"实验 D 已准备好"
（只有骨架，前置门还没过）。

**剩余风险**：① 我核对的是 v0.3.5，作者已把开发迁到新仓库，新版本可能有变化；
② 若审查方所指的 "SVD-SN2N" 是另一篇具体论文，本矩阵需要按它的官方代码重做；
③ 即便将来做了"近似 3D 扩展版"，它也**不能**当作原论文在小鼠/荧光数据上的复现结果来引用。
