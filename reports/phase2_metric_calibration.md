# 残差 proxy 的标定：这把尺子到底量的是什么

日期：2026-10-19　代码：`scripts/audit_metric_calibration.py`、`scripts/analyze_metric_calibration.py`
数据：`reports/phase2_calibration_2026-10-19/`

---

## 1. 结论

**尺子有刻度，但刻度不对应"噪声是否独立"；而且两臂情形下没有别的公式可以顶上。**

两条发现：

1. **`rel_matched` 量的是"两张图像不像"。** 它与两臂功率图相似度的 Spearman 达
   **+0.93…+0.98**；在**两臂零重叠**（完全不相交，独立性由构造保证）这个共同前提下，
   三种时间切法读出的数相差 **8 倍**（SA64 −0.040 / −0.153 / −0.317，加上 HSA64 的 −0.012
   则跨度 27 倍）。同一设计内它随臂重叠单调（16/16），说明尺子对"两臂变得更像"确有反应，
   只是它反应的不是独立性。

2. **置换估计量的尝试也失败了。** 直接测两臂噪声的复相关系数，在小 N 时被"两臂共享的
   减去均值"支配（恒为 +0.999，与独立性无关），在全 N 时被"求和为零"的有限池约束推向负值
   （−0.10…−0.44）。见 §5.1 与更正说明。

按预先声明的判定规则，这落入第 3 条：**构念有缺陷 → 必须换指标，不是调参数。**
而且第 2 条发现限定了换法：**必须改变臂的数目（或引入外部真值），换公式不够。**

## 2. 实验设计：不用合成模型

审计裁决里悬而未决的问题是：−0.163 这个数没有刻度，不知道它代表"噪声独立"还是"帧切得不同"。

**做法**：既然任何合成噪声模型都要赌一个假设，就不建模型。直接在真实 IQ 上操纵
**两臂的帧重叠比例**：

```
A = A0[n_shared:] + B0[:n_shared],    B = B0,    n_shared = round(overlap × |A0|)
```

`overlap=0` 就是 Phase 2 的原设计（两臂不交），`overlap=1` 是两臂完全相同。
真实折、真实校准集 C、真实秩规则、真实匹配算子、真实块统计——除帧成员外一行不改。

这个扫描自带两个可证伪的锚点：

| 锚点 | 要求 | 结果 |
|---|---|---|
| overlap=1 | 两臂是同一张图，匹配算子把两者变成互补半边 = 恰好就是 Tetris 对照，故 `rel_matched` 必须**精确为 0** | SA64 64 个格点、HSA64 12 个格点，最大 \|rel\| = **0.00e+00** ✅ |
| overlap=0 | 必须复现审计的 matched 数字 | SA64 as_impl −0.259/−0.305、f0_free −0.162/−0.195（审计：−0.259/−0.304、−0.163/−0.194）✅ |

锚点 2 在第三位小数上一致，说明本脚本与已审计的代码路径是同一条。
锚点 1 是硬验证：只要实现有任何偏差，这个格子就不可能是 0。

**为什么不用合成数据。** 先后建过四个生成器，全部败在同一个地方，而且都是先测出来才发现的：

1. 逐体素时间相位随机化——保留 `|E_v(ω)|` 让每一帧的逐体素功率都相同，两臂都塌到同一个固定包络，
   白噪声下臂间 r 也读到 0.998；
2. 复 AR(1) 噪声——再平均 N 帧仍然只剩包络，且丢掉真实帧的突发性；
3. 拿真实残差帧当池子——`e` 已减去 400 帧均值，无放回抽样的两臂被强制反相关，
   实测 N=133 时 −0.10、N=20 时 +0.88；
4. 空间相位随机化的帧——每帧的功率图变成"该帧总功率 × 平均谱密度"，逐帧空间异质性被抹平。

四者在 `rel_matched` 上对"真实臂间相关"都呈**三位小数完全平坦**。与其继续调生成器直到它给出
想要的答案，不如把手按在真实数据上——这个操纵对数据本身零改动。

## 3. 曲线：rel_matched 随臂重叠的走势（f0_free, proportional）

| split | N_A | ov=0 | 0.25 | 0.5 | 0.75 | 0.9 | 1 |
|---|---|---|---|---|---|---|---|
| sa64_cont3 | 132 | **−0.317** | −0.222 | −0.159 | −0.062 | −0.023 | +0.000 |
| sa64_int5 | 79 | **−0.153** | −0.107 | −0.077 | −0.050 | −0.025 | +0.000 |
| sa64_int3 | 132 | **−0.040** | −0.025 | −0.019 | −0.010 | −0.001 | +0.000 |
| hsa64_int3 | 132 | **−0.012** | −0.010 | −0.009 | −0.006 | −0.002 | +0.000 |

按 (variant, rule, split) 分组的 12 条曲线**全部单调不降**（12/12）。
所以问题是清楚的：在**固定设计内**，尺子对"两臂共享多少帧"是单调、可用的。

问题出在同一个 overlap=0 上：三条 SA64 曲线的起点相差 **8 倍**，而它们的共同点是
**两臂一帧都不共享**。三种切法都满足"噪声独立"这个前提，却一个不过门槛（int3, −0.04）、
一个勉强过（int5, −0.15）、一个大过（cont3, −0.32）。

## 4. 门槛 `rel ≤ −0.10` 实际在测什么

把上面每条曲线与门槛求交，得到"门槛能容忍两臂共享多少帧"：

| split | 通过的 overlap 上界 | 读法 |
|---|---|---|
| sa64_cont3 | **≤ 0.5** | 两臂共享一半帧仍然过——门槛几乎只能拒绝"完全相同" |
| sa64_int5 | **≤ 0.25** | 共享四分之一帧过 |
| sa64_int3 | **无** | 零重叠也过不了 |
| hsa64_int3 | **无** | 零重叠也过不了 |

同一组真实帧、同一个校准集大小、同一个秩规则，**只因为帧在时间上的排布不同**，
门槛就从"怎么都能过"变成"怎么都过不了"。门槛测的不是噪声独立性，是时间排布。

## 5. 它到底跟着什么走

跨全部格点（两序列、两 variant、两规则、6 个 overlap）：

- 与**两臂功率图相似度** `power_map_r`：Spearman **+0.976**（SA64）/ **+0.928**（HSA64）

这是本节唯一站得住的结论：`rel_matched` 是**两臂图像有多像**的单调函数。

> **更正（同日，见 §5.1）。原本这里还并列了一个"真实臂间噪声相关 `rho_eff`"的对比
> （主扫描 Spearman +0.703，臂预算扫描 +0.193，并附一组"相关性越高、分数越好"的反例）。
> 该对比全部撤回：`rho_eff` 这个估计量在两端都是坏的，不能充当"真实相关"的参照。**

### 5.1 撤回：`rho_eff` 估计量本身无效

原估计量：`e = x − mean_over_400(x)`，然后 `rho = Re⟨conj(mean_A e), mean_B e⟩ / (…)`。
问题出在那次减均值——它减掉的是**两臂共享的同一个固定向量**，而臂均值里真正属于该臂的部分
可能远小于它。直接测（`sa64_int3_c0a1b2` / `sa64_int5_…` / `sa64_cont3_…`，取首折）：

| split | N | ‖dA‖² | ‖dA‖²/‖μ‖² | rho(core) |
|---|---|---|---|---|
| int3 | 10 | 1.588e+06 | **4.96e-01** | +0.9996 |
| int3 | 20 | 1.331e+06 | 4.15e-01 | +0.9998 |
| int3 | 40 | 9.279e+05 | 2.89e-01 | +0.9999 |
| int3 | 133 | 3.426e+01 | **1.07e-05** | −0.1883 |
| int5 | 80 | 4.486e+02 | 1.40e-04 | −0.1023 |
| cont3 | 133 | 9.822e+04 | 3.06e-02 | −0.4373 |

（`‖μ‖² = 3.206e+06`；`dA = mean_A x − μ`。）

两端各有一个机制，都不是噪声独立性：

1. **小 N ——共享偏移支配。** `‖dA‖²/‖μ‖²` 在 N=10 时是 0.50，N=133 时是 1.1e-05，
   跨四个数量级。小 N 下臂均值几乎就是 `−μ` 本身，两条臂因此"高度相关"，
   而 `μ` 根本不是噪声。这就是被否掉的模型 3 的同一个 bug，换到真实数据上依然发作。
2. **全 N ——有限池求和为零强制反相关。** `Σ_{t∈400}(x_t − μ) = 0`，任何两个接近覆盖 400 帧的
   不相交子集，其均值的相关被这个约束推向负值。表里全 N 的三个数（−0.19 / −0.10 / −0.44）
   全是负的，就是这个约束，不是物理。

两个方向都错，中间没有可用区间。**结论：在只有两条臂的情况下没有可用的噪声相关估计量。**

### 5.2 撤回之后，还剩什么

三条不依赖 `rho_eff` 的证据仍然成立，而且足以支撑判定：

| 证据 | 数值 | 是否依赖 rho_eff |
|---|---|---|
| 同一设计内 rel 随臂重叠单调 | 16/16 条曲线 | 否 |
| **零重叠时不同设计之间 rel 相差 8 倍** | SA64 −0.040 / −0.153 / −0.317 | 否 |
| rel 与 `mapR` 单调 | Spearman +0.93…+0.98（含臂预算扫描 +0.932） | 否 |

第 2 行是核心：三条曲线的共同前提都是**两臂一帧不共享**。若该指标测量的是噪声独立性，
这三者应当相等；它们相差 8 倍（连同 HSA64 的 −0.012，跨度 27 倍）。

臂预算扫描（固定 overlap=0，N ∈ {10,20,40,80,全}）里 `rel` 本身仍然随 N 变化
（int3 非单调：−0.040 @132、−0.115 @20；int5 单调：−0.153 @79、−0.399 @10；
cont3 平缓：−0.317…−0.391），而 `mapR` 上的排序与之同向（Spearman +0.932）。
这条留在报告里作为"读数跟着图像相似度走"的旁证，**但不再声称它跟随或背离任何真实相关**。

## 6. 判据套用

实验前声明过三条判据，逐条对照：

| 判据 | 结果 |
|---|---|
| ① ρ=0 时 CF 明显优于 Tetris（如 −0.5）→ 尺子可用，真实数据的"无优势"是真结论 | **仅部分成立**：cont3 达 −0.32，但实际拟用的 int3 只有 −0.04 |
| ② ρ=0 时仍进不了 −10% → 尺子在此工作点没有分辨力 | **对拟用设计成立**：int3 零重叠 = −0.040，理想情况也过不了门槛 |
| ③ 跨设计不单调 → 构念有缺陷 → 必须换指标，不是调参数 | **成立**：零重叠（两臂完全不相交）下 rel 跨设计相差 8 倍；且 rel 与 `mapR` 单调 +0.93…+0.98 |

三条里第 ③ 条是决定性的：判据 ①② 的分歧（cont3 行 vs int3 不行）本身就是第 ③ 条的症状——
同一个统计量对"同样独立"的三种切法给出 8 倍差异。

**结论：当前残差 proxy 不能用作品质门槛。** 它没有"通过/不通过"的含义：
一个 −0.32 和一个 −0.04 都可能来自两臂完全不相交的设计。

**附带结论（原为"旁证"，更正后升为主要发现之一）：两臂情形下不存在简单的噪声相关估计量。**
被否掉的合成模型、被撤回的 `rho_eff`、以及原 proxy 本身，三者失败方式不同但都归结到同一点——
两条臂、没有真值、又没有第三条臂做交叉约束时，"噪声是否独立"这个量无法从数据中分离出来。
因此替换方案必须改变臂的数目或引入外部真值，单纯给现有两臂换一个公式是做不到的。

## 7. 现在能说与不能说的

**能说**

- 统计实现是对的：两个锚点（overlap=1 精确为 0；overlap=0 复现审计）都成立。
  本报告不质疑代码，只质疑刻度的含义。
- `rel_matched` 是两臂功率图相似度的近乎单调的函数（Spearman +0.93…+0.98），
  在固定设计内对臂重叠单调（16/16）。
- **两臂情形下没有可用的噪声相关估计量。** 现有的复相关系数估计量在小 N 被共享的减均值支配
  （+0.999）、在全 N 被求和为零约束推向负值（−0.10…−0.44），中间无可用区间。
- 拟用的 int3 设计在理想条件（零重叠）下读数为 −0.040，**即使噪声完全独立也过不了 −10% 门槛**。
- 审计里"CF 通过门槛"这件事依赖于帧 0 留在臂内（f0_free −0.040 vs as_impl −0.206）。

**不能说**

- 不能说"CF 的观测对噪声独立"或"不独立"——这个数读不出这件事。
- 不能说 −0.163 比随机切帧的 −0.230 更好或更差——两者都在尺子的盲区里。
- 不能用"多少帧 / 怎么切"来救：cont3 在任何 N 下都过（−0.32…−0.41），int3 在大多数 N 下都不过，
  这个差异来自时间排布，不来自样本量。
- **不能引用任何"两臂噪声相关为 X"的数**——包括本报告初版曾给出的 +0.999 那一组反例。
  两臂估计量已被证伪（§5.1），在有了三条以上臂之前，这个量在项目里是空的。

## 8. 通俗总结

这一步要回答的问题很简单：前一轮我们发现，交叉拟合的臂对（把 400 帧切成互不相交的几组，
用一组估计 SVD 基底、另外两组各出一张图）在按同一套空间处理方式比较之后，比 VALID 原版的
对照低了 16% 到 19%，看起来是赢了，但**随机切帧也能拿到同样的成绩**。于是整个论证卡在一句话上：
这个 16% 到底是真的说明"两组之间的噪声是独立的"，还是只说明"这两组用的是不同帧"？

这一步就是去量这把尺子。办法是**不动数据**，只让两组帧"共享一部分"：共享 0% 就是原设计，
共享 100% 就是两组用完全相同的帧——后者数学上必然给出 0，所以它是一个不会撒谎的校准点
（实测确实精确为 0，说明尺子和测量过程都没问题）。

结果分两层。

**好消息**：在一种固定的切法里，尺子是好用的。两组共享的帧越多，读数就越往 0 靠，
一路单调，毫不犹豫。也就是说，尺子确实能感受到"两组变得越像"。

**坏消息**：它感受的是"两张图看起来有多像"，而不是"两张图的噪声有多独立"。
最直接的一层证据：三种切法在"两组一帧都不共享"这个完全一样的前提下，读数分别是
−32%、−15%、−4%，相差八倍。同一个前提，同一个问题，八个不同的答案——这个东西不能拿来当
"合格/不合格"的判据。

**还有一层更麻烦的。** 既然老尺子不行，就去直接测"两组噪声的相关系数"。这个数一开始看着
很有说服力：有一对组合测出 +0.999（几乎是同一份噪声），老尺子给它打了个漂亮的 −40%。
但复查时发现**这个"相关系数"本身是算错的**：它减掉了一个两组共享的平均值，当每组只用
很少几帧时，减掉的那部分占了绝大部分，于是不管两组噪声独不独立，这个数都趋近于 +1。
换到每组帧数多的一端，另一个数学约束（所有帧的均值被强制为零）又把同一个数压成负数。
一头一尾都坏，中间没有能用的地方。**也就是说，我们目前根本没有一把能测"独立性"的尺子。**

所以这一步证明的是：**尺子本身是坏的，坏在它量的东西不对；而且换个公式换不出来。**
对项目主张意味着什么？
意味着现在不能说"我们的设计让噪声独立了"，也不能说"没独立"——这个数字读不出这件事。
反过来，也不能用"再多加几帧"或者"换一种切法"去凑过门槛，因为那只是在调整一个和它声称测量的
东西无关的量。

下一步必须做的是**换一把尺子**，而不是继续调参数。但上面第二层发现说明了一件事：
在"只有两组"的前提下，无论怎么换公式都测不出独立性来——因为没有第三个参照物能告诉我们
哪些是"两组共有的"，哪些是"各自独有的"。所以真正要改的可能不只是公式，而是**分几组**。
这是一次方案层面的改动，需要先定下来新的判据长什么样，再动手。
