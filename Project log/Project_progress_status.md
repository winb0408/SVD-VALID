## 后续（未开工，需先改方案）

按 §0.5，Phase 2 未通过后**不得**换秩带 / 换分组 / 换观测定义 / 加网络复杂度去救。
本次数据把真正该问的问题钉到了一个具体形式上：

> **每臂要看多少帧、怎么切，才能让两臂的差异既独立（不可学）又足够大（可监督）？**

这一条与 §439/§694 设想的"带宽"维度无关，且用现有 Gram 缓存、不训练即可测。
**但必须先修改方案、经确认后再执行**，故此处只记录，不自行开工。

审计后该问题升级为**两个必须同时回答**的子问题：

1. 上述"帧数与切法"问题（原样保留）；
2. **指标本身的可解释性**（本次新增，优先级更高）：残差相关这把尺子在什么条件下才算
   "噪声独立性"的证据？最小的一步是给它配一个**已知答案的合成基准**——把同一份臂数据里的噪声
   按已知比例替换成独立噪声，看 r 是否随独立性单调、且在"完全独立"时落到 Tetris 对照以下。
   这一步不训练、不需新数据。**在这条曲线出来之前，任何"通过/不通过"的读法都缺刻度。**

### 通俗总结（本阶段）

我们原来那把尺子，是拿"交叉拟合造的两条臂"去和"Tetris 造的两条臂"比，看谁更不像。
原来看起来差了 50%–111%，很糟。这一轮先确认：**差得这么多，主要是因为两把尺子量的是不同东西**
——Tetris 把同一张图按体素相位劈成两半，两条臂共用同一份噪声；交叉拟合的两条臂来自不同的帧，
本来就是两份噪声。这是"信息来源不同"，不是"处理手法不同"。

把这个差别拉平之后，交叉拟合在 SA64 上确实反超了，低 16%–19%，看着像通过了。
**但接着做了那个最关键的对照：把同一批帧随便打乱、随便切成两半，会怎样？**
答案是：**一样，甚至更好。** 16 折里只有 3 折真正比随机切分强，而那 3 折恰好是"按时间连续切块"的
——连续切块保住了帧与帧之间的时间相关性，占了便宜，和 SVD 那套东西没关系。

**所以对项目主张意味着什么。** 原本想证明的是："从 C 组帧估出投影，套到 A、B 两组帧上，
能得到一对噪声互相独立、且都保住了图像内容的观测，可以拿去训练。"这一轮证明的是：
**现在这把尺子量不出这件事。** 它量到的是"两条臂来自不同的帧"——这件事对任何切法都成立，
等于什么也没说。而唯一能算数的那个对照（随机切帧）显示，交叉拟合没有比别人多做出什么。

**哪些说法现在不能说。** 不能说"匹配之后门槛通过了，所以可以开始训练"。也不能反过来把它说成
"改完还是失败"——未匹配时那个难看的数字确实是混淆造成的，把它当结论同样是错的。
还有两件事不能再说：一不能说 frame 0 是个可以忽略的小瑕疵，它在自己那条臂里占了总功率的 77%，
是其余帧中位数的 288 倍，在 400 帧里排第一——它一直在悄悄替交叉拟合撑场面；
二不能把这个残差相关数字当成"噪声独立性"的证据。

**一句话**：这次不是"实验失败"，是**发现尺子坏了**。尺子修好之前不该往前走，也不该回头改题目。
