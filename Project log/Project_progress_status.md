### Phase 2 — 采样库与独立预测：✅ 通过（但主变量更换）

- **几何核算推翻了原主变量**：8 个 Tetris 模式互为全等变换（正四面体），对任何平稳噪声模型
  泄漏完全相同——"在 8 个模式里挑一个"理论上买不到任何东西。真杠杆是**视图间距**与**角色分配**
  （角色选择跨度 0.81→1.00 当前间距，0.05→0.81 间距翻倍）。已在 `Project_plan.md` §3 记为措辞修正。
- **间距的代价**：m=2 覆盖率 12.5%、m=3 为 3.70%，铺满全幅需 m³ 次前向（×8 / ×27）。
- **交付物**：预注册角色序（`v3_phase2_role_order.md`，128 个有序角色对，两独立采集排序完全相同，
  最好/最差差 31 倍）；`S_min` 的受控来源（`v3_phase2_transfer.md`）。
- **必须并列的矛盾**：泄漏最少的角色对（体对角 L=0.017）信号可传递性也最低（r_sig 0.27），
  而信号最好的（y 轴向 0.61–0.63）泄漏高 4.8–6.8 倍。**两个指标互相矛盾，不能合成一个数宣布答案。**

### Phase 3 — 最小网络验证：⛔ 不通过

- m=2（12.5% 覆盖）能收敛能出图，但**在仿真真值上落后 m=1 三到七倍**。
- 跨相位预测能力：同一角色对 m=1 是 r=0.389，m=2 只剩 **0.018（差 21 倍）**。
- **预注册的机制假设被反向证伪**："泄漏越小 ⇒ 学到真东西"不成立，体对角角色对在所有口径下
  都输给泄漏更大的 y 轴向角色对。
- **闸门本身与实测上界冲突**（`v3_precheck_sampling_geometry.md` §169）：m=1 下噪声可被线性预测
  81%–100%，理论增益上限约为噪声方差的 10%，而原闸门要求"相对 fixed-4 呈结构安全的正向验证趋势"。
  这条闸门需要重写，不是实验结果的问题。
- **撤回不了的部分**：报告自认 C 与 D 的差**同时混了"泄漏"和"信号位移距离"**，没有分开——
  所以"物理先验指导角色配对是否有用"这个子命题**至今未被干净检验**（见 §4）。

### Phase 4 — 真值/真实图像定量与消融：⛔ 不通过

- **结构性发现（本轮最重要的负结果）**：漏防式部署 `reconstruct()`（每个体素只看别的相位）
  在数学上把保真度封在 **~0.5**，而胜过"什么都不做"需要 0.95+。实测最优先收缩系数在
  背景是 **−0.007**、在血管是 **1.108**，两者**差到相反**；盲点预测器只有一个旋钮（≈0.5），
  于是两边都错。→ **不是参数没设对，是部署构造有结构性缺陷。**
- **训练无关的 ① Wiener 通过门槛**：5 个窗口中 4 个通过，最好 n2n=0.754，血管区几乎不动
  （b≈1，slope 0.98–0.99）。**① 是当前唯一可交付的基线。**
- **②（网络）能过门槛但不稳**：跨场景训练 + 留出早停后，方差超过门槛余量，血管区变差；
  单场景训到 600 epoch 会**记忆**，训练损失不能当进步证据。
- **三条"结构保持"创新点（SPW / PAS / TIRe）留出验证全部失败**，失败模式同源：
  "用挑选场景的局部统计去赌另一个噪声实现"。
- **已作废数字**：分区 oracle 0.584 复现不出来（重算 0.68–0.80），全文引用已划掉，不追认。

### Phase 5 — 跨采集泛化：⛔ 不通过

  "整片抹平"会得高分。J1.0 → J1.1 → J1.2 三轮，两次失败运行的原始数字、协议 v1→v2 的改因、

  [JUDGE_v1.md](../reports/v3_judge/JUDGE_v1.md)。标定 **5/5 通过**。
- **J1.2 下的真实数据判定**：SA64 仅 ①Wiener 三路全过；**HSA64 无一全过**——①Wiener 的
  `S_rel=0.9316 < 0.95`，它自己在那份数据上也在抹平血管。
- **④（SVD+网络，零样本）双向全败**：8 个数据集×seed 组合 0/8 通过；`N_rel` 0.93–0.96

**通俗总结（Round3 A 段）**

我们前段时间一直说不清一件事：训练出来的网络在"噪声大"的实验档位上表现很差，
到底是因为判据太严、数据本身没救，还是网络自己的问题。这一轮加了三个不同角度的检验，
把这件事钉死了。

第一个是"规律"。如果把"两次独立拍摄之间的差"当作噪声的尺子，那么"网络输出与真实图像的误差"越大，
评分就越差，两者关系可以写成一个很简单的公式。我们在十四种不同的场景组合上验证了这个公式，
误差都在百分之一以内。公式告诉我们：网络自身的误差大约是 0.02，而它几乎不随噪声大小改变。
这解释了之前一个很迷惑的现象——同一份模型换到噪声小的档位去跑，看起来"突然变好"，
其实它错的程度一模一样，只是拿来对比的噪声变小了，所以同样的错误显得更刺眼。

第二个是"最笨的对照"。我们什么都学，只把画面用高斯模糊糊一下，用来做"不学习能达到什么水平"的底线。
结果这把糊一下在真实噪声档上拿到 0.618（1.0 代表"原样不动"，越小越好），在网络原先表现好的档位上拿到 0.822；
而训练了那么久的网络在同一批数据上是 1.70 和 11.1 —— 不但没赢过"糊一下"，还差了好几倍。
这个对照彻底排除了"标准太苛刻"和"数据没救"这两种辩解：数据是有救的，标准也是合理的，
是网络自己在往里加错误。

第三个是自查。我们在一条验收标准里写错了一个东西："相关系数要大于 1"。相关系数最多就是 1，
所以这条标准永远不可能通过——它等于没写。我们在任何训练结果出来之前就发现了这个笔误并改成了
"要比输入那张图的相关性更高"，也就是原本就该有的意思；所有数值门槛一个没动。

这一步证明了什么：网络的问题从"说不清是不是方法不行"，变成了"它输出的误差本身就太大，
而且这个误差跟噪声高低无关"。对项目主张意味着：之前那些"在这个档位过不了关"的负结果，
不能再被解读成"方法无效"，它只是尺子刻度的问题；但反过来，也不能说方法就有效，因为
网络还没有在任何一个档位上赢过"糊一下"这条线。
现在还不能说的：换一种接法（把网络输出加回输入）就一定行——这是正在跑的最后一步，跑完才知道。

**通俗总结（Round3 B 段）**

上一段说"换一种接法会不会行，跑完才知道"。跑完了，答案是：**病灶确实在那里，改掉它有用，但成绩没上来。**

我们改的那一处很小：原来是让网络直接吐出一整张图，现在只让它吐出"这张图该往哪个方向修一点"，
再叠回输入；另做一个版本，让它一开始的修正量正好是零，也就是从"原样复制"起步。其余设置一个字没动。
效果非常干脆——原来网络是在帮倒忙，改完之后确实是在帮忙，噪声最弱那一档的提升是数量级的。
这说明我们之前的诊断是对的：毛病出在"网络没有一条把原图直接送过去的路"。

但接下来这条必须原样说：**我们最好的一版，仍然比不过一个最笨的做法**。那个做法就是把图像轻微糊一下，
不训练、不学习、一条命令。噪声较强那一档，它拿 0.618，我们 0.825；噪声最弱那一档它 0.822，我们 0.851。
评分里 1.0 表示"什么都没做"，越低越好，而且它已经把"糊一下会让细节变糊"的代价算进去了，
不存在"它靠偷工减料占便宜"的说法。另外我们还发现：噪声最弱那一档的 0.80 门槛，**连这个最笨的做法都过不去**，
说明那条线本身定得没意义——但这不是替网络开脱，因为另一档的门槛那个模糊能过、网络没过，那一档才是有判别力的证据。

所以这一步证明的东西和上一段正好接得上：可以确定的，是"缺陷真实存在、而且能被一个极小的改动修掉"。
**不可以说的，是"这个方法已经比常规去噪更强"**，也不是"再往网络上加点东西就能过"——恰恰相反，
在搞清楚"为什么一次平滑比训练四十轮还好"之前，加任何模块都无法证明是它在起作用。
按事先约定的中止条件，下一步是停下来解释这件事，而不是继续叠加复杂度。

### Round6 — 在**真实采集上重新自监督训练**后直接对照：❌ BD-2 仍不占优，且本轮尺子暴露自身缺陷（2026-11-02）

## 6. 通俗总结

**这一步到底证明了什么。** 我把项目的实际进度和判定如实填进了这份状态表，因为原来的表还写着
"第一步都没开始"，而实际上后面五步都跑完了，外部审查的人看了会被带偏。填完之后有三件事摆得
很清楚：第一，**"少拍一点、把间距拉大、让网络补回来"这个核心设想已经被检验过，不行**——缺得
越多，网络学到的真东西越少，是断崖式地少，差二十倍。第二，**"每个点只看别的角度来预测自己"
这个做法有一个算出来的天花板**，只有五成，而我们要九成五以上；背景和血管需要的处理方向恰好
相反，可这个做法只能给一个折中的数，所以两边都错。这不是多训几轮能解决的。第三，**我们唯一
拿得出手的是一个不需要训练、只调一个窗口的小滤波**，它在第一份数据上合格，在第二份数据上自己
也把细血管抹平了。

**对项目主张意味着什么。** 现在能说的最准的一句是：**这条路线的核心卖点没有被证明，其中一条
分支已经被证伪，另外两条撞上了结构性天花板。** 但还没到"整个想法被推翻"的程度，因为当初设计
实验时把两个因素混在了一起——"换了配对方式"和"点之间隔得更远"——导致"配对方式本身有没有用"
这个问题到今天还没有干净的答案。这是唯一还值得投钱去测的东西，也是我建议下一步做的第一件事。

**哪些话现在不能说。** 不能说"我们的方法在真实数据上有效"（八个组合零通过）；不能说"再多训练
就好"（天花板是算出来的，不是训出来的）；不能说"已经证明优于 VALID"（原版 VALID 基线在 V3 里
根本还没重训过）；不能说"三种改法都失败说明这条路没救"（三种失败在同一个原因上，等于只试了
一种）；也不能说"换个说法让指标过了就行"——门槛是看结果之前写死的。

## Round10 — 在 SA64/HSA64 上从头自监督训练后再测试（2026-11-03；已执行完毕，判定 0/2 未通过）

- **为什么开**：用户指出 Round9 的真实数据部分只是零样本外检，要求"在这笔数据上进行完整的自监督训练后测试"。

  A 上训练、去噪 A、与独立 B 比；`E[(f(A)−B)²] = 真信号误差 + σ²_B`，σ²_B 与方法无关 ⇒ **排名无偏**。

**通俗总结（Round10）**

用户上一轮问得对：我们只是拿现成模型在这两卷真实数据上试了试，那说明不了问题。这一轮就在这两卷数据上
**从零训练**再测。难处是这两卷没有"标准答案"，于是把同一卷按时间奇偶劈成两半，在一半上训练、去噪这一半、
跟另一半比。分数里多出来的那部分来自"另一半自身的噪声"，跟用什么方法无关，所以**排名是公平的**：
1.0 分等于什么都不做，0.707 分是完美。

结果是 1.85 到 4.27 分——**训完之后不但没帮上忙，还比什么都不做更糟**，最差的一卷错了四倍多。
同一批测试里，最简单的高斯模糊反而把分数降了一点，老式的 Wiener3D 也是。我们唯一赢过的是那个
早已被证明在这类数据上不成立的 2D 移植版。**赢过最差的，输给最简单的两个。** 试图靠自动调一个放大系数
去救也没有用：最佳系数只有 0.02–0.12，调完最多追平"什么都不做"。

那为什么图看着变清楚了？因为模型往背景里**加了东西**（背景起伏比输入大了六到九成），看图时每一列
各自按自己的亮度范围拉伸，加了东西就显得血管更实。**"看起来更清楚"和"误差更小"这一轮恰好是反方向的。**

**哪些话现在不能说**：不能说本方法在真实数据上有优势；不能说再多训几轮就好（18 轮也扫了，胜者仍是上游形态）；
不能拿图观感代替判定；也不能说这轮推翻了 Round9 的"停"——它是**加强**了它。
