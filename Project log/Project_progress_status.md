## 4. 阶段完成时的统一记录模板

每个 Phase 完成后必须填入：

1. **输入/环境**：采集 ID、数据哈希、Git commit、配置、模型种子、有效 mask。
2. **执行**：运行命令、预算、日志与图像产物路径。
3. **结果**：主终点、结构约束、误差条、完整控制组。
4. **判定**：通过/部分通过/未通过、与冻结门槛逐项对照。
5. **限制**：伪真值、代理指标、独立样本数、不可复现项。
6. **通俗总结**：本阶段究竟证明了什么，不能证明什么。
7. **下一步**：只从已验收门槛进入下一 Phase。
