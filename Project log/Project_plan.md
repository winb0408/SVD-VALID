## 0. 一句话主线与最终目标

**以三维 Power Doppler 微血管图像的最终恢复质量为根本目标，测量独立校准数据中的 PSF、散斑/残余噪声空间相关性，指导 VALID 的三维互补正交采样几何；保持 CRN 和训练目标不变，以可靠真值、血管结构与真实数据共同检验其相对最强固定采样基线的增益。**

**主要结果**：在相同数据表示、网络、损失、训练算力与显示协议下，改善背景抑制—微血管保真折中，尤其保留弱血管、细分支、连接性和管径；不得将高频下降或与输入的相似度单独作为成功证据。

**不作为主目标**：找到某个“最好”的 SVD 秩带、构造 CrossFit 时间 N2N 观测对、提升某种残差统计分数或训练更复杂的神经网络。上述 V1/V2 内容作为历史探索与对照经验保存。

## 1. 背景与经验教训

- **V1 SVD-guided Tetris**：早期引导采样在实际训练中近似退化为固定 pattern 4；其增益不能被归因于 SVD 选择器。固定模式及角色/位移方向的差异提示了新的、可证伪的几何研究问题；但旧结构指标以输入/伪真值为参照，并非真值恢复证明。
- **V2 SVD-CrossFit**：Phase 0/1 按原计划完成；Phase 2 的预设残差相关门槛失败，因而按原计划停止 Phase 3。该统计代理及 Tetris 对照存在适用边界，不能把“代理失败”扩展为对所有时间自监督方法的普遍否定。
- **共同教训**：物理测量并不等同于噪声独立性；PSF、散斑统计、残余杂波和真实血管结构必须区分；在固定采样对照之前不能声称“自适应”有用。

历史记录详见 [归档总览](../archive/README.md)、[V1](../archive/v1_svd_guided_sampling/Project_plan.md)、[V2](../archive/v2_svd_crossfit/Project_plan.md)。原始长篇日志继续保留于 [Project_log.md](Project_log.md)；V2 截止快照另行归档。

## 2. 科学问题与可证伪假设

| 假设 | 问题/预测 | 所需实验 | 失败或收缩结论 |
|---|---|---|---|
| H1 物理异质性 | 不同方向/位移的 PSF、散斑或噪声相关结构存在可重复差异 | 点目标/体模、相关函数、方向相关长度、独立采集与深度分析 | 无稳定各向异性时转为“相关距离”约束，不主张方向性优势 |
| H2 可预测采样 | 独立物理先验能预测某些输入—目标几何更适合自监督 | 八模式、角色置换、物理距离、信号保真/噪声相关性和独立排序 | 若预测不稳定，不增设复杂打分器 |
| H3 输出质量 | PSF/相关性感知采样优于最强合理固定几何 | 网络/损失/预算严格相同，真值仿真或体模+真实图像+多 seed | 若仅比随机好或靠平滑，不成立“物理自适应”创新 |
| H4 局部自适应（可选） | 随空间/深度变化的校准先验带来额外收益 | 全局物理固定 vs 深度/patch 级受控选择 | 若无明显增益，则保留全局简化版 |

**概念边界**：PSF 表征成像点响应；散斑来自相干成像的结构化统计；去趋势图像残差通常混有血管边缘/细节。三者不得互相替代。每个相关性代理须说明其适用域、构造方法和潜在偏差。

## 3. 创新点、贡献证据与否证标准

### I1（必须）：物理相关性感知的三维正交采样几何
由独立校准的 PSF 与残余噪声空间协方差指导 VALID 采样模式、输入—目标角色和物理位移。**验收**：模式预测能够在未参与校准的数据中复现；新采样相较 fixed-4 和最好固定方向具有真实质量增益；正确先验优于错误/打乱先验；任何一项失败均需要收缩创新表述。

### I2（支撑）：噪声去相关与微血管结构一致性的联合约束
初版采用 `min_k N(k)` 且 `S(k)≥S_min`、几何合法；N 是独立校准下的噪声依赖代理，S 是独立结构参考下的信号保真，而**不是**直接从同一待训练体积取整体相关系数。**验收**：能拒绝噪声低但细血管损伤高的候选；校准波动不会导致不可解释的剧烈切换。若没有独立贡献则简化规则。

### I3（证据体系，不预先宣称新算法）：面向血管的图像质量与失效边界
有真值体积的 PSNR/SSIM、弱血管检出、中心线/分支、宽度；真实数据的固定 ROI 背景、血管剖面、连续性与假阳性；形成噪声抑制—结构保真 Pareto 图。**验收**：报告真值来源、样本独立性、效应量与不确定性，不以单张好看的 MIP 代替证据。

**创新性边界**：结构化 blind spot、各向异性/PSF 引导和超声自监督已有相关研究，不能声称概念首次提出。潜在新意在于“实测三维物理协方差 → 合法互补正交视图 → 恢复质量提升”的专门实现和因果消融；未完成文献对比前不得定稿优先权。

## 4. 数据、预处理与信息隔离

1. 以 SA64/HSA64 和可用 PW 序列作为开发起点；登记原始采集 ID、扫描方式、维度、体素物理间距、时间帧数、空间轴含义、IQ 类型、哈希和有效体素掩膜。**19 个时间折不等于 19 个独立生物/采集样本**。
2. 官方 SA64/HSA64 血流 SVD 带按 MATLAB 1-based 模式 60:350（含端点），Python 0-based 半开区间为 `[59,350)`；必须与实际脚本逐项核对。官方 MATLAB 逐体素数值一致性尚未被验证，不应虚称完全复现。
3. 保存线性 Power Doppler、dB 及网络固定输入表示，训练/比较不允许各组独立拉伸强度；记录 SVD、log/remap 的每一个参数。
4. 分离 **calibration / training / validation / held-out test**。先按独立 acquisition/subject 分组；若仅有 SA64/HSA64 则承认样本局限，禁止把测试图像调参成训练集。PSF/先验估计不得直接由同一评价体积的目标噪声实现反向泄漏。
5. 仿真需提供干净血管几何与成像退化输入，并逐步加入各向异性 PSF、相关散斑、杂波、SVD/PD；只有独立高斯噪声的实验不足以支持超声物理主张。点目标/体模优先用于 PSF 校准；没有时严格标注“仿真 PSF”。

## 5. 方法架构与变量控制

流程：复数 IQ → 固定 SVD/PD → 固定输入表示 → **独立 PSF/相关性校准** → 合法三维采样库 → 物理约束模式选择 → 原始 VALID CRN+原损失 → 三维完整输出 → 冻结评价。

**候选**：原始 per-2×2×2 随机 Tetris；八固定模式；固定 pattern 4；必要角色置换；固定物理方向；PSF-only；noise-correlation-only；combined；错误/打乱物理先验。初版**禁止同时引入**新网络、损失、自适应局部权重和扩展位移。若原 2×2×2 采样距离未覆盖噪声相关长度，扩展位移单独立项，重新检验互斥、空间配准、视图信息量与损失定义，不能视作原采样的无成本替换。

**公平性**：同输入、训练划分、网络、损失、优化器、前向次数或明示的计算预算、seed 集、评价 ROI 和显示动态范围；保存原始浮点输出，绝不按方法单独归一化。以 `fixed-4` 和 **最强合理固定方向** 为主要竞争对象。

## 6. 阶段实施与验收闸门

### Phase 0 — 历史交接、基线/评价冻结

**目标**：让所有后续增益可复现、可归因。
- T0-1 归档 V2 计划/状态/日志时点快照和实测报告；V1 归档保留。
- T0-2 复查 `datasets/sampling.py` 的 VALID 随机 2×2×2 block 采样、固定模式、角色置换；增加样本互斥/位移/空间对齐单元测试。
- T0-3 审核 V2 既有统计报告的两类边界：均值帧数不同只改变估计方差，不必然产生 `T_B/T_A` 系统强度偏差；丢弃的空间块应按原 block ID 对齐，不能按剩余数组索引配对。这是历史审计，不篡改归档数据。
- T0-4 重建或核对 random/fixed-4 和其它固定模式；确定训练与评价预算，统一图像质量脚本（valid_mask、ROI、背景噪声、血管结构）。
- T0-5 明确独立样本划分、体模/仿真可得性、真实物理轴和体素间距，登记不得利用测试数据决策的规则。
**产物**：`reports/v3_phase0_baseline.md`、单元测试、固定数据清单与配置、固定图像评价规范。  
**Gate 0**：基线跑通且与历史差异可解释；评价指标通过合成单元测试；训练与测试界限冻结。否则停。

### Phase 1 — 三维 PSF/空间协方差的可信测量

**目标**：找到能预测采样行为的真实物理量。
- T1-1 核实各物理轴、间距、有效视野；点目标/体模 PSF 三方向 FWHM 和深度依赖；无可用点目标时使用受控仿真 PSF，禁止伪称测得真实 PSF。
- T1-2 在线性功率域、log 域分别估计各轴 `C(Δ,0,0)`、对角方向和深度分层相关；采用已知真值噪声、重复观测差异、无血管背景和残差带多代理交叉核验。
- T1-3 对照 Tetris 所有模式/角色的物理位移，与相关长度比较；测试不同 ROI 和独立采集上的重现性，采用按采集/非重叠大空间块汇总的不确定性估计。
**产物**：`reports/v3_phase1_physics.md`；方向 PSF/ACF 图、深度及采样距离曲线；代理差异报告。  
**Gate 1**：测量可靠且提出至少一项可独立检验的采样假设。方向性不显著时可降级为相关距离约束；测量不可重复则暂停。

### Phase 2 — 采样几何库与预注册物理排序

**目标**：避免训练后倒推一个“有效”的经验打分器。
- T2-1 罗列八 Tetris 模式、4 视图角色关系、真实物理位移，构建 geometrically valid 候选；独立验证采样互斥/覆盖/视图配准。
- T2-2 在仿真和校准数据估计 `N(k)`（噪声依赖代理）与 `S(k)`（已知结构保持），采用 **最小 N 且 S ≥ S_min**；S_min 先通过受控模拟/体模设定，不从留出测试结果回调。
- T2-3 冻结模式排序后，于独立数据验证预测关系；设置固定 4、最优固定方向、PSF-only、噪声-only、错误物理先验对照；检查是否退化为固定模式。
**产物**：`reports/v3_phase2_sampling.md`、模式位移表、噪声—结构散点图、排序稳定性与负控制。  
**Gate 2**：预测与真实质量排序方向可重复，且信号保持合格。仅固定方向可靠则缩减为固定方向研究；无预测力则停。

### Phase 3 — 最小端到端验证

**目标**：不引入第二个算法变量，确定有无训练价值。
- T3-1 单独实现 `physics_sampler`，与原 `datasets/sampling.py` 接口及损失一致。
- T3-2 冒烟测试：有限损失、梯度、shape、边界、seed 可重现、无输入目标重叠；验证推理尺度与存储。
- T3-3 同预算短程训练 **random / fixed-4 / Phase2 物理候选**（如必要附 PSF-only）。
- T3-4 使用小型 held-out 验证，报告噪声—结构 Pareto 和失败图，而非只报告 loss。
**产物**：`reports/v3_phase3_training.md`、训练日志、完整输出。  
**Gate 3**：相对 fixed-4 至少呈结构安全的正向验证趋势；无趋势或明显损伤则不扩大训练。

### Phase 4 — 主要图像质量与消融（论文核心）

**目标**：确证最终恢复质量，不以统计代理取代成像证据。
- T4-1 固定方案训练：原输入、VALID random、fixed-4、最优合理固定模式、PSF-only、correlation-only、combined，必要时加传统滤波。核心模型至少 **3 seeds**，按独立采集/仿真实例统计，而非拿 patch 当独立样本。
- T4-2 仿真/体模真值：PSNR、SSIM、结构 F1、弱血管召回（固定 FPR）、宽度误差、分支/连通性、假血管；选择一个主终点（建议弱血管召回@固定 FPR）并预先冻结。
- T4-3 真实 SA64/HSA64：统一 MIP/三正交切片/ROI、相同显示、背景代理、细血管连续性、血管剖面和假阳性；明确任何全帧伪真值的限制。
- T4-4 消融：模式 vs 角色、方向 vs 距离、PSF-only、correlation-only、combined、先验打乱；绘制噪声—保真 Pareto。
**参考挑战目标（尚未验证，须 Phase 0 预注册）**：相对最强固定采样 PSNR +0.5 dB 或弱血管召回 +3 个百分点；血管宽度中位误差不恶化超过 10%，结构保持不因过平滑受损。首要硬判据仍是主终点的独立正向证据和不恶化的结构安全约束；不能事后换主要指标。
**产物**：`reports/v3_phase4_image_quality.md`、全量统计/可视化、可再现 run ID。  
**Gate 4**：新法相对最强固定基线在主终点及结构安全方面有可复现收益，多 seed 同向，并通过负控制；否则收缩或否定方法主张。

### Phase 5 — 稳健性与可选局部适应

**目标**：检验跨空间/采集/条件适用边界。
- T5-1 SA64→HSA64、PW、独立采集/不同对象；记录 domain shift，至少一个真正独立采集支持泛化讨论。
- T5-2 PSF 各向异性、空间相关长度、SNR、深度、血管尺度、SVD 带的受控敏感性；完整记录失败模式。
- T5-3 仅当 Phase 1 的局部物理变化可重复、Phase 4 主方法通过时比较全局固定 vs 深度/patch 自适应；若无独立增益，删除局部复杂化。
**产物**：`reports/v3_phase5_generalization.md`、有效范围/失败案例。  
**Gate 5**：新采集上的方向性增益及限制清晰；仅两序列时不得称普遍泛化。

### Phase 6 — 论文证据与复现冻结

**目标**：从可复核证据构成清晰科学故事。
- Fig.1 成像问题与总体方法；Fig.2 PSF/相关物理依据；Fig.3 模式几何、统计预测与负控制；Fig.4 仿真/体模真值定量；Fig.5 真实三维血管图与结构保真；Fig.6 消融/深度/稳健性。补充图：SVD对齐、标定细节、八模式、相关性代理、训练等效性、失败案例。
- 讨论替代解释：过度平滑、伪真值循环、固定几何已足够、测试集选模式、实验独立单位不成立。
- 审核最终创新与相关先行研究（VALID / Noise2Self / Noise2Void / structured blind-spot / SVD-SN2N 等）。
**产物**：`reports/v3_phase6_paper_map.md`、复现包/数据来源、最终 limitations。  
**Gate 6**：每个论文主张均能映射到清楚的独立对照、定量结果及源码配置；无实测不标为通过。

## 8. 严格实验纪律及应对失败

- **单变量**：首轮只动 sampler；改网络/损失/预处理的实验另列，不能混作采样消融。
- **训练与评价隔离**：测试样本不得参与物理校准、模式选择、阈值调节。
- **真实参考**：全时序 PD 只是伪参考；噪声残差下降≠独立噪声下降；纹理频率下降≠血管更好。
- **主要比较**：必须赢最强固定几何，不能仅赢随机。
- **不依赖统计显著性错置**：空间块/帧折不默认独立；优先按独立采集做推断。
- **决策分岔**：若仅固定方向有效→收缩为固定物理方向；若仅物理机制可信但质量无增益→机制研究，不宣传高性能去噪；若测量不稳→暂停。
- **计算纪律**：Gate 未通过不进入下一期的大规模训练；先完成最小可信验证再扩展。
