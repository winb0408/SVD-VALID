## 一、项目主线

**SVD-guided Orthogonal Self-Supervised Denoising for Volumetric Ultrasound**
(面向体积超声的 SVD 引导正交自监督去噪)

### 1.1 一句话概括

在 VALID(Science Advances 2026, FDU-donglab)的 3D Tetris 正交采样自监督框架上,把
"随机正交采样"替换为"SVD 指导的正交采样",在不新增损失项、不修改网络的前提下,验证
**采样策略本身**能否带来更低的采样对噪声相关性,从而获得更好的体积超声自监督去噪效果。

### 1.2 方法论原则:采样优先,损失最小(Sampling-first, Loss-minimal)

这是贯穿全项目的实验纪律:

1. **网络不变**:沿用 VALID 的 CRN 网络(1.54M 参数,features=16),逐参数复现,不做任何改动。
2. **损失不变**:沿用 VALID 的三项损失
   `L = loss2neighbor + loss_idt + 1e-4 · Hessian(Haar-DWT 低频带 LLL/LLH/LHL/HLL)`,
   v0.1 阶段**禁止新增损失项**。
3. **只改采样**:自变量只有一个——把 per-block 随机 Tetris(VALID)换成 SVD 指导的 Tetris。
   这样任何性能差异都可以干净地归因于采样策略。

### 1.3 理论背景

- **SN2N / Noise2Noise 的前提**:噪声需为加性、信号独立,两次采样噪声独立同分布。
- **超声散斑的困难**:散斑是乘性噪声(I = S·N),破坏 N2N 的统计前提。SVD-SN2N(2026 preprint,
  Zhang et al.)证明:对 SVD 滤波后的数据做 **log 压缩**,可把乘性散斑转换为近似加性、信号独立的噪声,
  从而恢复 N2N 的统计前提。
- **VALID 的做法**:不需要 SVD,直接在原始 IQ/功率域上,通过 2×2×2 Tetris 正交采样(8 种模式,
  每块随机选一种 + 随机角色分配)获得四个"互补半覆盖"子体,两两配对做自监督。
- **本项目的关键洞察**:SVD 的**代数正交性**(信号/噪声子空间分离)与 VALID 的**空间采样正交性**
  (Tetris 互补覆盖)是两种不同维度的正交;若能将前者作为**先验**注入后者,即用 SVD 信号/噪声
  能量图指导每个 2×2×2 块选择哪种 Tetris 模式,理论上可让配对采样点的噪声相关性更低、
  信号互补性更好。

### 1.4 数据集

Dryad 公开数据集(10.5061/dryad.47d7wm3qg):可重复定位 3D CMUT RCA 指尖微血管成像,已下载至
`/ssd1/wjb/Data/Dyrad/data/`:

| 序列 | 形状 (Z,X,Y,T) | 体素 | 帧率 | 说明 |
|---|---|---|---|---|
| SA64 | 37×64×64×400 | 0.15 mm | 46.875 Hz | 64 阵元 SA,复杂波束合成 IQ,主实验数据 |
| HSA64 | 同量级 | 0.15 mm | — | 高速 SA,交叉验证 |
| PW3232 / PW1616 | — | — | — | 平面波序列,泛化验证 |

MATLAB v7.3(HDF5)格式;h5py 读取时轴序颠倒(T,X,Y,Z→需转回 Z,X,Y,T),复数以
('real','imag') 复合 dtype 存储。已实测:近表面若干 z 层为结构性零;

### 1.5 论文定位

- 若"采样假设"成立(引导采样确实降低采样对噪声相关并改善修复):**IEEE TMI / Medical Image

- 核心卖点:首次将子空间先验注入物理采样设计,采样策略本身即为可发表的创新,
  而非网络结构或损失函数的堆砌。

## 二、三大创新点

### 创新点 1:SVD 引导的正交采样(v1 核心)

**内容**:保留 VALID 的 Tetris 正交采样框架,但不再"每块均匀随机选模式",而是用 SVD 分解得到的
信号能量图 S(k) 与噪声能量图 N(k),对每个 patch 计算 8 种 Tetris 模式的质量分

```
Q(k) = zscore(S(k)) − zscore(N(k))
```

选 Q 最高(信号占比最高、噪声占比最低)的模式作为该 patch 的采样模式。

**属性**:无新增超参数(zscore 归一化消除了量纲);不引入可学习模块;完全兼容"只改采样"的纪律。
**风险**:引导采样是否真的降低采样对噪声相关性,是**待验证的假设**,必须先做统计验证
(见 Phase 3),不能默认成立。

> **【2026-10-10 重大修订,P1】** 上述"从 8 个整模式中逐 patch 选一个"的当前实现
> **已被对照实验否定**,证据三条(详见 L22):
> 1. 训练尺度退化:32×64×64 patch 下深度方向仅 6 个起点,选择器恒选 pattern 4;
> 2. F4(固定 pattern 4)与 C3(引导)在全部结构指标上**逐项等同**
>    (core 0.820/0.820,pseudoGT 0.966/0.967),引导未贡献可测增量;
> 3. 选择器交叉验证:even/odd 两半帧选择一致率仅 0.438,跨半帧评估 ρ_noise 差异
>    +0.0000(p=0.998)——L21 测到的优势**无法迁移到时间不相交数据**。
>
> **仍然成立**:采样几何对去噪质量有实质影响(F4 ≫ B3,core 0.820 vs 0.685);
> Tetris 半采样造成的高共享噪声(L21)。
> **论文主张相应降级**:不得以 C3>B3 作为"引导机制有效"的证据;核心叙事改为
> "采样几何设计",而非"子空间先验注入采样"。
> **创新点 1 的重启条件**(择一验证后才可恢复原主张):(a) 在更细粒度上做选择
> (逐 sub-block 而非整模式),使选择自由度不再退化为常数;(b) 换用具有跨帧稳定性的
> 选择统计量,并以 even/odd 交叉验证为验收门槛;(c) 转为 V3 的各向异性几何设计。
> **新的验收标准(硬性)**:任何引导类改动,必须在**空间不相交单元**上给出显著效应
> (非重叠窗口或 even/odd 交叉),重叠滑窗 p 值不再作为证据。

> **【2026-10-10 二次修订,P2】8 模式全扫描与角色置换(L23)之后的方案调整**
>
> 1. **引导判据 Q 分数予以放弃**。它与去噪质量无预测力且符号相反
>    (Spearman:ρ_signal r=−0.26、ρ_noise r=+0.36),且 ρ_noise 在模式间全距仅 0.005,
>    近乎无动态范围。选择器在训练尺度恒选 pattern 4(选择自由度实为 1),
>    仅"恰好选对",非判据生效。
> 2. **主线变量重新定位为"输入对的位移方向",首要为轴 0(轴向)**。这是本轮唯一
>    具备内部对照支持的量:8 模式中 P4 是唯一输入对位移纯沿轴 0 者、也是唯一真去噪者;
>    固定 P4 不变采样集的 4 个角色置换中,唯一破坏该性质的 r4 掉到 core 0.677。
>    该结论直接支撑 V3,并给出 V3 的具体假设(见创新点 3)。
> 3. **引导的可行重启路径(替代原先的"更细粒度"设想)**:不是在 8 个模式间选,
>    而是在**补丁级选择"输入对沿哪条轴位移"**(3 选 1,物理含义明确),判据用
>    该轴方向上的局部各向异性度量。重启门槛:① 小 patch 下选择确有变化
>    (16×32×32 有 23958 个不同起点,而 32×64×64 在 x、y 上只有 1 个);
>    ② 通过 even/odd 交叉验收;③ ≥3 种子。
> 4. **必须披露的方法学边界**:`eval_structure.py` 的保真类指标奖励"少去噪"
>    (不作为的模型全得 1.000),故**任何保真指标都必须与 `hf_noise_reduction`
>    同时报告**,且只在同去噪强度内比较;训练 loss 更低亦不构成优点证据
>    (低 loss 可由拟合噪声获得,见 L23(a))。
> 5. **待补的验证缺口**:跨模式结论为 n=8、单种子,且描述子无法解释全部变异
>    (P0/P1 输入对位移同为纯 x,去噪 +0.115 vs −0.231)。关键结论需补多种子。

### 创新点 2:子空间一致的自监督恢复(V2,后续阶段)

**内容**:探索在 N2N 配对中保证两个子体来自同一信号子空间(时间秩带一致),即
"SVD 域内的 Noise2Noise",结合 log 压缩恢复加性噪声前提。

**属性**:依赖 v1 的 SVD 基础设施;在 v1 验证采样假设之前不启动,防止多变量混淆。

### 创新点 3:PSF 感知的体积采样(V3,后续阶段)

**内容**:把点扩散函数(PSF)的各向异性引入采样设计——沿 PSF 主轴方向保留更完整的采样连续性,
使采样正交性与成像物理特性对齐。

**属性**:远期探索,需要 PSF 估计或仿真数据配合。

> **【2026-10-10 具体化,P2】** L23 给出了 V3 的第一个数据依据与可检验假设:
> 采样几何中最关键的量是**输入对的位移方向**,轴 0(轴向)位移是唯一能真正去噪的配置
> (8 模式中仅 P4 满足,其 hf 去噪 +0.486,其余 ≤0.253);固定采样集只改配对则不影响
> (0.486–0.503),而把输入对位移改为对角即掉到 0.290/0.677。因此 V3 的第一组实验应
> **直接构造各向异性模式集**(不在 x/y 上降采样而在 z 上降采样 → 2×2×1 等),
> 检验"轴线选择"是否为收益来源,而不必先做完整 PSF 估计。这是当前性价比最高的路线。

> **执行顺序纪律**:v1 是主线,v2/v3 只有在 v1 的采样假设被统计验证后才启动。

## 三、总体路线图(粗粒度)

```
Phase 0  代码基础设施与 VALID 忠实基线
   │     (复现 VALID 全套:CRN、Tetris 采样、三项损失、训练/推理管线)
   ▼
Phase 1  SVD + log 压缩基线(B 组)
   │     (SVD 预处理 + log,采样仍为随机 Tetris —— 隔离"预处理"的贡献)
   ▼
Phase 2  SVD 引导 Tetris(C 组)
   │     (只改采样,与 B 组全同 —— 这就是核心实验)
   ▼
Phase 3  统计验证
   │     (逐模式 ρ_signal/ρ_noise 相关性分析,2D 采样选择图,验证采样假设)
   ▼
Phase 4  全面 3D 验证
         (SA/HSA/PW 多序列、跨采集泛化、定量指标、消融)
```

### 核心实验设计(A/B/C 对照)

| 组 | SVD+log 预处理 | 采样方式 | 作用 |
|---|---|---|---|
| A | ✗ | 随机 Tetris(忠实复现 VALID) | 基线:VALID 原样 |
| B | ✓ | 随机 Tetris | 隔离预处理贡献 |
| C | ✓ | SVD 引导 Tetris | 隔离采样贡献(核心) |

三组共用同一 CRN、同一优化器、同一 LR 日程、同一损失、同一随机种子族,保证可归因性。

## 四、各阶段执行细节(细粒度)

### Phase 0:代码基础设施与 VALID 忠实基线

**目标**:搭建一套"逐参数忠实"于 VALID 的可运行代码底座,并保证每个组件可被独立验证。

执行内容:

1. **数据准备管线** `scripts/prepare_svd.py`
   - 读取 Dryad MAT(v7.3/HDF5,处理轴序颠倒与复合复数 dtype);
   - 时间维 SVD(经时间 Gram 矩阵 G = C^H C,避免展开完整 U);
   - 输出 log 压缩、归一化到 [0,1] 的功率多普勒体 `power_doppler.npy`,
     以及信号图 `signal_map.npy`、噪声图 `noise_map.npy`(供引导采样用);
   - 秩带默认:rank_low=10(能量集中证据支持),rank_high=80,噪声带 [rank_high, T)。
2. **采样器** `datasets/sampling.py`
   - `valid_random_tetris()`:忠实复现 VALID 的 per-block 随机 Tetris
     (每 2×2×2 块独立随机选 8 种模式之一 + 随机角色分配,4 个子体各占一半体素、互斥);
   - `guided_tetris_subvolumes()` + `select_guided_pattern()`:SVD 引导版本(Q 分数选模式);
   - 保留 `random_tetris_subvolumes()`(单模式/patch 版本)仅作消融对照,明确标注非原始 VALID。
3. **网络与损失**
   - CRN 逐参数复现(与原仓库 state_dict 键、形状、同种子前向输出完全一致);
   - Haar DWT 分解 `models/dwt3d.py`(能量守恒,数值等价于原 VALID 的矩阵 DWT);
   - Hessian 正则应用于**两个输出**的低频带(LLL/LLH/LHL/HLL)——顺带修正原仓库
     train_pipeline.py 中对 noisy_output_1 重复做 DWT 的笔误。
4. **训练与推理**
   - `train.py`:A/B/C 三模式入口(`--mode random / random+preproc / guided`),
     VALID 的 warmup+cosine LR 日程、梯度裁剪 20.0、种子 3407;
   - `infer.py`:滑窗重叠平均推理 + 快视图(三正交中面);
   - `tests/test_smoke.py`:模式语义、覆盖互斥性、DWT 能量守恒、CRN 前向反向、
     Hessian 粗糙度惩罚、引导选择、完整训练步——冒烟测试全部通过方可进入 Phase 1。
5. **A 组完整训练**(首次真实训练):SA64 功率多普勒体,patch 32×64×64,
   先跑短程(如 10 epoch)确认损失下降与视觉合理性,再定长程配置。

**Phase 0 验收标准**:8 项冒烟测试通过;A 组短程训练损失稳定下降;推理快视可辨结构。

### Phase 1:SVD + log 压缩基线(B 组)

**目标**:量化"SVD 预处理 + log 压缩"本身的贡献,与 A 组对照。

执行内容:

1. 对 SA64 跑 `prepare_svd.py` 生成处理后的训练体与信号/噪声图;
2. B 组训练:与 A 组完全相同的配置,仅换输入体;
3. 秩带敏感性小实验:rank_low ∈ {5,10,20}, rank_high ∈ {60,80,120} 的短程扫描,
   以 B 组短程损失与快视质量选定默认值(不做大规模网格,避免变相调参引入混杂);
4. 记录 A/B 差值作为"预处理贡献"基准。

**Phase 1 验收标准**:B vs A 有可解释的差异(方向不论,需给出解释);秩带默认值确定。

### Phase 2:SVD 引导 Tetris(C 组)——核心实验

**目标**:在与 B 组完全一致的前提下,仅把随机 Tetris 换成 SVD 引导 Tetris,检验采样策略的贡献。

执行内容:

1. C 组训练:同 B 组配置 + `--mode guided`(Q 分数选模式);
2. 与 B 组同一数据划分、同一种子族配对比较;
3. 评价:定量(无参考指标:噪声残余方差、结构细节保持;有条件时用仿真体模做 PSNR/SSIM)
   + 定性(三正交面快视、微血管连通性);
4. 若 C > B:进入 Phase 3 解释机理;若 C ≯ B:同样进入 Phase 3,检查引导是否真的
   降低了噪声相关(负结果也需机理解释,可能是重要的负贡献)。

**Phase 2 验收标准**:A/B/C 三组完整对照结果 + 初步结论。

### Phase 3:统计验证(采样假设的机理检验)

**目标**:直接测量"SVD 引导是否降低采样对的噪声相关性",把假设变成证据。这是论文的关键一环。

执行内容:

1. **逐模式相关性分析**:对 8 种 Tetris 模式,分别计算配对采样点之间的
   - ρ_signal:信号带(rank<rank_low)相关性;
   - ρ_noise:噪声带(rank≥rank_high)相关性;
   期望:引导后 ρ_noise 下降,ρ_signal 不降;
2. **2D 采样选择图**:把每个 patch 被选中的模式编号画成 2D 切面图,叠加信号图,
   展示引导的空间结构(论文 Figure 候选);
3. 对比随机 vs 引导两种策略下的 (ρ_signal, ρ_noise) 散点/直方图;
4. 若统计验证不支持假设,回溯修改引导准则(如调整 Q 的构造),但任何修改仍须保持
   "无新增超参数"或明确记录新增超参数的敏感性。

**Phase 3 验收标准**:一张能回答"引导采样是否降低了噪声相关"的统计图表。

> **【2026-10-10 修订,P1 后续】** Phase 3 已完成(L21),但验收口径按 L22 收紧:
> - 证据单元必须是**空间不相交**的(非重叠窗口,或 even/odd 帧交叉)。重叠滑窗的
>   Wilcoxon(n=1014)仅作描述,不作为证据;
> - 已执行:`phase3_stats.py` 新增 non_overlap 段(置换检验 + 自助 CI)、
>   `selector_crosscheck.py`(even/odd 交叉);
> - 结论:SA64 非重叠 n=32 下 ρ_noise 降幅 +0.0120(p=1.65e−3)**成立**;
>   HSA64 同口径 +0.0072(p=0.133)**不显著**(功效不足,非证否);
>   但 even/odd 交叉验证**未能复现**(差异 +0.0000,p=0.998),故该优势的
>   可迁移性不成立。**Phase 3 的验收结论从"假设成立"改为"假设在同批数据上成立、
>   但无法在时间不相交数据上复现"**。

### Phase 4:全面 3D 验证

**目标**:把结论从单一 SA64 推广,并补齐论文所需证据。

执行内容:

1. **多序列**:HSA64、PW3232、PW1616 重复 A/B/C 对照;
2. **跨采集泛化**:SA64 训练 → HSA64 推理(同探头同类目标);
3. **消融**:
   - 引导 vs 随机 vs 单模式/patch(保留的旧采样器在此派上用场);
   - **固定模式对照**:`--mode fixed --pattern K` 逐一扫描 8 个模式,给出"哪种几何最好"
     的完整排序(SA64 的 K=4 已做,见 L22(a));这是新的主线证据来源;
   - 秩带敏感性(Phase 1 已做,此处汇总);
   - log 压缩开/关(在引导模式下);
4. **定量基准**:若可获得仿真/体模配对数据,补 PSNR/SSIM/血管连通性指标;
5. 整理论文素材:主图、采样选择图、相关性统计、消融表。

**Phase 4 验收标准**:多序列一致的结论方向 + 完整消融表 → 论文可动笔。

## 五、风险与应对

| 风险 | 应对 |
|---|---|
| 引导采样假设不成立(C ≯ B) | Phase 3 统计验证给出机理解释;负结果配合相关性分析仍可发表(方法学警示价值) |
| **【已发生,P1】引导机制被对照实验否定** | F4 与 C3 逐项等同(L22)。已把核心叙事降级为"采样几何设计";创新点 1 按上文三个重启条件择一验证后方可恢复原主张。**不新增损失、不改网络**(identity 消融仅作诊断,见 L22(b)) |
| 无参考指标的"伪 GT"是含噪输入,保真类指标会奖励"少去噪" | `eval_structure.py` 为唯一真源并附输入行自检;报告时同时给出 `oob_frac` 与 `dark_mean`,避免把越界/压负当成保真 |
| **【已发生,P2】保真指标与去噪强度混淆** | 不作为的模型在 core/body 上全得 1.000。**强制**与 `hf_noise_reduction` 同表报告,只在同去噪强度内比较(`pattern_scan_report.py` 的 DENOISE_FLOOR);训练 loss 更低不构成优点证据 |
| **【已发生,P2】跨模式结论仅 n=8、单种子** | L23 中仅角色置换部分有内部对照;其余为假设级。关键结论补 ≥3 种子后才可写入论文 |
| SVD 谱在不同序列间差异大,秩带不通用 | 每序列独立报告谱分析,秩带按能量集中度自适应而非硬编码 |
| 近表面结构性零层干扰训练 | prepare 阶段已识别;必要时加体素有效掩码,并记录为已知的预处理选择 |
| 无 ground truth 难以定量 | 以无参考指标 + 仿真补数据 + 视觉评估三层组合;Phase 4 明确补 GT 计划 |
| 多变量混淆(网络/损失/采样同时改) | 全程执行"只改采样"纪律;每次实验只动一个变量 |
