## 0. 项目主线、研究目标与创新点

### 0.1 一句话主线

**利用时序交叉拟合的 SVD 子空间投影，从波束合成后的复数 IQ 序列中构造两份同空间网格、可检验统计关系的候选观测；先验证这对观测能否提供可信的自监督监督信号，再检验 VALID 的三维空间正交约束能否在该监督信号之上带来额外的微血管结构保真收益。**

该主线不是继续优化“根据 SVD 分数从 8 种 Tetris 模式中选一个”。当前项目结果已表明：现有 patch 级选择器退化为近似固定 pattern 4，选择分数没有展现跨时间拆分的稳定预测力。新方案应改变 SVD 的作用位置：从**采样模式选择器**转向**候选监督观测的构造与验证机制**。

### 0.2 研究目标

1. **数据层目标：**确认 SA64/HSA64 的复数 IQ 数据可被稳定读取，并复现官方 SVD / Power Doppler 处理的主要结果。
2. **观测对目标：**仅使用互不重叠的时序帧组，配合独立校准帧组估计的共同 SVD 投影，构造同一空间网格上的候选体积对 \((D_A,D_B)\)。
3. **统计目标：**判断 \((D_A,D_B)\) 是否同时满足足够的结构一致性、可接受的强度偏差和低到可利用的残余噪声相关性。不能把“帧不重叠”直接等同于“噪声独立”。
4. **方法目标：**先建立单纯时序观测对的 Noise2Noise（N2N）基线，再以受控的辅助损失引入 VALID 三维正交自监督，验证其是否有独立增益。
5. **证据目标：**通过同数据、同预处理、同模型容量、同训练预算的消融，多随机种子复现，使用独立帧组与明确的结构指标评估，分离“观测对有用”“VALID 有用”与“二者互补”这三个不同命题。

### 0.3 核心研究问题与可证伪假设

| 编号 | 研究问题 | 可检验假设 | 否证条件 |
|---|---|---|---|
| H1 | 交叉拟合 SVD 能否构造可信的候选观测对？ | 使用校准帧组估计的同一个投影处理两个不重叠观测帧组后，两份体积保留一致的血管结构，且误差/残差统计具备可利用的差异。 | 弱血管大量丢失、两视图结构不一致，或残差相关性并未比现有构造更低 / 无法可靠估计。 |
| H2 | 时序候选观测对能否支持直接 N2N 去噪？ | \(D_A\) 作为输入、\(D_B\) 作为目标，以及反向训练，能在独立帧组上稳定提升去噪—结构保真折中。 | 收益仅见于训练观测对，跨折不复现，或改善完全来自过度平滑 / 强度缩放。 |
| H3 | VALID 空间正交约束是否带来额外收益？ | 在相同 \(D_A,D_B\) 观测对和同样的训练预算下，N2N + VALID 辅助项优于纯时间 N2N。 | 混合方法不优于纯 N2N；或增益不能跨种子、序列及结构指标复现。 |
| H4 | 增益来自 SVD 交叉拟合，而非普通时间拆分？ | 与“不做独立 SVD 校准”“直接分帧生成 Power Doppler”等对照相比，交叉拟合投影有可测且可迁移的贡献。 | 交叉拟合没有额外增益，或简单时间拆分已达到同等效果。 |

### 0.4 预期创新点（待验证，不提前宣称成立）

**候选创新点 1：时序交叉拟合的 SVD 监督观测构造。**  将子空间估计帧与监督观测帧分离；同一个、由独立校准帧估计的投影作用于两组不重叠的 IQ 帧，减少观测自身噪声同时参与子空间估计和目标构造所造成的依赖。该机制必须通过跨帧、跨折统计检验，而不是仅凭“交叉拟合”这一名称宣称独立。

**候选创新点 2：时间互补监督与三维正交约束的互补性检验。**  将同空间坐标上的时间 N2N 监督作为主监督，以 VALID 的空间正交损失作为可开关的辅助项；通过纯 N2N、纯 VALID 和混合方法的对照，直接回答两种冗余来源是否互补。

**候选创新点 3：针对微血管结构的分层验证协议。**  将噪声抑制、血管中心线 / 分支 / 宽度、背景虚假增强、输出范围分开报告，防止以高频下降或输入—输出相关系数单独作为去噪质量结论。该部分属于支撑方法结论的必要实验贡献，单独是否构成论文创新取决于最终发现。

> **重要边界：**SVD 的代数正交不意味着噪声独立；不重叠帧不意味着时间噪声独立；共用同一个投影有利于保持两观测的滤波定义一致，但也不能自动保证观测误差独立。上述性质都需要测量。

### 0.5 不做什么

- 不再将当前 Q(k) 分数用于核心主线，也不以 C3 > B3 作为 SVD 引导有效的证据。
- 在观测对统计假设通过验收前，不开展大规模网络训练。
- 不直接把官方全 400 帧 Power Doppler 当作干净 ground truth；它与训练帧有数据重叠，只能明确标为高帧数参考 / 伪参考。
- 不把 rank 60–350 / 350–400 机械套到帧数更少的交叉拟合子集。子空间可用秩数受校准帧数量限制，必须重新定义秩选择规则。
- 不在第一轮同时改 CRN、所有损失、优化器、输入表示与采样几何。每轮只引入一个可归因变化。
- 不把目前尚未验证的混合损失直接写成“新方法”。若 VALID 辅助项没有增量，主线应转向真正有效的时序自监督方法或停止融合。
- **不在 Phase 2 未通过时换秩带、换分组、换观测定义或加网络复杂度去救。** v1 的教训就是"前提不存在时，换实现永远救不回来"。Phase 2 未通过即按结论 D 停止并完整记录，不进入大规模训练。
- **不用"改判据"来让一个未通过的结论变成通过（v0.5 新增）。** §5.6 替换指标的依据是
  **指标本身被证伪**（零重叠下跨设计相差 8–27 倍、与图像相似度 Spearman +0.93…+0.98），
  不是"它没通过所以换一个"。替换必须同时满足：(i) 旧指标有可复现的否证记录；
  (ii) 新指标有"已知答案"标定；(iii) 新指标的门限在**运行之前**写进本文档。
  三条缺一，替换无效。同理，新指标若也失败，不得再换第三个，而应按结论 D 停止。
- **不因为指标替换而放宽对设计的要求。** v0.5 把观测臂数由 2 提到 ≥3，代价是每臂帧数减少
  （C=133 时每臂约 89 帧）。**不接受"为了保住 133 帧/臂而退回 2 臂"**——2 臂的独立性
  不可识别，不是本钱不足，是问题本身没有答案。

### 0.6 本方案最可能的失败方式（请先接受这个前提）

**最可能的失败不是"网络不行"，而是"配对里没有噪声"。**

官方强度的 SVD 滤波（保留 1-based 60–350）会丢掉约 **99.93%** 的能量（该比例是 v1 在本数据上的实测值）。滤波之后，\(D_A-D_B\) 里究竟有多少是"可独立利用的噪声"，有多少是**真实的血流变化**？如果以后者为主，N2N 的目标噪声就与输入噪声同源，网络会去平滑掉真实的血流信息——Phase 2 会失败，整条线在训练之前就停住。

这就是本文档 §9 的"结论 D"。**它不是小概率分支，而是相当可能的分支。** 需要提前接受的是：

- 发现它的成本很低（**Phase 0–2 全程不训练网络**，最坏情况是数小时得到一份干净的否证记录）；
- 那也是一个有价值的、可写的结果，只是要提前定好边界——不要到时候为了救它去换秩带、换分组；
- 若 Phase 2 通过，才值得投入 Phase 3 之后的算力。

## 1. 数据、符号与方法定义

### 1.1 数据条件

Dryad `Data_SA64.mat` 和 `Data_HSA64.mat` 是波束合成后的复数 IQ 体积序列，而非未经波束合成的逐阵元原始 RF 通道数据。SA64/HSA64 的典型数据尺寸为 \(Z\times X\times Y\times T=37\times64\times64\times400\)，体素间距约 0.15 mm，帧率约 46.875 Hz。读取时要检查 MATLAB v7.3/HDF5 的轴顺序及复数 `real/imag` 复合字段。

数据事实与公开来源：

- Dryad 数据集：<https://datadryad.org/dataset/doi:10.5061/dryad.47d7wm3qg>
- 当前转换脚本：[`scripts/prepare_svd.py`](https://github.com/winb0408/SVD-VALID/blob/main/scripts/prepare_svd.py)
- 官方 VALID：<https://github.com/FDU-donglab/VALID>

### 1.2 符号约定

- \(X\in\mathbb C^{V\times T}\)：展平空间维度后的复数 IQ 数据，\(V=ZXY\)，时间为列。
- \(\mathcal C\)：校准帧集合，只用于估计 SVD 子空间与预先规定的秩选择规则。
- \(\mathcal A,\mathcal B\)：互不重叠的观测帧集合，不参与当前折的子空间估计。
- \(X_C,X_A,X_B\)：相应帧集合组成的矩阵。
- \(U_C\)：校准矩阵的左奇异向量（空间基）。
- \(\mathcal R_C\)：仅依据校准帧数据、预先约定的规则选出的保留模式集合。
- \(P_C=U_{C,\mathcal R_C}U_{C,\mathcal R_C}^{H}\)：共同空间投影。
- \(Y_A=P_CX_A,\;Y_B=P_CX_B\)：经过相同投影的复数 IQ 观测。
- \(D_A,D_B\)：由 \(Y_A,Y_B\) 分别计算的三维 Power Doppler 或预定义的强度表示。

### 1.3 候选观测构造的第一版定义

1. 按空间轴顺序和复数格式读取 IQ，形成 \(X\in\mathbb C^{V\times T}\)。
2. 根据预先规定的帧分组方案，划分 \(\mathcal C,\mathcal A,\mathcal B\)，确保三组帧索引互不重叠。
3. 只用 \(X_C\) 做 SVD：

   \[
   X_C=U_C\Sigma_CV_C^H.
   \]

4. 根据仅使用校准组即可执行的秩选择规则，确定 \(\mathcal R_C\)，并构造 \(P_C\)。
5. 将**同一个** \(P_C\) 应用于 A、B 两组：

   \[
   Y_A=P_CX_A,\qquad Y_B=P_CX_B.
   \]

6. 分别在各自的帧组上计算功率。**必须保证 \(T_A=T_B\)**（默认丢弃多余的 1 帧使其相等），否则下式的均值归一化会引入一个 \(T_B/T_A\) 的**系统性强度尺度差**——Phase 2 的强度门槛会因此必然报警，而报警是定义造出来的、不是数据里的：

   \[
   D_A(\mathbf r)=\frac{1}{T_A}\sum_{t\in\mathcal A}|Y_A(\mathbf r,t)|^2,
   \quad
   D_B(\mathbf r)=\frac{1}{T_B}\sum_{t\in\mathcal B}|Y_B(\mathbf r,t)|^2,
   \qquad T_A=T_B .
   \]

   帧数相等还有第二个好处：两组的功率估计方差相同，N2N 的期望目标才严格等于同一个量。若某一折确实必须使用不等帧数，则改用公共除数（或官方口径的 `sum`），并把该选择显式记录在 `pair_qc.json` 中。

7. 如需对数强度，先固定 \(\epsilon\)、动态范围和归一化规则，再单独生成变换版本。不可对 A/B 各自使用不同分位数映射，否则会人为改变两视图的强度统计。

此处先采用“共用校准投影”的主设计，是为了使 A、B 经过相同的空间滤波算子。另设“分别由 A/B 自身估计投影”的消融，用来测量独立子空间估计带来的子空间漂移与观测误差；该消融不能默认优于共同投影。

### 1.4 时间分组策略

**不以简单连续前半段 / 后半段作为唯一主方案。** 连续拆分容易把真实血流的慢变化与时间噪声差异混在一起。主方案采用时间覆盖较均匀的交错分组，并保留连续分组作为敏感性分析。

第一轮候选：

- 将 400 帧按帧索引交错分成 3 组（**133 / 133 / 134**），轮流作为校准组 C、观测组 A、观测组 B；A 与 B 必须等帧数，多余的 1 帧固定归入 C（见 §1.3 第 6 条）；
- 再做 5 折交错拆分（每折 80 帧），每次取两折为 A/B（各 80 帧，天然等长），其余三折共 240 帧为 C，共 C(5,2)=10 个交叉拟合组合；
- 比较连续切分与交错切分，检查血流动态改变和残差时间相关的影响。

上述数量是首轮设计建议，不意味着 3 组 / 5 折必然最优。若 3 组导致校准 SVD 可用秩过少，或 80–133 帧不足以生成稳定的 Power Doppler，就应先调整分组方案并记录原因，不得跳过统计可行性验证。

### 1.5 秩带 / 子空间选择原则

**已核实的官方口径**（`main_supplementary_figure_2.m`，随 Dryad 数据集提供）：SA64 / HSA64（各 400 帧）用**全部 400 帧**估计时域协方差，`eig` 后 `fliplr` 得到降序特征基，血流带取 `SVDcut1_400:SVDcut2_400 = 60:350`，即 **1-based 第 60–350 个模式、共 291 个**；功率图为 `sum(abs(filtered).^2,4)`，dB 为 `10*log10(PD/max(PD))`，显示窗口 `clim=[-20,0]`。

> **三处必须记录的偏差**（本仓库现有管线 vs 官方）：
> 1. 官方保留 **291** 个模式（1-based 60–350，含两端）；`scripts/prepare_svd.py` 用 0-based 切片 `V[:,60:350]` 只保留 **290** 个，少一个模式。若要严格复现官方，应改用 `V[:,59:350]`。
> 2. 官方用 `sum` 过帧，本仓库用 `mean`。经最大值归一化的 dB 图不受影响，但在交叉拟合里会**被帧数差异放大成系统性偏差**（见 §1.3 第 6 条）。
> 3. 「高秩残差带 350–400」**不是官方定义**，是本项目为了估计噪声水平自行引入的噪声带。对外表述不得称之为"官方秩带"。

**这套秩号不能直接用于仅有约 133 或 240 帧的校准矩阵**：可用奇异向量数受时间样本数限制（秩上限 = \(T_C\)），而且不同数据子集上的奇异向量顺序与分布会变化。因此交叉拟合的秩选择规则必须重新定义（见下文），且**不得**把"整序列 60–350"直接搬到校准组上。

#### 1.5.1 Phase 1 实测结论：官方带的右边缘**无法从奇异谱上识别**（v0.3 新增，已实测）

以整片 400 帧的奇异谱（`data/processed/crossfit/<seq>/spectrum_full.npy`，由 Phase 1 产出）实测：

| 量 | SA64 | HSA64 |
|---|---|---|
| 模式 1 占总能量 | 93.07% | 96.43% |
| 前 60 个模式累计 | 99.9168% | 99.9913% |
| 官方带 60..350 **实际携带**的能量 | **7.3e-4** | 8.3e-5 |
| \(\lambda_{60}/\lambda_{400}\) | **1.58** | 13.06 |
| 模式 61→400 的对数跨度 | **0.20 个数量级 / 340 个模式** | 1.10 / 340 |

**读法**：能量在前 60 个模式内就掉干净（模式 1 一个占 93%），此后 340 个模式的奇异值在 SA64 上只变化 **1.58 倍**。
**这条谱上不存在能把"血流"与"噪声"分开的阈值**，官方带的右端点 350 落在平尾巴**内部**，
更接近 `clim=[-20,0]` 显示约定下的**目视经验值**，而非从谱结构读出。

四条候选秩规则在同一序列上互相矛盾，**且同一规则跨序列也不一致**（1-based 闭区间，整片 400 帧）：

| 规则 | 判据 | SA64 | HSA64 |
|---|---|---|---|
| `proportional` | 官方 60:350 按帧数等比缩放 | [60,350] = 291 | [60,350] = 291 |
| `spectral` | 杂波功率掉到 1% 以下 + SNR 门限 | [3,18] = 16 | [3,66] = 64 |
| `cum_energy` | 累积能量 0.999 + 丢弃 1e-4 | [25,352] = 328 | [9,51] = 43 |
| `clutter_knee` | 尾部对数直线外推 + 1 dB | [47,400] = 354 | [148,400] = 253 |

注意 `spectral` 与官方**语义相反**：它只去杂波、保留靠前模式，而官方带是**丢掉**前 59 个模式。

**第二条实测结论（决定 Phase 2 的报告结构）**：保留子空间的可复现性随秩带宽度强烈分化。
以 `cos_mean(C, X)`（用 C 估计的保留子空间 vs 用 X 自估的保留子空间的平均主角余弦；1=同一子空间，0=正交）度量：

| split | proportional | cum_energy | clutter_knee | spectral |
|---|---|---|---|---|
| sa64_int3 (R=97/102/104) | 0.116 | 0.129 | 0.080 | **0.954** |
| sa64_int5 (R=175/192/202) | 0.104 | 0.175 | 0.106 | **0.952** |
| sa64_cont3 | 0.048 | 0.063 | 0.051 | **0.669** |
| hsa64_int3 | 0.542 | 0.864 | 0.371 | **0.922** |

- **宽带（R≈97–202）在 SA64 上近似正交**：宽带子空间主要由**帧特有的方向**撑起，可复现的共同成分很小。
  HSA64 上同一批规则却高得多（0.37–0.86）——**序列间差异巨大，此性质不可跨序列搬用**。
- **窄带 `spectral`（R≈7–27）高度可复现**（0.92–0.95）；**连续分组明显退化**（0.669）——
  这给"交错为主、连续为对照"这一选择提供了实测依据，而非直觉。
- 能量代价与此一致：`spectral` 的 \(P_C\) 施加到 A 后几乎无损（1.36e-2 → 1.36e-2），
  宽带规则损失 1–2 个数量级（8.26e-4 → 8.9e-5）。两处独立测量给出同一图像。

> **对措辞的硬约束（对外表述前请先读）**：不得声称"本项目找到了/复现了官方的血流带"。
> `[60,350]` 只是**照抄参数**，该带本身未获数据支持；也不得声称某条规则"是正确的"，四条互相矛盾。
> 正确表述是：**官方带的边缘不可从谱上识别，因此秩被当作需要扫描的敏感度参数处理。**

实施原则：

1. 第一阶段复现全 400 帧官方处理，建立原始参照。
2. 校准组秩选择仅使用 C 组的奇异值谱、预先选定的秩稳定性规则，以及必要的独立校准小样本；不能根据 A/B 最终去噪分数反向挑秩。
3. 明确比较至少两类秩选择规则：基于校准组的固定模式数量 / 奇异谱分位规则，以及基于已有官方 SVD 处理知识定义的候选秩比例映射。
4. 对每个选择规则，报告保留信号能量、丢弃能量、子空间稳定性、候选血管结构保留及 A/B 一致性。
5. 如不能获得稳定且跨折可复现的投影，不进入模型阶段。

## 4. Phase 1：交叉拟合 SVD 观测对构造

### 目标

生成若干组三维体积对 \((D_A,D_B)\)，它们拥有同一空间网格、使用相同的 SVD 投影、由互不重叠的观测帧形成，而且其子空间估计没有直接使用当前 A/B 帧。

### 执行步骤

#### 1. 实现可重复的分组器

- 输入：总帧数 T、分组策略、fold 数、seed（若分组需随机化）。
- 输出：`split_manifest.json`，逐个记录每帧属于 C/A/B 哪组，或属于哪个 fold。
- 运行 assert：A、B、C 互不相交；每帧在当前划分中只归入一个角色；交错分组覆盖整个采集周期。
- 主方案使用交错时间分组；连续时间分组作为敏感性对照。

#### 2. 构建交叉拟合矩阵

- 将空间维展平：`X.shape = [Z*X*Y, T]`，保留复数类型。
- 对当前 fold 的 C 帧单独计算时间 Gram 矩阵或等价 SVD，得到 `U_C` 与奇异谱。
- 保存 SVD 的 rank 上限、保留模式、能量比例、奇异谱和子空间稳定性数据。
- 重要检查：若 C 只有约 133 帧，SVD 模式数不能超过其数值秩；所有配置必须自动检查秩边界。

#### 3. 扫描秩带（v0.3：原"选定校准组内秩带"已按 Phase 1 实测结果改写）

> **为什么改写**：原步骤的前提是"存在一个能确定校准组秩带的规则"。Phase 1 实测（§1.5.1）表明
> **不存在这样的规则** —— 官方带的右边缘落在平尾巴内部，从谱上不可识别。继续"选定"一个秩，
> 等于把一个**没有数据依据的选择**伪装成结论。因此改为**扫描 + 分开报告**。

- 先完成校准组奇异谱的数值诊断，**并把"谱在候选带内近乎平坦"这一事实作为诊断输出记录**，
  不以"图看起来对"作为接受判据。
- **不再试图确定唯一的最优秩。** 秩是被扫描的敏感度轴，必须覆盖**至少两个数量级**：
  Phase 1 实测 R=7 与 R=202 都各自有"合理"的选定理由，两者产生的观测对结构完全不同。
- 至少覆盖 Phase 1 已实现的四条规则（`proportional` / `spectral` / `cum_energy` / `clutter_knee`），
  并保存规则版本号与全部参数。**四条规则互相矛盾这一事实本身要被报告**，不得只挑一条。
- **宽 / 窄滤波是本阶段的两类不同构造，不是同一方法的两个超参**：
  - 宽带 \(P_C\)（R≈100–200）是**强去相关算子**（只保留 A 组能量的 1e-4~1e-5）；
  - 窄带 `spectral`（R≈7–27）近乎恒等（保留 1e-2 量级，跨帧子空间夹角 0.92–0.95）。
  二者的噪声结构不同，**所有下游统计必须分组报告，不得合并**。
- 对每个规则记录：保留子空间维数、奇异值能量、跨折子空间夹角 / 投影差异、输入到投影输出的信号变化。
- **不得**通过网络损失反向挑选秩；也不得在 Phase 2 未通过后换秩带重试（见 §0.5 / §11）。
- 严禁以 A/B 的观测质量（结构保真、目视效果、下游指标）作为选择秩带或分组方式的依据。

#### 4. 生成共同投影与两组候选观测

```python
# 概念伪代码，不是现有仓库的可直接运行实现
U_C, spectrum = svd_spatial_basis(X_C)
R_C = rank_rule(spectrum, calibration_only=True)
P_C = U_C[:, R_C] @ U_C[:, R_C].conj().T
Y_A = P_C @ X_A
Y_B = P_C @ X_B
D_A = mean(abs(Y_A) ** 2, axis=time)
D_B = mean(abs(Y_B) ** 2, axis=time)
```

- 将 `P_C` 的显式矩阵或可等价执行的低秩投影参数保存下来；对于大体积数据，优先以低秩乘法实现，不创建高内存占用的稠密投影矩阵。
- A/B 使用同一个 `P_C` 与同一个功率变换。
- 同时保存投影前后 IQ 与功率域的摘要统计，避免只存最终强度图导致无法审计。
- 生成一套使用各自观测组估计投影的独立投影消融，但不作为默认方法。

#### 5. 生成对照观测对

最少构造以下三类候选对：

- **Pair-P0：无 SVD 校准的时间拆分基线。** 从 A/B 原始波束合成 IQ 分别计算功率体积，测试纯时间拆分本身的观测价值。
- **Pair-P1：共同校准投影的交叉拟合对。** 使用 C 估计共同投影，再应用到 A/B，这是候选主方法。
- **Pair-P2：分别估计投影的消融。** A/B 各自估计投影，用于分析子空间漂移和独立估计误差，不预先认定更优。

每类对均使用同一空间坐标与统一强度变换；不可分别对 A/B 做各自 percentile remap。对于 log 域，先记录 epsilon、log 底数、动态范围和是否截断。

## 5. Phase 2：候选观测对的统计可行性验证（关键闸门）

### 目标

在不训练深度网络的情况下，回答 \((D_A,D_B)\) 是否有资格被用作 N2N 训练对。该阶段是整个项目的核心决策关口。

### 需要分开测量的四件事

1. **噪声代理的直接标定（最先做，成本最低，可能单独决定成败）。** 高秩残差带（≈350–400，本项目自建概念，见 §1.5）本身不含血流信号，可以直接当作噪声代理：测量它在相邻帧、间隔 2 帧、……、间隔 k 帧上的时间自相关（分 ROI、分深度）。**若 lag≥1 处已接近 0，"帧不重叠 ⇒ 噪声独立"就成立，N2N 才有成立的基础；若显著非零，先据此决定交错/连续分组的取舍，再谈其他。** 这一项不需要训练，却直接检验整个方案的核心前提。

   > **v0.3 追加：必须同时报告残差带的绝对功率水平，且必须先做一次前提自检。**
   > Phase 1 实测（§1.5.1）宽带保留子空间在不同帧子集间**近似正交**（`cos_mean(C,X)` 仅 0.05–0.18），
   > 说明宽带 \(P_C\) 主要由**帧特有的方向**撑起来。因此存在一个替代解释：
   > \(D_A-D_B\) 的差异**并非来自独立噪声，而是来自 A/B 各自的帧特有结构被 \(P_C\) 削掉后的残留**。
   > 只测"自相关是否非零"无法区分以下两种情况：
   > (i) 残差里**没有噪声**；(ii) 残差里有噪声，但**噪声已被 \(P_C\) 提前抹掉**。
   > 二者对项目的含义完全不同（(i) 判死，(ii) 说明投影过强、应缩窄秩带）。
   > 故本项必须**成组报告**：`{残差自相关(lag 1…k), 残差带绝对功率, 残差带功率 / P0 功率}`，
   > 并**按宽/窄两类构造分别给出**（见 §4 步骤 3）。缺少后两项的结论不予采信。
2. **结构一致性：**两份观测是否呈现同一血管网络，而不是一份漏掉弱血管或改变大量细血管宽度。
3. **强度一致性：**功率分布、局部血管—背景对比与分位数是否存在系统偏差；若存在，偏差能否通过对两组共享的变换消除，而不对各组分别重标定。
4. **残差相关性：**不能只计算 `corr(D_A, D_B)`，因为真实血管信号本来就应该相关。需要把共同结构与波动分开，分析局部去趋势后的差异、时序残差以及背景区域中的相关结构。
5. **跨折稳定性：**结论是否只出现在某一组帧、某一秩带或某一种时间拆分方式。

### 执行步骤

#### 1. 结构一致性图与数值

- 在同一共享强度尺度下显示 A、B、全序列高帧数参考体，以及 A/B 差异图。
- 比较三正交中面、MIP 和微血管局部放大区域；MIP 不得单独作为结构保留结论。
- 在固定分割协议下计算：血管候选区域 Dice / Jaccard、中心线覆盖率（设置一个体素容差，并固定规则）、连通分支数、血管宽度分布与强度剖面。
- 全序列体积只称为“全帧参考 / 伪参考”，因为它与 A/B 来自同一个采集，不是独立干净真值。

#### 2. 噪声与差异统计

- **（本阶段首项）用高秩残差带直接标定噪声的时间相关结构**。在交叉拟合的投影域内，取高秩残差带（≈350–400）作为噪声代理，测量其时间自相关函数（lag 1…k，分 ROI / 分深度）；并报告"交错分组"与"连续分组"下的自相关差异。判读：lag≥1 接近 0 → 时间白噪声，"帧不重叠 ⇒ 噪声独立"成立；显著非零 → 该相关性就是 N2N 的敌人，必须先用分组方式把它压下去。
- **（v0.3 新增，与上一条同批执行）区分"无噪声"与"噪声被投影抹掉"**。对上一条测得的残差，**同时**报告其绝对功率水平与相对 P0 的功率比；并在**宽（R≈100–200）与窄（`spectral`, R≈7–27）两类秩带下分别重复**。判读：若窄带下残差自相关显著、宽带下消失，则说明宽带 \(P_C\) 把噪声连同帧特有结构一起抹掉了，**N2N 的监督信号也在其中被抹掉** —— 这是比"自相关非零"更早出现的失败模式，应据此缩窄秩带（须记录为一次有依据的修正，而不是为救结果换参数）。
- 再在复数 IQ 层面分析保留带（血流带）内的时间残差：检查各区域的时间自相关、相邻帧与间隔帧相关，以及不同深度区域的方差变化。
- 使用统一的信号 / 背景 ROI 协议，报告背景残差的均值、方差、偏度、空间自相关和 A/B 的差异分布。
- 进行局部去趋势前后对照，但不将“扣局部均值后的残差”直接等同于纯噪声；需将其标注为噪声代理量。
- 若使用 \(D_A-D_B\) 作为噪声差异代理，需明确其中还包含血流动态、估计误差和功率统计波动。
- 将新观测对与当前 VALID 的 Tetris 视图、直接时间拆分 Pair-P0、Pair-P2 投影消融统一用相同估计器比较。

#### 3. 跨折 / 不同时间拆分复验

- 至少覆盖三种 C/A/B 轮换组合。
- 对主要指标报告每折值、均值、95% bootstrap CI；bootstrap 单元使用非重叠空间块或独立 fold，不将高度重叠滑窗当作独立样本。
- 在 SA64 上开发，在 HSA64 上做第一次不改阈值的复现。

#### 4. 预注册首轮通过门槛

以下门槛为**建议的初始工作标准**，在看到模型结果前可依据 Phase 0 的经验重复性校准一次，随后冻结：

- **结构门槛：**在高信噪血管区域，A/B 的血管候选结构和中心线覆盖不得出现系统性的大幅下降；建议以相对全序列参考的中心线覆盖率 ≥0.85、局部血管宽度中位数变化 ≤15% 作为首轮警戒线，而非绝对真值指标。
- **强度门槛：**使用同一强度映射后，A/B 在高置信血管区域的强度比不得呈现明显的全局偏差；报告中位数、分位数差与 ROI 分布，不以分别归一化后的相关系数替代。

#### 5. 审计补充门槛（v0.4 新增，2026-10-19）

外部审计与随后的复核（`reports/phase2_audit_verdict.md`）确认：上述噪声统计门槛**即使数值通过，
也不足以判定噪声独立性**，必须在同一门槛之外再满足下面两条，缺一不得进入 Phase 3。

**(a) 空间算子必须匹配。** 残差统计的对照与被测臂对必须走**同一个空间算子**。
原实现中 P1 两臂带着 SVD 投影直进统计，而 TETRIS 对照先被 2×2×2 块平均再回填，
这个不匹配单独就能造出 +0.5…+1.1 的假差距。实测分解显示混淆主要来自**相位切分**
（−0.30…−0.38），smoothing 只贡献 +0.006…+0.014。

**(b) 必须报告随机划分零分布（构念效度对照）。** 匹配算子后得到的边距，必须与
"把同一批帧随机切成两半、走同一投影与同一对照"的零分布并列报告。

#### 6. Gate N：噪声独立性门槛（v0.5 新增，取代 §5.4 噪声统计门槛）

##### 6.1 为什么必须换，且为什么换公式不够

**为什么必须换。** 标定实验（`reports/phase2_metric_calibration.md`）在两个锚点都通过的前提下
（overlap=1 时 `rel_matched` 精确为 0；overlap=0 时复现审计数字到第三位小数），得到：

| 事实 | 数值 | 含义 |
|---|---|---|
| 两臂**零重叠**时，指标跨三种切法 | SA64 −0.040 / −0.153 / −0.317；HSA64 −0.012 | 独立性由构造保证，答案却差 8–27 倍 |
| 指标与 `power_map_r` 的 Spearman | +0.93…+0.98 | 它测的是"两臂图像有多像" |
| 同一设计内指标随臂重叠 | 16/16 单调 | 它对"两臂变得更像"确有反应——只是不是独立性 |

**为什么换公式不够。** 直接测两臂噪声的复相关系数（`e = x − 全帧均值`，再取臂均值）也失败：
小 N 时臂均值被两臂共享的 `−μ` 支配（`‖dA‖²/‖μ‖²` 从 N=10 的 0.50 降到 N=133 的 1.1e-05，
rho 恒趋 +1，与独立性无关）；全 N 时 `Σ_all(x−μ)=0` 的有限池约束把不相交子集的相关推向负值
（−0.10…−0.44）。**两端坏、中间空。**

根因是**可识别性**，不是公式选择：两条臂 + 无真值时，
\(d_i = s + \varepsilon_i\) 中的 \(s\) 与 \(\mathrm{Cov}(\varepsilon_1,\varepsilon_2)\) 无法分离——
任何两臂统计量要么假设独立性（那就是循环论证），要么测到别的东西。
**因此替换必须引入第三个参照物。**

##### 6.2 Gate N 的定义

**臂配置（硬要求）。** 同一次评估中必须有 \(k \ge 3\) 个**互不相交**、且**都不参与投影估计**
（即 \(C\cap G_i=\varnothing\)）的帧组 \(G_1..G_k\)，全部经**同一个** \(P_C\) 成图得到 \(D_1..D_k\)。
默认取 \(k=4\)：\(C=133\)，其余 267 帧按同一时间策略切成 4 组（每组约 66 帧）。
\(k=3\) 允许，但统计功效更低；\(k=2\) **不接受**（不可识别）。

**模型。** 逐体素 \(D_i(v)=S(v)+\varepsilon_i(v)\)，\(S\) 为各臂共有的信号，\(\varepsilon_i\) 为臂特有噪声。

**估计量（k 臂协方差分解）。** 令 \(c_{ij}=\mathrm{Cov}_v(D_i,D_j)\)（跨体素样本协方差，
**不做任何共享的减均值**——各 \(D_i\) 只减去它自己的体素均值）：

- 信号方差：\(\hat V_S=\operatorname{mean}_{i\ne j}\big(c_{ij}-\rho_\varepsilon\,\sqrt{\hat V_i\hat V_j}\big)\) 的解，
  在独立假设下退化为 \(\hat V_S=\operatorname{mean}_{i\ne j}c_{ij}\)，并作为迭代起点；
- 噪声方差：\(\hat V_i=c_{ii}-\hat V_S\)；
- **噪声相关**：\(\hat\rho_{ij}=(c_{ij}-\hat V_S)/\sqrt{\hat V_i\hat V_j}\)。

\(k\ge3\) 时多余观测（\(k(k-1)/2\) 个 \(c_{ij}\) 而只有 1 个 \(V_S\)）使该量**可检验**；
\(k=2\) 时方程数与未知数相等，\(\hat\rho_{12}\equiv0\)，这就是可识别性的算术表述。

**不确定性。** 跨体素的空间块 bootstrap（块沿用现有 4³/12³ 两档），\(\hat\rho\) 的 95% CI。
另报告 \(k\times k\) 的完整 \(\hat\rho\) 矩阵与 \(\hat V_i/c_{ii}\)（噪声占图像方差的比例）。

**直接可解释量。** \(R^2_{ij}=\hat\rho_{ij}^2\) = **目标臂噪声中可由输入臂噪声解释的方差比例**。
这正是 N2N 会去拟合、并留在输出里的那部分。

##### 6.3 预注册门限（运行前写定，不得事后调整）

| 项 | 门限 | 理由 |
|---|---|---|
| 主判定 | 所有臂对 \(\hat\rho_{ij}\le 0.10\)，且块 bootstrap 95% CI **上界** \(\le 0.10\) | \(\rho=0.10\Rightarrow R^2=1\%\)，即 N2N 最多把 1% 的目标噪声当信号学走；这是"可忽略"的常识尺度，不是从数据里调的 |
| 稳定性 | 方向必须在 ≥3 个折叠配置（不同 C 组 / 不同交错相位）上一致；HSA64 不要求每项显著，但不得出现显著相反结果 | 沿用 §5.4 稳定性门槛口径 |
| 一致性检验 | \(c_{ij}\) 的离散度（跨臂对的相对标准差）须匹配独立假设下的 block-bootstrap 预期；显著超出即为共享噪声 | 用三臂以上的多余观测直接检验 |
| 加性注入标定 | 见 6.4；先用后不用 | 任何门限在生效前必须先被这个标定证明"能测出来" |

**已知盲区（必须写在结论里）。** 一个**所有臂共有**的噪声成分在 \(k\) 臂分解中与 \(S\) 不可区分，
会被算进信号。缓解办法只有时间策略（交错取样把慢变成共有变共有、快变分解掉）——
所以结论的措辞一律是"在交错取样的前提下"，不得写成无条件独立。

##### 6.4 加性注入标定（替代原 (d) 的替换型合成基准）

**做法。** 保持真实 IQ 不变，向帧上**叠加**一个已知的复高斯噪声场：
共享部分按比例 \(\alpha\) 在两臂间共用同一实现，其余独立。\(\alpha\in\{0,\,0.25,\,0.5,\,0.75,\,1\}\)。
**通过判据：\(\hat\rho\) 在 \(\alpha\pm0.10\) 内恢复，且单调。** 不通过则 Gate N 不得用于判定。

**为什么换成加性。** 替换型基准会改写真实帧的包络与逐帧空间异质性——四次尝试都因此
在"真实相关"轴上完全平坦。加性注入不触碰原有内容，只在上面叠一层已知成分，
因此既能给出已知答案，又不会把数据变成另一种东西。注入幅度需扫描到能在
\(D_i\) 上分辨为止，报告该幅度，并说明真实数据上该幅度对应什么信噪比。

##### 6.5 Gate S：诊断量（不参与判定）

原 `rel_matched` / `rel_as_impl`、`power_map_r`、Tetris 对照边距**继续报告**，统称 Gate S，
标注为"**图像相似度诊断，不是独立性证据**"。保留它们的理由：它们仍能发现
"两臂图像严重不一致""投影把结构抹掉"这类失败，这是 Gate N 看不见的。

##### 6.6 判定口径（v0.5）

| 结果 | 处置 |
|---|---|
| Gate N 标定通过 **且** 正式评估通过 **且** 稳定性一致 | 可提出 Phase 3 训练申请 |
| Gate N 标定通过但评估不通过 | 观测对不满足 N2N 前提。**按结论 D 停止**，不改臂数/帧数/切法去凑；可写否定性结果 |
| Gate N 标定不通过 | 指标仍不可用。至此已用掉两次机会（原 proxy、Gate N），**不得再换第三个指标**，按结论 D 停止并记录 |

##### 6.7 实现现状与必要条件（2026-10-19 回填）

代码：`scripts/gate_noise_independence.py`；结果：`reports/phase2_gate_n.md`。

**三个"不修就得到错误答案"的定义性要求**（不是调参，是估计量成立的前提）：

| # | 要求 | 不做的后果（实测） |
|---|---|---|
| 1 | \(V_S=\operatorname{median}_{i\ne j}c_{ij}\)，**中位数不是均值** | "均值起步 + 迭代减共享项"退化——\(\alpha=1\) 时任何 \(V_S\) 都是不动点，实测 \(V_S=1.171\)（真值 1.000） |
| 2 | 先做**臂间增益归一**再分解 | 真实数据四臂图彼此成正比到 2%（\(c_{ij}=a_ia_j\mathrm{Var}(u)\)，\(a=(12.21,11.77,10.85,10.92)\)）；不归一则 `noise_frac` 出负值、\(\hat\rho\) 冲到 1.087 |
| 3 | 增益回归的参考用**逐体素中位数**，不用均值 | 被注入的一对臂污染均值参考，把未注入臂对拖到 \(\rho=0.89\)；中位数参考降到 0.31 |

第 2 条说明一件对方案有普遍意义的事：**真实数据上 \(D_i=S+\varepsilon_i\) 并不逐字成立**，
四张投影图之间存在全局增益差。任何基于该模型的估计量都必须先消掉这个自由度。

**加性注入标定结果（未通过）**：\(\alpha=0\) 读 0.000–0.033、\(\alpha=1\) 读 0.94–1.00、全程单调，
但 \(\alpha=0.5\) 读 0.48–0.91（**压缩映射**），非注入臂对泄漏 0.31–0.89。
\(\alpha\to\hat\rho\) 不是恒等映射，所以 \(\rho\le0.10\Leftrightarrow R^2\le1\%\) 这个换算**尚未建立**。

**注入方式的三个必要条件**（踩过才知道）：共享必须是**按臂对**的（全臂共享正落在 §6.3 声明的盲区里，
实测 0.005，什么也没测到）；必须**用注入后的数据重建 Gram**（投影算子只用 `gram[C,t]` 作系数，
不重建则注入完全消失，图均值五位有效数字不变）；注入场必须有**空间包络**（空间白注入破坏
各臂正比结构，泄漏 0.89）。

**当前状态：Gate N 已实现，标定未通过，不得用于判定。** Phase 3 不启动。

##### 6.8 实现中暴露的设计耦合（不得忽略）

拉大臂间距会同时缩短臂长。本轮扫描中 \(\hat\rho\) 随 stride 上升而下降（stride 1 时 SA64 int3
六折可见 0.13–0.76，stride ≥3 后最大值降到 0.02–0.31），但 `noise_frac` 同时从 0.02–0.06
升到 0.16–0.28 —— 短臂的独立噪声平均不足，估计误差随之变大。

因此**"stride 越大 \(\hat\rho\) 越低"不能直接读成"把臂拉开即可"**。真要做这个判断，
必须先把间距与臂长的效应分离（例如固定臂长、只改间距），那是额外的实验设计。

另有一个方向性观察（同样不可当判定）：\(\hat\rho\) 随**臂长增加**而升高。物理上自洽——
长臂把独立成分按 \(1/N\) 平均掉，共享的慢变成分平均不掉——若成立，则"多给帧能让两臂更独立"
的直觉是反的。这条需要用分离实验确认。

##### 6.9 标定失败的归因与能力声明（2026-10-19 回填）

依据 `reports/phase2_gate_n_calibration_analysis.md`。本条**只记录事实与能力边界，不改判据**。

**(1) 修正 §6.2 的臂数下限。** 原文写"k≥3（默认 4）"，**这一条是错的**。把每臂增益作为自由参数后，
残差自由度为 \(\mathrm{df}=k(k+1)/2-2k=k(k-3)/2\)：\(k=3\) 得 **0**，模型恰好定解，
**没有任何残差可用于检验**；\(k=4\) 得 2；\(k=6\) 得 8；\(k=8\) 得 19。
因此**能做出检验的最小臂数是 k=4**，且 k=4 只能提出"存在相关性"而无法定位到具体臂对。

**(2) 修正 §6.2 的估计量表述。** 原文的"先按增益归一，再取 \(V_S=\mathrm{median}\,c_{ij}\)"
中的**增益归一这一步在零假设下不是恒等变换**：\(\hat g_i\) 由臂自身噪声估计，与 \(\varepsilon_i\)
负相关，除以它会把 \(c_{ii}\) 压低、\(c_{ij}\) 抬高，两臂独立也读出正 \(\rho\)。
实测：真值 0.5 时中位数参考回归读 0.385、留一法读 0.268、正确做法读 **0.504**。
替代方案中"用图均值归一"在真实功率图上精确，但在真实四臂上失效（四臂差异不是全局倍数）。
**正确形式是自由增益秩-1 联合拟合 \(c_{ij}=a_ia_jW+\delta_{ij}V_i\)**，其代价是吸收真实相关
（k=4 只剩 32%，k=8 保留 76%）。

**(3) 修正 §6.4 的已知答案。** 原文要求"\(\hat\rho\) 在 \(\alpha\pm0.10\) 内恢复"**是错的**：
真实帧自带噪声，注入的共享成分被稀释，可测值是 \(\alpha V_{\text{inj}}/(V_{\text{inj}}+V_{\text{real}})\)。
正确的已知答案是响应曲线 \(R(\alpha)=[\hat\rho(\alpha)-\hat\rho(0)]/[\hat\rho(1)-\hat\rho(0)]\)，
它应等于 \(\alpha\)。按此重判，amp_scale ≥0.2 时 k=4 与 k=6 均通过（R(0.5)−0.5 = +0.057/−0.068）。
**§6.4 与 §6.6 的判据文字以此处为准。**

**(4) 能力声明（本条最重要，未解决）。** 噪声占比 \(f\approx0.02\) 时，一对臂的噪声相关 \(\rho\)
只把相关矩阵抬高约 \(\rho f\)。判据 \(\rho\le0.10\) 要求分辨 **0.2%**，而真实交叉相关元素实测散布
**1.9%（0.975–0.994）**，其中"真实相关"与"每臂噪声占比不同"的零假设偏离**同阶**。
注入标定给出的经验分辨率下限为 **0.3–0.4**（同一估计量在合成数据上是 0.017）。

> **因此：Gate N 以 \(\rho\le0.10\) 的形式无法签发结论——既不能判通过，也不能判不通过。**
> 这不是参数未调好（估计量在模型成立时精确，且与噪声占比无关，已实测三档），
> 而是数据决定的刻度落差。**§6.6 的"标定不通过 → 按结论 D 停止"一行暂不触发**，
> 因为该行预设的情境是"测了不及格"，而当前情境是"尺子够不到该刻度"。
> 后续处置（降低门槛并写明理由 / 改用时间维度的判据 / 停止）**待用户决定，本节不预设**。

**(5) 定性结论仍然可用。** 两种互不相同的估计量（中位数 \(V_S\)、自由增益秩-1）在 stride 1 时
一致指向 (0,1) 与 (2,3) 两对偏高，stride 2 时整片塌平。**结构可信，幅度不可信**
（k=4 的自由拟合给出的交叉对 −0.20…−0.30 是自由度约束下的补偿项，不是测量结果）。

##### 6.10 SVD 基在标定子集上不可复现（根因，2026-10-19 回填）

依据 `reports/phase2_basis_identifiability.md`。**改动原因：** Gate N（§6.9）与 Gate T（§5.7）
都以 \(P_C=U_CU_C^\dagger\) 为输入；在动手做第三个判据之前，必须先确认这个输入本身是不是一个
可定义的量。测下来它不是，而且这是**方法层**的问题，按 §0.5 记录而不绕过。

**(1) 实测。** 重叠定义为 \(\mathrm{Tr}(U_1^\dagger U_2U_2^\dagger U_1)/R\)。取两个**互不相交**的标定集：

| 波段 | 维数 | \|C\|=134 两两重叠 | \|C\|=200 | 随机水平 |
|---|---|---|---|---|
| `[0,10)` | 10 | **0.880** | 0.875 | 7e-5 |
| `[20,40)` | 20 | 0.071 | 0.134 | 1.3e-4 |
| `[20,117)` = 官方 60:350 的按比例映射 | 97 | **0.020** | 0.037 | 6.4e-4 |

三折（C≡0/1/2 mod 3）直接对照：0.029 / 0.029 / 0.028，最小奇异值 ≈0。

**(2) 原因是可辨识性算术，不是实现 bug。** 官方波段在 400 帧上保留 \(291/400=72.75\%\) 的时间维；
按比例映射到 134 帧就是保留 \(97/134=72.4\%\)。**保留七成维度的子空间，其尾部由噪声方向主导**，
用 1/3 的帧去估它，估出来的是一组随抽样而变的噪声方向。谱上也能看到：波段内相邻特征值相对间距
中位数 0.0042，而 134 帧子样本对特征值的扰动约 \(1/\sqrt{134}\approx9\%\)，是间距的 20 倍——
特征向量与整段波段的张成由抽样噪声决定。顶部 `[0,10)` 间距足够，所以稳定（0.88）。

**(3) 后果（同一份数据、只换标定相位）。**

| 量 | fold 0 | fold 1 | fold 2 |
|---|---|---|---|
| 单帧功率波动 \(\rho_f(1)\)（pool 内去均值） | **+0.467** | **−0.001** | **+0.024** |
| 单帧波动方差 \(c(0)\) | 4.72e10 | 1.16e13 | 1.01e13 |

波动方差相差 **240 倍**，且集中在前 100 个体素（59%/19%/35%）。

> **因此：\(P_C\) 在 1/3 标定率下不是任何东西的一致估计。**
> 任何"从 C 估基、再对 A/B 施加同一个 \(P_C\)"的统计结论，都是抽样相位的性质而非数据的性质。
> **§5.6 与 §5.7 的全部数值结论都继承这一条**，因此它们都不能作为对外结论。

**(4) 把选择收窄到什么（不预设，供决策）。** 能走的只有改采样设计，不能再加判据：

| 路径 | 做法 | 代价 |
|---|---|---|
| a | 基仍用全部 400 帧估（官方做法），承认 N2N 的"独立噪声"前提无法用分裂来保证 | 放弃 CrossFit 的严格性，改回结构假设 |
| b | 只在可复现波段（`[0,10)` 或更低）上做 CrossFit | 排除了本要降噪的部分，等于换了降噪对象 |
| c | 改分裂方式（如空间分块），使每个子集有足够时间帧去估基 | 破坏 2×2×2 Tetris 正交采样，需重设计 |

**(5) 不要误读成"官方管线错"。** 官方是在全部 400 帧上估一次，那是单一、确定的量。
本节说的是**不能用 1/3 子集去复现它**，两者不矛盾。

## 5.7 Gate T：时间维判据（v0.5.1，**预注册于运行之前**）

**为什么需要它。** §5.6.9(4) 证明 Gate N 的分辨率（0.3–0.4）够不到判据刻度（0.10），
原因是真实数据交叉相关矩阵里有约 1.9% 的偏离，与真实的噪声相关同阶、不可分。
那一层的病根是：**"结构偏离"与"噪声相关"在体素协方差里是同一种东西。**
Gate T 换一个维度取信息：二者对**帧时间距离**的依赖不同——真实的时间噪声相关应随帧距衰减，
而结构偏离（各臂看到的是同一批解剖结构）不随帧距衰减。

**这不替换 §5.6，是独立的一条测量。** 若 Gate T 与 Gate N 结论一致，可信度提高；
若不一致，说明体积协方差里测到的那个"相关"不是时间性的，即不是噪声。

### 5.7.1 统计量（预注册，不得事后调整）

1. **逐帧图**：用 C 帧建投影算子 \(P\)（与 Phase 1 完全一致），对 pool $=A\cup B$ 的每一帧算
   \(m_t=|Px_t|^2\)（**不跨帧平均**）。逐体素去时间均值得 \(f_t\)。
2. **时间自协方差**：\(c(d)=\frac{1}{V}\frac{1}{N_d}\sum_{t}\sum_v f_t(v)f_{t+d}(v)\)，\(d=0\ldots60\)。
3. **渐近校正**：\(c(\infty):=\operatorname{mean}\{c(d):d\in[55,60]\}\)，
   \(\tilde\rho_f(d)=\dfrac{c(d)-c(\infty)}{c(0)-c(\infty)}\)。**这条是为了扣除不随帧距衰减的那部分结构项。**
4. **两臂级预测**：\(\rho_{AB}=\operatorname{mean}_{a\in A,b\in B}\tilde\rho_f(|t_a-t_b|)\)。
   单帧图上噪声占比 \(\approx1\)，因此这一步**不受 §5.6.9(4) 那 2% 的墙影响**。

### 5.7.2 锚点（不过则 Gate T 不得用于判定）

| 锚点 | 要求 | 作用 |
|---|---|---|
| A0 实现一致 | 同一臂内 \(\frac{1}{\|S\|}\sum_{t\in S}m_t\) 必须等于 `tgt=S` 直接算出的臂图（相对误差 <1e-8） | 证明逐帧分解就是同一个对象 |
| A1 已知答案 | 注入已知时间相关 \(\rho_{\text{inj}}(d)=e^{-d/8}\) 的场，恢复曲线在 \(d\in\{1,5,20\}\) 上误差 ≤0.10 | 证明时间轴确实被测到 |
| A2 渐近 | \(|\tilde\rho_f(50)|\le0.10\) | 若不过，说明波动有**不衰减**成分，时间机制在该数据上不存在——这本身是结论 |

### 5.7.3 主判据（预注册）

- **通过**：\(\rho_{AB}\le0.10\) 且块自助 CI 上界 ≤0.10。
- **不通过**：\(\rho_{AB}\) CI 下界 ≥0.10。
- **不确定**：其余。
- 判据刻度沿用 §5.6.3 的 0.10（\(R^2\le1\%\)），**不因换判据而放宽**。

### 5.7.4 形状检验（本条的真正价值）

同时算**臂级超出相关**随"臂间平均帧距 \(d\)"的曲线（k=4，stride 1–5）。
预注册两条互斥的解释：

| 观察 | 结论 |
|---|---|
| 臂级超出**随 \(d\) 衰减**，且形状与 \(\tilde\rho_f(d)\) 一致 | 该超出是**时间性**的，即真是噪声相关 |
| 臂级超出**对 \(d\) 基本平坦** | 该超出是**结构性**的，与噪声无关；此时 Gate N 的读数不能解释为噪声相关 |

**比例一致性**：若为时间性，\(\text{excess}(d)/\tilde\rho_f(d)\) 应在各 \(d\) 上近似为常数（预注册：变异系数 ≤0.3）。

### 5.7.5 已知的适用范围（事先声明，防止事后追加）

- 时间相关**不足以**区分"噪声"与"随时间缓慢变化的生理结构"——二者都随帧距衰减。
  空间不相干性仍然是唯一的分类依据。因此 Gate T 单独**不能**回答"这个波动是不是噪声"。
- Gate T 能回答的是一个更窄但关键的问题：**体积协方差里测到的那个臂间超出，是不是时间性的。**
  若答案是"不是"，则 Gate N 的全部读数作废，方案 §5.6 的前提论证需要重来。
- **若 Gate T 也判不了，本方案不再引入第四个判据**，按 §0.5 停止并记录（此条重申 §5.6.6）。

### 5.7.6 执行结果（2026-10-19 回填，**不修改上述预注册**）

依据 `reports/phase2_gate_t.md`。**改动原因**：§5.7 写于运行之前，运行已结束，需如实回填结果与
锚点判定，并明确本条是否可用于判定。

| 锚点 | 事前判据 | 结果 |
|---|---|---|
| A0 | 相对误差 ≤1e−8 | **通过**（三折 0.000e+00） |
| A1 | d∈{1,5,20} 误差 ≤0.10 | **通过**（amp=2：0.013/0.071/0.066；amp=5：0.018/0.010/0.007） |
| A2 | \(\lvert\tilde\rho_f(50)\rvert\le0.10\) | pool 内去均值：通过（0.088/0.005/0.003）；全 400 帧去均值：fold 0 不过（0.165） |
| 主判据 | \(\rho_{AB}\le0.10\) | **退化**，见下 |

**(1) 估计量本身是对的。** A0 与 A1 都通过：一个已知的、按 \(\exp(-d/8)\) 衰减的注入场，经真实
投影器后功率波的衰减被如实还原为 \(\exp(-2d/8)\)。**实现层面存在的四处错误已在
`reports/phase2_gate_t.md` §3 逐条记录并修正**（已知答案应为 \(\rho_x^2\)；空间白噪声注入到不了
图上；须按子空间内功率归一；最终须按单帧波动方差归一）。

**(2) 主判据退化的原因是代数的，不是数据的。** 把单帧核接到"臂均值相关"必须选去均值集合：
用 pool（=A∪B，等大）时 \(M_A=-M_B\) 恒成立，\(\rho_{AB}\equiv-1\)；用全部 400 帧时
\(\rho_{AB}=-0.498/-0.501/-0.501\)，值由 C 帧的样本内压低决定。
**只有在 k≥4 且把共同结构作为自由参数拟合时才有自由度，而那正是 Gate N 的估计量本身**，
不构成新证据。Gate T 唯一独立的信息是单帧核 \(c(d)\)。

**(3) 单帧核本身随标定相位翻转。** \(\rho_f(1)=+0.467/-0.001/+0.024\)，见 §6.10(3)。
根因是 \(P_C\) 不可复现（§6.10），不是本判据的实现。

**(4) 参考量：时间波动主体不是噪声。** 原始数据的逐体素功率 \(\lvert x_t\rvert^2\) 的 lag-1 相关是
**0.967**（lag 10 仍 0.719）。这正是 §5.7.5 第一条事前写下的情形——时间相关无法把噪声与
缓慢生理变化分开。**本次是把这条量实了。**

> **结论：Gate T 不能签发判决。** 不是因为它的估计量（A0/A1 均通过），而是因为它的输入
> \(P_C\) 不可复现（§6.10），且主判据在 A/B 二分下代数退化。
> **按 §5.7.5 最后一条，本方案不再引入第四个判据。**

**通俗总结（为什么这样改）。**

原来那把尺子，是拿"交叉拟合造的两条臂"和"Tetris 造的两条臂"比，看谁更不像。
上一轮发现它不可信，这一轮把它量了一遍：让两条臂共享一部分帧，全共享时数学上必须是 0
（实测确实精确是 0，说明测量本身没毛病），一帧不共享时就是我们真正的设计。

结果是：在**一帧都不共享**这个前提下——也就是独立性由设计本身保证的时候——
三种不同的切法分别读出 4%、15%、32% 的改善。同一个前提，同一个问题，三个差 8 倍的答案。
一个能差 8 倍的东西，不能拿来当及格线。

接着想换个公式直接测"两条臂的噪声有多相关"。这个也失败了，而且失败得很干净：
每组帧少的时候，测出来的永远是接近 1（因为两组的平均值里都被减掉了同一个数）；
每组帧多的时候，另一个数学约束又把它压成负数。两头都坏，中间没有能用的地方。

于是看清了一件事：**只要只有两条臂，这个数就测不出来。** 这不是公式没找对，
是问题本身没有解——两条臂里，我们分不清"两张图都有的东西"是真实结构还是共同的噪声。
要分清，必须有第三个东西在旁边做参照。

所以方案这样改：**从两组改成三组以上。** 有了三组（默认四组），就能用"三组两两之间
该有多像"来反推每一组里有多少是噪声、多少是共同结构，从而算出两组噪声的相关程度，
并且这个相关程度第一次变得**可以被检验、也可能不通过**。判据也定死了：相关系数不超过 0.10，
等价于"目标图里的噪声，最多只有 1% 能被输入图预测出来"——超过这个，网络就会去学噪声而不是学血流。

代价是每组帧数变少（133 帧变成约 66 帧）。文档里明确写了**不接受**为了保住帧数退回两组，
因为那不是省成本，是回到一个没有答案的问题上。

另外加了一条自我约束：**换尺子的理由必须是"旧尺子被证伪"，不能是"旧尺子没通过"。**
所以新尺子还必须先在已知答案上考一次试——往真实数据里叠加一个已知相关程度的噪声，
看它能不能把这个数报对——考不过就不许用它下结论。而且这是最后一次换尺子：
如果新的也不行，就按结论 D 停下，不再找第三个。

**（2026-10-19 补记，尺子造出来之后）** 考试的结果是：**没过。** 掺 0 报 0、掺满报满，
这两头都对；但掺一半它报 0.5 到 0.9 不等，还会冤枉那些根本没掺过的组。
所以这把尺子现在**仍然不能用来下"通过/不通过"**，方案里没有为此放宽任何一个门限——
把数字往有利于自己的方向挪，正是 §0.5 明令禁止的那种做法。

另外这次造尺子暴露了一件和方案本身有关的事：四张投影图之间其实差着一个整体亮度，
不先拉平就直接比，会算出"负的噪声"。这说明方案里写的那个"每张图 = 真实结构 + 各自噪声"
的式子，在真实数据上并不逐字成立。这一条已经写进方案，作为后续任何估计量的前置条件。

还有一个不能忽略的耦合：**把两组的帧在时间上拉得越开，每组能分到的帧就越少。**
这两件事这次是绑在一起变的，所以看到"拉开之后读数变小了"，**不能**直接说"拉开就行了"。
要说这句话，得先做一次只改间距、不改组长的实验。

**这一轮没有改变任何判据，只改变了"我们认为自己已经证明了什么"。**

**（2026-10-19 再补记，归因做完之后）** 尺子没过考试，我们去查是尺子不行还是调错了。
查下来：**尺子本身是准的**——模型成立时，0、0.25、0.5、0.75、1 报得分毫不差，
把噪声降到很弱的 2% 也一样准，所以"噪声太弱测不出来"这个猜测不成立。

错在我们自己加的两步上，都已写进方案改正：一是"拉平四张图的亮度"那一步，
那个亮度是**用图里的噪声一起算出来的**，拉平的同时把噪声也改了形，凭空造出 0.16 到 0.47 的假相关；
二是我们把"掺一半就该报 0.5"当标准答案，这也不对，真实帧里本来就有噪声，掺进去的会被稀释。
改成"看它随掺入比例怎么变"之后，它是及格的。

**但有一道坎过不去，而且不是调参能解决的。** 判据要求分辨 0.10 的相关，
换算到相关矩阵上只有千分之二；而真实数据里两张图之间**本来就有百分之二左右**的差异，
真实的噪声相关和"四组帧数不同造成的小偏差"混在一起，一样大、分不开。
实测这把尺子的分辨率约 0.3–0.4。

**所以现在既不能说通过，也不能说失败。** "没测出来"和"测出来不及格"是两回事：
方案里那条"标定不通过就按结论 D 停止"，预设的是后者，**当前是前者，所以不触发**。
接下来是降低门槛（要写明理由）、换一个从**时间**维度取信息的判据、还是停止，**需要你定，方案里不预设**。

**通俗总结（为什么加这一条）。** 我们原来那把尺子，是拿"交叉拟合造的两条臂"去和
"Tetris 造的两条臂"比谁更不像。问题是 Tetris 把同一张图按体素相位劈成两半，
两条臂共用同一份噪声；交叉拟合的两条臂来自不同的帧，本来就是两份噪声。
**这是"信息来源不同"，不是"处理手法不同"**——所以原来的差距大半不是交叉拟合的功劳。
把算子对齐之后，交叉拟合在 SA64 上确实反超了 16%–19%，看着像通过了。
但接着做了最关键的对照：**把同一批帧随便打乱、随便切成两半，会怎样？**
答案是：一样，甚至更好（16 折里只有 3 折真正比随机强，而那 3 折恰好是按时间连续切块的）。
**所以现在这把尺子量的是"两条臂来自不同的帧"——这件事对任何切法都成立，等于什么也没说。**
加这一条的目的不是提高门槛，是承认**尺子本身还没标定**：在合成基准上把它的刻度测出来之前，
任何"通过 / 不通过"的读法都不作数。

### 输出产物

- `reports/phase2_pair_statistics.md`
- 每个 fold 的结构一致性图、残差相关图、强度剖面图和 bootstrap 结果。

### 验收决策

- **通过：**结构保留可接受，**且 Gate N（§5.6）在将用于训练的臂配置上通过**，进入 Phase 3。
- **部分通过：**结构一致但 Gate N 未通过或未标定。**只允许做小规模诊断模型，不得宣称观测对满足 N2N 假设。**
- **失败：**结构一致性或强度偏差未通过。暂停训练，不以增加网络复杂度弥补不合格监督信号。

**v0.5 口径修正。** 原"失败"条写的是"优先调整时间分组、秩选择或观测定义"——**这句与 §0.5 冲突，
已删除。** 结构性失败（结构/强度）与前提性失败（Gate N 不通过）处置不同：
前者是配方问题，可在预注册的敏感度轴内调整一次；后者是**前提不存在**，按结论 D 停止，
不得靠换分组/换秩带/换切法去凑。两类失败都必须在报告里写清属于哪一类。
另外，Phase 2 的总判定**当前状态为"部分通过"**（结构 ✅、强度 ✅、Gate N 已实现并完成归因，
但**在真实数据上的分辨率约 0.3–0.4，够不到判据刻度 0.10**，故既不能判"通过"也不能判"不通过"。
详见 §5.6.9 与 `reports/phase2_gate_n_calibration_analysis.md`）。

## 6. Phase 3：建立时间 N2N 基线

### 目标

验证通过 Phase 2 的观测对，能否在不使用 VALID Tetris 的情况下提供有效监督。该阶段用于单独验证 SVD 交叉拟合观测的价值。

### 最小实验组

| 实验 | 输入 / 目标 | 目的 |
|---|---|---|
| M0：官方全帧 SVD 参考 | 使用全帧参考，仅作输入图与结构参照 | 不把它误当成干净真值 |
| M1：当前 VALID-random | 现有 faithful random Tetris | 复现现有空间自监督基线 |
| M2：VALID-fixed-4 | 固定 pattern 4 | 检查当前更有希望的几何基线 |
| M3：Pair-P0 N2N | 无 SVD 校准的 A → B、B → A | 分离时间拆分本身的贡献 |
| M4：Pair-P1 N2N | 共同 SVD 校准投影后的 A → B、B → A | 测试交叉拟合观测对的贡献 |
| M5：Pair-P2 N2N | A/B 分别估计投影 | 测量投影独立估计的代价与收益 |

### 执行步骤

1. 首轮使用相同 CRN，固定 patch、优化器、学习率日程、损失的定义和训练步数。记录因输入域不同而不宜直接横比的训练 loss，只用于组内收敛诊断。
2. 在 M3/M4/M5 中以同网格的 \(D_A,D_B\) 构造对称 N2N 目标：

   \[
   L_{N2N}=\tfrac12\|f(D_A)-D_B\|_2^2+\tfrac12\|f(D_B)-D_A\|_2^2.
   \]

   若使用 log 域，A/B 必须应用相同的映射。若统计验证发现 log 域偏差无法接受，先保留线性功率域作为对照。
3. 模型训练不能同时使用测试 fold 生成的配对。所有模型选择只使用训练折与验证折；最终报表使用未参与训练或阈值选择的帧组。
4. 先以少量 steps/epochs 验证 loss、梯度、数值范围和推理，再进行正式训练。冒烟实验与正式实验分别记录，不能把前者指标合并。
5. 每个主要方案至少 3 个随机种子；若算力不足，先用 1 个 seed 做管线诊断，但不能据此作出性能结论。

### 评估指标

- **噪声抑制代理：**固定高通残差标准差变化，并结合背景 ROI 的残差统计；不得单独使用该指标。
- **血管结构：**中心线覆盖、分支保留、连通组件、血管宽度分布、血管—背景对比。
- **强度保真：**均值与分位数漂移、局部血管强度比、输出范围外比例。
- **稳定性：**不同帧折、不同种子与 SA64/HSA64 的结果分布。
- **显示：**所有模型共享强度窗口；同时显示 mid-slice、MIP、差异图和局部放大区域。

### 验收标准

- [ ] M3/M4 至少有一个方案在独立帧折上比未去噪观测获得更好的去噪—结构折中。
- [ ] 改进不能只体现为更低的高频能量；中心线、分支或宽度指标不得明显恶化。
- [ ] 结果不能依赖逐体积最大值归一化、单一阈值或输出截断才成立。
- [ ] M4 相对 M3 的差值单独报告，用以回答 SVD 校准是否额外有用。
- [ ] 至少 3 个种子的效应方向一致；报告均值和区间，而不是只挑最好的一次。

**失败解释：**若 M4 与 M3 相当，结论应是“当前 SVD 交叉拟合未显示增量”，而不是继续更换任意秩带直到出现显著结果。

## 7. Phase 4：将 VALID 的三维空间正交约束作为辅助项

### 目标

检验时间观测对与 VALID 的空间正交自监督是否互补。只有 Phase 2 通过、且 Phase 3 的 M4 形成可用基线后才启动。

### 设计原则

不要把“对 A/B 分别运行 VALID”直接称为已实现的融合方法。那只能作为 VALID-only 基线。混合方法必须具有明确的总损失，并通过消融证明空间项带来独立贡献。

### 实验组

| 实验 | 时间 N2N 损失 | VALID 空间损失 | 解释 |
|---|---:|---:|---|
| H0：VALID-only | 关闭 | 开启 | 在交叉拟合 A/B 体积上分别训练原始 VALID 的对照 |
| H1：N2N-only | 开启 | 关闭 | Phase 3 的 M4 基线 |
| H2：N2N + VALID | 开启 | 开启 | 候选混合方法 |
| H3：N2N + Hessian ablation | 开启 | 仅控制正则项 | 判断收益是否只是来自原有 Hessian / 平滑约束 |

### 候选混合损失

定义时间 N2N 主监督：

\[
L_{time}=\tfrac12\|f(D_A)-D_B\|_2^2
+\tfrac12\|f(D_B)-D_A\|_2^2.
\]

对 A、B 各自通过原版 VALID Tetris 采样及原始损失，记为 \(L_{VALID}(D_A)\)、\(L_{VALID}(D_B)\)。混合候选为：

\[
L_{hybrid}=L_{time}+\lambda_{orth}\,\frac{L_{VALID}(D_A)+L_{VALID}(D_B)}{2}.
\]

这是一种**待验证的双监督候选形式**，不是声称已证明最优。第一轮只测试少量预先约定的 \(\lambda_{orth}\) 值（例如 0.1、0.3、1.0，先统一各损失的数值尺度并检查梯度量级）。不得在测试折上挑选最佳系数。若两类损失的量纲 / 尺度差异过大，先报告归一化策略，并将其作为实验变量控制。

注意：H2 是将 VALID 的完整空间自监督损失作为辅助约束，而不是把时间帧简单变成四个 Tetris 通道。这样定义有清楚的可消融性；是否真的互补完全由 H2 相对于 H1 的结果决定。

### 执行步骤

1. 使用与 H1 完全相同的 A/B 观测对、网络结构、训练预算和随机种子。**"训练预算"必须写明对齐口径**：按 step 对齐时每步前向次数差别很大——H0（VALID-only）4 次、H1（N2N-only）2 次、H2（混合）**10 次**（`L_time` 2 次 + `L_VALID(D_A)`、`L_VALID(D_B)` 各 4 次 Tetris 前向）。因此除 step 数外还要记录并报告**每步前向次数与实际 wall-clock**，避免把"H2 更强"误读成"H2 跑得更多"。
2. 实现一个独立 `loss_temporal_n2n()` 和一个独立 `loss_valid_orthogonal()`，先用单元测试分别验证，再组合。
3. 对每个训练 patch，记录时间 N2N loss、VALID loss、Hessian loss 的单独值、梯度范数与相对权重，检查某一项是否完全主导训练。
4. 只在训练折更新参数，在验证折选择 \(\lambda_{orth}\)；最后使用完全未参与选择的测试帧组报告结果。
5. 做 H1/H2 及 H2/H3 对照，避免将一般平滑效应误归因于三维正交采样。
6. 检查输出越界值、血管强度衰减、分支断裂、背景虚假亮点和体积方向性伪影。

### 验收标准

- [ ] H2 相对 H1 在至少一个主要结构指标上改善，并且去噪强度相当；不能只凭 PSNR-like / 高频抑制量表判优。
- [ ] 混合增益在至少 3 个 seed 和多个独立帧组中保持一致方向。
- [ ] 增益不是由更强的 Hessian 平滑或对输出的后处理解释。
- [ ] H2 不应造成明显的血管分支、宽度或强度损失；输出越界率不显著恶化。
- [ ] 若 H2 与 H1 无差别，明确记录 VALID 空间损失无额外贡献，不能继续把“二者互补”当作主张。

## 8. Phase 5：鲁棒性、比较与最终统计

### 目标

验证结果是否超出某一数据序列、单一参数设置或偶然随机初始化的范围。

### 执行清单

1. **随机种子：**核心模型每个至少 3 个种子，关键最终结论争取 5 个种子；种子在结果揭盲前预先规定。
2. **序列复现：**在 SA64 完成开发后，使用相同秩选择规则、强度映射和阈值在 HSA64 验证；不得为 HSA64 单独调到最有利参数后再称为复现。
3. **交叉拟合分组：**至少检查交错分组与连续分组。连续分组结果若明显恶化，应报告其可能反映血流动态差异，而不能只删除不利设置。
4. **秩带敏感性：**在校准组可用的秩带规则内比较小范围配置。规则与范围应由 Phase 1 预先设定，避免大规模多重尝试。
5. **帧数敏感性：**比较约 80、133 及更高帧数的观测组。记录单帧子采样后帧间隔与积分帧数对图像稳定性的影响。
6. **基线公平性：**比较 SVD-SN2N 风格方案时，严格核对它的对数变换、对角重采样、插值和损失；如无法复现原论文完整设置，明确标为 adapted baseline，不称官方复现。
7. **统计单位：**主要统计使用种子、独立帧组和非重叠空间块。高度重叠滑窗可用于可视化 / 描述性分析，不能作为独立样本计算极小 p 值。
8. **报告负结果：**完整报告模型失效、输出越界、血管变细、中心线中断或 HSA64 不复现等情况。

### 验收标准

- [ ] 核心效应不是单一 seed 驱动，结果区间与每次运行均有留档。
- [x] SA64 与 HSA64 的效应方向和失败模式清楚可解释。**（2026-10-16）** 方向：两者一致；
  失败模式：残差相关高于 Tetris 对照（SA64 干净 8 折 +0.66…+0.75，HSA64 +0.51…+1.11），机制＝每臂帧平均压掉臂特有成分。
  SA64 另有一处采集假象（frame 0）污染 8/16 折，已定位并可隔离；HSA64 无此问题。
- [ ] 所有主张对应预先定义的指标及对照，不依赖临时阈值。
- [ ] 没有将同一采集的高帧数参考称为独立干净真值。
- [ ] 对比基线的输入信息、帧数、预处理、模型容量和训练预算均被说明。

## 9. Phase 6：研究结论与论文准备

### 可接受的结论形态

最终结果应落入以下某一种，而不是无论如何都写成“融合方法有效”。

**结论 A：观测对与 VALID 辅助项均通过。**  可以主张：交叉拟合的 SVD 观测对提供了可用的时间自监督信号，VALID 三维空间约束带来可复现的额外结构保真收益。需要用消融证明两部分各自贡献。

**结论 B：时间 N2N 有效，但 VALID 无额外增益。**  将论文主线定位为交叉拟合 SVD 时间监督；VALID 作为 baseline / 诊断对照。不要硬写“二者融合创新”。

**结论 C：一般时间拆分有效，但 SVD 交叉拟合无增益。**  说明收益可能主要来自不同时间观测，而不是 SVD 子空间投影。应重设题目与创新点；不再宣称 SVD 是关键机制。

**结论 D：候选对不满足统计条件或收益不复现。**  停止该方案，不进入大规模训练。完整记录否证结果，再考虑 PSF 感知采样等独立方向。

### 论文证据结构建议

1. 数据与官方处理复现。
2. 交叉拟合观测对生成方式及不泄漏设计。
3. 观测对的结构一致性、残差统计和跨折验证。
4. 时间 N2N 与现有 VALID / SVD-SN2N 风格基线比较。
5. 混合损失消融与多种子结果。
6. 微血管结构评价、局限性与失败案例。

### 最终交付清单

- 数据 manifest 与可复现配置。
- 分组、投影、观测生成与统计评价脚本。
- 训练与推理代码、测试用例、环境信息。
- 原始输出和统一尺度的展示图。
- 每阶段验收报告、未通过项目和最终决策记录。
- 论文实验表、误差区间、统计脚本和对照说明。

## 11. 关键风险登记表

| 风险 | 可能后果 | 预防 / 检验办法 | 停止条件 |
|---|---|---|---|
| **前提可能再次没有可用方差**（与 v1 同类失败） | 交叉拟合对里几乎没有独立噪声，`D_A−D_B` 主要是真实血流差异 → N2N 只会平滑掉血流 | **Phase 2 首项：高秩噪声带的时间自相关标定**；再加残差相关门槛。不训练即可判定 | Phase 2 未通过 → 按结论 D 停止，**不换秩带/分组去救** |
| **残差差异来自帧特有结构而非独立噪声**（**v0.3 新增，Phase 1 实测支持**） | 宽带 \(P_C\) 把 A/B 的帧特有结构连噪声一起削掉 → 观测对看似"独立"但监督信号已被抹掉，训练出来只会过平滑 | Phase 2 首项须**成组报告** `{残差自相关, 残差绝对功率, 残差/P0 功率比}`，并按宽/窄秩带分别给出 | 窄带残差自相关显著而宽带消失 → 属投影过强，缩窄秩带（记为有依据的修正，非救火）；两类构造均无可用残差 → Phase 2 未通过 |
| **官方血流带边缘不可从谱上识别**（**v0.3 新增，Phase 1 已实测成立**） | 秩无客观依据；若假装找到了带，等于把一个无数据支持的选择伪装成结论 | 秩降级为**被扫描的敏感度轴**（覆盖 ≥2 个数量级）；四条规则全部报告，宽/窄构造分开；对外不得声称"找到了/复现了血流带" | 不单独构成停止条件；但不得在任何结论中引用"最优秩" |
| 与 SVD-SN2N 撞车（bioRxiv 2026-09） | 候选创新点 1 可能已被前人做过 | **T0-3：先取得原文并写一页差异说明**，再决定是否投入（**不阻塞 Phase 2，阻塞 Phase 3**） | 写不出可测差异 → 创新点 1 不成立 |
| 校准帧不足导致 SVD 秩数受限 | 无法沿用官方 rank band，投影退化 | **已改写**：不再企图确定校准组秩规则，改为扫描秩带 + 报告跨折子空间稳定性 | 子空间无法稳定复现（**Phase 1 实测：宽带成立、窄带 `spectral` 不成立**，故不作为停止条件） |
| A/B 时间相关 | N2N 噪声独立假设不成立 | 计算 IQ 时间自相关、残差相关及间隔帧敏感性 | 残差相关无可靠改善或无法有效估计 |
| `T_A≠T_B` 的均值归一化 | 凭空造出强度尺度差，Phase 2 强度门槛误报 | §1.3 第 6 条：强制等帧数或改用公共除数 | 强度偏差无法与定义缺陷区分 |
| A/B 血流动态不同 | 监督目标不一致，血管模糊或断裂 | 交错分组、时间覆盖对照、结构一致性检查 | 结构门槛失败 |
| 子空间选择泄漏 | 观测对指标过乐观 | 当前 A/B 绝不参与同折投影估计和秩规则选择 | manifest 显示帧重叠即视为无效 run |
| 独立重标定强度 | 人为制造外观一致或指标增益 | A/B 使用共享变换与共享显示窗口 | 任何主要结果依赖独立重标定 |
| VALID 与 N2N 损失互相冲突 | 训练不稳定或结构过平滑 | 损失分开记录、lambda 小范围消融、梯度分析 | 混合项无增量或明显损害结构 |
| 指标偏向“不去噪” | 模型只保留输入噪声也得高分 | 同时报告去噪强度、结构与背景指标 | 单一 keep / correlation 指标成为结论依据 |
| 把伪参考当真值 | 夸大方法效果 | 明确使用“全帧参考 / 伪参考”，辅以合成数据或独立帧组 | 论文中对参考性质描述不实 |
| 过度调参 | 多重比较与选择偏差 | 预注册参数范围，独立帧折确定模型 | 结果只在临时挑选配置中成立 |

## 14. 方案的最终原则

1. **先证监督观测成立，再训练模型。** 观测对统计假设不成立，网络结构越复杂越不能挽救这一前提。
2. **先证时间 N2N 有效，再讨论 VALID 是否增益。** 不把两个方法简单拼接当作创新。
3. **把“独立性”写成需要测量的性质。** SVD 正交、帧索引不重叠和空间视图互补都不是噪声独立性的充分条件。
4. **用独立单位与多种子做结论。** 不依靠重叠滑窗产生的虚高显著性，也不依靠某一张定性图。
5. **允许实验否定方案。** 若交叉拟合没有比简单时间拆分更好，或 VALID 辅助项无增量，应据实简化研究主线，而不是持续叠加机制。

**最终成功标准不是“训练出更清晰的血管图”，而是明确证明：哪一种自监督观测构造在什么条件下有效、它的统计前提是否成立、VALID 的三维空间机制是否带来独立且可复现的收益。**
