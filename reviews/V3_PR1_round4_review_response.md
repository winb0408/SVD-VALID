## §1 Round4-0 —— **接受，但对两个指标做显式修改**

**接受**：e900/e901 校准、e902–e905 留出；统一 mask/图像域/归一/坐标；逐场景配对统计；
checkpoint 只按校准集选；vlow/low 权重不混名（跨档只标 `cross_level`、不进判定）；
真实 SA64/HSA64 一律标 **NO CLEAN GT**；`core` 只当亮区强度比、`dark` 只当暗区能量比，
**不**当中心线/分支指标或"假血管计数"。

**修改 1（关键）：结构指标的真值换成 `gt_imaging_pd`。**
R12 的已知答案表已经证伪了 `recall@fpr5`/AUC/`iou_core`/SSIM 的单调性，根因写在那份报告里：
真值用的是**锐利的 `gt_flow_pd`**，而所有预测都来自**被 PSF 模糊过**的 PD 图像。
把锐利真值拿去和模糊图像比"体素级可分性"，无噪真值必然输给含噪输入——这不是方法的锅，是参照选错。
本轮改用 `log1p(gt_imaging_pd/s)` 作参照（PSF 匹配的无噪成像真值），并把这个改动**当假设去检验**：
若改用成像真值后正控制仍不单调，就记 `METRIC_UNRESOLVED`，不豁免、不解释成"指标太难"。

**修改 2：`width`（管径偏差）标 `NOT_RESOLVABLE`，不硬算。**
`PSF_PD σ=(4.24,3.35,5.61)` 体素、血管半径 0.75/1.1/1.5 体素——成像后管子宽度由 PSF 决定，
任何去噪方法测出来的都是 PSF，不是血管。这与任务书"几何标签先明确 PSF/分辨率映射"一致：
映射已经明确，结论就是"这一项在本仿真里不可测"。替代给出 `ncomp_ratio`（连通性）与
`fp_blobs`（假血管计数，专为"造血管"负控制设计）。

**新增（任务书也要求但旧报告没有）**：Pareto 的旋钮必须写死。网络臂用 `y_β = x + β(net(x)−x)`，
β∈{0,0.25,0.5,0.75,1}；Gaussian 用 σ 网格、Wiener 用 w 网格。**选点在 e900/e901，曲线在 e902–e905 画**，
且明确"曲线不是选择"——不允许在留出集上挑 β 再报最优臂。

## §2 Round4-B —— **接受，补三条防混同措施**

1. **B0 的分层**（已测事实 / 代理假设 / 训练有效性）写进交付模板，且第一行就写
   "R0-v2 只测过 `log(PD)`，不构成 `log1p` 的结论"。
2. **`log(PD+ε)` 的定义先写死**：`x = log(PD·ε/s + ε)`，`ε = 1e-3`，反变换 `PD = s(e^x − ε)/ε`。
   取这个形式是为了 `x≥0`、零与低亮背景反变换数值稳定。跑第一臂前写死，不因某臂好训而改。
3. **公平性护栏**：三臂各自用**训练集**统计量做仿射标准化（常数写进 args 并冻结），
   评价统一反变换回线性 PD。同时留一条保留声明：标准化只对齐一阶/二阶尺度，不保证三域可优化性相同。

**档位选择（需说明理由，不能算挑数据）**：pilot 只在 **low** 档跑。理由：low 档上高斯优势最大
（0.618 vs 网络 0.825），表示域若真有作用，在这里必须以较大幅度显现；vlow 只作后续可选扩展。
