## 0. 总结与状态

**总体结论**：Round2 的真实数据审计（R0）和简单正控制（S0）有真实进展；低/中噪声的 VALID Tetris、整分辨率有监督与同位置 N2N 在当前协议中未稳定胜过输入。应接受这些**限定条件下的负结果**，但不能认为 I1（PSF/散斑感知三维正交采样）已经科学证伪：实验 C 尚未实际运行。

**最重要的新审查发现**：

1. R0 以 `r_A=A-S, r_B=B-S` 估计残差相关，**共同的有噪参考 S 自动引入正相关**。现报的 SA64 0.357、HSA64 0.374 与完全独立噪声下预期的约 0.333 很接近，不能直接解释为 36% 的真实噪声相关。
2. R0 log 条件方差回归的自变量口径不一致：`conditional_variance(sig_log,...)` 又对 `sig_log=mean(log PD)` 取对数；`SA64 log_slope=-0.93` 不能叫“近零”。而 `r0_gate.py` 的 `abs(log_slope)>=0.10` 恰恰奖励非零斜率，**通过 Gate 不等于加性/同方差化通过**。
3. “时间代理 vs 空间代理相差 14%”来自**相同四块时间数据和同一块间涨落场**，不能称为两条统计独立证据。真实剩余可去噪占比 10–14%、比仿真高 5–7 倍，现阶段应作为**有假设的代理估计**，而非已独立量出的物理噪声能量。
4. S0 的 `S_rand/S_fixed4` 所谓“有监督上界”只是把**互补空间相位的目标换为干净值**，不是同位置 `noisy_a → clean_a`；不能用与自监督结果接近推出“空间配对因素已排除”。`S_dense` 才是同位置干净监督的直接对照。
5. Round3 A2 的完美真值 α 扫描公式写错：`alpha=0.5` 的 N2N 理论比值应为 **0.625**，不是 0.125；必须在任何新 Gate 运行前修正。
6. 当前 `train.py --mode dense` 返回 `[arr, arr, arr, arr]`，两路网络输出完全相同，所以 `mse(ha,hb)=0`，identity loss 对 dense 臂**没有梯度**。Round3 的 B3 如果用于 dense，`--weight-identity 0` 是空操作。
7. `n2n_ratio≈(1+r²)/2` 只能在独立同方差、正确真值/相同评价域等条件下表示**期望风险关系**，不是 44 个有限样本上的严格恒等式；更不能直接从训练末 loss 推出完整体积推理的训练性能，并将其与留出体差值 **100% 归因跨解剖泛化**。
8. `GroupNorm(affine=True)` 提供共享可学习缩放/平移，**不能自动恢复每个 patch 已被归一化消掉的专属均值**；残差旁路值得优先试验，但也不能把“损失下降”自动等同于真实去噪。需要对照和真实终点。

**最终建议**：**暂缓按原版 Round3 直接上 B1–B4；先做 P0 统计、公式、坐标与消融有效性修复，再跑 A 探针/小规模 B。** B（log 表示）与 D（2026 超声 SVD-SN2N 文献/方法差异）不能永久因旧 A 负结果冻结。正式大规模 C 仍应等基础恢复链具备可信正控制后再跑。

## 1. P0 阻断项：修改 Round3 预注册并先做无训练自检

### R3-P01 / P0 —— 共同有噪参考导致残差相关伪像

**代码**：`scripts/v3_round2_r0_audit.py`，`r0_3_pairing`（约 L261–276）；报告 `reports/v3_round2_real_data_audit.md` §3.4。当前使用 g0/g1 两个 100 帧观测 A/B，以及后 200 帧合成的 S，同一个 S 分别从 A、B 相减。

**数学反例**：设 `A=μ+εA, B=μ+εB, S=μ+εS`，εA、εB、εS 相互独立、零均值。如果 εA/εB 由 100 帧平均、εS 由 200 帧平均，等每帧方差，那么
`Cov(A−S,B−S)=Var(εS)`、`Corr(A−S,B−S)=1/3`。实测 0.357/0.374 接近 1/3 **不证明独立，也无法证明具有 0.36 的真实依赖**。实际 SVD 共用基、PD 非线性与运动会进一步改变该值。

**要求**：
- [ ] 用已知独立的 A/B/C/D（4 个独立 100 帧代理，在加性信号域）做**模拟单元测试**，共同参考 `A−(C+D)/2` 与 `B−(C+D)/2` 应出现约 1/3 的正相关；这是旧统计量的**反例标定**。
- [ ] 再用**互不共享**的参考构造 `A−C` 与 `B−D`，在独立信号/稳定均值模型里期望相关为 0。注意真实时间漂移、共用 SVD 基以及 log-PD 过程会造成真实偏差；应按 block 置换顺序复算并展示结果波动。
- [ ] 明确区分“真实残余协方差”“使用共同参考造成的协方差”“SVD 共同投影与非平稳性”，提供理论/仿真基线及不确定度。无真正独立参考时宁可标记为 proxy，不宣称 Noise2Noise 必要条件已经成立或不成立。
- [ ] **保留历史 0.357/0.374 原值**，在新审计文档中加注其受共同参考污染，禁止静默覆盖旧 JSON。

**验收**：独立噪声零相关场景不再被误判为真实“0.33 相关”；真实 SA/HSA 新结论带模型假设和限制。建议测试 `tests/test_v3_round3_noise_covariance.py`。

### R3-P02 / P0 —— log 条件方差回归和 G-R0-b 判据重写

**代码**：`scripts/v3_round2_r0_audit.py` 的 `conditional_variance()`、`r0_2_conditional_var`（约 L98–124、L219–229）；`scripts/v3_round2_r0_gate.py` 中 `abs(log_slope)>=0.10`（约 L145–153）。

**问题**：linear 版传 `sig_lin`，log 版传 `sig_log`，但辅助函数内部统一做 `x=log(max(sig,eps))`。这使得 log 版是 **log(log PD)** 或在 log PD 为负时发生 clip，而不是同一原始强度的自变量。两个斜率不能直接解释为“对数压缩把斜率从 2 降到 0”。`log_slope=−0.93` 也不是接近零。现 Gate 只检查斜率不为零，跟“同方差化”科学目标不一致。

**要求**：
- [ ] 用**同一独立校准的原始信号强度代理**分箱，两域使用相同的 x 坐标（建议 `x=log(clean_or_calibrated_linear_PD)`）；y 分别为 `log Var(residual_linear|bin)` 与 `log Var(residual_log|bin)`。真实图无真值时明确用重复观测估计稳定信号的代理，避免拿同一含噪值同时做 x/y 而引入条件偏差。
- [ ] 比较 `linear PD`、现有 `log1p(PD/s)` 与 `log(PD+ε)`，s、ε 在 calibration 冻结；按信号分位报告原始方差、条件噪声均值、方差曲线、拟合区间。**不要把负的 log 强度再截断后取对数**。
- [ ] 新建 versioned 的 Gate：若欲主张方差稳定，必须比较 log 域在各强度箱的方差比/范围、斜率的**等效性区间**（而非仅“斜率未显著不等于零”）；公开容忍值与校准依据。旧 G-R0-b 只保留为“斜率可测性检查”。
- [ ] 用两个正控制校验：`P=S·exp(ε)` 应使 `log P` 的条件方差相对 S 稳定；`P=S+ε` 不应在不合适条件下也被强行判定乘性化成立。

**验收**：同一组 x 分箱的三种表示、曲线及斜率区间可重复；旧数字重标“口径不一致，不能推导加性化”。`R0-b` 修订通过才可做 B 的数据域结论。

### R3-P05 / P0 —— 修正 A2 α 已知答案公式；结果不可在测试集上后验选优

**现有 Round3 计划**：`reviews/V3_PR1_round2_next_plan.md` §3 A2，定义 `pred_α=(1−α)obs1 + α model(obs1)`。当 `model(obs1)=truth`、`obs1=truth+ε1`、`obs2=truth+ε2` 且 ε1、ε2 独立同方差：

`E[(pred_α−obs2)^2] = ((1−α)^2 + 1)·σ²`；`E[(obs1−obs2)^2]=2σ²`，

故 **`R_N2N(α)=((1−α)^2+1)/2`**。

| α | 正确理论值 |
|---:|---:|
| 0 | 1.000 |
| 0.25 | 0.78125 |
| 0.5 | **0.625** |
| 0.75 | 0.53125 |
| 1.0 | 0.500 |

旧计划写 `α=0.5 → 0.125`，是错误反例，**必须纠正**。

**要求**：
- [ ] 修改 A2 已知真值单测与预注册公式；若仅用有限实现，写容差/多 seed/均值误差而不是要求每次精确等于理论期望。
- [ ] 先在**校准/验证集**观察最优 α，冻结后在新的留出测试卷计算效果。若只在同一 2 卷上扫描 α 并选择最小，只能称“后验诊断上限”，不能当泛化改善证据。
- [ ] α<0、α≈0、α>1 的解释要同时看空间有符号偏置、ROI/背景和校准集稳定性，不能直接一一映射到某个唯一网络根因。

**验收**：理论与 Monte Carlo 单测通过；报告区分诊断 α 最优与独立测试收益。

### R3-P07 / P0 —— 修订 n2n 风险桥、训练损失与“固定偏置”归因

**关联**：`scripts/v3_round3_bridge_check.py`；`reviews/V3_PR1_round2_next_plan.md` §1.3/A4。

**要求**：
- [ ] 明确该桥是**期望风险关系**：若 `obs_i=truth+ε_i` 且噪声独立、零均值、同方差，预测器 `f(obs1)` 不使用 obs2，则 `E MSE(f(obs1),obs2)=E MSE(f(obs1),truth)+σ²`；分母 `2σ²`。有限样本/不同噪声尺度/共用投影/非零条件偏置时不一定严格成立。现 44 格最大差 0.0368 仅说明**近似一致**。
- [ ] **禁止**由训练末 `loss/σ²≈0.16` 直接映射“训练几何 n2n≈0.58”，再宣称与完整体积留出结果之间的 100% 差额必定是“跨解剖迁移”：训练目标可能含相位、正则项、输入分布和空间部署差异。须分别在 **train、validation、held-out** 上采用**相同完整体积 infer 与相同真值口径**才可归因泛化。
- [ ] A4 现在把 4 个点的 `RMSE_model=a·RMSE_input+b` 截距 `b=0.0206` 解释为“与噪声无关的固定偏置”；**RMSE 的正截距不是输出的有符号强度偏置**，尤其拟合 `R²≈0.29`。分开报告 `mean(pred−truth)`、`MSE`、`Var(pred−truth)`、低频误差谱、背景/血管 ROI，跨至少 6 个独立测试体及多个噪声幅度。
- [ ] 置信区间按独立模拟场景/体积聚类，不把同一体的 ROI、patch、两种噪声实现当独立场景。A4 可作为探索性分解，不能仅凭 b 的 95% CI 排除网络的全部替代机制。

**验收**：区分噪声方差、系统误差与训练部署差距；撤回“误差缺口 100% 来自跨解剖泛化”的过强断言。

| A2 α 扫描 | 冻结 checkpoint，无训练快速诊断 | **修正公式**；校准/测试集分离；α 最优不是独立性能证据 | `alpha_sweep.json` + 理论 Monte Carlo 测试 |
| A3 扩增评测场景 | 从两个体积扩大到至少六个 | 统计独立单位为生成场景；只靠 2 卷均值变化是否 >0.05 不应成为“旧结论作废/成立”唯一依据；同时报 raw MSE/RMSE/偏置和 ROI | `s0_6scene_eval.json` + 每场景数据 |
| A4 误差分解 | 提供跨场景不确定度 | **不要把 RMSE 截距叫输出 bias**；加有符号偏差/背景/血管和 MSE 分解，分开系统和随机项；同时要求全分辨率 train/eval/test 同口径 | `error_decomp.json` + 相关图/区间 |

**执行顺序**：P01/P02/P05/P06 的模拟数学/单元测试 → A1/A2（低成本）→ A3/A4。R0 实测估计的修正可与 A 阶段并行，但 R0 的新噪声独立性/加性化结论必须在进入真实训练前闭环。

## 3. 对 B1–B4 修复方案的具体建议

### B1 / 首选：残差参数化 + 零初始化（保留，但要做归因对照）

`prediction = input + residual_net(input)`，末层零初始化使起点与输入相同，便于排查绝对亮度漂移。与现有 `direct output` 进行下列至少三臂比较：

1. `direct + current initialization`（原基线）；
2. `residual + current initialization`（只改变旁路）；
3. `residual + zero-initialized final layer`（再改变初始化）。

同一数据、same-voxel dense 监督/独立 N2N 目标、网络宽度、loss、seed、预算及验证。勿把初始化与残差旁路的收益混成一个机制。

**注意**：起点为恒等是**安全初始化**，不保证每次训练损失下降都代表去噪。监督训练 MSE 下降也可由背景偏置或训练集拟合造成；以独立场景真值评估和背景/血管结构安全判定。

### B2 / GroupNorm affine（降为辅助机制）

`GroupNorm(affine=False)` 确实使中间特征归一化，但 `affine=True` 的参数是**跨样本共享**，不能自动逆向恢复每个输入 patch 的绝对均值/方差。若 A1 的直流响应不足，可优先依赖残差旁路或显式保留输入均值/尺度通道；`affine=True` 是附加小规模对照，不能先验宣称已修好直流。

### B3 / 损失形式（先做梯度审计）

- dense 相同双输入下 identity loss 完全为零，必须从 B3 的有效消融中移除。
- 检查 Hessian/DWT 正则的实际数值、梯度尺度与频谱方向，才讨论增大/减小系数；若观察到结构过平滑，则“加大正则”更可能伤害结构，除非实际梯度说明相反。
- 若希望证明 identity loss 的具体作用，须用有非零分支差异的受控双视图模型；不能与 dense baseline 混淆。

### B4 / 容量和训练预算（最后）

只有在简单正控制的网络已优于输入时再考虑扩大预算。12→60 体的单 seed 收益小**不足以普遍证明泛化不受数据量影响**；可报告“在这组固定配置中 5 倍场景增益有限”，不应把其它泛化因素全部排除。

## 4. B（对数域）和 D（SVD-SN2N）的定位不可被永久冻结

- B 的**统计检查与表示单变量训练**至少应设计并实施小规模 pilot：`linear PD`、`log1p(PD/s)`、`log(PD+ε)`，共享 calibrator；优先在已确认同位置监督或 N2N 能工作后比较网络性能，但**统计部分不依赖训练链通过**。
- D 必须针对 **Zhang et al. 2026 超声 SVD-SN2N**（bioRxiv DOI `10.64898/2026.09.10.750668`）阅读原文/方法/补充材料。仓库 `reports/v3_R11/sn2n_difference_matrix.md` 虽已有摘要级更正，但 2024 年荧光 SN2N 的代码矩阵仍不能当 2026 超声方法的严格对照；无法精确复现时要标“论文驱动近似实现”，且保留 log、子视图、Fourier 插值、双预测 loss 的独立解释。
- 不能用 2×2 子视图的**整体图像相关性**等同噪声相关；真实噪声独立性需先经 P01/P02 修正。
- 实验 C（物理先验选择）依然必须比较正确/错误先验和最强固定采样，并保证校准/stride/coverage 完全一致。**在基本训练/真值评估链未成功前暂停大规模 C 是合理的资源决策；暂停不等于否定 I1。**

## 5. 重新设计 Gate：防止“过门”逻辑被反向使用

旧 Round3 G-B0 用 `vlow` 两卷 `n2n≤0.80`，可以保留作为原方案的**挑战目标**，但需要下列区别：

1. **统计 Gate（R0）**：是否在假设和独立性检验下获得可信的噪声/条件方差估计；只有“数值有变化”不等于“成功同方差化”。旧 Gate 保留为 historical pass，但新的实质结论在 R0-v2 单列。
2. **工程 Gate（S0）**：至少一个**同位置有监督**和一个**同位置独立 N2N**在有真值、可恢复噪声的简单场景中优于输入，且不牺牲预注册的弱血管、连通与伪血管安全约束；同时报告失败场景。若没有达到，先不进行大规模 I1。
3. **机制 Gate（B1/B2/B3）**：是否通过已知答案探针和相应梯度/参数对照证明了修复针对指定问题，不能凭一条 `n2n` 阈值就宣称“GroupNorm 是唯一根因”。
4. **研究 Gate（C/I1）**：在独立校准与 held-out 数据上，真正使用物理先验驱动采样；相同覆盖率、相同模型/损失/预算，比最强 fixed + 正确/错误先验消融；若没有可重复增益，就**收缩或终止 I1**。
5. “S0 未通过”仍是有效负结果，但**它不能证明 B 统计、D 超声专用方法没有研究价值**；也不能为了让 B/C 有机会而事后把 S0 旧门槛改宽。为新研究问题另建版本化 Gate，保存旧数值。

**主结果层级**：首先是已知真值恢复的 MSE/PSNR、弱血管召回@固定 FPR、宽度/分支/假阳性；`N2N ratio`、`r_roi`、图像 ACF 等为补充。几何血管真值必须和成像真值分开，体模标注应考虑 PSF/可分辨尺度。
