## 1. 数据与度量口径（**沿用 Round6，不改一个字**）

数据：`data/processed/v3_round6_b1/{linear,log1p,logeps}/{seq}_{odd,even}_x.npy`。
400 帧按时间奇偶拆成两半，**同一次 SVD 带通滤波**、只按帧拆功率，`pd_odd + pd_even == pd_full`
精确成立。两半共享解剖、噪声实现互相独立。尺度 `s` 对两半对称（两半中位数的均值 / 仿真背景锚点）。

度量：冻结的 log1p 指标域 `L(pd) = log1p(max(pd,0)/s)`，**在 A 半训练、去噪 A、与独立的 B 半比**

```
X_RMSE(f) = sqrt( mean_{v∈valid} ( L(f(A))_v − L(B)_v )² )
```

由于 `noise_B ⊥ (A, f(A))`，`E[(f(A)−B)²] = 真信号误差(f) + σ²_B`，交叉项为零
⇒ **排序无偏**。归一化用 `X_RMSE/X_RMSE(input)`：1.0 = 没去噪，`1/√2 ≈ 0.707` = 完美去噪。

**这个口径的已知偏差必须同读**（Round6 §4.4 实测）：它偏袒低对比度输出——
把图压平的臂 `X` 会变小。所以**任何一臂的 `X` 变小都必须同时给 `slope`、`core ratio`、
`var 削去%` 三个读数**，确认不是靠压对比度赢的。

## 2. 臂与网格

| 轴 | 取值 | 说明 |
|---|---|---|
| 臂 | **A** = `--mode random --role-perm global`（VALID-faithful）；**B** = `--mode fixed --pattern 5 --role-order 0 1 3 2` | **逐字沿用 Round9 `scripts/v3_round9_run_phase1b.sh`**，不改任何 flag |
| 表示域 | `linear` / `log1p` / `logeps` | 两臂拿**完全相同**的网格 |

| 其余 | patch 32×64×64、steps/epoch 300、lr 1e-4 poly、clip 20、`--weight-reg 1e-4`、`--weight-identity 1.0`、features 16、groups 4、`--arch-head direct`、`--pairing within`、seed 3407 | 全部来自 Round9 COMMON |

候选配置数：2 臂 × 3 域 × 3 长度 = **18 / 数据集**、**36 个训练作业**（方向 1）。

非学习参照（零训练，同口径）：

- `input`（不去噪，恒等）；
- `gauss(σ)`，σ ∈ {0.2, 0.3, 0.4, 0.6, 0.8}，在**方向 1**上按同一规则选一个 σ；
- `wiener3d`（`scipy.signal.wiener`，立方窗 `mysize=3`，与 Round9 一致）。

忠实移植参照（要训练，但训练方式与几何无关）：

- `SN2N`：`scripts/v3_round7_sn2n.py` 的 2D 逐切片实现（v0.3.5 逐行核对版），
  **在与 A/B 完全相同的那个半卷上训练** 200 epoch，整帧单次前向，100% 覆盖。
  这一臂必须存在，否则"本方法训练后"就没有同等待遇的自监督对手。

## 3. 方向、选择与确认（Round6 的做法，照搬）

- **方向 1**（选型）：`A = odd 半训练 → 去噪 odd → 与 even 比`。在方向 1 上为该数据集该臂
  从 9 个候选（3 域 × 3 长度）里选 `X_RMSE` 最小的配置；σ、α 也只在方向 1 上选/拟合。
- **方向 2**（无偏确认）：把方向 1 选中的配置**原样**搬到 `A = even → B = odd` 重训，
  `α` 沿用方向 1 的值、**不重新拟合**。
- **只有方向 2 的数字可以当干净结果**；方向 1 的数字只用于选配置，一律标注「偏乐观」。

## 4. 判据（写死，事后不改）

对每个数据集、每个方向，定义 `Δ = X_RMSE(本方法最佳臂) − X_RMSE(gauss 最佳)`
（都在 `α=1` 的原始输出上；`α=α*` 的说法同时报，但**不参与判定**）。

| 结论 | 条件 |
|---|---|
| **OURS-BETTER** | 两个数据集、两个方向**全部**满足 `Δ < −0.005` |
| **BASELINE-BETTER** | 两个数据集、两个方向**全部**满足 `Δ > +0.005` |
| **INCONCLUSIVE** | 其余（含一处为正一处为负、或全部 `|Δ| ≤ 0.005`） |

同一判据顺带用于 `vs wiener3d` 与 `vs SN2N` 两栏，各出一张表。
之所以要求「两个数据集 × 两个方向全部同号」，是因为只有 2 笔采集，任何单点优势都不足以下结论。

## 5. 增益校准（沿袭 Round6，防止把「幅度没调好」读成「方法不行」）

对每个学习臂，修正量 `Δ = L(f(A)) − L(A)` 对真噪声代理 `n = L(A) − L(B)` 做一元回归:

```
κ = ⟨Δ, n⟩/‖n‖² ,   α* = −⟨n, Δ⟩/‖Δ‖² ,   ‖Δ⊥‖² = ‖Δ‖² − κ²‖n‖²
```

`α` 只在方向 1 拟合、方向 2 沿用。恒等式 `X² = (1−κ)²X_in² + ‖Δ⊥‖²` 必须逐臂自检到机器精度
（Round6 实测 `max|残差| = 2.8e-17`），**自检不过就是实现错误，不是结果**。

## 6. 次要问题（本轮顺带回答，不改主判据）

L88 在真实数据上测到：Round9 checkpoint 把 log1p 斜率压到 0.69–0.82（高斯 0.93–0.97）、
最亮 10% 的核心区保留率低到 0.29–0.59，归因是**输入电平超出仿真训练范围**。
本轮训练数据就是真实卷本身，电平在分布内，因此：

- **预期**：训练后的模型不再出现 L88 那种量级的压暗；
- **判据（写死）**：训练后模型在方向 2 上的 `core ratio` 与 `slope` 若仍落在
  「比高斯低 0.05 以上」的区间，则 L88 的压暗**不能**再归因于输入分布外，必须记为网络自身行为。
- 这一条只作诊断，**不改 §4 的判定**。
