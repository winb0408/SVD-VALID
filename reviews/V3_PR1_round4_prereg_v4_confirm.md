# Round4 预注册 v4：β 选点规则 + e906–e911 确认实验（**在看到确认集之前写死**）

> 起因：P0 的主结果（e902–e905，`reports/v3_round4/baseline_pareto.json`）在
> `(var_bg, |bias_ves|)` 平面上出现了网络臂**位于 Pareto 前沿**的位置，
> 其中 vlow 档 `net_residual`/`net_zeroinit` 在 β≈0.5 处同时取得
> "背景残余方差 ≤ 冻结高斯" 与 "血管幅度偏差 ≪ 冻结高斯"。
>
> **诚实限定**：这个观察来自留出体 e902–e905，而 β 是 Round4 新引入的旋钮、
> 没有预先注册选点规则。因此 e902–e905 上的结论只能叫**探索性**。
> 本文件的作用是：把 β 的选点规则与通过线**现在**写死，然后只在**从未看过的**
> e906–e911（6 卷 × 2 档，已生成、尚未评估）上做一次确认。

## 1. β 选点规则（只在校准集 e900/e901 上算，冻结）

对每个网络臂 `A ∈ {net_direct, net_residual, net_zeroinit}` 与每一档：

```
β*(A) = argmin_{β ∈ {0,0.25,0.5,0.75,1}} |bias_ves(β)|   s.t.  var_bg(β) ≤ var_bg(gauss σ*)
       若该约束集为空 → β*(A) = "NO_FEASIBLE_BETA"（该臂在"匹配噪声抑制"意义下没有可比点）
```

- 约束右端 `var_bg(gauss σ*)` 用**同一校准集**上的冻结高斯算（σ* = low 0.6 / vlow 0.5，A5 冻结）。
- 目标 `|bias_ves|` 是 v3 定义的血管区系统偏差（越小=结构越保真）。
- 若约束集内多点，取 `|bias_ves|` 最小者；再并列取 β 较小者（保守）。

## 2. 确认实验（e906–e911，**本轮唯一一次评估**）

对每一档、每一网络臂，取 §1 选出的 β*，在 e906–e911 六卷上算：
`var_bg`、`|bias_ves|`、`overall_rmse`，与同一体的 `gauss(σ*)` 与 `wiener(w*)`（w* 仍取校准集选出的值）配对比较。

**通过线（全部满足才算 `STRUCT_SAFE_GAIN_CONFIRMED`）**：

1. `var_bg(net, β*) ≤ var_bg(gauss)` 在 **≥5/6 卷**成立（噪声抑制不劣于冻结高斯）；
2. `|bias_ves(net, β*)| < |bias_ves(gauss)|` 在 **≥5/6 卷**成立（血管幅度更保真）；
3. `overall_rmse(net, β*) ≤ overall_rmse(gauss)` 在 **≥5/6 卷**成立（总误差不劣，防"低偏差但没降噪"）；
4. 与 `wiener(w*)` 同样比较，三条也需 ≥5/6 成立（防"只赢一条盲模糊"）。

不满足 → `STRUCT_SAFE_GAIN_NOT_CONFIRMED`，并按任务书 §5 处理（不得转去加模块/调损失）。
