## 1. 真实数据上"最好"怎么定义（这是本轮唯一的新东西）

真实采集没有干净真值，所以必须先把度量定死，否则"最好"是虚的。

**数据构造。** 400 帧按时间奇偶拆成互相独立的两半，**用同一次 SVD 带通滤波的结果**
（不做第二次 SVD，避免两半的秩带物理含义漂移）按帧累加功率：
`pd_odd + pd_even == pd_full` 精确成立（实测与 `official/pd_linear.npy` 相对误差 ≤ 1.0e-7，
corr = 1.00000000）。两半共享同一解剖、同一秩带，**噪声实现互相独立**。
尺度 `s` 取两半中位数的均值（对 odd/even 完全对称），使两半 `u=PD/s` 的中位数都为约 1.000，
与仿真训练分布对齐。

**判据（主）。** 在冻结的 log1p 指标域 `L(pd) = log1p(pd/s)` 上，取 `A` 半训练、去噪 `A`，
与独立的 `B` 半比较：

```
X_MSE(f) = mean_{v ∈ valid} ( L(f(A))_v − L(B)_v )²
X_RMSE(f) = sqrt(X_MSE(f))          % 报告用
```

**为什么这个数无偏。** 设 `B = signal + noise_B`，且 `noise_B ⊥ (A, f(A))`，则

```
E[(f(A) − B)²] = E[(f(A) − signal)²] + E[noise_B²] − 2·E[(f(A) − signal)·noise_B]
               = 真信号误差(f) + σ²            （交叉项 = 0）
```

`σ²` 对所有方法相同 ⇒ **X_MSE 的排序就是真信号误差的排序**，各方法之间可直接比大小，
差值可读作信号误差的差。这正是 Noise2Noise 式评价，是真实数据上少数几个不掺假的口径。

**参照归一化。** `X_MSE(input)` 就是"完全不去噪"。若两半噪声同量级且独立，
`E[(L(A) − L(B))²] ≈ 2σ²`，故**完美去噪只能把 `X_MSE` 降到约一半**。
因此主报告量是 `X_MSE/X_MSE_in`：1.0 = 没去噪，0.5 ≈ 理论上限。任何低于 0.5 的结果视为
"口径假设被破坏"并**优先怀疑实现**，不得当作更好。
（log 非线性使该等式只是近似，故写"约"。）

> **§1 更正（2026-11-02 20:26，仍在任何结果产生之前；写明原因）**
> 上一段把 `X_MSE` 的"降到一半"与 `X_RMSE` 的比值混用了。代数上 `X_RMSE = √X_MSE`，
> 所以换成 `X_RMSE/X_RMSE_in` 表示时，理论上限是 **1/√2 ≈ 0.707 而不是 0.5**。
> 本文 §4 的判据用的是 `X_RMSE` 的**差值**（0.005），不受此影响；
> 只有"归一化比值"的基准线需要改：**`X_RMSE/X_RMSE_in = 1.0` 未去噪、`≈0.707` 完美去噪**。
> 图和表一律按 RMSE 比值画（与 JSON 里的数一致），基准线标 0.707。
> 这是一处叙述性的数学更正，不改判据、不改阈值、不改任何实验设定。

## 2. 臂与"各自最好"的网格

几何是"方法"，表示域与训练长度是"超参"。**为公平，两种几何拿到完全相同的网格**：

| 轴 | 取值 |
|---|---|
| 几何 | `D1`（`--stride 1 --mode random --pairing cross`）、`BD-2`（`--stride 2 --mode fixed --slots 1 4 6 3 --pairing cross`） |
| 表示域 | `linear`、`log1p`、`logeps`（三域全给，不按 Round5 的偏好预设） |
| epochs | `6`、`18`（单卷数据极易过拟合，必须留一条早停轴） |
| 其余 | 完全固定：patch 32×64×64、steps/epoch 300、lr 1e-4 poly、features 16、groups 4、seed 3407、`--arch-head residual --zero-init-final` |

另加两条**非学习参照**：`input`（不去噪）与 `gauss(σ)`（σ 在 `{0.4,0.6,0.8}` 中按同一规则选）。

候选配置数：2 几何 × 3 域 × 2 长度 = **12/数据集**。

## 2b. 推理口径（BD-2 的回填，跑之前定）

BD-2 训练时只喂了 `1→6`、`4→3` 两条角色映射，单卷只能直接算出 **1/4** 体素；
D1（m=1）天然 100%。这会让两者落在不同体素集上，必须定死口径：

- **主口径（配对、不外推）**：两种几何都在 BD-2 直接覆盖的那批体素上算 `X_RMSE`。
  D1 的预测先取到同一批体素再比。→ 完全同体素、同分母，**不依赖任何未经训练的东西**。
- **副口径（全图）**：BD-2 另用 `target = input XOR 7` 铺满 8 个相位对（64 次前向）
  得到整幅图再算。该规则在 Round5 已被验证是训练出的那条几何规则的天然延伸，
  且已核对"已训练部分数值逐位不变"；但 **8 对里有 6 对没在真实数据上训练过**，
  所以副口径的结论必须带这条限定，**不得单独用来支持 BD-2 更好**。

推断成本一并记录：主口径 D1 8 次前向 / BD-2 16 次；副口径 BD-2 64 次。

## 3. 选择规则与无偏确认（两段式，防止在报数上挑）

1. **方向 1（选择）**：在 `A = odd` 上训练，对 `B = even` 算 `X_RMSE`。
   对每种几何，取 12 个配置中最好的那个 → "该几何在真实数据上的最好结果"。
   **明确披露**：这是**在报告口径上选**，因此方向 1 的数字对每种几何都**偏乐观**；
   由于网格对两种几何完全相同、候选数相同，**偏乐观的程度同阶**，但不可当作无偏结论。
2. **方向 2（无偏确认）**：把上一步选中的配置原样搬到 `A = even` → `B = odd` 重训一次，
   报 `X_RMSE`。这一步**完全不参与选择**，是唯一可以当作干净数字的部分。
3. 主结论以方向 2 为准；方向 1 只用于选配置和展示"最好的样子"。

## 4. 判定（跑之前写死）

设 `Δ = X_RMSE_2(BD-2 最优) − X_RMSE_2(D1 最优)`（方向 2、**主口径**（配对体素），
负值表示 BD-2 更好）。

- **SUPPORT**：`Δ < −0.005`（即 BD-2 至少好 0.005 log 单位）**且**两个数据集方向一致。
- **WORSE**：`Δ > +0.005` 且两个数据集方向一致。
- **INCONCLUSIVE**：其余情况（含两个数据集方向相反、或 |Δ| ≤ 0.005）。

`0.005` 的来历：真实数据两半的 log1p 差异 RMS 实测为 SA64 0.0342 / HSA64 0.0376，
0.005 约为该噪声底座的 14%，小于它就不可能稳定分辨。这个阈值**在看任何结果之前定下**。

同时报出**可去除上限**（`reports/v3_r06/testretest_calibration.json` 的实测值）：
SA64 的 log-PD 方差中只有 **5.2%** 是可去除的，HSA64 只有 **0.52%**。
因此本轮的所有改善都必须同时报"占该上限的百分比"。**若某个方法的改善超过上限，
一律判定为实现或口径有问题，不得当作优点。**

**补充 1：1 参数增益校准。** 令 `L(f_α(A)) = L(A) + α·Δ`，最优 `α* = −⟨n,Δ⟩/‖Δ‖²` 有闭式解。
这只调一个标量、**不重训任何模型**，等价于"把这个方法的输出幅度调到它自己最好的样子"，
正是本轮要回答的"各方法最好结果"。**公平性约束**：
- α 只在**方向 1** 上拟合，把 α 写进 `selections.json`，**方向 2 一律沿用该值，不得重拟合**；
- 参照臂 `gauss(σ)` 同样做增益校准（否则对学习臂不公平），(σ, α) 一起在方向 1 上选；
- `input` 无修正量，无可校准。

**补充 2：N2N 正对照补跑方向 2。** 三个方法必须同处一个方向，否则"偏乐观 / 无偏"混在一张表里没法比。

**补充 3：BD-2 的 4 对映射稳健性。** 主口径 `SCATTER={1→6, 4→3}` 只用了模型学过的 4 条映射中的 2 条，
覆盖 25%。训练时 `--slots 1 4 6 3 --pairing cross` 实际学到 `1→6, 4→3, 6→1, 3→4` 四条，
全用可覆盖 **50%** 且**仍然零外推**。这对 BD-2 是更有利的口径，必须报，
否则"BD-2 更差"可能只是"给了它更少的映射"。
