## 2. P0 — 必须先解决的阻断项

### R01 / P0 — 建立上游 faithful VALID 训练—推理基线；不再混淆相位回填与完整体积推理

**已核实的代码事实**：
- `datasets/sampling.py` 现有 `valid_random_tetris()`（同一个 Tetris pattern 选四角并随机角色）与 V3 新增的 `valid_random_tetris_cross()`（输入 tet A 两角、目标互补 tet B 两角）**不是同一个采样定义**。
- `train.py` 在 `--pairing cross` 时改变了输入—目标角色来源。
- `scripts/v3_phase3_eval.py` 的 `reconstruct()` 用八个相位前向，再按 `scatter_to` 或原相位回填。
- 仓库已有 `infer.py` 使用完整三维 patch 上的 CRN 前向及滑窗平均；它与上述相位回填**是两种不同的推理**。
- 原版 VALID 的精确生成规则/推理契约应以已固定版本的**上游源码**逐函数核对，不能只凭仓库注释断言“faithful”。

**要求**：
1. 定位 VALID 上游明确 commit、许可及生成视图、角色映射、前向、整卷重建的对应函数，撰写源码逐项对照表，标注已核验和有意不同之处；不得悄悄将 cross 模式覆盖 faithful 模式。
2. 将 `valid_random_tetris` + 上游等价网络/损失 + 整卷 patch 推理形成单独、可运行的 **VALID-faithful** baseline（按上游实码定义）。
3. 分离至少两个明确的推理 API：`infer_full_volume`（完整三维输入）与 `infer_phase_scatter`（相位监督预测）。各自只用于合法训练设定；所有比较图注注明哪个 API。
4. 设计 **脉冲/坐标编码体积**的空间配准测试：每个输出位置映射必须明确，不能把目标格点预测无条件散回输入格点而不计配准偏差。
5. 在同一仿真数据上比较相同 checkpoint 的两种推理（在 checkpoint 语义许可时），再单独重训 faithful baseline；不能把不同训练/推理模型混比较成纯部署消融。

**通过标准**：忠实复现上游行为的单元测试通过，网络训练+推理可重现，输出坐标与尺寸匹配；random、fixed-4（同一套基线）具有可追溯 seeds、参数、完整浮点结果与固定显示。没有原始权重不阻碍写好代码测试，但**没有实际重训不得标为通过**。

**关联文件**：`datasets/sampling.py`、`train.py`、`infer.py`、`scripts/v3_phase3_eval.py`、`tests/test_smoke.py`。

### R02 / P0 — 纠正 m=2 对照：不允许把“采样距离”与“有效覆盖率”混为单变量

**已核实**：`strided_phase` 在每轴以 `2m` 为周期取子格，m=1 的 8 相位联合覆盖 100%，m=2 联合覆盖 12.5%，m=3 是 3.70%；与此同时网络视图大小、条件信息量、血管采样数、推理网格及算力预算都变动。

**要求**：
1. 保留原始 m=2 负结果，并重命名为 **稀疏覆盖+远距离耦合实验**，不得据此认定“同覆盖率下优化方向无效”。
2. 新建**同原始输入体积、同整体体素覆盖、同结构 ROI、同训练预算**的采样方向/角色/位移对照。可使用多个平移 offset、密集局部相位平铺等，但必须显式验证每个体素的监督/重建对应关系及信息使用次数。
3. 对照至少含 m=1 random、fixed-4、同几何不同角色、物理约束采样。把 **同距离、不同泄漏** 与 **同物理信息量、不同距离** 分成两个实验，不能只用 body diagonal vs y axis 得出“泄漏无用”。
4. 单独追加等前向计算或等有效体素预算的 m=2 诊断；若不值得运行，明确放弃，绝不把“不足预算”作为永久的失败免责理由。

**通过标准**：实验表列清 stride、覆盖率、参与训练体素数、各角色物理位移、forward 次数和可评价体素数；至少有**真正只改变一个变量**的对照和相同有效 ROI 上的独立结构评价。

**关联文件**：`datasets/sampling.py`、`scripts/v3_physics_sampler.py`、`scripts/v3_phase3_probe.py`、`scripts/v3_phase3_eval.py`、`reports/v3_phase3_probe.md`。

### R03 / P0 — 端到端 I1 创新尚未跑通：把物理先验真正接入训练 sampler

**现状**：现有 `scripts/v3_role_order.py`、`scripts/v3_correlation_length.py` 产生离线统计；`train.py` 实际通过手动 `--slots` / `--stride` / `--pairing` 运行，并非已验证的「独立 PSF/散斑校准→受约束选择→训练→恢复」闭环。

**要求**：
1. 明确物理量：独立点目标/体模 PSF、仿真 PSF（须标注）、残余噪声协方差代理、真实血管信号一致性，不混为一个相关系数。
2. 建立独立**calibration** 输出（物理轴、mm 间距、协方差及不确定度、使用样本 ID）；形成冻结的 `sampler_config.json`。
3. 选择器至少接受 `N(k)` 和 `S(k)`，先用结构保真门槛筛选，再以噪声依赖挑候选；`S_min` 从校准集冻结，不用测试集回调。
4. 选择器接入 `train.py`，在 run meta 中保存每次采样规则及分布；加入**先验随机打乱/错误物理先验**负控制。
5. 与最强固定模式比较，训练/验证/test 的 acquisition 不泄漏。没有真实 PSF 时只能叫“仿真 PSF 引导”，不能用背景 ACF 取代实测 PSF。

**通过标准**：端到端生成可复现、可追溯的物理选择记录；正确先验与错误先验的真正独立实验已完成；fixed-4 和最优固定方向都在对照中。否则 I1 标“未完成验证”，不是“科学上被否证”。

### R04 / P0 — 对数域 + 配对的统计条件需要**实验验证**，而不是只加一次 log

**已核实**：Phase 3 与 N2N 使用 `log1p(PD/s)`，所以不是完全没做对数压缩。但 `log1p(SN/s)` **通常不能精确分离**为 `f(S)+g(N)`，特别是背景 `P/s` 约 1 时；真实 SVD-PD 还可能混有加性残差、杂波及信号依赖噪声。

**要求**：
1. 同一数据、同一 sampler、相同网络/预算，冻结比较 **linear PD / log1p(PD/s) / log(PD+epsilon)**（epsilon 和 s 从 calibration 拟定，不随方法任意变化）；不是为漂亮显示单独调动态范围。
2. 对每个表示，按独立真值/校准结构的信号水平分桶，记录残差条件均值、条件方差、跨视图残差协方差、偏置随信号变化的曲线。
3. 显式检查 N2N 的必要条件：是否满足或近似满足 **E[目标噪声 | 输入观测]≈0**（或者解释不满足时网络具体在拟合什么）。“奇偶帧不重叠”本身不保证这一点；各自 SVD 子空间估计可能引入共性或分布差异。
4. 在不改其他因素的情况下报告真实输出质量，区分“加性化改善”与“强度范围压缩改善”。不得预设普通 log 必胜，也不得把当前 log1p 当作完全没有意义。

**通过标准**：有测量曲线和数值表；训练尺度和评价尺度一致；至少能判断某种表示是否比另一种提供更合适的监督信号。若统计条件不成立，应修配对构造或重新定位任务，而不是继续叠加相位采样策略。

### R05 / P0 — 修订“0.5 普适上限”“非线性泄漏上界”等过强结论

**已核实**：`scripts/v3_phase4_linear_ceiling.py` 拟合的是**同一个 2×2×2 块内其他 7 个角点的全局最小二乘线性预测**，其结果约 `n2n=9.353`、`slope≈0.503`、`r_ves≈−0.193`。使用单卷 obs1 的点进行拟合并在同一数据上计分，不能当独立测试集的严格线性上限。

**必须纠正**：
- `slope(pred, noisy_input)≈0.5` **不是**真实血管信号振幅保留“数学上限 0.5”；有噪输入被去噪后斜率变小是可能且正常的。
- 这仅证明当前**局部线性预测器/当前相位回填流程**失效，不能推导任意空间上下文、任意非线性 CRN 或 faithful VALID 必败。
- `L=cᵀC⁻¹c` 是线性预测解释方差；在联合高斯等条件下具有更强解释，非高斯乘性散斑下**不得直接称为任意非线性网络的严格上界**。
- 八种 Tetris 模式“任意平稳噪声下全等”须限定其对称性条件及完整**有符号、物理轴方向**位移。镜像朝向在具有交叉方向协方差、旋转 PSF 或非平稳成像时未必统计等价。
- “盲点网络只有单一 b 旋钮”不成立：非线性上下文估计可以局部依赖信号；是否可学是实证问题。

**要求**：保留原始数值、实验和失败结论，但把 `phase4_report.md §5.2–5.4`、`v3_precheck_sampling_geometry.md`、`Project_progress_status.md` 中普适断言改成**指定模型、指定噪声假设和指定部署条件下的观察**；附可复核的数学推导与反例。必要时将“linear ceiling”重命名为“in-sample local linear diagnostic”，真正可称上界的对象须定义清楚。

**通过标准**：报告不存在由该数据直接推出任意网络理论上限的跳跃；明确哪些数仅用于局部线性基线与当前实现诊断。

### R06 / P0 — 仿真器成像正向模型与目标信号定义审计

**已核实**：`scripts/v3_simulator.py` 的血流空间项为 `gauss_field(...)*vessels`，并非明确的“血管散射分布→声学 PSF 卷积→IQ→SVD/PD”的前向测量。血管半径约 1.1 voxel，与拟合的相关核尺度相比很小。旧版“血流为秩 1 导致 SVD 消除”的 bug 虽已修，但这不是完全真实的微血管模拟。

**要求**：
1. 分别保存 **几何血管真值**、**无噪成像真值**、**有噪 IQ/PD 观测**、**采样后的网络表示**；不能拿纯血管功率和含有真实背景本底的 PD 当同一目标。
2. 至少增加一条显式前向模型：血管散射场/流动项先经 PSF，再加其他可控成分，最后走 IQ→SVD→PD；改变 PSF 宽度、血管半径、SNR 时能输出合理规律。
3. 在物理轴与体素间距下校验血管剖面/宽度、PSF FWHM、强度/背景统计、ACF；区别标定出的经验相关尺度和真实点目标 PSF。
4. 受控仿真包括：无散斑或独立噪声、强相关散斑、已知 PSF、血管结构细分支；独立多场景，不只在单个 seed 上挑最好的方法。

**通过标准**：前向模型通过单元/定量 sanity checks；输出三类真值边界明确；在至少两类不同相关性条件下复现对照趋势。未经物理校准不能宣称“真实 PSF 模型已验证”。

### R08 / P1 — 区分时间 N2N 真正的泛化与“模拟→真实零样本域偏移”

**已核实**：`scripts/v3_phase4_train_n2n.py`、`scripts/train_n2n.py` 在仿真独立场景训练/验证；真实 `v3_phase5_real_network.py` 属**zero-shot**，并未在 SA64/HSA64 用真实配对训练，因此真实表现同时包含训练分布差异，不能当作“在真实数据训练的 N2N 本身无效”。

**要求**：先在独立模拟场景复现实测，再做真实 A/B 统计检测（奇偶分帧、共同/分别 SVD 的协方差和目标强度差异），必要时在真实采集或独立体模中构建可用配对；按 acquisition 分 train/validation/test。报告 faithful 单卷 SSL、中心可见时间 N2N、Wiener 的用途与训练数据区别。不要把多折或 patch 数量算成独立 acquisition 数量。

**通过标准**：明确三个命题：仿真场景泛化、真实训练可行性、模拟→真实迁移。每种失败只归因到它检验的命题。实际无独立真实数据时，不能宣传真实域普遍有效或无效。

### R09 / P1 — J1.2 的 B 项含义、阈值和假阳性解释必须限定

**代码事实**：`scripts/v3_judge.py` 中
`B_dark(p,q)=mean_dark((p²+q²)/2)−0.5 mean_dark((p−q)²)=mean_dark(pq)`，因此它实际测的是**跨两次输出的平均乘积**。只有在适当相同信号/零均值/跨实现误差无相关等条件下，才能约化为平方偏置。

**要求**：
1. 明确背景存在真实弱血流及残余相关时 B 不一定等于假阳性 bias²；对模拟真值设计相关残差/非零真实背景的反例。
2. `S_rel` 是亮核均值保持，不能单独识别断裂、细分支损失、局部过冲和假管；必须增加真值体模的结构指标（弱血管 recall@固定 FPR、宽度/连通性/假阳性）。
3. 由一套幻影给出的 `B_db≤−7.3` 与 `N_rel≤0.5` 是工程门槛，不是天然物理常数；真实 SA64/HSA64 的跨域应用需校准，不准因某 seed 通过而宣布图像质量提升。
4. 保留 J1.2 的旧数值和原始结果；如有改进另建 **J2**，原实验判定继续能被复现。

**通过标准**：J1.2 的三个指标及其局限由受控实例验证；新增 J2 之前有预注册版本、正负控制与无需后验调参的 hold-out。

### R10 / P1 — 纠正“经验 n2n≈0.615 是所有模型严格下限”等措辞

`reports/v3_phase4_2026-10-21/phase4_report.md` 和 `scripts/train_n2n.py` 将**当前仿真若干实现平均得到的 0.615**写成训练/验证比值的普适不可超越下限，并据此将低于 0.615 直接断言为记忆。

应修正为：在独立、条件零均值等假设下存在条件均值的最优风险；**有限实现均值 0.615 只是该仿真协议的可用参考估计，并不等于精确 Bayes 下界**。是否记忆要用独立目标实现/独立场景的验证曲线、训练/验证差异判断，不能仅凭落在某数字以下。历史中单场景 600 epoch 出现过拟合的结果可以保留，因为有未见过实现上的独立证据。

**通过标准**：注释、日志和报告统一更正；验证协议不依赖单一经验常数来“证明过拟合”。

### R11 / P1 — 把 SVD-SN2N 当作完整方法对照，不是“改成 log 即可”

SVD-SN2N 把对数域统计、子视图构造/插值与预测约束协同设计。需要从原文/官方代码确定其适用对象、具体对角重采样、傅里叶零填充插值、损失及推理，与 V3 逐项做**文献+代码差异矩阵**。

至少有两种明确独立实验：
- **表示 ablation**：只变 linear/log1p/log，其他全固定（对应 R04）。
- **完整方法对照**：尽可能忠实复现 SVD-SN2N；如果无法移植到 3D，标明“近似扩展版”，不可写作原论文复现结果。

**通过标准**：有来源、版本与关键步骤核对；任何结果对应清晰定义的方法，不以仅增加 log 的结果代表 SVD-SN2N 全部思想。

### R12 / P1 — 将微血管图像质量作为主要判据，覆盖真值与真实数据

正式评价需包含：有真值模拟/体模的 PSNR、SSIM、弱血管 Recall@固定 FPR、中心线与分支、宽度误差、虚假血管；真实 SA64/HSA64 的固定窗 MIP、三切片、同 ROI、相同线性/对数数值处理、背景定量及伪真值限制。保存 raw float 输出。主终点和 sample 独立单位必须在实验前冻结。

**通过标准**：以最强固定采样而不只以随机为竞争对象；≥3 seeds 的效果方向、独立 acquisition/仿真实例不确定度并列；不能以“n2n 小”自动判断血管更好。

### R13 / P1 — 审计真实数据的轴序、归一化、rank 与 valid_mask

涉及 `scripts/official_pipeline.py`、`scripts/v3_phase5_real_network.py`、`scripts/v3_judge_real.py`。需固定真实空间轴(z/x/y)含义及 spacing，校核 1-based MATLAB band 60:350 对应的 Python 半开区间（文档中存在 60–350 比例化和索引口径表述差异，应统一到明确实现），核对全帧与半帧 SVD 的选频方式、每链共享尺度、无效近场掩膜、裁剪至 z=32 的影响。

**通过标准**：输出可机器检验的 manifest + 轴向坐标图 + shape/rank/mask 测试；若无法逐像素比对官方 MATLAB 脚本，明确写“逻辑口径移植，非官方逐像素一致”。

## 4. 建议的最小化执行顺序（优先少量决定性实验）

**M0 / 静态修订，不训练**：先完成 R05/R09/R10 的理论限定，审计 R01/R07/R13；记录上游 VALID 对照。避免在错误理论上继续投入。

**A / 恢复基础能力（R01 + R06）**：在有真值仿真体上用同一个可追溯协议比较 **输入、Wiener、faithful VALID random、fixed-4**。必须使用可信整卷推理，并显示结构保真。**A 失败**→停止开发 PSF 采样选择器，先解决输入/任务和基础自监督基线；**A 有效**→可转 B/C。

**B / 检查 log 是否真正产生更可用的监督（R04 + R07）**：严格固定 A 的 sampler/net/loss，比较 linear PD、log1p、固定 epsilon log；联合报告条件残差及最终图像质量。**不允许**一次改 log、pairing 和网络。B 结论必须说明“噪声加性近似/条件偏置是否改善”，不能只看输出更好看。

**C / I1 的第一次公平检验（R02 + R03）**：仅在 A/B 表示冻结后，比较 **faithful random、fixed-4、同距离不同角色、同覆盖不同几何、真实物理规则、错误物理规则**；保持网络/损失/体素预算/评价坐标不变。主终点为独立真值弱血管/结构指标。若只赢 random 而没赢最强固定，不能叫物理选择创新成立。

**D / 超声特定方法参照（R08 + R11）**：在可公平数据口径上复现/构造 SVD-SN2N 对照，区分其噪声表示、配对、插值、损失各自贡献。若 D 有效而 A 不行，重点检查 VALID 的空间自监督条件；若 A/D 都有效而旧 V3 失败，主要归因旧采样与部署；若二者都失败，回到数据与噪声模型而非继续堆新评分器。

每一步结束**先写实验报告和 Gate 判定**，后开始下步；没有相关数据可跑时允许交付“代码与测试就绪 / 实验未完成”而不是虚构已通过。
