## 0. 先明确本轮审查结论与更正

1. **确认已有负结果**：v2 仿真上 16 个训练体、两个留出测试体，VALID random/fixed-4 每臂 200k steps × 2 seeds，使用完整 patch 推理，均未在 `n2n_ratio` 和 `r_roi` 上优于输入；random 的结构损失明显更大。对应 `reports/v3_expA_v2/results_stage2.md`。
2. **不能称 I1 被科学证伪**：同覆盖率「正确物理先验 vs 错误先验/角色互换 vs 最强固定」的 **实验 C 训练没有执行**；`train.py --sampler-config` 当前主要是**校验/记录配置**，并非从物理先验动态计算采样。状态只能写「本仿真的原始/固定 VALID 训练失败；I1 未完成直接测试」。
3. **T2 的冻结是资源管理规则，不是逻辑证明**：实验 B（log 变换）及 C（用物理先验修复采样）本来就在测试 A 为什么失败；A 不通过不能作为 B/C 在科学上无需执行的理由。保留旧预注册的 T2 结果，**为本轮新诊断开一个有版本的新 Gate**，不可回填覆盖旧结果。
4. **v2 仿真可独立扰动的随机成分可能很少**：`reports/v3_r06/v2_endpoint_audit.json` 测得
   `MSE(obs1,obs2)/Var(obs1)` 约 2.02%（s30）/1.70%（s31）。若假设两次观测的随机扰动独立同方差且稳定场景相同，则单次可分离噪声方差约为总体方差的 **1.01% / 0.85%**。这是**有前提的 proxy，不是已经量出的全部残余噪声能量**。该测试可能已经处于低噪声/高稳定结构条件，去噪收益空间小且一点结构偏差便让输出得分变差。
5. **两个真值不能混为一谈**：`gt_flow_pd` 是血流分量单独 SVD/PD 的参考，而 Noise2Noise 第二观测的目标更接近含稳定杂波与背景的观测条件期望。SVD 子空间依赖全体输入、PD 为平方模，二者不等价；在同一实验中同时要求「像血流单分量真值」与「像完整第二观测」可能出现冲突。下一步要把几何血管、稳定完整成像目标、血流分量目标分别列出。
6. **R12 尚不完备**：既有 `recall@FPR`、AUC、IoU 在 v2 模拟中发生「成像真值输给含噪图」说明 **几何标签 vs PSF 模糊图的评价目标/尺度不匹配**；不是证明这些检测指标在一切超声微血管任务中不成立。不能只剩 `r_weak` 就宣布血管结构验收完成。
7. **明确 R11 纠错**：DeepSeek 误把 2024 年荧光显微 **SN2N** 当作用户指称的 **2026 年超声 SVD-SN2N**，这是**错误对照对象**。真正论文：Zhang et al., *SVD-SN2N: Self-Inspired Noise2Noise Learning for Denoising Log-Compressed SVD-Filtered Ultrasound Imaging*, bioRxiv (2026-09-13), DOI `10.64898/2026.09.10.750668`，原文 https://www.biorxiv.org/content/10.64898/2026.09.10.750668v1 。必须以该论文为对照对象，既有 `reports/v3_R11/sn2n_difference_matrix.md` 标记「**针对另一种 SN2N 的历史审计，不是 SVD-SN2N 复现**」。
8. **噪声相关性 ≠ 原图空间相关性**：既有 `corr(A,B)=0.90–0.95` 是背景区域**视图强度相关**，包含共享慢变结构、散斑平台与可能的血流，并非纯噪声条件互相关；`percentile` 是单调变换不代表 Pearson 相关不变（除正仿射且不截断）。不得据此直接宣称 SVD-SN2N 的噪声独立性已被严格证伪；需要估计/消除共同信号后再判断。

## 1. 真实数据是否比 v2 仿真合适：明确答案

**结论**：应将用户已经下载、V1/V2 已处理过的 Dryad 数据作为**真实成像目标和核心评价对象**，但不能用它单独证明有无去噪能力。采用两条互补证据链：**受控合成/物理仿真建立有真值因果证据；真实 RCA 指尖三维数据验证实际微血管视觉/结构可用性和噪声统计**。

| 数据 | 官方规格 | 优点与限制 |
|---|---|---|
| **SA64** | `[Z,X,Y,Frames,Array]=[37,64,64,400,1]`，0.15 mm，46.875 Hz | 实测 RCA beamformed 时序（IQ），可研究 SVD 前后、3D 结构与散斑 |
| **HSA64** | 同上 | 另一采集策略，可做**协议迁移**；不是同一噪声实现的独立同场景重复 |
| **PW3232** | `[37,64,64,400,2]`，46.875 Hz | 两发射阵列，官方需先做正确的数组合成 |
| **PW1616** | `[37,64,64,800,2]`，93.75 Hz | 时序更长；官方秩带和阵列处理**与 SA64 不同** |

**已存在的代码资产（优先复用）**：`docs/datasets.md`、`scripts/official_pipeline.py`、`scripts/audit_iq_data.py`、`datasets/iq_io.py`、`reports/phase0_data_audit.md`、`reports/v3_R13/axis_manifest.json`、`scripts/v3_judge_real.py`、`scripts/v3_phase5_real_compare.py`。不要重新下载已经在本机的数据，先检查 local manifest/哈希是否与仓库记录相符；如果 PW 文件未在执行机器上，记录缺失并继续 SA/HSA，不得声称全套已分析。

**官方 SVD**：以 `main_supplementary_figure_2.m` 为准，仓库当前映射 `SA64/HSA64/PW3232: MATLAB 60:350 = Python [59,350)`，`PW1616: 120:750 = [119,750)`（需再次核对官方源）。全帧 PD 官方是**时间维功率求和**而非均值；做不同时间长度块的比较时需记录并统一物理单位/帧数归一，不能混用 sum/mean。

**独立性限制**：四种发射协议不能当作四只动物、四个独立志愿者或四次完全配准的重复成像。SA64/HSA64 甚至不应默认同一时刻场景像素级匹配。不同序列可用于协议敏感性，不能构造未经检验的 Noise2Noise 独立目标。

## 2. 第一阶段：R0 / Dryad RCA 真实数据与噪声“难度”审计（必须先做）

**为什么先做**：v2 仿真可能只含约 1% 的可分离波动；真实 SA64/HSA64 噪声是否更大**目前未知**，禁止先下“真实噪声更多”的结论。

### R0-1 数据资产与处理链
- [ ] 枚举已有 SA64/HSA64/PW 数据文件、形状、dtype、帧数、间距、文件哈希、有效 mask、空间方向、无效扇形成像体素；建立真正执行机器上的 manifest。
- [ ] 确认 MATLAB v7.3 复数读取；校核按原版脚本对整个时序做 SVD；按原版索引保留模式，输出 IQ 带通结果、线性 PD、固定参考尺度的 log/ log1p 表示。
- [ ] 不把 PW 的双阵列维度简单拼接为相同样本；按官方脚本的 coherent sum/X-Doppler 分支单独处理。
- [ ] 增加官方处理链的 unit tests：帧数、秩带、轴序、mask、能量守恒/非负性、sum 与 mean 关系、不同块长度的强度规范化、有限值。

### R0-2 到底是否存在值得去除的残差噪声？
- [ ] 采用**至少两种相互独立的代理**分析：时间分组重复 PD 差、SVD 模态/残余带以及背景/血管分区统计；每个代理都标出“是否可能混入真实流动/运动/静态散斑”。
- [ ] 对整个 IQ 时序按独立**时间块**绘制血管与背景 PD 的均值/方差、功率谱、空间 ACF/PSD、时间 ACF、深度趋势；按物理间距（0.15 mm）报告各方向相关长度。
- [ ] 比较原始 PD、`log1p(P/s)`、`log(P+ε)`、固定规范的线性域；在不同亮度分位下比较**跨重复差/残差**的条件均值、条件方差和空间依赖。不要直接用总体 `corr(PD_A,PD_B)` 当噪声相关。
- [ ] 建立无训练基线：输入本身、Wiener/空间平滑、时间平均/较长积分（只做**不可独立的高 SNR proxy**）、原位幂变换/对数变换；对图像同 ROI/同显示，不在不同方法上重新拉伸。
- [ ] 从真实图像中选**锁定的血管 ROI、弱血管 ROI、明确背景 ROI**，保留全场 3D MIP+三切片及局部剖面；不把 ROI 内低亮度直接当纯噪声或用每方法自己的阈值重选 ROI。

### R0-3 时序配对是否真的能支持 N2N？
- [ ] 对奇/偶和**非重叠连续块**分别评估运动、血管变化、条件偏置与残差相关；奇偶不重叠≠独立，相关高也可能是共享真实信号。
- [ ] 若使用分组 SVD，明确投影基的来源：**同一全帧 SVD 会将分组数据耦合**，单独分组 SVD 又使秩带/电平不可比。建议并行比较（i）固定、与训练目标独立的 calibration 投影（ii）每组独立估计投影，记录偏差和实际可比性；不要把共用基当独立噪声保证。
- [ ] 分成多时间块后的长度小于全长：**不许把 400 帧的 60:350 模式直接套到 200 帧 Gram 矩阵**；如需重定义秩带，按奇异谱与原脚本物理目标校准，标明是派生方案，不是“官方复现”。
- [ ] 数据未明确提供**同一 ROI 的真正独立再采集**时，任何时间拆分/跨协议对照必须标注“pseudo-pair”；只有条件独立/信号稳定经受控测试支持后才用于自监督训练。

**R0 Gate（不是单数阈值）**：
- 可回答：真实场景中残余波动大小、方向依赖、log 后信号依赖方差是否改变、目前哪些配对有效/哪些无效；并提供置信区间/不同 ROI、至少 SA64/HSA64。
- 如果未发现可分离的噪声，记录“该批成像已经过强平均/残余主要为结构相关”，**不得**因为实验效果小就宣称所有真实超声无须去噪；可退回有对照难度的仿真和其它序列。
- **R0 必须实际跑**，即使历史实验 A 失败。不要从 V2 1% 噪声结论外推 SA64/HSA64。

**交付**：`reports/v3_round2_real_data_audit.md`、`reports/v3_round2_real_data_audit.json`、统一 ROI/噪声谱/条件方差图及重现脚本；若源文件不可用，分别列出可完成项和缺口。

## 3. 第二阶段：S0 / 低成本正控制 + 噪声强度阶梯

**目标**：判断是“代码/监督目标有问题”，还是“物理相关散斑让 VALID 难以训练”。用相同或极为接近的 `NetworkCNR`/原 VALID 损失 + `infer.py` 完整体积推理。

- [ ] **S0a 简单正控制**：构造干净 3D 管状/分支 phantom（尺度合理，含易/难分辨血管），经过已知 PSF 后**再添加独立零均值加性噪声**；提供 clean imaging truth 与几何 truth。比较 noisy input、identity、Wiener、faithful VALID random、fixed-4。若连简单独立噪声都不能改善，则重点审查训练/推理/损失/任务表示，不急于研发物理 sampler。
- [ ] **S0b 噪声强度阶梯**：至少设置**低/中/高**三档独立噪声，并展示输入图像质量、可分离噪声相对能量（明示定义）、弱血管结构可见性、真实/噪声协方差；低噪声档应包含 v2 近似难度，高噪声档须保持物理/成像合理性（不能凭空假定等于真实数据）。
- [ ] **S0c 相关性阶梯**：在保持稳定信号真值与总噪声方差相近时，从独立噪声逐步引入各向异性 PSF/相关散斑/结构化残差，观测 **噪声相关长度↑ → 可预测血管信号↑或↓ → 去噪质量** 的关系。
- [ ] **S0d 对应真实数据**：将模拟分布与 SA/HSA 的 PSF/ACF/强度分布、残余代理进行对照，标注未匹配的方向与差值；一版调到真实统计仅用 calibration，held-out 绝不参与调参。
- [ ] **S0e 真值定义**：至少同时保存 (i) 几何标注 `rho`，(ii) **无噪完整成像期望/高重复平均**，(iii) 血流-only 模态/PD，(iv) 单次含噪观测与独立第二观测。明确主终点与哪个目标比较。对包含静态背景的目标，不得拿血流-only GT 作 N2N 理论目标。
- [ ] **S0f 评分正反标定**：用 clean、identity、zero、blur、过锐化、局部断血管、注入假血管等**已知改动**验证评分。注意“全零输”只证明排除一种平凡解，**不保证全部评分具有血管检出有效性**。

**评分**：clean imaging truth 下 PSNR/SSIM（与假阳性/结构安全同看）、宽/细血管中心线与分支、宽度/形态、弱血管召回@固定 FPR；对几何 GT 先固定适当 PSF-aware 标签映射。 `r_roi/r_weak` 为补充，不能替代结构指标。

**S0 Gate**：至少一档**确实有可恢复噪声**的正控制上，faithful VALID 能在可信真值和结构约束下优于不处理，或明确证明当前实现有尚未修好的缺陷。不能将 S0 失败直接升级为 I1 科学证伪。

**交付**：`reports/v3_round2_positive_control.md`、受控噪声阶梯指标、配置/seed、真值生成与单元测试。

## 4. 第三阶段：B / 对数压缩与监督配对条件（不再被旧 A 阻止）

**核心问题**：SVD-SN2N 的 log 不是“显示变换”，而是**针对乘性残余改变学习噪声条件**。当前 V3 用 `log1p(P/s)`，不必然具有 `log(P+ε)` 的乘性可分性。应实测，不能凭理论期待或旧 A Gate 冻结。

- [ ] 冻结统一输入/输出尺度和变换逆映射，比较 **linear PD / log1p(P/s) / log(P+ε)**。 `s` 与 `ε` 在校准数据选定并固定；不能三表示分别采用有利裁剪/显示。
- [ ] 在 S0 正控制及**真实 RCA 分块统计**上测 `E[noise|signal bin]`、`Var(noise|signal bin)`、跨视图残差相关，区分稳定静态背景与动态噪声；若真实信号不可得，报告 proxy/偏差，绝不强行声称满足条件期望。
- [ ] 同 faithful VALID 采样、相同损失/网络/学习率/训练预算比较输出质量；优先小规模 pilot（固定种子+不同场景），只有值得进一步比较才扩展。
- [ ] 若 log 明显改善噪声独立近似但自监督学习仍失败，排查 **空间目标结构一致性、signal leakage、整体 bias**；若 log 未改善，拒绝“加 log 就会好”的预期。

**交付**：`reports/v3_round2_log_domain.md` + 条件噪声表/曲线 + 输出图/指标 + 明确结论。**与旧实验 B 的 prereg 保持分开**；注明这是旧 A Gate 后获准的诊断实验，不是声称旧 B 已运行。

## 5. 第四阶段：C / 直接验证 PSF/散斑感知采样 I1（优先在正控制通过的场景）

- [ ] **物理量和采样规则真正连接**：训练用的 sampler 必须根据 calibration 冻结的先验选择/应用角色或位移；不能只通过 `--sampler-config` 校验 sha1 然后仍依赖人为 `--slots`。
- [ ] 重算与**实际 stride 一致**的先验和角色表：旧 `sampler_config.json` 用 `m=2` 校准，旧 C 草案训练 `stride=1`，两者不一致。先独立生成 `m=1` 有效版本，再考虑 m=2 的扩展（必须额外控制覆盖率和配准）。
- [ ] 明确训练/推理覆盖率：faithful VALID 每个 2×2×2 块训练使用 4/8=**50%**；先前 `coverage_m1=1.0` 的字段需注明这是哪一种“推理相位联合扫描口径”，不要混作训练。
- [ ] 核心最公平的对照：same four voxel positions / same source voxels / same network / same training budget / same output coordinates，仅交换**目标角色**；其次比较正确先验 vs 错误先验、强固定几何（包括 fixed-4）和 random。错误先验应**事前验证导致不同可测采样**，不能因脚本 tie-break 而成为空操作。
- [ ] 选取 `N(k)` 小且 **信号保持约束 `S(k)` 通过** 的候选，不再仅最小化相关性。事先记录可用候选、多样性/角色分布和模式退化情况。
- [ ] 对照主终点必须包含成像图像质量和弱血管结构安全，不以噪声泄漏值或训练 loss 决定胜者。比较随机、fixed-4 与**最强合理固定方向**；同时执行错误先验负控制。
- [ ] 首先在有真值仿真做机制因果实验；真实 RCA 用不同 ROI 的可重复、非捏造的结构证据做外部验证。

**C Gate**：若在至少一个具有真实可恢复噪声、基础自监督能工作的场景里，正确物理先验稳定优于最强固定方案并通过结构安全，I1 才进入后续验证。若正确/错误先验无差异、只赢 random 不赢 fixed、或以血管损伤换噪声独立，**I1 创新不成立或收缩**；不能用“未预定的参数扫一遍”挽救。

## 7. 总体验收与继续/停止决策

| 发现 | 含义 | 允许的行动 |
|---|---|---|
| **S0 简单独立噪声都失败** | 更可能是实现、训练目标或评价链未正确建立 | 首先修正 fidelity；暂停大规模 C，不是直接否定 I1 |
| **S0 简单成功，相关噪声下失败** | 支持相关性/信号保真冲突的物理机制 | 值得做 C，寻找真正有信息量的物理采样策略 |
| **B log 有效，当前 log1p 无效** | 预处理/噪声模型是关键环节 | 固定正确表示后再做 C |
| **D 可行而 VALID 不可行** | 超声特定子视图/损失可能关键 | 考虑新训练构造，但**不把其收益自动归因于 PSF 采样** |
| **C 正确先验优于 fixed 与错误先验** | I1 有可重复因果证据 | 进入更多独立场景/真实结构验证 |
| **C 长期不优于最佳 fixed，或只靠损伤血管降噪** | I1 没有独立方法收益 | **终止或收缩当前 PSF 采样创新**；保留负结果 |
| **真实 RCA 噪声很低，无可测收益空间** | 该数据集不够敏感，不等于方法无用 | 标记这套 RCA 数据的适用边界，避免事后挑图/造噪 |
| **真实数据中的微血管改善不可证实** | 方法实际成像价值未成立 | 不宣传“深层/细血管改善”，只可报告受控场景机制结果 |

**最重要的变化**：旧 T2 Gate 的否定结果保存不变，**新的 R0/S0/B/C/D 不因它而停做**。旧 Gate 是对当时固定协议的否定，不是对所有相关后继假设的否定。也不能反过来无限重开实验；每个新假设有明确上限和独立负控制，结果失败要接受。

## 8. 推荐执行顺序与预算纪律

1. **R0**（先做，不训练）：真实 RCA 数据复核、定量判断残余噪声与配对有效性，至少 SA64/HSA64；可获取 PW 时一起做。
2. **S0**（最小 pilot）：简单正控制+噪声强度/空间相关阶梯，先 1–2 个 seed 和短预算确认代码有效；只有出现结构安全的正向效果再扩展到与旧 A 相当的正式预算。
3. **B 与 D**（可在 R0 后并行做条件统计/文献核对；训练先最小 pilot）：判定 log 域统计和超声专用方法能否让训练目标可用。**不要用旧 A 失败阻止它们**。
4. **C**（有意义的物理机制检验）：当 S0 显示可学或 B/D 指向可用自监督构造时，在同训练损失/表示/预算下只换物理几何，正确先验对照错误先验及最强固定。
5. **真实数据结果**：最终至少 SA64/HSA64，若文件齐全再加 PW；图像统一显示、固定 ROI、相同背景与假血管指标，报告无真值限制，不凭 proxy 夸大收益。

禁止一上来把 6–12 个方法都跑 200k step。每完成一阶段先交小规模有真值结果与判定、再决定是否扩大；不同方案比较需等效训练/体素预算和预注册 seeds。
