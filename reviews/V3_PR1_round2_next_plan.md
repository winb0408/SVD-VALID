### 1.2 剩下的那个东西：误差的**绝对量**不随噪声缩放

这是全轮最硬的一条，也是 Round3 的出发点（`positive_control.md` §5.5 表）：

| 档 | σ_eff（输入上的实际噪声） | `rmse(pred, truth)` e900 / e901 | `rmse/σ` |
|---|---|---|---|
| `low` | 0.0198 | 0.0230 / 0.0294 | 1.16 / 1.48 |
| `vlow` | 0.0066（= low/3） | **0.0198 / 0.0253** | **3.00 / 3.84** |

噪声降到 1/3，模型误差只降到 **0.86 倍**（而不是 0.33 倍）。反过来说：
**σ 从 0.0198 掉到 0.0066，模型的绝对误差几乎原地不动。**

一条必须写清楚、否则会被误读的推论：§5.5 的标题"在显然可做的问题上表现更差"，
其中"更差"**部分是这个绝对误差 ÷ 更小的 σ ** 的算术后果，不是第二件独立的事实。
真正的实测内容是**误差不随 σ 缩放**这一条；`n2n` 在 `vlow` 上爆到 4.97/7.57 是它的表现。
把它当成两件独立证据是错的，这里改正。

### 1.3 一条把 44 个格子串起来的算术桥（本轮新增的分析工具，只用于诊断，不当门槛）

已有指标的定义可以化成一条恒等式。设 `r = rmse(pred, truth) / rmse(input, truth)`，
在"第二次观测的噪声与输入误差独立、两边方差相同"的条件下：

```
n2n_ratio = mse(pred, obs2) / mse(obs1, obs2) = (1 + r²) / 2
```

**在 5 份存档 metrics JSON 的全部 44 个（臂 × 体积）格子上验算，最大偏差 0.0368，`G-BRIDGE` PASS**
（`low`/`low60`/`vlow`/`mid`，含 dense 与相位几何、监督与自监督）。
复算：`$PY -u scripts/v3_round3_bridge_check.py` → `reports/v3_round3/bridge_check.json`。
这一步在写本文件时已跑过一次——它核的是**已有两列数的口径是否一致**，不是实验，不消耗 GPU。
它不是新判据，只是把已有两个数（`n2n` 与 `rmse_vs_imaging`）的关系写死，好处有三个：

| 用途 | 换算 |
|---|---|
| 判 `n2n < 1` 到底在判什么 | 等价于"**绝对误差小于输入误差**"，与噪声档无关 |
| `n2n ≤ 0.80`（§4 的 B 段门槛） | 等价于 `r ≤ 0.775` |
| `n2n ≤ 0.90` | 等价于 `r ≤ 0.894` |
| `oracle` 的 0.51 | 等价于 `r ≈ 0.14` |

**最有用的一个用法**：它把**训练损失**和 `n2n` 接上了。R2 的 dense 监督臂训练末损失是
`0.11–0.16 σ²`（训练几何里 `mse(pred, truth)`，`weight_identity` 项因 `xa==xb` 恒为 0，
reg 项权重 1e-4 可忽略），代入上式得

```
loss = 0.16σ²  ⇒  r_train ≈ 0.40  ⇒  训练几何里的 n2n 等价 ≈ 0.58
loss = 0.11σ²  ⇒  r_train ≈ 0.33  ⇒  n2n 等价 ≈ 0.56
```

**也就是说：网络在它训练时看到的那批 patch 上，确实做到了 `n2n ≈ 0.56–0.58` 档的误差，
而同一批权重在留出体上是 1.17/1.56。缺口 100% 在"从训练解剖搬到留出解剖"这一步。**

这一句比 R2 的"它不是没学会，是学到的东西不迁移"更精确，也把 Round3 的攻击面收窄了：
不是"能不能拟合"，而是**"拟合出来的东西为什么一换解剖就变成一段固定偏差"**。

> 用一条独立的存档事实交叉验证：`n2n_ratio_roi`（只在 `ρ>0` 的 ROI 内算）系统性低于全局
> `n2n_ratio`，差值 0.10–0.33（如 `low60` 0.865/1.191 vs 1.137/1.507；`mid` 0.855/0.867 vs 0.963/1.132）。
> 也就是**误差集中在背景（`ρ≤0`）**，ROI 里的血管结构本身没被破坏（`r_roi` 0.98–0.997）。
> 这与"输出是一段电平错位的场，而不是血管被抹掉"完全一致。

## 2. 三个候选机制：只列**可判别的预言**，不下结论

R2 §5.5 把嫌疑收到"损失函数/网络结构/优化"，但那三个词太粗，落不到一个可跑的实验上。
下面把它拆成三个互相**可区分**的机制。每条都写出"如果它成立，一定还会看到什么"——
这才叫可判别的预言，而不是三种都能解释一切的托词。

### H1 —— 直流（电平）在每个 `conv_pair` 出口被抹掉，输出无法携带输入的绝对电平

**代码事实**（`models/model_CRN.py`，已逐行核对）：
1. 每个 `conv_pair` 的最后两级是 `nn.GroupNorm(groups, hidden, eps=1e-5, affine=False)`。
   `affine=False` ⇒ 没有可学习的 per-channel 缩放/平移；GroupNorm 对每个样本、每个组做
   "减均值、除标准差" ⇒ **逐 patch 的直流分量在每个 block 出口都被丢掉**；
2. `CRN.forward` **没有任何输入→输出的旁路**（没有 skip / 没有残差），输出由
   `self.out = nn.Conv3d(f, 1, 1)` 直接从归一化后的特征给出 —— 一个 1×1 卷积，
   它的偏置只能给出**一个常数**，无法给出"跟随输入电平"的项；
3. `SE3DBlock` 用 `AdaptiveAvgPool3d(1)` 做通道门控，输出电平又由**patch 的全局能量**驱动。

⇒ 结构上，模型能表示的映射是"**输出的电平由归一化后的 patch 统计决定，而不是由输入电平决定**"。
这正是"误差是一段与噪声无关的固定偏差、且集中在背景"的形状。

**若 H1 成立，还会看到**：
- (a) 给输入加一个常数 `c`，输出几乎不变：`|mean(out(x+c) − out(x))| / c ≈ 0`；
- (b) 输入缩放 `a` 倍，输出的形状变、但**电平**不跟着变；
- (c) 误差主要落在背景 —— **已被现有数据支持**（§1.3 末尾的 `n2n_ratio_roi` 交叉验证）。

### H2 —— 损失函数把"输出该 patch 的条件均值"排在"结构保真"之前

**代码事实**（`train.py:324-328`）：
```python
loss_neighbor = 0.5 * mse(ha, ya) + 0.5 * mse(hb, yb)
loss_reg      = wavelet_hessian_loss(ha, hb, hessian)      # 权重 1e-4
loss          = loss_neighbor + 1e-4*loss_reg + 1.0 * mse(ha, hb)
```
`mse(ha, hb)`（VALID 的 identity 项）只要求**两路输出相等**，**不要求接近输入**。
在 L2 下，"输出该 patch 的条件均值"同时满足：让 `mse(ha,hb)` 最小、让 `mse(ha,ya)` 也小。
**这是 L2 的已知性质，不是实现 bug**；但它把"背景压得平"排在"血管结构保真"之前。
权重 1e-4 的 Hessian 正则惩罚的正是"不平滑"，方向上也支持塌向平滑。

**若 H2 成立，还会看到**：
- (d) 输出与输入在 ROI 内高度相关（`r_roi` ≈ 0.99，已观察到），但输出的**空间方差显著小于输入**
  （背景 std 比 < 1）——即"形状对、对比度被压低"；
- (e) 残差 `pred − input` 的空间谱集中在低频（是"整体电平/低频形状"的错，不是高频噪声残留的错）；
- (f) 把 `weight_identity` 单独关掉（`--weight-identity 0`）应当**改善**而不是恶化 `n2n` ——
  因为这一项对"输出=常数"是完全奖赏的。这是一条**极便宜**的单变量实验，已具备（`train.py` 有这个开关）。

### H3 —— 容量 / 预算不足

**已被部分否掉**：5 倍训练体只换来 3%（§5.5）。但"预算曲线"从未跑过 —— 只跑过
`40 ep × 500 step` 一个点。降为第三顺位：**只有在 H1/H2 都判否之后才做**，
且必须用"两个预算点的曲线"，不接受"再训久一点看看"。

## 3. A 段：诊断（全部只读 / 单次前向 / 离线，不训练）

**A 段的总原则**：在花 GPU 小时之前，先花分钟级成本把 H1/H2/H3 判掉一个。
每个探针都是"读数"，因此按方案 §0.5 的纪律，**先做已知答案标定**，标定不过就不解读它的数。

### A1 —— 直流 / 尺度传递探针（判 H1）

**新脚本**（待实现）：`scripts/v3_round3_dc_probe.py`
**做法**：对同一批 patch 取常数偏移 `c ∈ {0.5, 1.0, 2.0} × σ_eff` 与缩放 `a ∈ {0.5, 0.9, 1.1, 2.0}`，测

```
g_dc(c)    = mean(out(x+c) − out(x)) / c                      # 直流增益
g_scale(a) = std(out(a·x)) / std(out(x))                        # 幅度缩放
corr(a)    = corr(out(a·x), out(x))                             # 形状是否被保住
```

对三个对象各跑一次：**(i) 恒等模型**（`lambda x: x`）、**(ii) 随机初始化的 CRN**、
**(iii) `S_dense` s3407 训练后的 checkpoint**。

**已知答案标定（跑之前写死）**：恒等模型必须给出 `g_dc = 1.00`、`g_scale = a`、`corr = 1.00`。
若恒等模型给不出这些数，说明探针本身（边界/padding/valid_mask）写错了，**CRN 的数不得解读**。

**判据 G-A1（写死）**：

| 训练后 ckpt 的 `|g_dc|` | 判定 |
|---|---|
| `< 0.05` | **H1 成立**：电平确实进不去 ⇒ B1（残差旁路）是对口修复 |
| `0.05 – 0.50` | H1 部分成立 ⇒ B1 之后还要看 B2（`affine=True`） |
| `> 0.50` | **H1 否掉**：电平能进、问题在别处 ⇒ 不进 B1，改走 H2 的 (f) 与 B3 |

### A2 —— α 扫描（判"模型的修正量里有没有可用信号"）

**新脚本**（待实现）：`scripts/v3_round3_alpha_sweep.py`
**做法**：不改一个权重，只改输出后处理：

```
pred_α = (1−α)·obs1 + α·model(obs1),   α ∈ {−0.5, −0.25, 0, 0.25, 0.5, 0.75, 1.0, 1.25, 1.5}
```
在 `low` 与 `vlow` 的 4 个（体积 × 档）格子上算 `n2n`、`n2n_ratio_roi`、`r_roi`。

**已知答案标定（三条，跑之前写死）**：
1. `α = 0` 必须**精确**复现 `n2n = 1.000`（恒等）；
2. `α = 1` 必须**精确**复现存档值 `1.171/1.559`（low, dense s3407）与 `4.970/7.570`（vlow）；
3. 用一个合成臂 `pred = truth` 验算解析式 `n2n(α) = [(1−α)²·2 + α² − 2α(1−α)] / 2`
   （`α=0` 给 1.000，`α=0.5` 给 0.125，`α=1` 给 0.500）—— 这条验的是扫描算术本身。

**判据 G-A2（写死）**：

| 最优 α（`n2n` 最小处） | 读法 | 下一步 |
|---|---|---|
| `≈ 0` 或 `< 0` | 模型的"修正量"里没有可用信号（方向都不对） | **B1**（残差化，让网络只学修正量），不调损失 |
| `∈ (0, 1)`，且最小值明显低于 `n2n(1)` 但仍 `≥ 1` | 方向对、幅度错（被系统性压小或放大） | **B1**，之后按残差幅度看 B2 |
| `> 1` | 修正量被系统性压小 ⇒ 与 H1 的"电平丢失"一致 | **B1** |

### A3 —— 评测面扩张（判"两卷偶然"）

现有全部结论只用 **2 个留出体**（`*_e900`/`*_e901`）。把 `low` 与 `vlow` 的评测扩到 **6 卷**
（新增 4 卷，同名生成器、不同种子；`scripts/v3_round2_s0_dataset.py` 已支持）：
对 `S_dense` s3407 报 `n2n` 的**跨体中位数 + 全距**，而不是两个数。

**判据 G-A3（写死）**：若 6 卷中位数与现在这 2 卷均值相差 `> 0.05`，
则 R2 里所有基于 2 卷的单点结论在正式文稿中一律降级为"两卷上的观察"，并补上分布。

### A4 —— 误差分解（把 §1.3 的桥扩到全表，给区间）

**新脚本**（待实现）：`scripts/v3_round3_error_decomp.py`
**做法**：从 5 份存档 metrics JSON 取全部 (rmse_input, rmse_model) 格子，
拟合 `rmse_model = a·rmse_input + b`，报 `a`、`b`、每格残差、`R²`，
并**分 ROI / 背景**各拟合一遍；`b` 给 bootstrap 95% 区间（1000 次，按体积整簇重采样）。

**说明**：`a = 0.283`、`b = +0.0206` 这两个数 R2 已经报过（4 个点，dense 两档）。
A4 **不是新结论**，只是把面从 4 格扩到全部格子并给出区间——
这一步的目的是让"固定偏差"从一个观察变成一个**有区间的量**。

**判据 G-A4（写死）**：若 `b` 的 95% 区间**不含 0** 且 `b > 0.015` ⇒ "存在与噪声无关的固定误差"
成立，H1/H2 有了共同的量化落点；若区间含 0 ⇒ "固定偏置"这条解释要收回，
A 段结论改为"H1/H2 均未获支持"，转 H3。

## 4. B 段：单变量修复（每条都先在 `vlow` 上过 G-B0，再上 low/mid）

**总门槛 G-B0（对所有 B 条目统一，写死）**：

在 `vlow` 的两卷上都拿到 `n2n ≤ 0.80`（⇔ `r ≤ 0.775`）才算"这条链能去噪"。
选 0.80 不是新数：`positive_control.md` §5.5 在跑之前就写了"正确实现应轻松拿到 `n2n ≈ 0.55–0.7`"，
0.80 是那个区间的上界放宽一档。**未过 G-B0 的条目，不允许拿 low/mid 的数去解释**。

### B1 —— 残差参数化 + 末层零初始化（主候选，同时对口 H1 与 H2）

`pred = x + net(x)`，`net` 的最后一层 `Conv3d` 权重与偏置**置零**。

两个作用各自独立、都要在结果里分开报：
- 对 H1：输入电平经旁路直接到达输出，`net` 只负责"偏离输入的成分"，而这一项在噪声问题上恰好是零均值的；
- 对 H2：训练起点就是恒等（`loss = 1.0σ²`，与恒等下界对齐），**损失的任何下降都必须是真去噪**，
  塌到常数这条捷径在残差参数化下不再免费（要学出"整体拉向均值"得自己显式生成整个偏置场）。

**实现**（待实现）：`train.py` 加 `--param {direct,residual}` 与 `--zero-init-out`（默认关，保持旧 run 可复现）。

**判据 G-B1（写死）**：

| 条件 | 门槛 |
|---|---|
| `vlow` 两卷 | `n2n ≤ 0.80`（= G-B0） |
| `low` 两卷 | `n2n < 1.00` |
| `mid` 两卷 | `n2n < 1.00` 且 `r_roi ≥` 输入臂的 `r_roi`（0.9794 / 0.9912） |

- `vlow` 过、`low/mid` 不过 ⇒ **进 B2**；
- `vlow` 不过 ⇒ H1/H2 都不够，**进 B3**，且在开工前先写 `_v2` 增补。

### B1c —— 残差参数化 + 常规初始化（对照，只为归因）

同一结构、不置零末层。**不设过门要求**，只报 `n2n` 与 B1 的差值。
**判据 G-B1c（写死）**：若 `|n2n(B1) − n2n(B1c)| < 0.05` ⇒ 收益来自**残差旁路**（结构），
不是"从恒等起点出发"这个初始化技巧；若差值 ≥ 0.05 ⇒ 初始化本身也是一半原因，要在结论里分开写。
这一条是为防止把 B1 的成功笼统归给"残差化"了事。

### B2 —— `GroupNorm(affine=False)` → `affine=True`（单变量，只改一行）

**只在 B1 过 `vlow` 但 `low/mid` 仍有缺口时做**。它是 H1 的"部分成立"分支的直接对口修复：
给每组一个可学习的 per-channel 缩放与平移，让模型能自己恢复电平。

**判据 G-B2（写死）**：`mid` 两卷 `n2n ≤ 0.90` 且 `n2n_ratio_roi ≤ 0.90`。
（`mid` 才是与真实数据同难度的那档 —— `positive_control.md` §2.3 已证 —— 所以 B2 的门槛按 `mid` 写。）

### B3 —— 损失形式（便宜的单变量，具备现成开关）

**第一刀用已有开关，不写新损失**：`--weight-identity 0`（关掉 `mse(ha,hb)`），
以及把 `--weight-reg` 从 `1e-4` 扫到 `{1e-3, 1e-2}` —— 每次只动一个。
理由不是"调参试试"，而是 H2 的预言 (f)：**identity 项对"输出=常数"是完全奖赏的**，
所以关掉它应当改善而不是恶化；`reg` 项惩罚"不平滑"、方向上也支持塌向平滑，所以放大它会加大塌陷。
**这两条预言都能被证伪**——这正是它们值得跑的原因。

**判据 G-B3（写死）**：对每个单变量，在 `vlow` 上要么过 G-B0 要么把 `n2n` 至少降 0.20。
两者都不到 ⇒ 该变量不是主因，**不追加扫描**（防止变成"调参救火"）。

### B4 —— 容量 / 预算（最后，且必须有曲线）

**触发条件（写死）**：只有在 B1–B3 中至少一条把 `mid` 推到 `n2n ≤ 0.95` 之后才做；

## 9. 通俗总结

**这一轮要解决的问题，用一句普通话讲**：我们造了一个噪声大小完全已知的假数据，
连正确答案都给了网络看，网络还是学不好。上一轮已经排除了六种可能里的五种
（不是"用另一次采集当答案"这个想法有毒、不是训练不够、不是判断标准坏了、不是推理方式不对，
也不是数据太少）。剩下的那一件事，我们这一轮把它压缩成了一个能看见的形状：

**网络的误差几乎是一个固定的数，跟噪声大小没关系。**

噪声降到三分之一，它的误差只跟着降了一点点（降到 0.86 倍，而不是三分之一）。
这件事有个直接后果：在噪声大的时候它看起来还行，噪声一小它就立刻显得很差——
上一轮"噪声更小反而更差"那张表，其实就是这一个数在不同尺子下的读数，
不是两件独立的坏事。我在这一轮把这句话改正了。

**顺着这个形状，我们找到了三个具体的、能被一票否决的解释**，并且每条都写清了
"如果是它，一定还会看到什么"：

1. **网络的"电平"进不去。** 我们逐行看了网络：每一层做完卷积都立刻做一次"减去本块均值"的归一化，
   而输出又只有一根 1×1 卷积、没有把输入直接接到输出的旁路。结构上，输出的整体亮度由
   "这一块的统计特征"决定，而不是由"这一块有多亮"决定。这正好能解释"误差是一段固定偏差、
   而且主要落在背景上"——现有的另一组数字（只看血管区域时的误差明显更小）已经与它一致。
2. **损失函数的形状允许它偷懒。** 现在有两项损失：一项要求输出接近答案，一项只要求
   "两路输出彼此相等"。第二项对"输出一个常数"是满分奖励。用平方误差做优化时，
   "输出这一块的平均值"本来就是数学上的最优解之一——这不是写错了，是这套损失把
   "把背景压平"排在了"保住血管"前面。
3. **容量或训练不够。** 这条上一轮已经被"加五倍数据只换来三个百分点"打了一半，
   但仍没被"多训一会儿"正面检验过，所以排在第三顺位。

**下一步怎么做。** 先不训练，先花几分钟做三个"读数"实验：给输入加一个常数看输出动不动
（直接检验第 1 条）、把网络输出和输入按不同比例混合看哪个比例最好（检验它的"修正量"里到底有没有东西）、
把误差按"跟噪声有关"和"跟噪声无关"两部分拆开算区间。每次读数实验都先在一个答案已知的假网络
上校准一遍，校准不过就不信它。这三步都通过了，才动第二段的修复：最可能是把网络从"直接输出图像"
改成"只输出修正量、再叠回输入"（这样一开局就等于什么都没做，之后每一次损失下降都只能是真去噪），
然后是给归一化层加回可学参数，最后才是动损失函数。

**对项目主张意味着什么。** 到目前为止，**没有任何一条证据指向"这个方法不成立"**；
指向的都是"这条实现链还没学会去噪"。这是好消息，也是坏消息：好消息是方法本身还没被证伪；
坏消息是我们**现在仍然不能做采样实验**——因为如果管道连"把已知的噪声减掉"都做不到，
那么换一种采样方式带来的差别根本量不出来，跑出来的任何"更好"或"更差"都是噪声。
所以这一轮的顺序是死的：**先修链，再谈采样。**

**哪些话现在不能说。** 不能说"方法不行"；不能说"S0 通过"；不能说"再加点数据/再训久一点就好"
（前一条已被五倍数据顶回来，后一条还没测但排在最后）；不能说"上一轮证明了噪声越小越难"
（准确说法是"误差不随噪声缩放"，本文 §1.2 已改正）；也不能说"修好网络就能过门"——
修好只是让"能不能过门"这个问题第一次变得可以被回答。
