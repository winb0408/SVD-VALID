## 1. 两次失败的共同根因（这是本轮的一个真实结论，不只是"指标没调好"）

| 指标族 | 失败形态 | 根因 |
|---|---|---|
| v1 voxel 级检测（`recall@fpr5`、`iou`、`ncomp`） | 完美真值 0.36–0.57，输入/高斯也是 0.36–0.57，**差 ≤0.005**；断枝 0/6、造假 1/6 | 管径 0.75–1.5 体素 ≪ `PSF_PD σ=(4.24,3.35,5.61)`，体素级"弱血管 vs 背景"在**无噪真值里就已重叠** |
| v2 段级 CNR（`seg_cnr_median`、`seg_recall_z2`） | 真值 1.26 / 输入 1.26 / 高斯 1.26（两位小数相同）；断枝召回 0/6 | 噪声零均值，**段内平均把噪声抹掉**；分母 `bg_sd` 由 PSF 旁瓣（结构性振铃）主导，各臂相同 |

**结论（写进 P0 报告，作为对任务书 §0B 的答复）**：在这个仿真器上，
**任何"检测式"结构指标（recall / AUC / IoU / SSIM / 段级 CNR / 段召回）都无法区分"结构完好"与"结构被毁"**，
因为信号与背景的分界由 PSF 决定、且噪声在段尺度上已被平均掉。这与 R12 的原始结论方向一致，
但与"换用成像真值就能修好"的假设相反——**该假设已被 v1 证伪**。

## 2. v3：偏差—方差分解（对 PSF 匹配真值）

不使用任何阈值化检测，改用**代数分解**。设 `e = pred − truth_img`（log1p 域，`valid` 内），
血管区 `ves = valid & (rho ≥ 0.1)`、背景 `bg = valid & (rho ≤ 0)`：

```
bias_X  = mean(e[X])            # 系统性抬高/压低（过平滑 = 负偏；注入结构 = 正偏）
var_X   = var(e[X])             # 残余噪声（抑制得好 = 小）
rmse_X  = sqrt(mean(e[X]²))     # 恒等于 sqrt(bias_X² + var_X)  ← 代数恒等式，可当已知答案检验
```

| 端点 | 含义 | 方向 |
|---|---|---|
| `overall_rmse` | 恢复误差（主误差轴） | 小好 |
| `bias_ves` | **血管信号保留**（负=被压低/过平滑；正=被抬高/注入） | 接近 0 |
| `var_ves` | 血管区残余噪声 | 小好 |
| `bias_bg` / `var_bg` | 背景是否被压偏/压净 | 0 / 小 |
| `bg_std_ratio` | 背景波动抑制（沿用 v1 定义，与旧结论可比） | 小=抑制强 |
| `n2n` | 旧端点，仅作连续性对照 | — |
| `ret_p10` | 逐段幅度保留率 `mean(pred[V_s])/mean(truth[V_s])` 的 10% 分位（**描述性**，不作判据） | 接近 1 |

管径 `width` 仍 `NOT_RESOLVABLE`（理由见 v1 预注册 §1）。

### 2.1 已知答案检验（**代数恒等式 + 三个构造臂**，先写死再跑）

| 检验 | 期望 | 通过线 |
|---|---|---|
| 恒等式 | `rmse_X² = bias_X² + var_X`（`X ∈ {ves, bg}`） | 相对误差 < 1e-6，6/6 卷 |
| 完美答案 | `truth_img`：`bias = 0` 且 `var = 0` | 6/6 卷 |
| 空答案 | `zero`：`bias_ves = −mean(truth[ves])`（严格相等，容差 1e-6） | 6/6 卷 |
| 断枝 | `cut30`：`bias_ves(cut30) < bias_ves(truth)`（整段被抹必然压低均值） | 6/6 卷 |
| 过平滑 | `gauss(σ*)`：`var_ves < var_ves(input)`（确实降噪）**且** `bias_ves < 0`（确实压低信号） | 6/6 卷 |

五项全过 → `METRIC_RESOLVED_V3`。任一项不过 → `METRIC_UNRESOLVED`（终态，不再换指标版本），
P0 只报 `n2n` / `overall_rmse` / `bg_std_ratio`，且明确写出"结构安全性在本仿真中不可判"。

**为什么这次不是"指标购物"**：前两次是**阈值化检测**（需要判别区间），这次是**代数分解**（不需要判别区间），
其正确性由恒等式与构造臂的**严格数学关系**检验，而不是靠"能不能把好坏排开"。
同时，本节把"检测式指标不可用"本身写成了本轮的一个结论，而不是把它藏起来。

### 2.2 对 Gate 的替换（其余全部不变）

- 0 Gate 的"结构"分量：由 v1 的 `recall_at_fpr5` 换成 **`bias_ves`（接近 0 为好）**；
  "背景抑制"分量仍是 `bg_std_ratio`；"误差"分量仍是 `overall_rmse`。
  **支配定义**：在某个留出体上，若存在基线的 `bg_std_ratio ≤` 网络臂且 `overall_rmse ≤` 网络臂
  且 `|bias_ves| ≤` 网络臂，且至少一项严格更优 → 该体上网络臂被支配。
- Pareto 曲线画两条：`(bg_std_ratio, overall_rmse)` 与 `(bg_std_ratio, |bias_ves|)`。
- B Gate 的"结构安全"分量同上替换（`|bias_ves|` 不劣于 `gauss(σ*)`）。
- 预算、split、选参纪律、停止条件、旧 Gate **全部不变**。
