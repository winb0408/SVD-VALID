### 1.2 成立，但要补一句限定（否则结论会被读大）

| # | 审查原文 | 我们的限定 |
|---|---|---|
| 0.4 |「单次可分离噪声方差约为总体方差的 1.01%/0.85%」 | 这是**在两项假设下**的 proxy：两次观测的随机扰动独立**且同方差**、场景在两次观测之间不变。真实情况里静态散斑与杂波在两次观测中**共享**（这正是 N2N 想要的），所以 1% 应读作"可分离部分的上界估计"，不是"残余噪声总量"。本轮 R0 会把这两个量分列 |
| 0.7 |「DeepSeek 误把 2024 年荧光 SN2N 当作 SVD-SN2N」 | 部分成立：我们的矩阵 §0 当时**明确写了"没有可核对的原文"并请求链接**，并声明"不把 log1p 当作 SN2N"。所以它不是把 Qu 2024 冒充成 SVD-SN2N，而是**在缺原文时做了替代对照**。现在原文可核实，矩阵重做，历史段落保留并标注 |
| §7 |「C 不能因 A 失败而称已被证伪」 | 同意，且本仓库从未这样写过；但**旧 revision plan 的"🔒 冻结"措辞容易被读成逻辑结论**，本轮已改写为"资源冻结 + 待 S0 结论解锁" |
| §2 R0 |「R0 必须实际跑」 | 同意。但 Dryad 数据是**四次成像（SA/HSA/PW3232/PW1616）**，不是四次独立生物重复；本报告只作为**协议敏感性**证据，不当独立样本 |

### 1.3 需要更正的事实

1. **SVD-SN2N 论文确实存在**（我们此前的"无法核实"结论是环境限制，不是对方错误）。
   2026-10-27 由 bioRxiv 官方 API 核实：
   `api.biorxiv.org/details/biorxiv/10.64898/2026.09.10.750668` 返回
   title = *SVD-SN2N: Self-Inspired Noise2Noise Learning for Denoising Log-Compressed SVD-Filtered
   Ultrasound Imaging*，作者 Zhang, G.; Buffle, E.; Zucker, N. S. J.; Deffieux, T.; Ialy-Radio, N.;
   Pernot, M.; Pezet, S.; Tanter, M.（Physics for Medicine Paris），date 2026-09-13，version 1，
   license CC-BY-NC-ND。**注意：许可为 ND（禁止演绎）**，因此本轮 D 只能做"论文描述驱动的近似复现"，
   且不得分发其补充材料；若官方代码另有许可，以代码仓库许可为准。
2. **正文关键主张已从摘要取得**（用于 B/D 的设计依据，不冒充全文阅读）：
   ① SVD 滤波后的残余波动以**乘性散斑**为主，违反 N2N 的零均值可加假设；
   ② **一次对数压缩**把它变成方差与信号无关的可加扰动；
   ③ 对数图用**对角 2×2 重采样**拆成两份统计独立的半尺寸副本，再用**傅里叶零填充**插值回原尺寸；
   ④ U-Net + 自约束双预测损失；
   ⑤ 四个数据集（临床/临床前、造影/非造影、2D/3D），相对常规 SVD 提升 SNR 4.2–10.6 dB、
   血管 FWHM 收窄 34–59%。
   **未取得全文**：方法细节（损失权重、网络宽度、插值实现、归一化）以原文/代码为准；在拿到前，
   任何"复现了 SVD-SN2N"的措辞都不成立。
3. **本轮不承诺复现 D 的训练**。审查要求 D 可与 B 并行，但 D 需要完整方法细节；本轮先做
   （i）文献对象更正、（ii）与现有可能实现的差异表、（iii）"论文描述驱动的近似复现"可行性与
   成本判定，**训练留到 S0/B 结论之后**。这属于审查允许的"没有合法复现条件就写限制"。
