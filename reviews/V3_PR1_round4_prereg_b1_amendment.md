# Round4-B1 预注册修订（v2）—— 冻结前发现"三臂退化成两臂"，改在开跑之前

> **修订日期**：2026-10-29
> **修订对象**：[V3_PR1_round4_prereg.md](V3_PR1_round4_prereg.md) §3.2 的 `logeps` 定义
> **状态**：撰写时 **没有任何 B1 训练启动**（B1 三个作业 0/3 未跑），因此不构成"看结果改判据"。

## 1. 为什么必须改（改动原因）

预注册 §3.2 把第三臂写成 `x = log(PD·ε/s + ε)`，`ε = 1e-3`，反变换 `PD = s·(exp(x) − ε)/ε`。
这个式子有一个**代数恒等式**：

```
log(PD·ε/s + ε) = log( ε · (PD/s + 1) ) = log( 1 + PD/s ) + log ε = log1p(PD/s) + log(1e-3)
```

即：在给定的 ε、s 下，第三臂与第二臂**相差一个常数**。

§3.2 同时规定"每域用训练集统计量做一次仿射标准化"。常数偏移在仿射标准化里被完全吸收
（`(x + c − mean(x + c)) / std(x + c) = (x − mean x) / std x`），所以

> **两臂在标准化之后逐位相同，第三臂不能提供任何独立信息。**

数值核对（训练集 `data/processed/v3_round2_s0/low/train/`，两卷）：

| 卷 | `max |(logeps − log1p) − log(1e-3)|` | `corr(logeps, log1p)` |
|---|---|---|
| `s0_low_s200` | 5.7e-7 | 1 − 6e-14 |
| `s0_low_s201` | 5.7e-7 | 1 − 8e-14 |

（残差 5.7e-7 是 float32 精度，不是真实差异。）

如果照原样跑，会得到一条**看起来像实验、实际上只是同一实验跑两遍**的结果，
并且很可能被误读成"logeps 与 log1p 表现一致，说明 ε 的选择不重要"——这是假的结论。

## 2. 为什么改法是"取更紧的 ε"，而不是"换一个更花哨的变换"

B0（[reports/v3_round4/b0_logstats.json](../reports/v3_round4/b0_logstats.json)）在同一天测出的三域条件是：

| 域 | SA64 条件方差斜率 | HSA64 条件方差斜率 | 乘性噪声正控制 |
|---|---|---|---|
| `linear PD` | 2.147 | 2.141 | 2.097 / 2.063 |
| `log1p(PD/s)` | 1.371 | 1.459 | 1.325 / 1.372 |
| `log(PD + 1e-3·s)` | **0.035** | **0.107** | 0.017 / 0.007 |

预注册写的"更符合超声统计的 `log(PD+ε)`"在 B0 里对应的就是**第三行**（真对数 + 一个小地板），
它的方差已经与信号无关；第二行（`log1p(PD/s)`）**只是部分稳定化**。这正是本 pilot 想区分的两件事。
也就是说：原式写错了符号位置（把 ε 乘在分子上），但**意图与被测对象在 B0 里已经定死**。

## 3. 冻结的新定义（开跑前写死，不因哪一臂好训再改）

| 臂 | 输入/目标 | 反变换 | 说明 |
|---|---|---|---|
| `linear` | `u = PD/s` | `PD = s·u` | 线性域，无压缩 |
| `log1p` | `log1p(u)` | `PD = s·expm1(x)` | 当前训练域（B1 正控制的域） |
| `logeps` | `log(u + ε)`，`ε = 1e-3` | `PD = s·(exp(x) − ε)` | 真对数 + 地板；与 B0 第三行同构（差常数 `log s`） |

- `s` = 每卷 npz 里的 `s` 字段（仿真器的冻结物理尺度），**三臂共用同一个 s**，不各自自适应。
- 无效体素统一填**该域的零信号值**（`linear/log1p → 0`，`logeps → log(1e-3) = −6.9078`），
  不用"填 0"这种做法在 `logeps` 域里会人为造出一块亮区（`0` 反变换是 `s·(1−1e-3) ≈ s`）。
- 每域用**训练集**（12 卷，`valid` 体素）统计量做一次仿射标准化，常数落盘
  `reports/v3_round4/b1_norm.json`；**不在留出集重算**。
- 目标用同一变换作用于 `gt_imaging_pd`（PSF 匹配的成像真值），不是锐利的 `gt_flow_pd`。

## 4. 公平性护栏（新增两条）

1. **`logeps` 与 `log1p` 不再等价**：两臂的输入差 `log(u+1e-3) − log1p(u)` 是 u 的非线性函数，
   在 `u ≲ 1e-2`（背景/极低亮）区间差别最大。这一条在 `b1_norm.json` 里用
   `corr(logeps, log1p)` 与最大绝对差**留证**，不是口头声明。
2. **共享物理尺度**：三臂都由同一个 `u = PD/s` 派生，`s` 来自 npz 而非各臂自估，
   避免"某个表示更容易训练"被归一化冒充。保留声明不变：**标准化只对齐一阶/二阶尺度，
   不能保证三域的可优化性完全相同。**

## 6. B Gate（不变，原样保留）

判据仍按原预注册 §3.3：相对 B1 现正控制 `rmse_img` 改善 ≥3/4 体、且不劣于 `gauss(σ*)` 4/4、
且 `recall_at_fpr5` 不比 `gauss(σ*)` 差超过 0.02（4/4）。三臂全不满足 → `B_NO_GAIN`。

**补充一条（防止误读）**：pilot 的 `log1p` 臂是**加了标准化**的 log1p，与冻结的 B1 checkpoint
不是同一权重，所以 Gate 里"相对 B1 现正控制"比较的是**两个不同的模型**（pilot 臂 vs 冻结 checkpoint），
这一点在报告里必须写明，不能当成"同一模型换域"。
