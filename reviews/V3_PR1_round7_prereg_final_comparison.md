## 1. 四列的定义（冻结）

| 列 | 定义 | 是否训练 |
|---|---|---|
| C1 原始带噪 | `PD_raw = Σ_t |IQ_t|²`（全部 400 帧，**不做 SVD 杂波抑制**），dB 归一 | 否 |
| C2 普通 SVD | 官方血流带（1-based 60:350，0-based `[59,350)`）SVD 带通 → `PD = Σ_t |filtered_t|²` → dB 归一 | 否 |
| C3 SVD-SN2N | C2 的 log 压缩表示 → SN2N 2D 忠实移植 → 反变换回 PD | 是（自监督，在 C2 上） |
| C4 本方法 | C2 的 logeps 表示 → 本项目采样（间距 1、固定体对角互补角色对）→ 8 相位拼装 → 反变换 | 是（自监督，在 C2 上） |

C2 是 C3/C4 的共同输入，因此三列可直接比。

## 2. 本方法 100% 覆盖的实现口径（用户 2026-11-03 决定）

- **间距取 m=1**（用户指示："m=2 似乎已被证伪，那么用 m=1 应该就可以了"）。
  m=1 下 8 个相位是 2×2×2 块的全部 8 个体素，铺满体积，**8 次前向即 100% 覆盖**，
  不需要 m=2 的 64 次。
- **角色对固定为体对角互补对** `p → p XOR 7`（＝预注册首选：体对角线位移）。
  8 个输入相位需要 4 次训练（每次覆盖 2 个输入相位）：

  | 训练 | slots（xa,xb,ya,yb） | 覆盖的映射 |
  |---|---|---|
  | P0 | `1 4 6 3` | 1→6, 4→3 |
  | P1 | `0 2 7 5` | 0→7, 2→5 |
  | P2 | `3 6 4 1` | 3→4, 6→1 |
  | P3 | `5 7 2 0` | 5→2, 7→0 |

- **拼装规则**：对每个输入相位 `p`，用覆盖它的模型前向，把输出写入 `p XOR 7` 的格点
  （own-pairing，即该模型真正训练过的映射）。8 个相位各写一次 ⇒ 每体素恰好被写一次，
  **100% 覆盖、零外推**（不写 `target = input XOR 7` 以外任何未训练的规则）。
- 训练数据 = 该序列全部 400 帧的 C2 logeps 表示（自监督，与 SN2N 同一份输入）。

## 3. SN2N 忠实性清单（逐项对应源码位置）

| 项 | 实现 |
|---|---|
| 归一化 | percentile `(20, 99.9)` → 0–255 → /255（`percentile_normalization.py`） |
| 子视图 | 每张 2D 帧按 2×2 对角均值造 A、B（`datagen.py:block2d`） |
| 插值 | A、B 经 `fourier_inter`（对称填充 + `interpft` 频域补零）放大 2× 回原尺寸 |
| 网络 | `Unet_2d`，通道 64→128→256→512→512，**输出 sigmoid**（`models.py:88-121`） |
| 损失 | `(L1(f(A),B)+L1(f(B),A)+w·L1(f(B),f(A)))/(2+w)`，w=1，L1（`trainer.py`） |
| 优化器 | Adam lr 2e-4, betas (0.5, 0.999)，ReduceLROnPlateau |
| 推理 | **整帧单次前向**（`inference.py`），因此天然 100% 覆盖、无拼装 |
| 数据组织 | 逐 z 切片当 2D 帧（`(37,64,64)` → 37 张 64×64）＋ 翻转旋转增广 |

**已知且必须写进图注的差异**：SN2N 原版对**荧光显微**设计，其前提是"2×2 对角像素
噪声独立"；本项目实测该前提在真实 PD 上**不成立**（纯噪声差场相关 0.386/0.375，
阈值 0.10，见 `reports/v3_R11/sn2n_difference_matrix.md` §3.2）。因此本臂预期**去噪不足**，
这是方法前提与本数据不匹配的结果，不是实现错误。相反方向的偏差（把上采样/插值当成去噪）
也须在结果里检查。

## 6. 执行中的实现决定（**事后追加，标注原因**，2026-11-03）

写实现时发现三处必须落笔记录的事，不改上面已冻结的口径，只补充说明：

1. **`fourier_inter` 原实现在本尺寸下会崩。** `SN2N/datagen.py:338-386` 在
   "64×64 帧 → 32×32 半分辨率 → 放大回 64" 这条路径上，其切片索引会切出 127 行再塞进
   128 列宽的数组，直接照抄会报维度错。这里按其**意图**（MATLAB `interpft` 频域补零、2× 上采样）
   实现为 `scripts/v3_round7_sn2n.py::interpft2x`。**这是偏离，已写在脚本头**。
2. **percentile 参数取代码里的执行值 30/99.8**，而 `percentile_normalization.py` 的 docstring
   写的是 20/99.9。以实际执行的代码为准。
3. **`official/pd_db.npy` 含 `-inf`**（扇区外体素 PD 恒为 0）。直接喂网络会出 NaN（已实测复现）。
   本轮在 `v3_round7_prep.py` 里统一压到 -60 dB 地板，四列共用同一地板值，不改变列间可比性。
4. **C4 的 z 轴从 37 裁到 36**：`phase_slices` 要求每个轴能被 `2m=2` 整除。
   官方图用满 37 层，本图第 37 层不参与，图注写明。
