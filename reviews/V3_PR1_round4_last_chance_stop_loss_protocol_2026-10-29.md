## 0. 结论与原则：不再尝试通过堆网络拯救项目

当前证据：
- S0 / B1 低噪声 vlow 的 direct / residual / residual+zero-init 平均 N2N 为 11.103 / 0.851 / 0.980；low 档为 1.939 / 1.430 / 0.825。B1 有真实工程改善，但所有臂**未通过旧 G-B1**。
- 不训练的掩膜高斯在 low/vlow 上 N2N 分别约 0.618/0.822。**独立于选参的 e902–e905 四体积**：low 网络最好 0.836 vs 高斯 0.622（高斯 4/4 胜）；vlow 网络 0.863 vs 高斯 0.834（高斯 3/4 胜）。“未击败平凡基线”不依赖将选参体混进最终均值。
- 真实 SA64/HSA64 的零样本 B1：4/4 臂均未同时通过 Wiener 对照与 core≥0.95；极低 N2N 常伴随明显 bright-core 强度损失。**真实数据无干净 GT**，这里的 N2N 降低不能表述为真实血管修复。
- I1（PSF/散斑相关性感知正交采样）**仍未完成实际 C 训练对照**；不可称“已证伪”，也不可无限期以“未测试”为理由持续投资。

**本轮只允许回答三个可决策问题**：
1. 当前模型与 Gaussian/Wiener 比较时，是否存在**结构保真条件下的独立优势**？（Round4-0）

3. 如果基础链得到改善，正确物理先验是否比最强固定采样和打乱先验有**额外价值**？（Round4-C）

## 1. Round4-0（P0，无新训练）：先做真实的 baseline 与结构安全对照

### 0A. 对照集与公平性

- 使用冻结的 e900/e901 作 Gaussian/Wiener 参数校准，**独立报告 e902–e905 的 held-out 结果**；在计算预算允许时再生成 e906–e911 新场景作为最终 confirmation（须在见结果前写入 split），不因它们表现变化反选参数。
- 比较未处理、Gaussian（masked、固定 σ）、W iener（固定校准参数）、当前 direct/residual/zero-init B1 权重；严格统一有效 mask、图像域、强度归一、输出坐标、相同场景。任何 checkpoint 选择只基于校准集；vlow-trained/low-trained 权重不可混名。
- 按**场景**统计逐场景配对差、均值/中位数/区间；不可把同一场景的 ROI/体素当独立样本。单一 seed 的置信区间不能替代训练随机性证据。

### 0B. 恢复与验收指标

- 在有真值模拟中主报 **MSE/PSNR 对 clean imaging truth**、弱血管召回@固定 FPR、可解析管径段的宽度偏差、中心线/分支连续性与假阳性；几何标签先明确 PSF/分辨率映射，不能让无噪成像真值在检测指标上系统性输给有噪图而不解释。若结构指标尚不可信，先做 clean/identity/blur/断血管/造血管的正负控制，**结构指标未修好前不能判断“结构安全”**。
- 固定 ROI 与共同显示窗口（线性 PD 及 dB 展示均一致）；在**匹配背景波动抑制程度**时比较结构，或在**匹配血管保留**时比较背景噪声，绘制 Gaussian/Wiener/Network 的 **Pareto 曲线**；不可简单以未匹配的 n2n 排序判断真实血管优劣。
- 在真实 SA64/HSA64，仅报告 SVD 输入、Gaussian、Wiener、B1（固定 checkpoint）的对照 MIP/切片/弱血管局部图，并标注 **no clean GT**；`core` 是亮区平均强度比，**不是**血管中心线或分支指标，`dark` 是暗区能量比，**不是**严格的“假血管计数”。
- 只用训练/校准数据确定阈值和 ROI，确认集不得重新调图像强度、掩膜、σ 或比较方向。

**0 Gate**：
- 若模型在所有有效的背景抑制—结构保真区域均被 Gaussian/Wiener 支配，记 `BASELINE_DOMINATED`：停止“仅改网络架构”分支；可以开展下面**最后一次 B 表示 pilot**，但不得继续加大 CRN、改一堆损失、增加新算法模块。
- 若结构指标尚未校准，标 `METRIC_UNRESOLVED`，不允许用 N2N 一项宣告胜利。优先把正负控制修好，再决定是否继续。
- 如果模型存在 Pareto 非支配区，精确定义该区间及血管/噪声代价；不能以一个局部图替代全场评价。

**交付**：`reports/v3_round4/baseline_pareto.md` + machine-readable JSON/表格/统一显示四联图；复算脚本与阈值冻结记录。

## 2. Round4-B（最多 3 个短训练）：对数域是否真的改变学习结果？

前提提醒：R0-v2 的方差回归检验的是 **`log(PD)`**（新的 SA64/HSA64 斜率约 0.033/0.104，跨箱比 1.049/1.115），**不能自动等同当前网络用的 `log1p(PD/s)`**；同方差不等于零条件均值或噪声独立，线性域异方差也不自动使 N2N 数学上失效。

### B0. 先做真实数据表征统计（无训练）

- 对 SA64/HSA64 用相同 calibration 信号协变量分箱，比较 `linear PD` / `log1p(PD/s)` / `log(PD+ε)` 条件方差和条件残差均值、空间相关性；s、ε 必须在 calibration 冻结，不能各域按其输出重新自适应展示。
- 用独立乘性噪声正控制检验 log 统计，且明确奇偶块在共同 SVD 投影下依然可能相关；非共享参考残差相关 0.017/0.036 仅是某个差分代理结果，不等于所有目标噪声都满足 N2N 条件。
- 日志区分**已测事实、代理假设、神经网络训练有效性**三个层级。

### B1. 单变量短训练 pilot

- 选取 **同一个最可靠的 residual+zero-init dense 正控制**，相同 CRN、loss、patch、seed、数据划分、steps/epoch。三臂只改变输入/目标**表示域**：线性 PD、`log1p`、`log(PD+ε)`，并保留数据域一致的 clean truth。
- **请注意**：不同表示的输入数值范围和 target MSE 尺度差异很大。必须采用**预先冻结**的共享物理 PD 参考尺度或透明校准归一，不允许“某个表示更容易训练”被学习率/剪裁偏置冒充；最终统一**反变换到同一线性 PD 真值域**评价，再单列转换域指标。对 `log(PD+ε)` 确保零、低亮背景及 inverse transform 数值稳定。
- pilot 每臂先 10–15 epoch，`≤3` 次训练；只有在校准集能同时改善恢复误差和结构、且不是明显坏于 Gaussian，才允许给 **最有希望的一臂**补足至最多 40 epoch；优先**续训同一个** checkpoint 而不是换种子无限重启。
- 最终比较 held-out e902–e905 +（如已提前固定）新增场景，所有方法相同评测 mask/真值。报告 bootstrap 或按独立场景配对统计与失败场景，不能只报最佳图。
- 这里**不要求 B 的某个表示必过旧的 G-B1=0.80**；旧 Gate 原样保留。本轮新 Gate 是：相对于固定 Gaussian/Wiener，能否在**结构保真约束下**表现出可信的 Pareto 非支配，并且不依赖后验选择测试集。

**B Gate**：
- 如果三种表示均不能达到可信的结构安全增益，记录 `B_NO_GAIN`。**立刻停止 CRN 结构/损失继续调参**；D 只完成文献方法核对，不开展昂贵全量复现；I1 不进入大规模训练。
- 如果仅 `log(PD+ε)` 显示收益，先验证是否来自改善条件方差/偏置，再进入 C 的最小采样消融；**不能**自动将 log 收益归因于 I1。
- 如果全部训练都学不到比平滑好的算子，接受“这套 CRN/训练任务在当前场景上缺乏优势”，不要通过改变 ROI、移除难例、重复跑 seeds 寻找正结果。

**交付**：`reports/v3_round4/log_domain_pilot.md` + 三域方差/条件均值曲线、训练配置、checkpoint SHA、held-out image+structure 数值。

## 3. Round4-D（可与 B 并行，零或极少 GPU）：真正的超声 SVD-SN2N 对照

- 对照对象**必须是** Zhang et al., 2026, *SVD-SN2N: Self-Inspired Noise2Noise Learning for Denoising Log-Compressed SVD-Filtered Ultrasound Imaging*, bioRxiv DOI `10.64898/2026.09.10.750668`，不是先前误找的 2024 荧光 SN2N。
- 阅读可核验原文/补充与若存在的官方代码，列清**输入、对数操作、对角子视图构造、Fourier 插值、双向损失、网络结构、训练与推理处理、实际假设**，每项标“原文确定/推断/未知”，附真实出处。
- **暂不强制复现完整论文**。优先做一个不训练或小规模数值检验：使用当前真实数据/模拟正控制，检查这种子视图构造是否比现有 Tetris 更利于保持信号几何、降低残余依赖（注意视图强度相关≠纯噪声相关）。

## 4. Round4-C（只在 B/0 Gate 看到正向结构安全信号时启动）：给 I1 最后一次直接验证机会

**先做无训练的采样几何筛选，避免为无效先验训练**：
- 用 calibration 得到真实或可信模拟 PSF / 残余相关 `N(k)`，以及同真值血管的信号可预测性 `S(k)`；实际 stride、物理间距、角色映射、采样覆盖率必须完全一致。采样器必须真的读入先验并更改 sampler 角色，不只是保存 `--sampler-config`。
- 预先检查 8 个 tetra/Tetris 候选里正确先验所选模式/角色是否与 fixed-4 或最强固定方向**实质不同**；打乱先验必须改变实际采样。若所有选择都退化成同一固定模式、或相关估计无法复现，直接标 `I1_NO_DISTINCT_INTERVENTION` 并终止，不消耗训练预算。

**若筛选有明确区分，运行极简 C-pilot**：
- 最多 3 臂×1 seed：最强固定角色 vs 正确物理先验 vs 错误/打乱先验；同训练体素、覆盖率、网络、表示域、损失、预算、输入坐标和输出评测坐标。
- C 使用 B 中已有的**被证实能保留结构的**网络/表示做训练，并保证其中没有其它组件同时发生变化。不把 C 结果与 D 的其它网络直接比较后归因给物理先验。
- 主报干净成像真值恢复误差 + 弱血管/断枝/伪血管；相关性下降、N2N 和训练 loss 只是机制副指标。若正确先验只赢 random、不赢最强 fixed，或正确与打乱先验基本相同，或“降噪”靠丢细血管，判 `I1_NO_INDEPENDENT_GAIN`。
- 一次 seed 的 C-pilot **只能叫探索信号，不能叫可发表的验证**；真正独立收益需多 seed/场景（必须用户另行批准新增预算）。如果连 pilot 都无可解释的改善，**立即终止 I1**。

**C Gate**：
- `PROMISING_ONLY`：正确先验在事前锁定的 ≥4 held-out 场景上显示一致方向、具有血管结构安全的改进，且明显不同于打乱先验；提交证据，**先请用户决定是否值得扩大预算**。
- `STOP_I1`：没有上述信号 / 打乱与正确无法区分 / 退化为 fixed / 以结构损失换指标，停止该路线；若基础去噪链自身失败且 C 未运行，状态要写 `I1_UNTESTED_BECAUSE_BASELINE_FAILED`，**不是“I1 被严格证伪”**。

**交付**：`reports/v3_round4/i1_last_pilot.md`（未解锁时说明触发条件不满足、`NOT_RUN`），所有实际采样坐标和正确/错误先验指纹可查。

## 5. 明确的停止条件与结项决策（优先于任何“下一阶段计划”）
